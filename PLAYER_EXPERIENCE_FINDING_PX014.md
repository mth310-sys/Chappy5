# Player Experience Finding PX-014 — resonance exit cost is strategically important but visually hidden

Updated: 2026-08-26 16:10 JST
Target: latest `main` ECHO DRIFT / HUMAN_CANDIDATE_01
Director: Player Experience Analysis Director

- Status: WATCH_STRATEGIC_TRANSPARENCY / MATCH_CONTINUATION_IS_NEXT_PX_BOUNDARY
- Severity(1-5): 4
- Confidence: HIGH for observed UI/rule mismatch; HIGH for measured mismatch direction; MEDIUM-HIGH for predicted experience impact
- Verification Type: OBSERVED + SIMULATED
- Evidence: Current UI exposes immediate consequences unusually clearly: every route shows exact `選択後脅威`, rolled EN cost and base gain, anomaly bonus, calm recovery, and an immediate resonance continuation bonus when a resonance route matches the active signal. Yet when an active resonance chain exists and the player chooses calm or deep, `chooseRoute()` ignores the displayed A/B/C signal and performs an undisclosed 50% random check that can erase the entire chain. Previous GS-016 evidence established that active-chain future value materially changes route decisions. GS-017 now narrows the source: across the same 104,736 production-sampled active-chain states, the 69,669 states where the offered resonance signal mismatched the active chain already favored switching to calm/deep on average under production rules (`switch - resonance` +0.58843 bank over 2 decisions, +0.26474 over 3). Disabling automatic mismatch renewal did not improve the aggregate switching gap; it slightly worsened mean `switch - resonance` by -0.04953 / -0.06054. Therefore the earlier PX concern should no longer imply that generic resonance restart/insurance is the main hidden pressure. The remaining strategic pressure is more likely concentrated in signal-match states where resonance can immediately continue the existing chain, especially as chainLen grows. These measurements are SIMULATED, never HUMAN_VERIFIED.
- Player Experience Impact: The current interface still has a trust/legibility problem because calm/deep chain survival is not predictable before tapping. However, GS-017 also reveals an important positive possibility: mismatch states already contain many genuinely viable calm/deep departures over 2–3 decisions. That means the desired experience may not require making every resonance exit safer. The higher-value PX target is to preserve readable moments where the player can intentionally leave resonance when the offered resonance signal does not continue the chain, while ensuring that match-state continuation pressure does not become an opaque `resonance is always correct` lesson. If Systems finds the problem concentrated at chainLen 2+, the UX should communicate the value of a mature matching chain without hiding a large future-state tax on alternatives. If chainLen 1 match states already dominate, even the first visible continuation reward may be too decision-dominant and should be reviewed before adding more explanation or effects.
- Recommended Action: Keep `HUMAN_CANDIDATE_01` frozen and do not alter production from Player Experience alone. Do not revive `same signal preserves / different signal breaks`; the direct A/B probe already showed that candidate slightly worsened switching. Follow GS-017's next diagnostic: split active-chain signal-match states by chainLen (1 versus 2+) under the common-RNG 2–3 decision branch comparison. PX should then map the measured boundary to the smallest readable interaction: if mature matching chains are the problem, make their continuation/sacrifice value legible without changing unrelated mismatch exits; if first-match continuation is already dominant, review the first continuation reward and its presentation together. Avoid solving the hidden 50% rule only with prose.

## Human verification boundary

No new general fun question is added. `HUMAN_CANDIDATE_01` remains unchanged. During existing human play, if a chain disappears after calm/deep, only note whether the player understood what caused the loss and whether it felt like a deliberate sacrifice or an unexplained punishment.

If a later controlled candidate changes chain-exit/continuation semantics, human verification should stay narrow:

1. Before tapping calm/deep with an active chain, can the player predict the meaningful chain consequence without tutorial prompting?
2. In a signal-mismatch state, does calm/deep feel like a credible alternative rather than a hidden mistake; in a signal-match state, does resonance continuation feel valuable for a reason the player can see?

PX-014 does not claim that any replacement rule is more fun. It records that GS-017 has refuted mismatch renewal as the primary stickiness source while production still contains an undisclosed calm/deep chain-loss transition.
