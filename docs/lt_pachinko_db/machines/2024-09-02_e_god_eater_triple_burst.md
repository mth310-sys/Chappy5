machineName: eゴッドイーター TRIPLE BURST
manufacturer: Sansei R&D（サンセイアールアンドディ）
releaseDate: 2024-09-02
modelType: スマパチ / ライトミドル / LT搭載
gameType: 一種二種混合 / セットストック型RUSH
jackpotProbability: 通常時大当り 1/199.5。液晶図柄揃い期待値 1/539.2、あらがみちゃーじ 1/314.2（液晶図柄揃い値はあらがみちゃーじからの10Rを含む合算期待値で条件装置作動確率とは異なる）
initialPayout: 液晶図柄揃い10R 約1500個払出。あらがみちゃーじ2R 約300個払出。別系統2R約154個払出あり
rushEntryRate: 液晶図柄揃い後JUDGMENT成功 約64%（特図2保留を1個以上獲得できる確率）
rushContinuationRate: 神速神撃BURST 1セット時 約80.1%
ltName: 神バトルRUSH RAGE BURST（LT状態）。保留数により神速神撃BURST / 神速神撃W BURST / PREMIUM神BURST
ltEntryRoute: 液晶図柄揃い10R「バトルBONUS」後JUDGMENT → 成功でLT状態。獲得した特図2保留1～3個がRUSHセット数となる
ltEntryRate: JUDGMENT成功 約64%（液晶図柄揃いを分母とする）。通常大当り1/199.5全体基準の総到達率は直接値なしのため算出しない
ltContinuationRate: 1セット 約80.1% / 2セット 約90.1% / 3セット 約93.4%。2/3セットは突入以降の平均大当り数からのTOTAL継続率
ltPayoutStructure: 継続時10R 約1500個払出。継続失敗時は2Rを介して1セット消費し、残ストックがあれば再度約80%ループへ、ストック0で終了
totalPayoutDistribution: 通常は液晶図柄揃い10R約1500個→JUDGMENT、あらがみちゃーじ2R約300個→通常（10R昇格例外あり）。RUSH継続時10R約1500個、非継続時2R
 timeShortening: 公開資料上、一般的なST回数ではなく特図2保留ストック1～3個を用いたセット制。回数を推測しない
cTimeOrSpecialSystems: LT新解釈対応。特図2保留ストック最大3個によるRUSHセット制
ceilingOrSupport: 遊タイムなし
gameFlow: 通常時 → 液晶図柄揃い10R約1500個 → JUDGMENT（成功約64%） → 成功時の特図2保留数1/2/3個に応じてLT RUSH 1/2/3セット → 各セット約80%ループ、TOTAL約80.1/90.1/93.4% → ストック消費後終了。あらがみちゃーじ2Rは原則通常へ
notes: 大当り1/199.5、液晶図柄揃い1/539.2、あらがみちゃーじ1/314.2は定義が異なるため混同しない。RUSHそのものがLT状態と解析資料が明記。出玉は払出値、実獲得値は一撃資料で10R約1400/2R約280等だがDB基準値には混ぜない。
