ltEntryRate: 約25%（BETチャージからの突入込み）。
ltContinuationRate: 約80%。7500個大当り獲得時の1G連を含む公表TOTAL値。
ltPayoutStructure: LT中大当りは基礎1500個。40%で50/50ジャッジメント、60%は1500個でLT継続。50/50ジャッジメント成功率50%で絶対王政BONUSへ。絶対王政BONUSは7500個+ツラヌキチャレンジ 41.0% / 6000個 41.0% / 4500個 15.4% / 3000個 2.5% / 1500個 0.1%（払出）。7500個は1500個×5回。
totalPayoutDistribution: 総払出300 / 1500 / 3000 / 4500 / 6000 / 7500個。複数大当り合計値を単一大当り出玉と混同しない。
timeShortening: LTは148回。普図抽選のため残保留なし。148回スルーで通常時へ。資料上0回 / 148回 / 実質次回までの電サポ状態あり。
cTimeOrSpecialSystems: 7500個到達時にツラヌキチャレンジ。成功時は絶対王政BONUSを再度獲得する1G連系統。BETチャージからLT突入経路あり。
ceilingOrSupport: 遊タイム非搭載。
gameFlow: 通常時 → 初当り → 約75%は300個で通常へ / 約25%は絶対王政RUSH BURST(LT)へ（1500個ルートでは上乗せジャッジメント） → LT148回 → 大当り → 60%は1500個でLT継続 / 40%は50/50ジャッジメント → 成功で絶対王政BONUS1500～7500個 → 7500個到達時はツラヌキチャレンジ → 成功なら絶対王政BONUS再獲得、失敗でも1500個 → LTへ。148回スルーで通常へ。
notes: 同日導入の「eカケグルイ 7500ver.」とは別型式・別スペック。継続約80%は7500個獲得時の1G連込み。通常初当り基準のLT突入率は公表約25%を採用し、BETチャージ込みという定義を保持。
