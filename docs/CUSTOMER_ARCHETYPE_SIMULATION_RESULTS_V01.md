# N-01 個体客AI シミュレーション結果 v0.1

更新日: 2026-08-31

目的: `CUSTOMER_ARCHETYPES_V01.md` の常連型R / ライト型Lを、N-01メリハリ10台島 `1,1,1,1,1,2,4,5,6,6` へ流す簡易モンテカルロ試験を行い、hidden settingを客へ渡さなくても客層差と誤認が発生するか確認する。

注意: これは客AI評価関数の構造検証。10,000営業日。各日の台別gamesPlayed、BB/RB、差枚は確率生成したが、まだ完全な持ちメダル/現金投資/途中移動時系列ではない。正式バランス値ではない。

## 1. 条件

- 島: N-01 10台
- 配分: S1×5 / S2×1 / S4×1 / S5×1 / S6×2
- 日数: 10,000
- 各台gamesPlayed: 日ごとに300〜8,500G範囲で確率生成
- BB/RB: N-01暫定設定別確率
- 差枚: N-01暫定理論出玉率を中心に日次ノイズ
- 客比率: R 35 / L 65
- 客はsettingを参照しない

RはRB・合算・サンプルを重視し、Lは差枚・直近好調を強く見る。

## 2. 実設定別の選択傾向

100人分の選択を日ごとに公開データだけから確率配分した結果。

|---:|---:|---:|---:|---:|---:|
|1|5|32.23%|35.59%|2.26|4.63|
|2|1|7.05%|7.89%|2.47|5.13|
|4|1|10.57%|10.57%|3.70|6.87|

実設定は解析時の答え合わせにだけ使用している。

### 読み方

島の半分が設定1なので、設定1への総着席は当然多い。しかし1台あたりで見るとRはS1 2.26に対しS6 6.42で、公開データから高設定へ約2.8倍強く寄った。

Lも高設定へある程度寄るが、Rより設定1誤爆へ引っ張られやすい。

## 3. 誤認試験

各営業日の10台内で、公開評価スコア上位25%を「強く見えた台」、下位25%を「弱く見えた台」と仮定。

### 設定1が強く見えた割合
- R: 約9.44%
- L: 約14.58%

ライト型は差枚・直近当たりの影響が強いため、設定1の上振れを強台と誤認する率がRより約1.5倍高い。

### 設定6が弱く見えた割合
- R: 約4.43%
- L: 約5.49%

設定6でも不発日は存在し、客AIは真値を知らないため下位評価へ落ちる。

重要: S6が常に発見されるモデルにはなっていない。

## 4. 確認できたこと

### A. hidden settingを読ませなくても設定差が行動へ現れる
BB/RB/差枚/サンプルという公開結果だけで、長期集計では高設定ほど選ばれやすくなった。

これは理想的な構造。

`hidden setting → 確率的な実結果 → 公開データ → 客の評価 → 選択`

であり、

`hidden setting → 客が直接選択`

ではない。

### B. 客層によって誤認率が違う
LはS1上振れに釣られやすい。RはRB/サンプルを重く見るため比較的回避する。

同じ島を見て違う客が違う台を選ぶ条件が成立した。

### C. 設定6にも空席リスクを残せる
S6が弱く見える日が存在するため、完全な設定透視AIではない。

実時系列化すると:
- 朝S6不発
- Rが見切る
- Lも差枚を見て避ける
- 数時間空席
- 後客が再試行
- RBが付き再評価

という営業中の物語へ接続できる。

## 5. 現モデルの不足

今回の「選択」は日次公開結果を用いた簡易選好試験であり、次は13時間時系列へ個体を統合する必要がある。

まだ不足:
- 実際のarrivalTime
- leaveDeadline
- cashBudget消費
- medalsHeld
- 250〜500Gごとの再評価
- 空席待ち
- 台移動
- 同じ客の複数日再来店
- 客が観測できた範囲だけ記憶する処理

したがって「S6平均空席時間」などはこの段階では確定値を出さない。

## 6. 次の実装モデル

次は `N01_INTRADAY_13H_SIMULATION_V01.md` と本個体モデルを統合する。

1. 10:00に朝客を生成
2. 個体ごとに公開データを見て着席
3. 250〜500GごとにBB/RB/差枚更新
4. R/Lそれぞれ再評価
5. 続行 / 移動 / 退店
6. 時間帯ごとに新規客流入
7. 23:00閉店
8. 客ごとに観測経験を記憶
9. 翌日の来店判断へ反映

ここで初めて計測する:
- S6の平均/最大空席時間
- S1誤認追跡時間
- R/L別平均滞在時間
- R/L別移動回数
- R/L別投資/持ちメダル推移
- 客個体の再来店率

## 7. 現時点の判断

2客層だけでも認識差は成立する見込みがある。

したがって客タイプを追加する前に、まずR/Lを13時間個体時系列へ統合して挙動を固める。

本結果は正式バランス採用ではなく、構造検証結果として保存する。
