# Customer Character Base Attributes v0.1

Status: ADOPTED

パチスロホール経営ゲームの客キャラクター生成に使う基礎属性。

## 年代
- 20代
- 30代
- 40代
- 50代
- 60代
- 70代

## 生活・職業
- 大学生
- アルバイト
- 会社員
- 自営業
- フリーランス
- 主婦
- 無職
- 年金暮らし
- パチプロ

「ニート」は独立した職業ではなく、無職に属する生活タイプとして扱う。

## 経済力
職業とは分離する。
- 低
- やや低
- 標準
- 余裕あり
- 富裕

旧案の「お金持ち」は職業から外し、経済力=富裕などで表現する。

## 勤務・時間タイプ
職業そのものとは分離し、来店可能時間の計算に使う。
- 日勤
- 夜勤
- シフト
- 不規則
- 時間自由

職業に応じて選択可能な勤務タイプや発生確率を変える。

## パチプロ
パチプロは独立した生活・職業タイプとして採用する。
一般客より、来店前評価・前日履歴・設定傾向・台選択・見切り・長時間遊技などを強く評価する客AIを持たせる。
ただしパチプロが来ること自体を単純なプラス/マイナスにはしない。
高設定を長時間遊技することでホール利益を圧迫する一方、粘る姿が他客の店・島評価へ影響する可能性を持たせる。

## 設計原則
年代・職業だけで行動を固定しない。
各属性は来店確率、来店可能時間、予算、遊技時間などの確率分布へ影響させ、個人差を残す。

客キャラクターは概ね以下の階層で生成する。

年代
+ 生活・職業
+ 経済力
+ 勤務・時間タイプ
+ パチスロ遊技スタイル（別途設計）
+ 個人差

これにより同じ「30代・会社員」でも異なる来店時間、予算、好み、判断、滞在時間を持つ個体を生成する。

## シミュレーション接続
客キャラクターの個体行動を積み上げてホール数値を生成する。

来店 → 店/台評価 → 移動 → 着席 → 遊技 → OUT発生 → 結果観測 → 継続/離席 → 記憶更新 → 次回来店判断

OUTを先に台へ割り当てるのではなく、客の実遊技時間から結果として生成する方向を維持する。
