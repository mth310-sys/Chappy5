# N-01 10台島 設定配分検証（暫定）

更新日: 2026-08-31

目的: 単台モデルから10台島へ拡張し、設定配分が島売上・期待粗利・島出玉率・客からの見え方へどう影響するかを検証する。

注意: N-01および設定別コイン単価・出玉率は現段階では計算検証用の暫定値。ゲーム採用確定値ではない。

島集計は設定値の単純平均ではなく、総アウト・総セーフから島出玉率を計算する。

## 2. 比較する10台設定配分

### A: 低設定中心
`1,1,1,1,1,1,2,2,3,4`

意図: 短期粗利を取りやすい配分。高設定らしい台は少ない。

### B: 中間中心
`1,2,2,3,3,3,3,4,4,5`

意図: 低設定一辺倒を避け、島全体を遊びやすくする配分。

### C: メリハリ
`1,1,1,1,1,2,4,5,6,6`

意図: 低設定を多く残しつつ、強い当たり台を明確に作る配分。

### D: 全台系（高設定）
`4,4,4,4,5,5,5,5,6,6`

意図: イベント的な強い営業を検証する極端な比較ケース。

## 4. この単純比較だけでは不十分な理由

全台に同じアウトを与えると、高設定は単に粗利を削るだけに見える。しかしゲームの本体では設定配分が客行動を変え、その結果として各台アウトが変化する。

したがって実装モデルでは以下を分離する。

1. 店長が各台設定を決める。
2. 客は設定そのものを知らない。
3. 客はBB/RB、合算、差枚、周辺台、過去営業、店の評判から設定期待を推測する。
4. 推測によって着席・継続・台移動・退店が変わる。
5. その集積として各台アウトが決まる。
6. 実アウトと実績出玉から島売上・島粗利・島出玉率が確定する。
7. 営業結果が翌日以降の店への期待・再来店へ影響する。

つまり「設定6だから15,000アウト」と直接決めるのではなく、客の観測と判断を経由させる。

## 5. 配分ごとのゲーム上の性格（仮説）

### A 低設定中心
- 当日の期待粗利は最も取りやすい。
- 高設定挙動が見えにくく、島への期待を失いやすい。
- 短期回収向けだが連用すると翌日以降のアウト低下リスクを持たせる。

### B 中間中心
- 直接粗利は小さい。
- 大きな見せ台は少ないが、遊技継続しやすい島を作れる可能性。
- 常連維持型の営業候補。

### C メリハリ
- 当日の期待粗利を削る。
- 設定5/6の明確な好挙動が出れば、客が「この島には上がある」と認識しやすい。
- 強い台を探す客・設定推測を好む客との相性を検証する価値が高い。

### D 全台系
- 単日の期待粗利負担が非常に大きい。
- 発見された場合の島・店舗評価上昇を大きくするイベント的運用候補。
- 常用する配分ではなく、将来の集客効果との費用対効果を検証するための比較ケース。

## 6. 重要な発見

同じ島総アウトなら、N-01暫定モデルでは低設定中心が短期粗利で圧倒的に有利になる。したがって経営ゲームとして成立させるには、高設定投入の価値を「その日の直接利益」ではなく、客行動と将来稼働へ接続する必要がある。

特に重要なのは「平均設定」だけでは営業の意味を表現できないこと。

例えば中間中心とメリハリは島平均だけを見ると近くても、客から見える高設定挙動の台数・強さが異なる。ゲーム内部では設定平均ではなく各台の観測結果を客AIへ入力する。

## 7. 次の検証

次段階では、設定配分からアウトを固定で与える方式をやめ、10台島に簡易客AIを接続する。

最低限の客行動:
- 入店時に空き台から候補を選ぶ
- BB/RB・合算・差枚を観測する
- 一定ゲーム数で続行/ヤメを判断する
- 良さそうな空き台へ移動する
- 島全体が弱いと判断すれば退店する
- 前日までの店の設定期待を翌日の来店判断へ持ち越す

これによりA〜Dの設定配分について、設定投入 → 見え方 → 客行動 → アウト → 売上/粗利 → 翌日期待、というホール経営ゲームの中心ループを検証する。
