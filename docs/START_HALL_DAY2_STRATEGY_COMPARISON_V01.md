# 開始ホール Day 2 営業戦略比較 v0.1

目的: Day 1で形成された客期待を入力として、Day 2にプレイヤーが何もしない場合(A)と、注目されたA+RTへ追加設定投資する場合(B)を比較する。

**位置づけ:** 構造検証用の仮計算。正式バランスではない。数値は今後machineInstance/実機DBの個別抽選へ置換する。

## 3. 戦略B: A+RTへ設定を追加投入

Day 1で注目されたA+RTへDay 2も設定を使い、期待を継続させるケース。

この検証ではA+RTの当日設定投資により、前日期待+当日粘り/再着席が強まるとして、A+RT OUTをDay 1比 +15%の172,960まで伸ばす仮ケースとする。他カテゴリは戦略Aと同値。

|カテゴリ|Day 2 B OUT|
|---|---:|
|25Φ|152,880|
|30Φ|134,400|
|A+RT|172,960|
|ART/CZ|63,840|
|旧台|58,212|
|**合計**|**582,292**|

売上概算は約1,098,064円。

A+RTは高設定投資と短期ブレを含め実績出玉率100.50%の仮ケースとする。

A+RT粗利:

```text
172,960 × (1 - 1.005) × 20 ≒ -17,296円
```

他カテゴリが戦略Aと同じ結果なら全店粗利は約150,183円。

### 戦略Aとの差

- 総OUT: +10,528
- 売上: 約+20,529円
- 当日粗利: 約-56,280円
- A+RT客期待: 維持/上昇しやすい
- Day 3以降のA+RT朝一着席・粘り: Aより強くなる可能性

つまりBは約5.6万円の当日粗利を「翌日以降の信用獲得」に使った形になる。

## 4. この比較でゲームに必要になる指標

単純な当日粗利だけでは戦略Bが常に損に見えるため、ゲーム内部では設定投資の将来価値を追跡する。

```text
customerAcquisitionCostLike
= strategyAProfit - strategyBProfit
```

今回の仮ケースでは約56,280円。

この投資によってDay 3以降に増える累積粗利が56,280円を超えれば、Bは中期的に回収できたことになる。

ただしプレイヤーにはこの未来利益を確定値として表示しない。客が期待通りに反応する保証はないためである。

## 5. Day 3への記憶差

仮にA+RTのDay 1観測信号を +0.18 とする。

### 戦略A
Day 2で回収寄り結果になれば観測信号を -0.08程度と仮置き。

```text
A+RT memory: 上昇後に反落
```

### 戦略B
Day 2も客側に強く見えれば観測信号を +0.20程度と仮置き。

```text
A+RT memory: 2日連続で上昇
```

同じ「昨日出ていた店」でも、1日だけか2日続いたかでDay 3の信用を変える。

## 6. プレイヤーに生まれる選択

Day 2運営画面でプレイヤーは、

- 昨日出たA+RTから今日は回収する
- もう1日設定を使って客に印象付ける
- A+RTではなく弱かった30Φへ設定を移す
- 全体粗利を優先する

などを選べる。

ゲーム側は「正解の設定配分」を用意しない。資金、曜日、競合、新台、客記憶によって最適解が変わる構造を目標とする。

## 7. 現時点の検証結果

この仮モデルでは、

- A = 当日粗利を取りやすい
- B = 当日粗利を約5.6万円犠牲にして、A+RTの稼働と将来信用を買う

という明確なトレードオフが成立した。

これはホール経営ゲームの中心判断として有効。

ただし、Bの+15% OUTや実績100.50%は正式値ではない。次段階ではS059〜S090の32台について実際の設定変更を行い、実機DB由来の設定別出玉率・客AIの着席/継続から結果を積み上げ、このトップダウン仮定を外す。
