# Customer Fixed Model Policy v0.1

Status: ADOPTED

## 方針
客キャラクターは完全ランダム生成にしない。

固定モデルの単位を次とする。

**年代 × 生活・職業 × 打ち方 = 固定客モデル**

まず年代×生活・職業について、現実的に成立する42基礎モデルを用意する。その42モデルそれぞれについて、無理のない「打ち方」だけを接続し、成立可能な全組み合わせを固定モデルとしてマスター化する。

最大組み合わせを機械的に採用せず、年齢・生活・職業との整合性を審査して不自然なモデルを除外する。

## 42基礎モデル

### 20代（8）
大学生 / アルバイト / 会社員 / 自営業 / フリーランス / 主婦 / 無職 / パチプロ

### 30代（7）
アルバイト / 会社員 / 自営業 / フリーランス / 主婦 / 無職 / パチプロ

### 40代（7）
アルバイト / 会社員 / 自営業 / フリーランス / 主婦 / 無職 / パチプロ

### 50代（7）
アルバイト / 会社員 / 自営業 / フリーランス / 主婦 / 無職 / パチプロ

### 60代（8）
アルバイト / 会社員 / 自営業 / フリーランス / 主婦 / 無職 / 年金暮らし / パチプロ

### 70代（5）
アルバイト / 自営業 / 主婦 / 無職 / 年金暮らし

合計42基礎モデル。

「存在可能」と「出現しやすい」は分離し、固定モデルごとに出現ウェイトを持たせる。

## 打ち方（固定モデル側）
打ち方は機種嗜好と分離する。候補カテゴリは以下を基礎として精査する。

- 設定狙い
- ハイエナ
- 新台追随
- 機種固定
- 勝負型
- エンジョイ
- 無計画

42基礎モデルの全てに7種を機械的に付与するのではなく、現実的に成立する組み合わせのみ固定モデルとして登録する。

特にパチプロは設定狙い・ハイエナなど期待値行動との親和性を高くし、一般客と同じウェイトにはしない。

## 機種嗜好（個体側）
以下は「打ち方」ではないため固定モデルの主キーから分離する。

- ノーマル系
- A+RT系
- ART/AT系
- 沖スロ系
- 新台への嗜好
- 特定機種への嗜好
- 特になし

年代や固定モデルに応じて抽選可能範囲とウェイトを制限するが、年代だけで嗜好を決め打ちしない。

## 個体生成
固定客モデルを選んだ後、そのモデルで成立する範囲内から個人差を生成する。

主な個体差:
- 経済力
- 勤務・時間タイプ
- 機種嗜好
- 粘り強さ
- 見切りの早さ
- 熱くなりやすさ
- 慎重さ
- 台移動傾向
- 店への忠誠度
- 情報感度
- 設定判別力
- 技術力
- 勝敗への執着
- 店・島・機種・台への記憶

固定モデルごとに各属性のmin/max・分布・禁止条件を持たせ、無理な個性が生成されないよう制約する。

## 常連化
「常連」は初期職業や固定モデルではなく、実際の来店履歴から獲得する状態とする。

初来店 → 再来店客 → 準常連 → 常連 → 超常連

逆方向の離反も可能とする。

評価要素の候補:
- 過去一定期間の来店回数
- 来店間隔
- 店への信用
- 好きな機種の設置
- 台への満足
- 設定状況への評価
- 座りやすさ
- 店内環境
- 競合店との比較
- 個人の勝敗履歴

勝敗だけで常連化を決定しない。

## 地域客プール
毎日すべての客を使い捨て生成する方式にはしない。
地域に潜在客キャラクターのプールを保持し、曜日・時間・生活条件・店評価などからその日の来店者を選ぶ。

同じ個体が再来店し、記憶を蓄積することで常連化を成立させる。

## 次工程
42基礎モデル × 打ち方について成立可否を1件ずつ精査し、固定客モデル総覧を作成する。
総数は事前に決め打ちせず、現実性の審査後に確定する。
