# Candidate A — `SIGNAL//3`
**一文フック:** 3回のSTOPで、雑音の中から「当たりの信号」を捕まえる。

世界観は未知の信号を探す巨大受信施設。NORMAL SCAN → SIGNAL TRACE → LOCK WINDOW → TRANSMISSION → CONTACT → LOST SIGNAL / RE-SCAN。Signature体験は雑音が3STOPで純音／音楽へ解像すること。

### Game & Reel骨格
レバーONでそのGの帯域が開く。リール語彙は `PULSE / WAVE / NODE / LOCK / VOID`。1stで基準波、2ndで同位相・1コマ遅れ・鏡像・断線等の位相差、3rdで `SYNC / ECHO / DRIFT / NOISE` を確定する。通常は短いSCANを基準とし、ECHO、片側共鳴、SILENT等を混在。LOCK WINDOWではECHOを次Gへ保持。TRANSMISSIONでは3STOPで音楽レイヤーを確定し、CONTACTでは通常時の“ズレ”が完全同期へ意味反転する。設定差で出目法則を壊さない。

### Visual & Mechanism Director深化 — 「計器を読む台」ではなく「台全体が受信する機械」
**筐体シルエット:** 上部中央に円環型 `TUNING RING` を半埋込みし、その左右から細いアンテナ状フィンが斜め上へ伸びる。遠景では「円環＋左右フィン＋横長の走査光」で識別できる。円環を巨大液晶にはせず、物理フレームとして存在させる。

**素材・奥行き:** 外装は暗い梨地金属、透明スモーク樹脂、乳白導光材を分離。液晶は奥まった観測窓、リール窓はさらに手前の厚い透明層＋黒い遮光壁で独立した回転体として見せる。上部リング、液晶、リールを同一平面へ並べない。

**リール窓:** 各リールの上下端に細い固定 `PHASE MARK` を置き、図柄側の太い波形端部と重なる／1段ずれる／鏡像になることを一瞥可能にする。数値・針・波形グラフを読ませない。位相差は「線がつながる／一段ずれる／反転する」という造形で理解させる。これにより計器ゲーム化を回避する。

**液晶:** 主役ではなく“受信したものの正体”を見せる奥窓。通常は暗く情報量を抑え、リールが作った関係を後追いで可視化する。STOP前に答えを表示しない。

**LED:** 左右フレームの水平走査光はレバーONで一度だけ薄く走る。1st STOPで停止リール位置の短い局所光、2ndで2本間を結ぶ導光、3rdで成立関係に応じて光がリングへ到達／途中で残響／斜めへ逸れる。LEDを単純な全点滅にしない。透明エッジと金属面へ照り返しを持たせる。

**機構:** TUNING RINGは毎STOP動かさない。通常は静止し、`SYNC`級で数度だけ“遊びを詰める”ように回転→機械的停止、LOCK WINDOW確定で一段深く回る。CONTACTでは初めて一周ではなく複数段の短いロック回転を行い、希少性を守る。大可動より「普段動かない物が意味ある時だけ動く」を核にする。

**操作部:** STOPボタンは透明外周に細い三分割導光。1st/2nd/3rdの押下後、押したボタンの光が消えるのでなく“固定された基準”として低輝度保持される。レバーは短い金属軸＋黒いグリップで受信機の切替スイッチ感。操作卓は計器盤ではなく厚い機械パネル。

**代表同期:** `LEVER ON → 走査光1回 → リール始動 → STOP1で基準線固定 → STOP2で2本間の導光 → 150〜250ms程度の視覚的間 → STOP3 → 出目関係確定 → 光がTUNING RINGへ到達 → 必要時のみリング機械停止 → 液晶が後追いで受信像を解像 → Audio解放`。具体尺はStage 2以降。

**当たり／上位:** 当たりは“画面が派手になる”より、普段は雑然としていた光線が一本の連続線になり、筐体全体のノイズ光が消えてリング中心へ集束する。CONTACTではリール窓背面、左右導光、リングが同じ一点へ位相同期し、筐体が初めて完全な左右対称光になる。

**Visual判定:** 生存・上昇。PHASE MARKと太い線接続なら位相概念を文字説明なしで翻訳できる可能性が高い。最大リスクはSF計器の情報量を増やした瞬間に独自のリール体験がUI読解へ退化すること。

# Candidate B — `FORGE//HEART`
**一文フック:** 3回のSTOPを3回の鍛打に変え、台そのものを鍛えて当たりを打ち出す。

世界観は巨大自動鍛造炉。IDLE FORGE → HEAT RISE → ANVIL CHANCE → FORGE RUSH → CORE MELT → COOL DOWN。核は熱・質量・反動。

### Game & Reel骨格
全リール共通語彙 `ORE / HEAT / EDGE / SEAL / CRACK / CORE`。1stで加工起点、2ndで `TEMPER / OVERHEAT / COLD / FOLD`、3rdで `MASTER / USABLE / CRACK / REFORGE`。通常は静かなGを基準とし、REFORGEを次BET理由にする。ANVIL CHANCEは加工連鎖、報酬中も出目で品質を変える。

### Visual & Mechanism Director深化 — 「毎STOPハンマー」を捨て、圧力が蓄積する筐体へ
**筐体シルエット:** 下部が広く重い鋳造台形、リール窓左右に太い支柱、上部に水平の `PRESS RAM` を持つ。巨大ハンマーが常時振り下ろされる形ではなく、工業プレスのラムが上部に“待機している”姿を看板にする。遠景では低重心＋上部横梁で識別。

**素材・奥行き:** 黒皮鉄風の粗い金属、焼け色を持つ縁、炉内だけの橙色間接光。クローム多用を避ける。リール窓は厚い耐熱ガラス越しの炉内観測口として奥へ沈め、操作卓は鋳物の厚みを感じる前傾面。

**リール図柄可読性:** 図柄そのものを“金属片”として太い輪郭で作り、`FOLD` は左右図柄のエッジが折り重なる、`TEMPER` は熱帯と刃線が重なる、`CRACK` は3本にまたがる亀裂が断続するなど、語彙を文字ではなく輪郭関係へ寄せる。役物停止中でも加工状態を出目だけで読めることを必須条件にする。

**LED/光:** 炉の光は外周LED点滅ではなく、リール窓の奥と筐体の継ぎ目から漏れる間接光。REFORGEが残る時だけ次BETまで残熱が弱く残る。OVERHEATは全体赤化ではなく、金属縁の反射が局所的に強まる。

**機構:** PRESS RAMは通常STOPでは動かない。1st/2ndでは筐体内部の小さなラッチ／圧力インジケータが段階的に沈む程度。3rdでMASTER級が成立した時のみRAMが短距離・低速始動→加速→衝突直前に減速→重い停止を見せる。CORE MELTではRAMではなく炉扉状の左右シャッターが少し開き、内部光が露出する別機構で状態差を作る。

**操作部:** STOPボタンは金属リングを持つが、毎回物理衝撃を模倣する振動表現には頼らない。押下に合わせボタン奥の小さな残光が“焼印”のように残り、3rd後に消える。レバーは太めで短い工具グリップ感。

**代表同期:** 通常Gは `STOP→金属図柄の停止感→局所残光` に留める。REFORGEでは3rd後も炉内残熱が消えず次BETで再点火。MASTER時だけ `STOP3 → 亀裂線が一本へ閉じる → 一瞬の暗さ → PRESS RAM作動 → 衝突点で炉内光が前面へ漏れる → 告知／BGM`。強さは頻度の低さから生む。

**当たり／上位:** FORGE RUSHは“火力を上げるだけ”にせず、筐体の冷たい外殻と熱い内部のコントラストが広がる。CORE MELTでは左右炉扉が開き、通常見えない深層発光部が露出。上位は色違いではなく筐体の内部構造が一段見える状態。

**Visual判定:** 条件付き生存。REALITY/PRESENCEは3案中最も物質的。ただし機構を減らした結果、リールの加工輪郭だけで面白さが成立しなければ失格。大型RAMの希少運用は長時間疲労を大きく改善する。

# Candidate C — `VAULT://3`
**一文フック:** 3つのリールを3つのタンブラーとして止め、毎ゲーム金庫を開ける。

世界観は巨大自律金庫。LOCKED FLOOR → CLICK TRACE → AUTH WINDOW → OPEN VAULT → INNER VAULT → RELOCK。台そのものが金庫に見えることがREALITYの核。

### Game & Reel骨格
主図柄 `PIN / KEY / BOLT / SEAL / BAR` にNOTCH方向を持たせる。1stで基準角、2ndで `DOUBLE CLICK / OFFSET / CROSS / DEAD`、3rdで `OPEN LINE / FALSE GATE / ONE PIN LEFT / RELOCK`。AUTH WINDOWでは一部タンブラー半固定。報酬中も切欠き法則を残し、INNERで解錠法則を反転候補とする。

### Visual & Mechanism Director深化 — NOTCHを「細い切欠き」から「太いゲート」に再定義
**重要修正:** iPhone一瞥性を守るため、NOTCHを細密な角度目盛りとして描かない。各主図柄の外周に大きな `GATE CUT`（太い欠け／白抜き）を3〜4方向程度の明確な向きで持たせる企画表現へ変更する。具体配列・方向数はStage 2で検証。3本のGATE CUTが横一本の“解錠路”を作るかが遠目でも読める。

**筐体シルエット:** 上部〜左右を一体化した厚い円形 `LOCK RING`、左右側面に水平 `BOLT`。中央リール窓は金庫扉の覗き窓のように深く、液晶は上部リング中心ではなくリール上の細い状態窓に抑える。遠景で円環と左右ボルトだけで識別できる。

**素材・奥行き:** ガンメタルの厚板、ブラッシュ金属、黒いゴム／樹脂の目地、リール前面の厚い防護ガラス。リングはリールより前、液晶は奥、BOLTは側面から実際に扉へ差し込まれているような前後関係を持つ。

**リール窓:** 3本それぞれを完全分離せず、一本の横長深窓の中に三つの回転体があり、その手前に固定された一本の `SHEAR LINE` を通す。STOPするたびGATE CUTとSHEAR LINEの関係が固定され、2nd時点で3rdに欲しい位置を直感できる。細かい数字や角度表示は禁止。

**LED:** 通常はSHEAR LINE自体が低輝度。1stで左／押したリール周辺だけ短く点灯、2ndで二つのGATE CUTが近ければその間だけ線がつながる。3rdでOPEN LINEなら一本の光路が左右BOLTまで貫通する。ニアミスは全点滅ではなく、光路が最後の数cmだけ届かず消えることで“あと一つ”を見せる。

**機構:** LOCK RINGとBOLTを役割分担。通常の意味あるCLICKではリングが数度だけ回り機械的に止まる。OPEN級でのみ左右BOLTが一段引く。AUTH WINDOWでは半固定されたリールに対応する小型ラッチ光が物理的に“保持中”を示す。OPEN VAULTでBOLTが完全後退、INNER VAULTではリングが前方へわずかにせり出す／内輪が逆回転する二重構造候補。毎Gボルトを動かさない。

**操作部:** STOPボタンを金庫ダイヤルに見立てすぎず通常の3ボタン操作性を守る。各ボタン外周にGATE CUTと同じ太い欠けモチーフを一箇所持たせ、押下後はそのリールが“固定済み”であることを低輝度表示。レバーは扉ハンドルではなく短いロック解除レバーとして操作テンポを守る。

**代表同期:** `LEVER ON → 内部ラッチの短い予備反応 → リール始動 → STOP1でGATE固定 → STOP2でSHEAR LINEが二点間だけ接続 → STOP3 → OPEN LINEなら光路が左右へ走る → 100〜300ms程度の静止感 → LOCK RINGが数度回転して止まる → BOLTが一段後退 → 液晶は最後に状態名を表示 → Audio解放`。具体尺はStage 2。

**当たり／上位:** OPEN VAULTでは派手な画面割れではなく、左右BOLTの後退で中央部の“圧迫感”が解け、奥の液晶／内部光が初めて広く見える。INNER VAULTでは同じリングの内輪が逆方向へ動き、通常の「横一直線」と違う法則を物理的に示す。色替えだけにしない。

**Visual判定:** 生存・首位維持。GATE CUT化により最大リスクだった細密パズル化を大きく軽減できる。弱点は金庫モチーフが直感的すぎて、演出が単調な“開く／開かない”へ収束すること。FALSE GATE、ONE PIN LEFT、AUTH保持を光路とラッチの差で豊かにする必要がある。

# Visual & Mechanism Director 第1巡 統合所見
3案とも、1st/2nd/3rdの情報差を液晶説明なしに物理翻訳できる見込みは残った。

- `SIGNAL//3`: **最も統合美がある。** PHASE MARK・線接続・導光・TUNING RINGを同じ“同期”言語へ揃えられる。計器情報を増やさないことが絶対条件。
- `VAULT://3`: **最も一瞥性が高い。** NOTCHをGATE CUTへ太く再定義し、SHEAR LINEで3STOPの途中経過を読ませる。看板筐体の説明力は依然最強。
- `FORGE//HEART`: **物質感は最強。** 大型機構を希少化したことで疲労は改善。ただし役物を休ませた通常Gでも出目の加工関係が面白いかは未解決。

Visual & Mechanism専門評価は `VAULT ≈ SIGNAL → FORGE`。VAULTは完成筐体を一瞬で理解できる強さ、SIGNALはゲーム・光・機構を同一言語にできる伸びしろで僅差。採択はしない。

## Sound & Experience Directorへの引継ぎ
共通課題は、今回作った“物理的な途中経過”を音が説明しすぎず補強できるか。

- SIGNAL: STOP1/2/3で音程を上げるだけにせず、位相・残響・無音を使って `SYNC/ECHO/DRIFT` を耳でも区別できるか。リング動作音とSignature Soundを競合させない。
- FORGE: 毎STOPを大打撃音にしない。通常の金属停止、残熱、REFORGE、希少なRAM衝突でダイナミクスを作り、3時間疲労を抑える。
- VAULT: クリック音の段階上昇だけにしない。GATE CUT接続、ニアミス、ラッチ保持、BOLT後退を異なる材質／空間感で聞き分けられるか。
