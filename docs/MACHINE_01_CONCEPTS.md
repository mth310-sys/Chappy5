# Candidate A — `SIGNAL//3`

**一文フック:** 3回のSTOPで、雑音の中から「当たりの信号」を捕まえる。

世界観は未知の信号を探す巨大受信施設。NORMAL SCAN → SIGNAL TRACE → LOCK WINDOW → TRANSMISSION → CONTACT → LOST SIGNAL / RE-SCAN。筐体は受信塔、TUNING RING、水平走査LED、計器盤液晶。Signature体験は雑音が3STOPで純音／音楽へ解像すること。

### Game & Reel Director深化 — 3STOPをゲームにする骨格

**レバーON:** そのGの「帯域」が開く。内部結果の単なる告知開始ではなく、どの出目系統を読むGかがリール始動時の物理情報（リール始動音／バックライトの帯域差）で薄く示唆される。ただし当否は答えない。

**リール語彙:** `PULSE`=点、`WAVE`=線、`NODE`=接点、`LOCK`=固定、`VOID`=無信号。図柄単体より、隣接した図柄の位相関係を読む。

**1st STOP:** 基準波を固定する。止まった図柄の上下関係が「点系／線系／接点系」のどの同期を狙うGかを初めて具体化する。ここで残り2リールの“良いズレ方”が変わる。

**2nd STOP:** 2本の位相差が出る。完全一致だけが強いのではなく、同位相、1コマ遅れ、鏡像、断線の4系統を視認できる。これにより3rdに必要な形がプレイヤー自身に分かる。

**3rd STOP:** 三本の関係が `SYNC / ECHO / DRIFT / NOISE` のいずれかへ確定。SYNCは強い契機、ECHOは次Gへ弱い継続情報、DRIFTは別系統契機、NOISEは通常終了。3rdは液晶結果表示ではなく出目そのものが判定語になる。

**通常100Gの反復回避:** 毎Gロック演出をしない。大半は短いSCANで終わり、(a)一発で完結する同期、(b)ECHOが数G残る連続観測、(c)左右だけが反応する片側共鳴、(d)通常法則から外れるSILENT系、の読み味を混在させる。前兆SIGNAL TRACEは“派手になる”より同じ小さな異常が再現することで期待を形成。

**レア役・主要契機:** レア役は派手な専用絵ではなく、通常法則では出にくい位相関係。初心者は形の揃い方で強弱を理解し、熟練者はズレ方から系統を読む。

**LOCK WINDOW:** 数G間だけECHOを保持でき、各Gの3rd結果が次Gの基準波を変える。単なるポイントCZにしない。

**TRANSMISSION / CONTACT:** 報酬中もSTOP責務を残す。TRANSMISSIONでは3STOPで音楽レイヤーを確定、CONTACTでは通常時に“ズレ”だった出目が完全同期へ反転して見える。

**出玉思想:** 中〜中高。小さな同期発見→LOCK→主要報酬→上位の段階上昇。上位だけを価値にしない。数値はStage 2。

**設定差思想:** 出目法則・演出信頼度は設定で壊さず、初当たり／再捕捉／状態移行の長期頻度へ分散する方向。

**30分:** まず一致を見る→ECHOの意味に気づく→3rdを待つ理由が生まれる。**3時間:** ズレ方を読む熟練が成立する可能性が最も高い。最大リスクは“位相”が視覚的に難解になること。

**Game & Reel判定:** 生存。今回最も伸びた候補。3STOP情報階層を自然な図柄だけで読ませられるなら、液晶ゲーム化を回避できる。

# Candidate B — `FORGE//HEART`

**一文フック:** 3回のSTOPを3回の鍛打に変え、台そのものを鍛えて当たりを打ち出す。

世界観は巨大自動鍛造炉。IDLE FORGE → HEAT RISE → ANVIL CHANCE → FORGE RUSH → CORE MELT → COOL DOWN。筐体は下重心の鋳造機、上部FORGE HAMMER、炉の間接光。核は熱・質量・反動。

### Game & Reel Director深化 — “三打一組”から脱却できるか

**リール語彙:** `ORE`=素材、`HEAT`=温度、`EDGE`=形、`SEAL`=完成、`CRACK`=欠陥、`CORE`=高価値。3リールを左=素材／中=熱／右=刻印へ固定する案は却下。押し順自由度と出目読みを殺すため、全リールに共通語彙を持たせる。

**1st STOP:** 今Gの“素材性”が決まる。ORE起点だけでなくHEAT起点、EDGE起点があり、最初の停止で完成条件が分岐する。

**2nd STOP:** 1stとの組合せから `TEMPER`（良い焼き）、`OVERHEAT`（強いが危険）、`COLD`（弱い）、`FOLD`（次停止で化ける）の中間状態が出目として読める。

**3rd STOP:** `MASTER / USABLE / CRACK / REFORGE` に確定。失敗を全部CRACKにせず、REFORGEは次Gへ素材性を持ち越すため再BET理由になる。

**通常100Gの反復回避:** 毎STOPで火花・打撃を鳴らす案を明確に否定。通常はリールの金属的出目だけを読む静かなGを基準とし、機構反応は“意味のある鍛造”だけ。HEAT RISEは強演出の連打ではなく、REFORGE連鎖やFOLD目が重なることで炉が目覚める。

**ANVIL CHANCE:** 数Gの耐久ポイント制ではなく、各GでCRACKを避けつつFOLD→TEMPER→MASTERの加工連鎖を作る。STOP順で期待が変わるが、押し順ナビの作業化は避ける。

**FORGE RUSH / CORE MELT:** 報酬中は“完成品を作る”より、出目で加工品質を上げて報酬波を変える。CORE MELTでは通常のCRACKが高熱ゆえの強契機へ意味反転する案を残す。

**出玉思想:** 中高の瞬発力。ただし初回FORGE RUSH自体で完成感を出す。**設定差:** 素材供給／初当たり／再着火の安定へ寄せ、同じ出目の意味を設定で変えない。

**30分:** 押す=叩くは最速で理解できる。**3時間:** 物理衝撃を抑えれば出目の加工連鎖に熟練余地。ただしテーマが“結果の言い換え”へ落ちやすい。

**Game & Reel判定:** 条件付き生存。STOP身体性は強いが、リールゲーム単体の独自性は3案中まだ最弱。Visual/Mechanismが強すぎるほど飾りリール化する逆説的リスクあり。

# Candidate C — `VAULT://3`

**一文フック:** 3つのリールを3つのタンブラーとして止め、毎ゲーム金庫を開ける。

世界観は巨大自律金庫。LOCKED FLOOR → CLICK TRACE → AUTH WINDOW → OPEN VAULT → INNER VAULT → RELOCK。巨大LOCK RING、左右BOLT、4段階解除音。台そのものが金庫に見えることがREALITYの核。

### Game & Reel Director深化 — “揃えば開く”以上の深さ

**リール語彙:** 各図柄に細い`NOTCH`（切欠き）方向を持たせる。主図柄は `PIN / KEY / BOLT / SEAL / BAR`。価値は図柄一致だけでなく3本の切欠き角度関係に宿る。

**1st STOP:** 1本目のタンブラー角を固定し、そのGの基準位置を作る。どの図柄でも起点になり得るため“鍵図柄待ち”にしない。

**2nd STOP:** 2本の切欠き関係が `DOUBLE CLICK`（同角）、`OFFSET-1`（1段差）、`CROSS`（逆角）、`DEAD` に見える。ここで3rdに必要な角度を直感的に予測できる。

**3rd STOP:** `OPEN LINE`（3切欠き貫通）、`FALSE GATE`（見た目は近いが別系統）、`ONE PIN LEFT`、`RELOCK` を確定。OPEN LINEだけを当たりにせず、FALSE GATEは前兆／別契機、ONE PIN LEFTは次Gへの期待情報として使う。

**通常100Gの反復回避:** “毎G金庫を開ける”という初期表現を修正。毎Gはタンブラー探索であり、本当にボルトが動くのは意味のある出目だけ。外層は切欠きの高さ、中層は角度、内層は左右対称など、状態で読む法則が変わる。ただし通常から頻繁に法則変更して初心者を迷わせない。

**CLICK TRACE:** 数GにわたりONE PIN LEFTやFALSE GATEの再現率が上がり、プレイヤーが“内部ピンが寄っている”と出目から察する。液晶の煽りを主にしない。

**AUTH WINDOW:** 既定回数のポイント集めではなく、3STOPで得た切欠き関係を次Gへ一部保持できる“半固定タンブラー”状態。1本固定→残り2本、2本固定→最後1本という局面が生まれ、STOPの意味が通常と変化する。

**OPEN VAULT / INNER VAULT:** 報酬中も切欠き法則を残し、INNERでは“揃える”から“異なる3角度で一周を完成させる”へ意味反転する候補。上位が色違いにならない。

**出玉思想:** 中〜中高。初当たりOPEN VAULTにも満足を持たせる。**設定差:** 初当たり／AUTH到達／RELOCKからの引戻しへ分散し、ニアミス出目の信頼性は設定で汚さない。

**30分:** 最も早く3rd STOP待ちを理解できる。**3時間:** 切欠き関係と層ごとの法則が十分なら読みが育つ。ただし視覚情報が細かいとiPhoneで破綻する。

**Game & Reel判定:** 生存。入口の強さは維持。ただし“切欠き角度”がリール図柄として一瞥できることが絶対条件。細密パズルになれば即失格。

# Game & Reel Director 第1巡 統合所見

3候補すべてについて、`1st=情報発生 → 2nd=期待分岐 → 3rd=意味確定` の骨格は企画上成立可能と判断した。ただし強さは同じではない。

- `SIGNAL//3`: **最もリールゲームとして化けた。** 同じ図柄の“ズレ”を価値にでき、通常時の違和感・前兆・報酬を同一言語で繋げられる。
- `VAULT://3`: **最も初見に強い。** ただしNOTCHを細かくしすぎると、直感性という最大長所を自ら失う。
- `FORGE//HEART`: **操作身体性は最強、リール固有性はまだ弱い。** 次のVisual & Mechanismは派手なハンマー追加ではなく、通常時に機構を休ませても台として成立するかを優先評価すべき。

数値確率・具体的リール配列・停止制御はStage 2以降であり、現段階では確定しない。Human Gateはまだ待機へ移さない。
