# パチスロホール経営ゲーム — 企画決定事項

更新日: 2026-08-31

この文書は、ユーザーとChatGPTの企画会議で**採用が確定した事項**を記録する。
未確定案と決定事項を混同しないこと。
今後Chappy5で実装を開始する際は、GitHubの最新mainと本書を確認する。

## 1. ゲームの基本コンセプト

- ジャンル: パチスロホール経営ゲーム
- 開始コンセプト: **経営がギリギリの地元の小さな「マイホール」を建て直していく**
- ゼロから会社設立・土地購入・融資・許認可を細かく行う重い開業シミュレーションにはしない
- 既に営業可能な小規模ホールを引き継ぎ、日々の営業と経営判断から始める
- 開始時点では営業継続は可能だが、資金・人員・設備等に大きな余裕がある状態にはしない
- 序盤の目的は「開業」ではなく、既存店の赤字・低稼働・老朽化等の問題と向き合い、経営を立て直すこと

### 初期スタッフ【採用確定】

ゲーム開始時のホールは、10:00〜23:00の営業を早番・遅番で現実的に回せる最低限の人員を持つ。

- 初期在籍人数: **6人**
- 店長: **1人**
- 社員: **1人**
- パート: **4人**
- 早番・遅番の2交代を基本とする
- 1日8時間・週40時間など現実の労働ルールを基準に、休日を確保できる人数として6人スタートとする

ゲーム開始直後から違法・非現実的な長時間勤務を強いる設計にはしない。
一方で、初期6人は「余裕のある人員」ではなく、小規模店を維持する最低限に近い体制として扱う。
スタッフの具体的な勤務時間、休憩、休日は今後詰める。

### 人件費【採用確定】

スタッフは単なる演出ではなく、ホール経営上のコストとして扱う。

- 給与・賃金を経営支出に含める
- 人員を増やせば営業体制に余裕が生まれる一方、人件費が増加する
- 人員を抑えれば人件費は下がるが、必要なシフトを成立させる制約が強くなる
- 店舗規模の拡大に伴い、必要人員と人件費も増加する設計を基本とする
- 違法な勤務を安価な攻略法として成立させない

給与水準、時給、社会保険等をどこまでゲーム内費用として分解するかは今後決定する。

## 2. 基本ゲームループ【採用確定】

ゲームは大きく2フェーズで構成する。

### 運営フェーズ

営業していない状態で、プレイヤーが経営判断を行うフェーズ。
ゲーム内営業時計は進行させない。

想定する主な判断:
- 前営業日のデータ確認
- 設定の検討・変更
- 台配置・移動・撤去
- 新台購入
- 中古台購入・売却
- 入替計画
- 人員・人件費の管理
- その他のホール運営判断

### 営業フェーズ【観察型として採用確定】

実際にホールを営業し、客・台・売上・出玉・稼働などが動くフェーズ。

- 基本営業時間は現実のホール感覚に寄せる
- 現時点の基準: 10:00 OPEN → 23:00 CLOSE
- 13時間をリアルタイムではなく圧縮して進行させる
- **1営業日の基準テンポは約3〜5分程度を目標とする**
- 営業フェーズは原則として「観察」がプレイヤーの中心行動
- 営業中に無理にミニゲームや店長作業を追加しない
- プレイヤーは、運営フェーズで仕込んだ経営判断の結果を営業中の客・稼働・出玉・売上などから観察する
- 時間帯によって客の来店・退店・行動が変化する設計を目指す
- 営業速度変更を持たせる方向とし、通常日は速く、新台入替初日など注目したい日はじっくり観察できるようにする

営業フェーズの核は「操作量」ではなく、
**自分の経営判断がホール内の人と台の動きとして目に見えて返ってくること**とする。

### 一日の循環

運営フェーズ
→ 開店
→ 営業フェーズ（10:00〜23:00 / 約3〜5分を基準）
→ 閉店
→ 営業結果確認
→ 運営フェーズ
→ 翌営業日

運営フェーズで行った判断の結果が、次の営業フェーズで目に見えて返ってくることをゲームの中心にする。

## 3. 新台・中古台【採用方向】

ホール経営の主要システムとして、新台と中古台を別の選択肢として扱う。

### 新台
- 導入費が高い
- 発売・導入時の集客効果を持たせる
- 導入台数をプレイヤーが判断する
- 導入後にヒットするか失敗するかが経営に影響する

### 中古台
- 中古市場から購入できる
- 機種の人気・需要などによって中古相場が変動する仕組みを検討する
- 安く仕入れて稼働させる、小規模ホールらしい経営判断を可能にする
- 所有台を中古市場へ売却する仕組みも候補とする

## 4. 遊技機入替の現実性【採用方向】

「購入ボタンを押した瞬間に台が営業フロアへ出現する」方式にはしない。

現実の遊技機入替にある、申請・設置・確認・承認という時間差を、ゲームテンポを壊さない範囲で再現する。

ゲーム上の基本イメージ:

台を選定・購入
→ 入替手続き/申請
→ 導入予定日まで通常営業
→ 閉店後に旧台撤去・新台設置
→ 必要な確認・検査
→ 承認後に営業投入

現実の行政手続きを完全再現することが目的ではなく、
「次の入替日を逆算して仕入れ・資金・撤去台・配置を考える」経営判断を生み出すことを目的とする。

### 調査メモ
沖縄県警の公開資料では、一定条件の遊技機増設・交替等について、申請から承認までの処理期間の目安として12日という記載が確認された。
これは実地検査そのものに12日かかるという意味ではなく、行政処理全体の目安として扱う。
ゲーム内の日数はテンポを考慮して別途決定する。

## 5. 設計上の重要方針

- リアルさは重視するが、面倒な行政作業そのものをプレイヤーに大量にやらせない
- 「リアルだから入れる」のではなく、経営判断として面白くなる現実要素を採用する
- 営業フェーズではホールを眺めているだけでも状況変化が分かり、面白いことを目指す
- 営業中の操作不足を理由に、不要な作業やミニゲームを足さない
- 小規模店から成長することで、最初は一台単位、将来は島・フロア単位へと経営視点が変化する設計を目指す
- 中核アイデア・採否はユーザーが決定する
- Chappy5は企画が固まってから制作・実装チームとして使用する

## 6. 参考作品・研究対象【記録】

以下は模倣対象ではなく、パチスロホール経営ゲームを設計する際の研究対象として記録する。
各作品から有用な仕組みと問題点を分析し、採用可否は別途ユーザーが決定する。

### PMSG（パチンコマネジメントシミュレーションゲーム）
**主に研究するもの: ホール経営ロジック**
- 新台戦略
- 中古機相場と機械経費効率
- 設置機種の集客力・時間経過による変化
- 売上・利益・資産
- 人材教育
- 資金調達
- 競合店との顧客獲得競争
- 小型店が大型店へ対抗する経営戦略
- PDCA / OODA型の経営サイクル

### Arcade Tycoon
**主に研究するもの: 店舗を眺める経営ゲームとしての表現**
- ピクセル系の店舗表現
- 客が店内を移動して設備を利用する可視化
- 店舗レイアウト
- スタッフ・財務・設備を店内表示と両立させる方法
- 「経営数字を扱いながら店内を眺めるだけでも楽しい」構造

### Megaquarium
**主に研究するもの: 多数の客・スタッフ・設備の同時シミュレーション**
- 客・スタッフの行動
- 施設運営と観察の両立
- 客満足と店舗状態の可視化
- 規模拡大時の管理方法

### Let's Build a Zoo
**主に研究するもの: ピクセルアート型の大規模経営ゲーム**
- 多数の施設・客・スタッフをピクセル表現で動かす方法
- 店舗成長の視覚的フィードバック
- 大規模化しても状況を把握できるUI
- 反面教師として、規模拡大時の管理作業・反復作業が過剰にならない設計

### SimCasino
**主に研究するもの: 遊技設備単位の経営管理**
- 遊技設備ごとの収益特性
- オッズ等の調整と店舗全体の利益の関係
- スタッフ・シフト・警備等の経営要素
- カジノ運営を個別設備と店舗全体の双方から扱う構造

### Casino Management Simulator
**主に研究するもの: 小規模店再建と客の観察**
- 小さく苦しい店舗からの成長
- スロット等の設備配置
- スタッフ・財務
- 客の遊技行動・導線・行列の観察
- 題材が近いだけでは面白さを保証しない点も含めて研究する

### Casino Resort Tower
**主に研究するもの: 客AIと行動履歴**
- 客が待つ・楽しむ・苛立つ・回復する等の状態変化
- 店内での経験が次の行動へ影響する仕組み
- パチスロ向けには「本命機種が満席→第二候補→退店/競合流出」「勝敗や着席経験→再来店意向」等への応用を検討する

### 過去のパチンコホール経営ゲーム
**主に研究するもの: ジャンル固有の先例と反面教師**
- SimPARLOR / SimPARLOR97
- パチンコホール～新装大開店～
- キングオブパーラー系
- 設定・釘・新台入替・設備投資・広告・スタッフ・店舗拡大等、過去にどこまでゲーム化されたかを調査する
- 経営表だけに寄せすぎず、ホール内部そのものを見て楽しめることを重視する

### 現時点の研究方針
- **PMSGから「経営の頭脳」**を研究する
- **Arcade Tycoon / Megaquarium等から「店内を眺める楽しさ」**を研究する
- **Casino系から「客の行動AI」**を研究する
- **過去のパチンコ経営ゲームからジャンル固有の成功例・失敗例**を研究する
- 参考作品のシステムをそのままコピーせず、パチスロ固有の設定・差枚・機種人気・新台入替・中古市場・常連・時間帯稼働・競合店などへ変換して検討する

## 7. 現時点で未確定

以下はまだ確定事項として扱わない。

- 初期設置台数
- 初期資金・負債・月次収支の具体的数値
- 経営ギリギリの状態を構成する具体的要因と数値
- スタッフの具体的な勤務時間・休憩・休日
- 給与・時給など具体的な人件費
- 社会保険等を経営費としてどこまで細分化するか
- 3〜5分の範囲での最終的な標準営業速度
- 営業速度変更の具体的な倍率・UI
- 正確な営業時間（地域・ゲーム設定として固定/変更可能にするか）
- 設定1〜6の具体的な操作方式
- 客AIの詳細
- 新台価格・中古相場の具体的数値
- 入替申請から稼働開始までのゲーム内日数
- スタッフの採用・成長の詳細
- 店舗拡張、広告、競合店などの詳細
- 視点・画面構成

これらは今後、一項目ずつユーザーと決定して追記する。
