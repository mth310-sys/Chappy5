# N-01 客AI接続シミュレーション v0.1

更新日: 2026-08-31

目的: `N01_CUSTOMER_AI_V01.md` の考え方を10台島へ初めて数値接続し、設定配分 → 客からの見え方 → 稼働 → 売上/粗利 → 翌日期待、の因果ループが成立するかを確認する。

重要: これは客AIの最初のキャリブレーション用プロキシモデルであり、ゲーム採用確定値ではない。来店数、観測スコア、継続係数、評判更新係数等は暫定。

## 1. 比較設定配分

- A 低設定中心: `1,1,1,1,1,1,2,2,3,4`
- B 中間中心: `1,2,2,3,3,3,3,4,4,5`
- C メリハリ: `1,1,1,1,1,2,4,5,6,6`
- D 全台系: `4,4,4,4,5,5,5,5,6,6`

## 2. v0.1で接続した因果

1. 前日までの店舗期待が当日の来店需要へ影響。
2. 真の設定そのものは客に公開しない。
3. 各台には理論性能を中心とした大きな日次ノイズを与え、客が観測できる「好挙動/弱挙動」を生成。
4. 好挙動台が多いほど島内探索と遊技継続が伸びる。
5. 客は観測結果の良い台へ偏って着席・滞在する。
6. 各台の実アウトから売上と実績出玉率を生成。
7. 島全体の実績と目立つ好挙動台数から翌日の店舗期待を更新。

この段階では個々の客を完全なエージェントとして逐次歩かせる前の、集約型客AIプロキシである。

## 3. 長期安定状態の試算

## 4. 最初の結果

狙っていた因果は発生した。

- 強い設定配分ほど店舗期待が上がり、島アウトも増えた。
- 低設定中心は客期待をほぼ作れないが、短期粗利は唯一プラスになった。
- 全台系は最も客を呼ぶ一方、N-01暫定性能ではコストが大きすぎ、稼働増だけでは赤字を回収できなかった。
- メリハリも「客から強く見える」効果は出たが、この暫定係数では高設定2台の費用を十分回収できていない。

これは失敗ではなく重要なキャリブレーション結果。ゲームを成立させるために高設定の集客効果を恣意的に大きくするべきではない。実ホールに近い経営感覚を目指すなら、単一のN-01島だけで高設定費用を必ず当日回収できる設計にしない。

## 5. 経営ゲームとしての重要点

高設定投入のリターンは同じ島の当日粗利だけで評価しない。

将来モデルでは店舗期待が以下へ波及する必要がある。

- 翌日の総来店人数
- 他機種/他島への回遊
- 常連化
- 新台導入時の初動
- 店舗全体の滞在時間
- 「この店なら設定がある」という設定狙い客の来店

つまり設定6を1台入れる費用を、その設定6自身の売上だけで回収する必要はない。ホール全体への集客投資として評価する。

## 6. v0.1でまだやっていないこと

- 実際のBB/RB履歴を時系列生成して客が読む処理
- 個客ごとの知識差/資金/滞在可能時間
- 朝一の台選択
- 空き台待ち
- 台移動の競合
- 時間帯別来店波
- 低設定の誤爆を見て追う客
- 高設定不発を捨てる客
- 閉店時刻によるヤメ
- 他島/他機種への回遊
- 店舗全体の評判

## 7. 次段階

次は集約プロキシを一段細かくし、10:00〜23:00の13時間を時間帯別に処理する。

最低限:
- 朝・昼・夕方・夜で来店量を変える
- 台ごとにBB/RB/差枚を累積する
- 客はその時点までの公開データだけを見る
- 1時間ごとに続行/移動/退店を判定
- 高設定でも序盤不発なら空く
- 低設定でも序盤上振れなら追われる
- 閉店時に島売上/粗利と翌日期待を確定

この段階で初めて「営業中に店内を眺めていると、客の判断で島の状況が変わっていく」挙動へ近づく。
