# 開始ホール130台 再計算 v0.1

更新日: 2026-08-31

目的: ゲーム開始時代を5号機モデルとする採用決定を受け、開始ホール130台の経営計算を再開する。

## 0. 前提

- 最大設置可能台数: 216台
- 開始設置台数: 130台
- 空き容量: 86台
- 営業時間: 10:00〜23:00
- 開始時代: 現実の5号機時代をモデルにした架空時代
- 実機研究DB: `docs/real_machine_db/`
- 進捗正本: `docs/real_machine_db/LATEST_HANDOFF.md`
- 2026-08-31時点のLATEST_HANDOFF基準: 156機種、2007-09-10「恐怖新聞」まで

重要: 本書の数値は開始ホールの正式バランス値ではない。既存のN-01単日/13時間モデルを130台へ接続する最初の再計算チェックポイント。

## 1. 既存10台島モデルから130台へ単純拡張した基準

`N01_INTRADAY_13H_SIMULATION_RESULTS_V01.md` のA「低設定中心」10台島平均:

- 島アウト: 42,591
- 島売上: 77,466円
- 島期待粗利: +14,655円

130台は10台島換算で13島分なので、構造確認のため単純に13倍する。

### 130台換算

- 総アウト: **553,683枚/日**
- 総売上: **1,007,058円/日**
- 期待粗利: **190,515円/日**

### 1台平均

- アウト: **4,259枚/台日**
- 売上: **7,747円/台日**
- 粗利: **1,466円/台日**
- 暗黙の平均コイン単価: 約**1.82円**

## 2. 現代全国平均との距離

基礎データに保存している2025年DK-SIS 20円スロット全国1台1日平均:

- アウト 8,665枚
- 売上 24,805円
- 粗利 3,013円

今回の開始ホール暫定値はそれに対し、おおよそ:

- アウト: 約49%
- 売上: 約31%
- 粗利: 約49%

となる。

ただしゲーム開始時代は5号機モデルであり、2025年スマスロを含む全国平均をそのまま目標値にはしない。ここでは「開始店がかなり低稼働」というスケール感確認用に使う。

## 3. この値のゲーム上の意味

開始店を「営業は継続できているが近隣大型店に客を奪われ、かなり弱っている店」とするなら、1台平均4,000台前半アウトは開始状態候補としては使える。

130台をすべて同一性能・同一人気のN-01として扱うのはここまで。
次段階からは実機DBの5号機データを使い、機種タイプと人気差を入れる。

## 4. 次段階の130台構成

開始130台は以下の役割へ分けて検証する。

- 主力機種群: 複数台設置、店の顔になる
- 準主力機種群: 3〜5台程度の小規模構成
- 30Φ/沖スロ系: 地域性・固定客を持つ
- 技術介入/ノーマル系: 常連・設定推測客向け
- ボーナス+RT/ART系: 出玉体験・若い客層向け
- バラエティ/旧台: 1〜2台単位、低コストだが集客力に差

実在機名は研究基準として参照し、最終製品では架空メーカー・架空機種へ変換する。

## 5. 次の計算手順

1. 156機種DBから、開始時点で利用可能な5号機をタイプ分類する。
2. 130台の機種別台数を作る。
3. 各機種に設定配分を与える。
4. 客AIから時間帯別アウトを生成する。
5. 各機種スペックからセーフ・差枚・売上・粗利を生成する。
6. 店全体の総アウト/売上/粗利/出玉率を集計する。
7. 開始店として黒字すぎないか、赤字すぎないかを検証する。
8. 翌日のstoreTrust/機種期待/島期待へ接続する。

## 6. 現時点の判断

- 既存モデルを130台へ接続できることは確認。
- 開始ホールの暫定稼働水準として、総アウト約55万枚/日・1台約4,259枚は低稼働店らしい候補。
- ただし売上約100.7万円/日・粗利約19.1万円/日は、機種構成・交換条件・人件費・光熱費等を入れる前の遊技台粗利。
- 正式な開始収支は、実機DBを使った130台構成と固定費を接続した後に決める。
