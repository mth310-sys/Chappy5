## Purpose

Run 5 stays inside real-machine study. It does not design a Chappy5 cabinet, reproduce protected HANABI artwork, flash choreography, panel graphics, symbols, logo geometry, or proprietary lamp programming.

This pass narrows the question further:

**How can a reel-first cabinet change the meaning of the same physical surfaces over one game without replacing the player’s visual workspace?**

The focus is the visual sequence across START → STOP1 → STOP2 → STOP3 → post-stop flash / information resolution, and the contrast between normal, RT high-duty moments and low-duty moments.

## 1. Blackout is a progressive edit to the work surface

### Sourced fact

The number of reel blackouts is rule-bearing during normal play. The blackout count denies different role classes.

### Interpretation

The important visual property is not merely that "a lamp turns off." The machine modifies the already-observed reel workspace progressively across the stop sequence.

This makes the visual sequence behave like:

`READ → STOP → MODIFY CONTEXT → READ AGAIN → STOP → MODIFY CONTEXT → RESOLVE`

Reusable principle:

`A VISUAL STATE CHANGE CAN EDIT THE MEANING OF AN EXISTING WORK SURFACE INSTEAD OF REPLACING IT.`

This extends Run 3's `CHANGE THE CONDITION OF THE WORK SURFACE BEFORE COVERING THE WORK SURFACE.`

---

## 2. The same visual event can change informational weight by timing

### Direct observation / sourced behavior

A blackout after the first stop, a second blackout after the second stop, and a third blackout after the third stop occur at different points in the player's inference process. The physical reel window remains the same, but the amount of unresolved information changes.

### Interpretation

The visual value of a cue depends on **when** it arrives relative to the stop sequence.

Reusable principle:

`VISUAL IMPORTANCE = SIGNAL CONTENT × TIMING WITHIN THE PLAYER'S CURRENT QUESTION.`

A small change at the exact point where the player is deciding whether a role remains possible can matter more than a larger animation that arrives after the question is already resolved.

This is a study principle, not a claim about manufacturer internal intent.

---

## 3. Post-stop flash works because STOP3 creates a natural visual punctuation point

### Sourced fact

Normal play includes flash patterns after the stop sequence, and flash correspondence contradictions can indicate bonus possibility.

### Interpretation

STOP3 is already a natural punctuation point: the physical result is now fully visible. A post-stop flash can therefore act as a second-stage interpretation of a completed physical result rather than competing with symbol discrimination during motion.

Reusable principle:

`AFTER THE PRIMARY PHYSICAL RESULT IS COMPLETE, PRESENTATION MAY INTERPRET IT MORE AGGRESSIVELY.`

Boundary:

This does not license copying any HANABI flash pattern, color sequence, timing table or proprietary meaning.

---

## 4. Conditional secondary display creates an escalation ladder without replacing the reels

### Sourced fact

`たまやチャレンジ` is conditional rather than continuously dominant and follows specific reel/flash conditions.

### Interpretation

The visual hierarchy can temporarily escalate in steps:

`physical stopped form → blackout / flash relation → optional mini-display interpretation`

The secondary display therefore behaves as an **interpretation escalator**, not the permanent main playfield.

Reusable principle:

`SECONDARY DISPLAY VALUE IS HIGHEST WHEN IT EXPLAINS OR REFRAMES A PRIMARY RESULT, NOT WHEN IT COMPETES WITH IT EVERY GAME.`

This strengthens Run 3's `SECONDARY DISPLAY SHOULD ADD INTERPRETATION WITHOUT DEMOTING THE PRIMARY PHYSICAL GAME.`

---

## 5. Quiet intervals are not dead visual time; they preserve comparator memory

### Direct observation / interpretation

In ordinary powered cabinet photography, the machine has many fixed and illuminated identity surfaces, yet the reel-reading region does not continuously display a high-volume overlay. During repeated play, the player repeatedly sees a similar baseline arrangement before a blackout/flash/temporary instruction changes it.

Reusable principle:

`A STABLE BASELINE IS A VISUAL MEMORY REFERENCE.`

and:

`DEVIATION IS EASIER TO READ WHEN THE PLAYER DOES NOT HAVE TO RELEARN THE BASELINE EVERY GAME.`

This connects visual restraint to detection accuracy rather than to aesthetic minimalism.

---

## 6. RT changes duty more than geometry

### Sourced fact

During 花火チャレンジ, reverse-order navigation / aiming is required on specific warning conditions; JAC IN uses normal-order navigation; flash calls for normal small-role handling; otherwise free stopping is acceptable. 花火GAME similarly raises duty on flash/warning conditions and otherwise permits low-duty play.

### Interpretation

The cabinet does not need to redraw the player's whole visual map every time duty rises. It can mark a temporary instruction on top of stable physical controls/reels and then release it.

Reusable principle:

`TEMPORARY HIGH-DUTY VISUALS SHOULD MODIFY TASK PRIORITY, NOT DESTROY SPATIAL FAMILIARITY.`

This is the visual counterpart of Game & Reel's current finding that responsibility should open and close with information need.

---

## 7. Hall identity and play identity operate on different temporal scales

### Direct observation

The red upper mass, bilateral dark cavities, side bright/translucent-looking strips, chrome/reflective edges and large lower identity panel are static or slow-changing coarse visual features. The reel field, blackout/flash relations and temporary information change game by game.

### Interpretation

Two different clocks are present:

- **hall identity clock**: mostly stable, seconds-to-minutes, read from distance;
- **play identity clock**: game-by-game, read from the seated precision zone.

Reusable principle:

`A CABINET DOES NOT NEED TO RE-ANNOUNCE ITS IDENTITY EVERY GAME.`

and:

`STATIC FORM CAN CARRY BRAND/PRESENCE WHILE DYNAMIC CHANGE IS RESERVED FOR PLAY MEANING.`

This explains how a comparatively restrained cabinet can remain identifiable in a noisy hall without giant moving mechanisms.

---

## 8. Material contrast is useful only where it clarifies layer boundaries

### Direct observation

Actual-unit photography shows visually different surface families: saturated red outer mass, dark grille/void regions, reflective metallic-looking edge pieces, clear/translucent side regions, dark glossy operation deck and bright reel field.

### Interpretation only

Exact material chemistry is unknown. The useful observation is that different reflectance/transmission appearances help separate structural layers:

`outer shell / negative void / reflective edge / precision aperture / touch deck / identity panel`

Reusable principle:

`MATERIAL CONTRAST SHOULD HELP THE PLAYER PARSE DEPTH AND FUNCTION BEFORE IT SERVES DECORATION.`

No material family is declared reusable from the real machine.

## 9. New visual QA checks derived from Run 5

These are study checks for future reality evaluation, not a design of an original machine.

### Sequential Surface Edit Test

Across STOP1 / STOP2 / STOP3, ask whether each visual change preserves knowledge of:
- what just stopped;
- what remains unresolved;
- where the player should look next.

Fail if presentation forces the player to reacquire the basic reel layout after every stop.

### Baseline Comparator Test

Show multiple ordinary games followed by a small deviation. Ask whether the deviation is detectable because the baseline was stable, not because the deviation was made excessively large.

### Post-Resolution Escalation Test

After STOP3, confirm that any stronger secondary visual layer adds interpretation after the physical result rather than obscuring the physical result itself.

### Temporary Duty Exit Test

During an RT instruction, verify that the visual instruction has a clear end state and that the player's normal reel/control map remains immediately usable afterward.
