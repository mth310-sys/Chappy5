## Central answer

Game & Reel Run 8 established:

`CONTROL IDENTITY != ACTION-LAW IDENTITY.`

Visual/Mechanism answer:

`KEEP MOTOR OWNERSHIP STABLE; MOVE RULE OWNERSHIP THROUGH EVIDENCE.`

The same STOP hardware can remain spatially stable while temporary action-law ownership opens, goes dormant, retires, or returns to the base grammar. The transition should be legible through the state of the evidence surface rather than by adding a global reset/all-clear overlay.

## Main delta

- `DORMANT` and `RETIRED` should not collapse into the same generic calm;
- dormancy preserves an open question, while retirement preserves the fact that closed it;
- stopped-result persistence is the cheapest local proof that one action law has retired;
- next-grammar binding should restore visual hierarchy/ownership rather than reset the whole screen;
- brief touch occlusion may hide pixels but should not reassign ownership of evidence or controls;
- one stopped object may be closed for action while remaining open for inference;
- repeated technical duties should retire per attempt and reopen as new episodes rather than create continuous vigilance.

Research abstraction:

`NEXT-GRAMMAR BINDING = TERMINAL OLD EVIDENCE + RESTORED BASE HIERARCHY + LEGIBLE NEXT OWNER`

This is not an implementation formula.
