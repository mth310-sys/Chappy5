## New learning

### 1. A reused STOP button does not imply a reused action law

The physical control can remain identical while its valid interpretation changes from one moment to the next.

Research distinction:

`CONTROL IDENTITY != ACTION-LAW IDENTITY`

A STOP button is only the motor interface. The player's current action law is determined by the currently live question, the evidence already exposed and the state in which the next stop occurs.

Therefore a local duty can retire even though the player will press the same physical STOP again milliseconds later.

### 2. Observable retirement requires loss of future consequence under the old law

An obsolete action law is genuinely retired when additional compliance with that law can no longer change or protect the question it governed.

Game/Reel research test:

`OLD LAW RETIRED WHEN: ITS TARGET QUESTION IS RESOLVED + NO REMAINING VALID STOP CAN IMPROVE THAT QUESTION BY FOLLOWING THE OLD LAW.`

Examples at the abstraction level:

- candidate eliminated -> role-specific aiming no longer protects that role;
- role fulfilled -> the collection duty for that role is over;
- state exits -> the state-specific procedure no longer governs the next game;
- bounded skill judgment returned -> that attempt's execution duty is over even if another attempt can open on the next game.

This is stronger than merely showing a result. It requires **future irrelevance of the old law to that local question**.

### 3. Retirement evidence and inference evidence may be the same stop result

One stopped-reel result can do two logically different things at once:

`CLOSE DUTY A + PRESERVE / OPEN QUESTION B`

For example, a visible relation can eliminate a small-role handling duty while making a bonus-related contradiction more interesting. The player should not be forced to treat that stop as globally resolved.

New rule:

`ONE RESULT MAY RETIRE AN ACTION LAW WITHOUT RETIRING ITS INFORMATION VALUE.`

This separates **what the player must still do** from **what the player may still infer**.

### 4. Action duties and inference duties need different closure tests

Action duty closure asks:

`DO I STILL NEED TO DO SOMETHING DIFFERENT ON A LATER STOP?`

Inference duty closure asks:

`IS THERE STILL A LIVE QUESTION WORTH READING FROM THE RESULT?`

They can diverge.

A player can have:
- no special aiming responsibility left;
- but an unresolved bonus/reach-eye inference still alive;
- while the next physical STOP returns to the baseline motor routine.

Therefore:

`ACTION-LAW CLOSURE != INFERENCE CLOSURE.`

### 5. The next valid action law should be recoverable by continuity, not memorized reset commands

When a temporary law ends, the next action law is easiest to bind when it is already part of a stable parent grammar.

Research model:

`BASE GRAMMAR -> TEMPORARY DELTA -> END CONDITION -> BASE GRAMMAR WITH UPDATED KNOWLEDGE`

rather than:

`MODE A -> EXPLICIT RESET MESSAGE -> MODE B -> NEW INSTRUCTIONS`

This supports low return cost after temporary technical procedures or state-specific stopping duties.

New principle:

`GOOD TEMPORARY PLAY MODIFIES A KNOWN GRAMMAR; IT SHOULD NOT REQUIRE A SECOND LESSON TO RETURN FROM IT.`

### 6. Legible state ownership can retire a whole family of obsolete laws

Some duties are not closed by a particular symbol relation but by a state transition whose consequence is unambiguous for the next game.

At the abstraction level:

`STATE OWNERSHIP CHANGE -> OLD STATE ACTION FAMILY INVALID -> NEXT STATE ACTION FAMILY VALID`

The important Game/Reel requirement is not a flashy transition. It is that the next game's legal procedure is no longer ambiguous.

Thus:

`STATE TRANSITION IS CLOSURE EVIDENCE ONLY IF IT CHANGES WHICH ACTION LAW CAN VALIDLY GOVERN THE NEXT INPUT.`

### 7. Bounded skill attempts need per-attempt retirement, not permanent vigilance

Technical intervention can repeat many times across a session. If every attempt leaves the player unsure whether its responsibility is still pending, repeated play accumulates defensive monitoring.

Healthy structure:

`ATTEMPT OPENS -> AIM / STOP -> JUDGMENT EVIDENCE -> ATTEMPT RETIRED`

and only later:

`NEXT LEGITIMATE ATTEMPT -> NEW BINDING`

This preserves reopenability without carrying the prior attempt forward.

New principle:

`REPEATABLE SKILL SHOULD REOPEN AS NEW EPISODES, NOT REMAIN OPEN AS ONE CONTINUOUS DUTY.`

### 8. Three observable properties support next-grammar binding

Without proposing an implementation, the research suggests three observable properties are especially valuable:

1. **Question exhaustion** — the old target can no longer be affected by later stops.
2. **State ownership** — the current game/state visibly determines which procedure is valid next.
3. **Motor continuity** — the underlying BET/START/STOP grammar remains familiar unless a legitimate deviation explicitly changes it.

Combined:

`NEXT-GRAMMAR BINDING = OLD QUESTION EXHAUSTED + CURRENT STATE OWNERSHIP LEGIBLE + BASE MOTOR GRAMMAR PRESERVED`

This is a research abstraction, not a runtime formula.

### 9. Dormant is not retired

A duty is merely dormant if the same unresolved question is expected to demand the same special action later in the same logical episode.

Game/Reel distinction:

`DORMANT = NO ACTION REQUIRED THIS INSTANT, BUT OLD QUESTION STILL GOVERNS A FUTURE STOP.`

`RETIRED = OLD QUESTION CAN NO LONGER LEGITIMATELY GOVERN A FUTURE STOP IN THIS EPISODE.`

This distinction prevents a false closure declaration between STOP1 and STOP2 when the next stop still carries the same unresolved handling obligation.

### 10. Mastery should reduce dead-law carryover

A novice may continue mentally carrying an obsolete aiming rule because they are unsure whether it has ended. A skilled player often recognizes the exact stop/state evidence that makes the old law irrelevant and returns to the baseline motor routine sooner.

Research principle:

`MASTERY SHOULD IMPROVE RETIREMENT PRECISION, NOT JUST RECOGNITION SPEED.`

This extends the prior finding that mastery compresses both opening and closing costs.

## Selective closure matrix

| Local condition | Old action law | Retirement evidence | What may remain open |
|---|---|---|---|
| Candidate eliminated | protect/aim for candidate | visible candidate exhaustion | contradiction / bonus inference |
| Role fulfilled | complete role handling | fulfillment evidence | state/bonus inference |
| Temporary state exited | state-specific procedure | legible state ownership change | baseline reel reading |
| Skill attempt judged | execute current precision task | bounded judgment/result | next future attempt, session mastery |
| Stop result still leaves target live | same handling duty | **none yet** | old action law remains active |

The matrix is conceptual and does not define any Chappy5 original mechanic.

## Revised Game/Reel closure chain

`QUESTION OPENS`

→ `ACTION LAW BINDS`

→ `STOP / STATE EVIDENCE ACCUMULATES`

→ one of:

- `QUESTION STILL LIVE -> OLD LAW REMAINS`
- `QUESTION EXHAUSTED -> OLD LAW RETIRES`
- `QUESTION A EXHAUSTED + QUESTION B OPENS -> LAW A RETIRES / INFERENCE B REMAINS`
- `STATE OWNERSHIP CHANGES -> OLD ACTION FAMILY RETIRES / NEXT FAMILY BINDS`

→ `BASE MOTOR GRAMMAR CONTINUES WITH UPDATED KNOWLEDGE`

This gives the Machine Director a concrete Game/Reel answer without turning closure into one global machine state.

## Changed understanding

Game & Reel Run 7 focused on proof operators that can close a duty. Run 8 clarifies **exactly what is being closed**: not the button, not the channel, not necessarily the inference question, and not the whole machine state. What retires is one action law's authority over future stops in the current logical episode.

The strongest next grammar is often not newly announced. It is the stable parent grammar that was never removed, now made valid again because the temporary law has lost consequence.

## Limits / unresolved

- No manufacturer-undisclosed stop-control table is inferred.
- No numeric reaction time, slip threshold, cue probability or timing threshold is proposed.
- Whether humans reliably distinguish `dormant` from `retired` under fatigue remains unverified.
- Whether state ownership alone is sufficient after a long absence from play remains unverified.
- Overlapping duties that share the same evidence source may still create ambiguity if their end conditions are too similar.
- Human Trial is required later to test whether players truly stop carrying dead action laws while remaining sensitive to future legitimate deviations.
