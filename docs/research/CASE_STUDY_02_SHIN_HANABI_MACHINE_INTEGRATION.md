## Machine verdict for this cycle

Case Study 02 demonstrates a pachislot product architecture that does not require CZ → AT → upper-state escalation to sustain repeated play. Its primary product surface is the current physical stop itself. The machine repeatedly converts an ordinary three-STOP action into a small information problem, then allows player knowledge to make the same hardware richer over time.

The integrated loop is:

`AIM → CLASSIFY → RESOLVE → DISCOVER → EXECUTE → EXTEND / TRANSITION → RETURN WITH MORE KNOWLEDGE`

This is not merely an A-type-versus-AT distinction. The deeper contrast with Case Study 01 is where value is stored.

- 北斗 stores much value in `future state`: a rare role changes expectation of mode / foreshadowing / BB / continuation / upper state.
- 新ハナビ stores much value in `current observation`: aimed position, stopped position, slip, remaining role candidates, denial/contradiction, reach-eye recognition and self-confirmation.

Both still use the same fundamental human loop: action → partial evidence → interpretation → resolution → consequence.

## What keeps normal play alive

### Sourced / specialist-grounded structure

The physical reel window remains the central work surface. Multiple practical aiming routes create different candidate sets. Frequent replay/small-role handling means a bonus drought is not literally an event drought. Blackout, flash, delay and the mini-LCD add sparse deviations without replacing reel reading. Bonus discovery may occur before explicit notification. BIG then reframes STOP responsibility through 花火チャレンジ / 花火GAME; REG reframes it through tiered technical intervention.

### Machine interpretation

The 401st game in a dry spell can remain structurally playable only if the player is still asking a question before the third STOP. A future jackpot alone cannot validate the preceding drought. Therefore the correct machine-level test is not event count but `QUESTION DENSITY PER ORDINARY GAME`.

A useful abstraction is:

`REPEATABILITY = STABLE ROUTINE × VARIABLE INTERPRETATION × LEARNABLE RESOLUTION`

The routine is stable enough to become bodily automatic, but interpretation is not fully exhausted because knowledge changes what the player notices.

## Reward is plural, not one peak

Case Study 02 separates at least five reward layers:

1. `LOTTERY REWARD` — bonus was internally won.
2. `DISCOVERY REWARD` — the player recognizes truth from the reels before explicit notice.
3. `EXECUTION REWARD` — a technical action is performed successfully.
4. `KNOWLEDGE REWARD` — a slip / denial / relation is understood.
5. `OUTPUT REWARD` — medals / RT time are actually obtained.

Machine implication: reward architecture should not be judged only by payout peak or audiovisual climax. A player may receive a meaningful reward at the moment of understanding.

## Same controls, changed responsibility

Across normal, bonus and RT, the lever/reel/three-STOP body grammar is retained. State change changes what the same hand action means before it changes the hardware.

This yields a reusable principle:

`CHANGE RESPONSIBILITY BEFORE ADDING CONTROLS`

A reward state can feel different because the player now aims for avoidance, insertion, precision or confirmation rather than because a new interaction device appears.

## Sparse presentation is an information budget

Visual and Sound findings converge. The central workspace is comparatively quiet; static cabinet identity handles hall-distance recognition, while blackout/flash/timing/audio subtraction carry game-state information near the existing gaze/listening loop.

Reusable integrated principle:

`BASELINE STABILITY CREATES DEVIATION VALUE`

A delay matters only if normal start timing is trusted. Darkness matters only if normal reel illumination is trusted. BGM stopping matters only if state BGM has become an expected sensor. Sparse presentation therefore raises, rather than lowers, the quality requirement for baseline operation sound, reel visibility and timing consistency.

## Skill: agency and tax coexist

REG difficulty tiers and RT technique show that skill can make the player an author of result quality. But published full-strategy performance is execution-dependent, and missed execution can become self-blame rather than random disappointment.

Machine requirement:

`SKILL REWARD SHOULD SCALE PRIDE FASTER THAN REGRET`

Skill systems should be evaluated by skill tier, not by expert payout alone. Beginner access, intermediate competence and expert optimization are separate experiences.

## 100G / 500G / 3-hour integrated model

### 100G

The beginner can enter through a narrow routine: one landmark, role follow-up, obvious deviations. The expert sees more questions in the same three STOPs. Good mastery therefore adds perception instead of merely reducing difficulty.

### 500G dry spell

There can still be small-role handling, slips, timing/light deviations and route variation, but these do not prove quality. Apply `DRY-SPELL WITHOUT PAYOFF TEST`: remove the relief of the eventual bonus and judge an ordinary 100G segment on its own.

### 3 hours

The design has a credible mastery engine because repeated aiming can expose more information with knowledge. The same repetition is also a plausible eye/hand/audio fatigue engine. Controlled three-hour fatigue remains unresolved and must not be declared solved from edited video or enthusiast testimony.

## Post-reward truth test

If normal play is genuinely the product, RT ending must not feel like expulsion from the real game. The first ~30 normal games after reward should recover voluntary reel attention.

Use:

`POST-REWARD BASELINE RECOVERY TEST`

If attention collapses immediately to merely waiting for the next bonus, the claimed base-game strength has failed even if RT itself was enjoyable.

## Cross-case synthesis: 北斗 × 新ハナビ

The two cases are deliberately opposite in architecture, yet several principles survive both.

1. `STABLE BODY GRAMMAR` — repeated lever/reel/STOP coordinates remain an anchor while meaning changes.
2. `BASELINE BEFORE DEVIATION` — strong signals depend on a trusted normal state in timing, light and sound.
3. `STATE/ROLE VALUE IS CONTEXTUAL` — the same input or role gains different responsibility/value by context.
4. `PLAYER INTERPRETATION IS PART OF THE GAME` — expectation reading in 北斗 and stop/reach-eye reading in 新ハナビ both place unresolved meaning between action and outcome.
5. `REWARD NEEDS SUSTAIN, NOT ONLY ENTRY IMPACT` — BB/continuation or bonus/RT must remain playable after the initial hit.
6. `RELIEF != BASE QUALITY` — a hit after drought cannot retroactively prove the drought was good.
7. `PRESENTATION SHOULD SERVE INFORMATION` — light/audio density should support the primary work surface, not compete with it.
8. `RETURN LOOP MATTERS` — post-BB/post-RT return determines whether the base machine remains worth playing.

The key non-common principle is equally important: there is no single mandatory source of pachislot depth. 北斗 demonstrates depth through changing future-state value; 新ハナビ demonstrates depth through changing player perception of a stable present-state grammar.

Therefore Chappy5 must not prematurely canonize either `state escalation` or `reel mastery` as the studio formula.
