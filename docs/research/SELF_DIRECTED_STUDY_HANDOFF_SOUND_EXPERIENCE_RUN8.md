## Central answer

Visual Run 8 established:

`one stopped object may be closed for action while remaining open for inference.`

Sound answer:

`AUDITORY DUTY CLOSED != SEMANTIC SCENE CLOSED.`

A completion cue should close the smallest true responsibility domain. Audio should retire an obsolete listening/action duty, restore the trusted machine baseline, and then yield ownership to any reel/visual evidence that is still live. It should not create a second listening task merely to announce that the first one ended.

Research abstraction:

`SELECTIVE AUDITORY RELEASE = END OBSOLETE DUTY + RESTORE BASELINE + DO NOT OVERRIDE LIVE EVIDENCE`

This is not an implementation formula.

## Main delta

- auditory responsibility needs more than binary active/finished states;
- `LOCALLY_RELEASED` can coexist with `INFERENCE_REMAINS`;
- subtractive release can be stronger than an added all-clear cue when baseline recovery is already legible;
- normal grammar should usually reassert authority by resuming trusted causal behavior, not by adding a dedicated “normal restored” sound;
- local execution confirmation should validate the action at the scale of the action, without also implying reward/state/global closure;
- dormant and retired listening duties should not be conflated, but Audio alone need not carry the entire distinction if reel/visual context already does;
- repeated technical duties need semantic episode boundaries so they do not merge into continuous alarm listening;
- sound should yield ownership when the next important question belongs to the reel/result surface.
