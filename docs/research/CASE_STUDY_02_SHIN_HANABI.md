## Why this machine

Case Study 01 covered an AT / mode / continuation / upper-state lineage through スマスロ北斗の拳. Case Study 02 deliberately moves to a different lineage: a bonus + RT, reach-eye and technical-intervention machine in which repeated value is concentrated in physical reels, stopping, slip, role denial/contradiction, bonus discovery and player skill rather than CZ → AT → upper-state escalation.

Official Universal material identifies 新ハナビ as a 6号機 A PROJECT title, released July 2021, type `ボーナス＋RT`, and explicitly says its flow fully inherits the 5号機「ハナビ」 while adding 6号機-specific RB technical intervention, mini-LCD `たまやチャレンジ`, and changes to reel arrangement / blackout rules. This makes it useful not as a nostalgia object but as a study of how a known reel-centered grammar was translated under a different regulation/product generation.

## Machine Director — opening baseline

### Sourced facts

- Manufacturer: エレコ / Universal Entertainment family. Release: 2021-07. Type: Bonus + RT. Cabinet listed by official page as `アーチャー`.
- Official product description: the game flow inherits 5号機「ハナビ」; output is centered on bonuses; `花火チャレンジ` retains JAC-IN avoidance; RB adds level-based technical intervention; mini LCD `たまやチャレンジ`, reel arrangement changes and blackout-rule changes add new play.
- Major strategy reference lists BIG max 202枚 and REG max 112枚. After BIG, RT `花火チャレンジ` follows; special replay transitions to `花火ゲーム`.
- Reference full-strategy payout rates: setting 1 102.0%, 2 104.0%, 5 106.5%, 6 109.0%; bonus combined probability ranges roughly 1/156.0 to 1/131.6 in that source. These values must be rechecked by Game & Reel against primary/independent references before becoming shared numeric truth.
- Normal presentation uses a comparatively small set of recurring deviations: blackout, flash and delay, with `たまやチャレンジ` as an added expectation layer.
- Long-term mastery is demonstrably nontrivial: a specialist profiled by Pachiseven had recorded 1.15 million games and continued studying reach-eye collection/control behavior. This is field evidence of depth, not proof that all players experience the same longevity.

### Direct structural observation

Unlike 北斗, the machine does not need a long state ladder to continually redefine the next objective. The physical STOP itself can remain the object of attention because ordinary stopping contains unresolved information: target position, slip, small-role possibility, denial, two-reel certainty, reach-eye discovery and bonus detection.

The important contrast is therefore not simply `AT vs A-type`. It is:

`FUTURE-STATE EXPECTATION` (北斗) versus `CURRENT-STOP DISCOVERY` (新ハナビ).

Both can coexist in pachislot generally, but this case study intentionally isolates the latter.

### Working repeated-play model — interpretation, not final verdict

`BASE STOP ROUTINE → SMALL DEVIATION / SLIP / ROLE SHAPE → PLAYER CLASSIFICATION → THIRD-STOP RESOLUTION → BONUS DISCOVERY → BONUS SKILL → RT SKILL/EXTENSION → RETURN TO SAME REEL GRAMMAR`

This differs from Case Study 01 because reward does not permanently replace the learned normal grammar. After bonus/RT, the player returns to the same physical reels with more learned patterns. Mastery can therefore compound without requiring a new upper state.

### Why a player may sit down — hypotheses to test

1. Immediate reel-reading pleasure: the next three STOPs can themselves contain the question and answer.
2. Mastery accumulation: knowing more stop positions, slips, role contradictions and reach eyes changes perception of the same machine.
3. Skill agency: technical intervention makes some result quality depend on execution, not only lottery outcome.
4. Compact reward cycle: bonus → RT → normal creates a shorter repeated arc than an AT ladder.
5. Sparse-presentation sensitivity: because baseline presentation is restrained, small timing/blackout/flash deviations can remain legible.

These are hypotheses until the specialist Directors and long-form evidence test them.

## Time-scale questions for all Directors

### First 5 minutes
- Can a beginner identify a safe/basic aiming routine without understanding the full reach-eye language?
- Which feedback teaches success versus merely punishes misses?

### Normal 100G
- What percentage of attention is on reels versus mini-LCD/lamps?
- How often does the player change aiming location or stop order voluntarily?
- Does sparse presentation create calm concentration or empty repetition?

### 500G dry spell
- With no CZ milestone or upper-state promise, what makes the 401st–500th games meaningfully playable?
- Does reel discovery survive when bonus relief is absent?
- Which repetitive sounds/visuals become fatigue sources?

### 3 hours
- Does accumulated knowledge make later games richer than the first 100G?
- How much physical/visual fatigue comes from repeated aiming?
- Does technical intervention feel like earned agency, mandatory tax, or both depending on skill?

## Reward architecture to investigate

The initial model is deliberately simple: normal play finds BIG/REG; BIG is followed by an RT sequence involving 花火チャレンジ and 花火ゲーム; REG itself contains technical intervention. The critical research question is not only expected payout but how each reward changes what the hands, eyes and ears do.

Case Study 02 must distinguish:
- lottery reward,
- discovery reward (recognizing a reach eye before explicit notice),
- execution reward (successful technical intervention),
- knowledge reward (understanding a slip/contradiction),
- collection/mastery reward,
- output reward.

A machine can feel rewarding before medals are paid if the player discovers truth through the reels. This must be tested rather than assumed.

## Integration questions

### Game / Reel
Actual reel array, valid lines, internal roles, observable forms, slip and stop-order information, reach-eye families, bonus detection, technical intervention, RT transition and setting/skill relationships.

### Visual / Mechanism
How much physical area and depth are reserved for reel readability; how lamps, blackouts, flashes, mini-LCD and cabinet identity support rather than obscure the reels; what stays visually quiet.

### Sound / Experience
How baseline BET/lever/reel/STOP/payout sounds establish routine; how delay, cue omission/addition, flash synchronization, bonus/RT transitions and skill feedback make sparse deviation memorable without covering reel information.

### Playtest / QA
Beginner vs expert observation; first-5-minute intimidation; 100G intrinsic reel satisfaction; 500G dry-spell durability; skill failure friction; 3-hour eye/hand fatigue; whether relief after a bonus drought is being mistaken for reel-play quality.

## Reusable principles — provisional

- `CURRENT STOP CAN BE THE CONTENT`: a game need not always defer meaning to a future state if the stop itself contains learnable uncertainty.
- `MASTERY SHOULD CHANGE PERCEPTION`: long-term depth can come from seeing more information in the same three reels rather than adding more modes.
- `SPARSE BASELINE CREATES DEVIATION VALUE`: quiet/regular presentation gives small timing, light and sound changes room to matter.
- `SKILL REWARD != SKILL TAX`: technical intervention must be evaluated both as agency and as friction for weaker players.
- `REWARD CAN BE DISCOVERED BEFORE ANNOUNCED`: recognizing a true result from reels can be a separate reward layer from explicit notification.
- `RETURN SHOULD DEEPEN THE BASE GAME`: after bonus/RT, returning to normal should not feel like losing access to the real game if normal play is genuinely the product.

## Contradictions / cautions

- Community experts' detailed stop-control observations are valuable field evidence but are not manufacturer disclosure. Mark observed/inferred control separately.
- Full-strategy payout assumes execution quality; it cannot be treated as the beginner experience.
- Nostalgia and inherited familiarity can improve veteran reception. Do not mistake brand memory for universally reusable game design.
- A small presentation set can be elegant for experts but intimidating or unreadable to newcomers. Both must be tested.
