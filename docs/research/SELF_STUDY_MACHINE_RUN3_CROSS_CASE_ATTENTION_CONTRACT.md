Latest `main` is the sole source of truth. Case Study 01「スマスロ北斗の拳」is complete through all five fixed Directors for its current cycle. Case Study 02「新ハナビ」is also already closed as an active shared object after its five-Director cycle. Machine Run 2 left one high-value integration question: can cross-Director attention responsibility be represented without prematurely turning research principles into an original-machine specification?

This run answers that question by comparing only already-studied real-machine evidence and specialist findings. It does not design a Chappy5 machine.

## 2. Prior unknown

We had strong local principles:
- Game/Reel: conditional duty should open from a cue and close when resolved.
- Visual: REST is a calibration state; signal authority is finite.
- Sound: routine audio should confirm prediction more often than demand orienting.
- QA: mastery should increase information gained per unit of attention while reducing unnecessary monitoring.
- Machine: REST trains prediction; meaningful deviation should purchase a model update.

What remained unclear was whether these could be integrated into one research model that remains valid across radically different lineages.

## 3. Investigation

### SOURCED FACT — repository evidence

Case Study 01 records 北斗 as a forward-projection architecture:

`state inference → rare-role value → precursor observation → BB continuation → possible value upgrade`

Its integrated loop is:

`BASE ROUTINE → MEANINGFUL DEVIATION → STATE EDIT → OBSERVATION WINDOW → REWARD LOOP → JUDGEMENT → VALUE UPGRADE → POST-END CONTRACT → BASE ROUTINE`

Case Study 02 records 新ハナビ as a present-interaction architecture:

`aim → stop → read/slip → contradiction/discovery → bonus → technical/RT duty → return`

Its late-cycle Machine synthesis is:

`HOME → CLAIM → TEMPORARY RESPONSIBILITY → RESOLUTION → RELEASE → RE-ANCHOR → HOME`

Case Study 02 explicitly concludes that repeated value may live either in future-state projection or present-reel interpretation, and that two cases are not enough to choose an architecture for Chappy5.

### OBSERVATION

Despite very different reward structures, both case studies repeatedly contain the same attention transition:

`KNOWN BASELINE → EVIDENCE THAT SOMETHING CHANGED → TEMPORARY NEED TO READ/ACT MORE CAREFULLY → RESOLUTION → TRUSTED RETURN`

The *content* of attention differs.

In 北斗, attention may shift toward state inference, precursor persistence, rare-role aftermath, continuation and post-end residue.

In 新ハナビ, attention may shift toward stop position, slip, role denial, reach-eye relation, bonus detection and temporary technical duty.

The commonality is therefore not an AT/bonus/reel mechanic. It is a contract about when extra attention becomes justified and when it is released.

## 4. New learning — research-only ATTENTION CONTRACT

A useful cross-Director research representation is possible if it describes **claims about player responsibility**, not future Chappy5 features.

For any observed real-machine event, record five fields:

1. `CLAIM OPENER` — what observable evidence first justifies extra attention?
2. `RESPONSIBILITY` — what must the player now watch, predict, aim, remember or decide?
3. `CROSS-CHANNEL SUPPORT` — which reel / visual / mechanism / audio channels support that same responsibility?
4. `RESOLUTION EVIDENCE` — what observable event proves the responsibility has ended or changed?
5. `RELEASE / RE-ANCHOR` — how does the machine make ordinary play safely ordinary again?

This is an analysis template only. It does not prescribe that every future machine needs the same events, timings, channels or density.

## 5. Changed understanding

Previous loose model:

`important event = stronger presentation`

Revised model:

`important event = justified temporary change in player responsibility, supported coherently by the machine, with an observable end condition`

Presentation strength is only one possible support mechanism.

A quiet reel contradiction can open a high-value claim. A loud event can be low-information. A state may remain valuable after presentation has calmed. Therefore attention responsibility cannot be inferred from effect size alone.

## 6. Reusable principles

`ATTENTION SHOULD FOLLOW RESPONSIBILITY, NOT EFFECT SIZE.`

`A CLAIM IS NOT COMPLETE UNTIL THE PLAYER CAN LEARN HOW IT RESOLVES.`

`CROSS-DIRECTOR COHERENCE MEANS AGREEING ON WHAT THE PLAYER IS RESPONSIBLE FOR NOW.`

`RELEASE IS PART OF THE EVENT CONTRACT; WITHOUT RELEASE, DEPTH CAN DEGRADE INTO VIGILANCE.`

`THE BASELINE MUST BE TRUSTWORTHY ENOUGH THAT ORDINARY PLAY CAN BECOME COMPRESSED.`

`A REALITY STUDY SHOULD RECORD ATTENTION OPENERS AND CLOSERS, NOT ONLY MEMORABLE PEAKS.`

`THE SAME ATTENTION-CONTRACT FORM CAN DESCRIBE DIFFERENT LINEAGES WITHOUT CLAIMING THEY SHARE THE SAME GAME ARCHITECTURE.`

## 7. Limits / misuse

- This model is derived from only two deliberately contrasting case-study families plus current specialist self-study. It is not a universal law of pachislot.
- Do not turn the five fields into a mandatory Chappy5 feature checklist.
- Do not infer hidden internal state from presentation unless a reliable source establishes it.
- Do not equate a presentation cue with economic value.
- Do not force every ordinary game to contain a claim opener.
- Do not treat “release” as silence; it means the player can safely reduce a specific responsibility.
- Do not use this model to rank or refine SIGNAL/FORGE/VAULT.

## 8. Remaining unknowns

- Does the model survive a third lineage where announcement is much more explicit and reel interpretation is less central?
- Does it survive A+ART, where real bonus and longer ART can create overlapping responsibilities?
- Can two responsibilities remain open simultaneously without producing defensive vigilance?
- How should responsibility priority be represented when reel, state and technical duties overlap?
- How quickly do players learn a release condition after hours/days away?
- Which responsibilities remain legible under hall noise, finger occlusion and smartphone interruption?

## 9. Next worthwhile Machine study

Do not open or design a new machine from this document alone.

The next high-value Machine question is:

`WHEN MULTIPLE REAL RESPONSIBILITIES OVERLAP, HOW DOES A MACHINE PRIORITIZE THEM WITHOUT MAKING THE PLAYER MONITOR EVERYTHING?`

A future deliberately different real-machine lineage can test this better than further abstraction from 北斗/新ハナビ.

## 10. Possible future Chappy5 value

Only after Human Gate and later design authorization, the research-only ATTENTION CONTRACT could become an audit instrument for checking whether Game/Reel, Visual/Mechanism, Sound and QA are describing the same current player responsibility.

For now it remains Reality Baseline research.
