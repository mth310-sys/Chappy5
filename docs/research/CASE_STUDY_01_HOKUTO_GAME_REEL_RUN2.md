# 1. リール配列は「同じ役をどの情報として見せるか」を変換する

## SOURCED FACT
本機は1ライン機。公開配列表では各リール20コマ構成として掲載されており、北斗図柄、ラオウ図柄、赤7、ベル、スイカ、チェリー、リプレイ等が異なる間隔で配置されている。

通常時の代表的な小役フォローは少なくとも以下3系統。
1. 中押し赤7狙い
2. 順押し白BAR狙い
3. 順押し赤7狙い

同一機で複数手順が成立するが、得られる情報は同じではない。

## SOURCED FACT — 中押し赤7
中リール枠上付近へ赤7を狙うと、第1停止で大きく候補が分岐する。
- 中リールが `リプレイ/赤7/ベル` 系停止 → リプレイ、チェリー群、リーチ目候補
- 中リール中段ベル → ハズレ、ベル、チャンス目候補
- 中リール中段スイカ → スイカ群、リーチ目候補

その後の右・左停止で候補を狭める。

例：最初の分岐がリプレイ系なら、右上段リプレイ停止でリプレイ側へ、右上段リプレイ非停止なら最後に左チェリー狙いを要求し、角/中段チェリー/リーチ目へ分かれる。

## INTERPRETATION
ここで第1停止は「結果の1/3」ではなく、**次に何を狙う必要があるかを決める分類器**である。

停止順が `押す → 結果を見る → 次の狙い位置を変える` という条件分岐を含むので、3STOPは同じ操作を三回繰り返していない。

## REUSABLE PRINCIPLE
3STOPに意味を持たせる方法の一つは、各STOPへ演出脚本を付けることではなく、**第N停止の結果が第N+1停止の観測方法を変える配列/判別構造**を作ること。

# 2. 中押しは万能ではなく「情報の交換」になっている

## SOURCED FACT
中押し赤7ではスイカの強弱判別を行いやすい一方、中段チェリーA/Bは中押し時に両方とも中段チェリーとして停止するため判別できない。

一方、順押し白BAR狙いでは中段チェリーA/Bの判別に使える停止形がある。

さらに順押し赤7狙いは別のトレードオフを持つ。
- 弱/強スイカ判別やチャンス目判別を失う。
- 中段チェリー成立時に北斗カウンターが作動しない。
- リーチ目成立時にJACを揃えられる。
- 左リールJACがチェリー代用となるためチェリー取りこぼしを避けられる。

## INTERPRETATION
「攻略手順＝正解手順1つ」ではなく、北斗では手順ごとに観測できる情報・演出連動・図柄揃いの体験が変わる。

これは100G以上の反復において、同じ抽選器を別の読み方で遊べる余地になる。

## REUSABLE PRINCIPLE
打ち方選択を採用する場合、単なる難易度差だけでなく
`得る情報 A / 捨てる情報 B / 追加される出目体験 C`
の交換関係を設計すると、プレイヤーの知識が操作へ反映される。

# 3. 小役名と停止形は1対1ではない

## SOURCED FACT
公開解析では以下のように、内部役分類と停止形が単純な1対1ではない。

### 中段チェリーA/B
- A：基本は中段チェリー停止。
- B：順押しでは角チェリー停止後に3連チェリー等の形を取る場合がある。
- A/Bとも左リール下段へチェリーをビタ押しすると角チェリー停止になると公開されている。

### スイカA/B
中押しでの右リール狙い位置により、同じ強スイカAでも中段揃い/斜め揃い側へ表示が変わり得る。強スイカBは斜め揃いとして認識しやすい。

### チャンス目
中押しでは中・右中段ベルテンパイ後の左ハズレ等で認識できるが、順押しではベルこぼしが類似停止形を作る場合がある。

## INTERPRETATION
プレイヤーが画面上で見る「出目」は内部役の印刷結果ではない。押し順・押下位置・図柄配置を通した**観測像**である。

Game & Reel設計で「中段チェリー役を引いたら中段チェリー画像を止める」のような1:1処理を先に考えると、パチスロ特有の読みの層が消える。

## REUSABLE PRINCIPLE
将来のChappy5では、少なくとも概念上
`INTERNAL ROLE != OBSERVED STOP FORM`
を仕様段階から分離する。

ただし停止制御そのものはHuman Gate後のStage 2以降で設計し、現在は実装しない。

# 4. 「リーチ目」は別ゲームではなく通常判別木に混ざっている

## SOURCED FACT
中押しでは、チェリー候補からチェリー非停止、スイカ候補からスイカハズレ等でリーチ目となる停止例が公開されている。

順押しでもスイカテンパイハズレ、ボーナス図柄一直線等の例がある。

リーチ目確率は設定差があり、公開値で設定1約1/16384、設定6約1/8192。

## INTERPRETATION
リーチ目は「専用の確定図柄を突然表示する」より、普段学習している小役判別文法が最後だけ裏切られることで強くなる。

つまり確定役の価値は希少確率だけでなく、**通常時に学んだ規則を使って本人が異常を発見する**ところにある。

## REUSABLE PRINCIPLE
強い確定結果ほど通常文法から切り離さず、普段の候補集合からの矛盾として発見できる余地を持たせる。

# 5. 確定画面でもリールは「儀式」ではなく継続率情報を持つ

## SOURCED FACT
ボーナス確定画面中には赤7揃いA/B、赤7フェイクA/Bの異なるフラグが公開されている。

- 赤7揃いA：基本中段揃い。
- 赤7揃いB：基本下段または右下がり揃い。出現時は約79%以上のBB継続率濃厚。
- フェイクA/Bは赤7を狙ってハズれるパターンで、次Gの北斗揃い昇格へ接続する大チャンスと解析されている。

## INTERPRETATION
AT確定後の「7を狙え」は単なる入賞儀式ではない。

`どこに止まるか / 揃うか外れるか / 次Gへ持ち越すか`
がBBの価値情報を追加する。

当たりが確定した後にもSTOP観察の価値が残っているため、通常→確定→BBでリールの重要度が突然ゼロにならない。

## REUSABLE PRINCIPLE
当選後の図柄狙いを入れるなら、映像上のセレモニーだけではなく、停止位置または結果に本物の情報価値を持たせる余地を検討する。

# 6. BBは同じレア役の責務を状態別に再利用している

## SOURCED FACT — 小役パート
BBは基本 `30G+α 小役パート → 8G バトルパート`。
小役パート中は成立役に応じて宿命バトル突入を抽選し、勝利でVストックを得る。

宿命バトル抽選はレバーON時と明記され、第3停止時ではない。

## SOURCED FACT — バトルパート
継続率66/79/84/89%を基に継続を判定。
- 非継続状態でレア役 → 継続書き換え抽選。
- 継続状態でレア役 → 継続率昇格・演出書き換え等。

## SOURCED FACT — 上位
無想転生バトルでは基本入力文法/BBループを保ったまま継続率が94%へ上がる。通常の無想転生チャンスは存在せず、上位中のリーチ目等は無想転生ボーナス側の恩恵へ再配分される。

## INTERPRETATION
同じ中段チェリーや強スイカでも
- 通常：モード編集/本前兆
- BB小役パート：宿命バトル/Vストック機会
- バトル：敗北書き換え/継続率側の強化
- 上位：上位固有の追加報酬
と役割が変わる。

図柄資産を増やさなくても「今ここで引きたい役」が状態ごとに変わるので、同じリールを長時間見続ける理由が更新される。

## REUSABLE PRINCIPLE
状態設計とは背景を変えることではなく、`同じ成立役の現在価値を変えること`でもある。

# 7. 第3停止は常に「結果確定ボタン」ではない

## SOURCED FACT
Run 1で確認した通り通常時のモード昇格/転落は第3停止ボタンを離した時点で行われると公開解析されている。

一方、BB小役パートの宿命バトル抽選はレバーON時と明記されている。

## INTERPRETATION
同一機でも内部処理責務は局面ごとに違う。

- 通常時：第3停止離しが次G状態の境界になり得る。
- BB小役パート：成立役に伴う宿命バトル抽選はレバーON。

したがって「レバー=抽選、第3停止=全部確定」という単純な共通式を全状態へ適用しない。

## REUSABLE PRINCIPLE
将来仕様では状態ごとに
`WHEN IS THE LOTTERY? / WHEN IS THE STATE EDIT? / WHEN IS THE RESULT REVEALED?`
を別欄で明文化する。

# 8. 100G / 500G / 3時間でGame & Reelが担っているもの

## 100G
- 大半は高速処理してよい普通G。
- 数十Gに1回程度のレア役が注意を圧縮する。
- 第1停止候補分岐が起きた時だけ狙いを変える。
- 押し方によって自分が取得する情報を選べる。
- レア役後は停止形だけでなく状態/前兆観察へ意識を移す。

## 500G
重要なのは「毎G違う出目を見せる」ことではない。
同じ手順反復の中で、レア役→状態期待→不発→次の役という長い循環を許容している。

ただし500Gハマリ時に中押しそのものが疲れるか、どの程度オート化した身体動作になるかは実機長時間操作で未確認。

## 3時間
プレイヤーのリール責務が状態に応じて変わる。
`通常の判別 → 本前兆期待 → 確定画面の図柄狙い/継続率情報 → BB中のレア役期待 → 継続バトル → 上位でも同じ基礎入力`

これにより「リールを見続ける理由」が単一ではない。

# 9. Game & Reel Director — Case Study 01 追加結論

1. **第1停止はドラマの第一幕ではなく、次操作を変える分類器になり得る。**
2. **押し順/狙い位置は攻略精度だけでなく、どの情報を見るかの選択になり得る。**
3. **内部役と停止形を1対1にしないことが、目押し・スベリ・矛盾・リーチ目の基盤になる。**
4. **確定後もリール結果へ情報を残すことで、当たり突入がLCDだけのイベントにならない。**
5. **同じレア役を状態別に別価値へ再利用すると、図柄を増やさず長時間の期待対象を更新できる。**
6. **抽選タイミング・状態更新タイミング・結果提示タイミングは別仕様として扱う。**
7. **中段チェリーの本質は固有出目ではなく、通常モード推測→役認識→状態編集→前兆観測→BBまでをつなぐ時間構造。固有数値・名称・停止形はコピーしない。**
