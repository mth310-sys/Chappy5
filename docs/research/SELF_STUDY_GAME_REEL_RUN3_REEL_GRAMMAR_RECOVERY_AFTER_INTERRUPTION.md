## 1. Why this topic now

Run 2 separated latent reel complexity from exposed decision entropy and concluded that mastery should compress many internal possibilities into a small number of reliable action chunks. The unresolved question is whether those chunks remain usable after hours or days away, especially in an iPhone/browser context where interruption and session resumption are ordinary rather than exceptional.

Machine Run 3 also formalized an attention contract in which responsibility opens, resolves, and releases. If re-entry after interruption requires the player to rebuild the entire responsibility model from memory, the learned grammar is fragile even if it felt fluent at the end of the prior session.

## 2. Prior unknown

We did not know how to distinguish:

- durable reel grammar from short-lived session fluency,
- true skill loss from temporary warm-up decrement,
- motor reacclimation from declarative rule recall,
- useful re-entry cues from tutorial repetition,
- context restoration from leading/reminding the player so strongly that retention can no longer be measured.

## 3. Investigation

### SOURCED FACT — temporary post-rest performance loss exists separately from persistent learning

Motor-learning literature describes **warm-up decrement**: performance can temporarily worsen after a rest interval even when the underlying learned component persists. A multi-day star-tracing study modeled performance as a fast transient warm-up process superimposed on a slower persistent learning process; the persistent component survived between sessions while early-session performance still required reaccommodation.

Source: Adams et al., *Task Difficulty and the Time Scales of Warm-Up and Motor Learning*, Journal of Motor Behavior (2013), DOI 10.1080/00222895.2013.784240.

### SOURCED FACT — appropriate reinstating activity can reduce warm-up decrement

Classic motor studies found that a task-relevant or structurally related activity immediately before resumption can reduce warm-up decrement, whereas generic activation is not equivalent. This supports the idea that re-entry quality can depend on reinstating the correct action set rather than merely making the player “active” again.

Sources: Murray, *The Activity-Set Hypothesis for Warm-up Decrement in a Movement Balance Task* (1980), DOI 10.1080/00222895.1980.10735225; Schmidt & Wrisberg, movement-speed activity-set study (1971), DOI 10.1080/00222895.1971.10734912.

### SOURCED FACT — motor-sequence retrieval can be context-dependent

A motor-sequence memory study manipulated keyboard/display orientation, stimuli, background, hand position and workstation between learning and retrieval. Recall differed across context conditions, supporting the conclusion that features of the learning context can guide later retrieval of motor sequences.

Source: Schmidt, Frings & Tempel, *Context-Dependent Memory of Motor Sequences*, Journal of Cognition (2021), DOI 10.5334/joc.152.

### SOURCED FACT — interruption and resumption are not equivalent to a clean break

Human-factors studies show that interruption can increase resumption lag and sequence error, with more complex/nested interruptions producing worse resumption. Cue utilization can support faster or more accurate return to a procedural task.

Sources: Sasangohar et al., *Effects of Nested Interruptions on Task Resumption* (Human Factors, 2017); Falkland et al., *Cue Utilization Differentiates Performance in the Management of Interruptions* (Human Factors, 2020); Falkland, *Interruptions versus breaks: The role of cue utilisation* (Applied Cognitive Psychology, 2021).

### SOURCED FACT — sequence memory can operate at subsequence/chunk scale

Recent movement-sequence work reports repetition benefits when sufficiently long subsequences recur, supporting a representation richer than isolated one-step transitions but not necessarily requiring the whole sequence to be recalled as one monolithic unit.

Source: *Repetition effects reveal the subsequence representation of actions*, Journal of Neurophysiology (2025), DOI 10.1152/jn.00372.2024.

### SOURCED FACT — initial chunking can shape later execution for days

Instructional chunk boundaries in a finger-sequence learning study continued to influence execution timing after extended practice, even though participants could gradually overcome poorly aligned chunking. This suggests that the way a skill is first cognitively partitioned can leave durable structure in later performance.

Source: *The effect of instruction on motor skill learning*, Journal of Neurophysiology (2020), DOI 10.1152/jn.00271.2020.

## 4. New learning

### INTERPRETATION — session fluency and retained grammar must be separated

For reel play, a player can finish a 500G session looking fluent because aim points, stop order and interpretation rules remain activated in short-term/session context. Returning the next day and hesitating for the first few games does not automatically mean the reel grammar was forgotten.

A better research model is:

`RETAINED GRAMMAR + TRANSIENT RE-ENTRY COST = EARLY RESUMPTION PERFORMANCE`

The transient term may include reacquiring aim rhythm, reloading which cues matter, restoring stop-order intent, and re-establishing confidence in the action→consequence relation.

### INTERPRETATION — the first few games after return are diagnostic

The highest-value evidence is not simply “can the player still play after one day?” but:

- which action chunk returns first,
- which rules require conscious reconstruction,
- whether the player can identify a safe default route before expert optional routes,
- how many games are needed before predictive interpretation returns,
- whether mistakes are execution errors, rule-selection errors, or uncertainty-driven hesitation.

### INTERPRETATION — re-entry should restore the learned world, not reteach it

If a machine must show a full tutorial every session, it has not demonstrated durable grammar. But if the machine removes every familiar anchor and demands perfect recall immediately, it may be measuring context disruption rather than the quality of learning.

The useful middle ground is **context reinstatement without answer disclosure**: stable reel landmarks, consistent spatial ownership, unchanged safe action classes, and the same action→visible-consequence law can help reactivate prior learning without explicitly solving the game for the player.

### INTERPRETATION — optional expert depth should reopen after the base grammar recovers

Run 2 argued that expert routes may voluntarily re-expand uncertainty. Run 3 adds a time dimension: after interruption, the base grammar should recover before the player must again manage optional high-entropy interpretation. A design that makes expert-only questions immediately mandatory on return can turn retained mastery into re-entry friction.

## 5. Changed understanding

Previous model:

`mastery = fewer cognitive units needed during continuous play`

Updated model:

`durable mastery = compressed grammar that can be rapidly reinstated after context loss`

This changes the quality target. A reel system is not fully learnable merely because a player becomes fluent during one uninterrupted session. Its grammar should survive ordinary absence well enough that the player can reconstruct the necessary action state from stable cues with limited warm-up.

## 6. Reusable principles

- `MEASURE RETENTION AFTER RE-ENTRY, NOT ONLY FLUENCY BEFORE EXIT.`
- `WARM-UP DECREMENT IS NOT THE SAME AS FORGOTTEN GRAMMAR.`
- `RE-ENTRY SHOULD REINSTATE THE ACTION SET BEFORE IT REOPENS OPTIONAL COMPLEXITY.`
- `CONTEXT CUES SHOULD REACTIVATE LEARNING WITHOUT DISCLOSING THE ANSWER.`
- `A SAFE DEFAULT ROUTE SHOULD BE THE FIRST CHUNK THAT RETURNS.`
- `DURABLE MASTERY COMPRESSES ACROSS TIME, NOT ONLY ACROSS BRANCHES.`
- `RE-ENTRY ERRORS SHOULD BE CLASSIFIED AS EXECUTION / RULE-SELECTION / INTERPRETATION / CONFIDENCE ERRORS.`
- `CONSISTENT SPATIAL AND ACTION LANDMARKS ARE PART OF RETRIEVAL, NOT MERELY PRESENTATION.`
- `DO NOT CONFUSE A FULL RETUTORIAL WITH GOOD RETENTION.`
- `DO NOT CONFUSE IMMEDIATE POST-RETURN HESITATION WITH TOTAL SKILL LOSS.`

## 7. Limits / misuse

- The cited motor tasks are not pachislot reel tasks; transfer is conceptual, not proof of a specific reel-control design.
- Warm-up studies cannot establish how many pachislot games should be required for reacquisition.
- Context-dependence evidence does not justify deliberately changing visual context to manipulate retention.
- No manufacturer-undisclosed stop-control table is inferred.
- No original reel array, role table, payout table, stop law, aim window or skill intervention is designed here.
- A familiar UI can improve retrieval while simultaneously hiding weak underlying learning; eventual Human testing must separate cue-supported retrieval from unsupported recall.

## 8. Remaining unknowns

- What is the minimum interruption length that measurably changes reel-task resumption on target iPhone?
- Does one hour, one day and one week produce qualitatively different error types?
- Which re-entry cue is most useful: visible reel landmark, first safe aim, stop-order reminder, state recap, or simply one ordinary practice game?
- How much context drift from Safari viewport/brightness/orientation changes harms retrieval?
- Can optional expert routes recover without explicit prompts once the safe default route is restored?
- How should confidence recover relative to actual accuracy?

## 9. Next worthwhile Game & Reel study

**Error attribution under skill play:** when a player misses value or misreads a stop result, what evidence lets them correctly distinguish `my timing`, `my chosen stop order`, `internal role/state`, and `machine control`? This is central to whether skill feels learnable rather than arbitrary.

## 10. Possible future Chappy5 value

If Human Gate later authorizes production, this research can inform a retention test that compares:

`end-of-session fluent block → interruption → first-return block → reacquired steady block`

without inventing a mandatory tutorial. The goal would be to verify that a reel grammar becomes recoverable knowledge rather than a fragile checklist held only inside one uninterrupted session.
