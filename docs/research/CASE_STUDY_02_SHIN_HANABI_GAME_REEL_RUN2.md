## 0. Why Run 2 exists

Run 1 established the core repeated-play model:

`AIM → CLASSIFY → RESOLVE → DISCOVER → EXECUTE → EXTEND / TRANSITION → RETURN WITH MORE KNOWLEDGE`

Run 2 does not replace that model and does not design an original machine. It resolves a narrower Game & Reel gap left after Machine Integration Run 2:

1. distinguish **published stop-control evidence** from guessed control;
2. map internal role families to visible stop forms without pretending that one visible form uniquely reveals one internal flag;
3. make the role of stop order and aiming route more concrete;
4. connect normal play, bonus detection, BIG/REG execution and two-stage RT into one continuous reel-responsibility loop;
5. explain how setting and player skill create two different long-session information economies.

Evidence labels:
- `MANUFACTURER FACT`: official Universal material.
- `PUBLISHED ANALYSIS`: major strategy / analysis source.
- `FIELD / VIDEO OBSERVATION`: long-form or specialist play evidence available publicly; not manufacturer specification.
- `INTERPRETATION`: Game & Reel Director synthesis.
- `UNRESOLVED`: deliberately not promoted to fact.

No third-party reel art, protected layouts, sound, video or exact proprietary tables are copied into Chappy5. Published control-table existence and examples are studied as evidence only.

## 1. Current source-of-truth machine definition

### MANUFACTURER FACT

Universal's official product page identifies 新ハナビ as a 2021 6号機 A PROJECT title using `ボーナス＋RT`. It states that the game flow fully inherits 5号機「ハナビ」 while adding RB difficulty-selectable technical intervention, the mini-LCD `たまやチャレンジ`, reel-array changes and revised blackout rules.

Official source:
- https://www.universal-777.com/product/slot/shin_hanabi/

### PUBLISHED ANALYSIS

Major analysis converges on the following base structure:

| Item | Published structure |
|---|---|
| Settings | 1 / 2 / 5 / 6 |
| BIG | red-7 BIG / Don BIG, max 202 medals |
| REG | max 112 medals, 8 wins or 12 games termination structure |
| Bonus combined | approximately 1/156.0 at setting 1 to 1/131.6 at setting 6 |
| BIG aftermath | always enters `花火チャレンジ` |
| 花火チャレンジ | max 20G, JAC-IN avoidance can preserve the phase |
| 花火GAME | JAC-IN replay entry, 20G |
| Reach-eye scale | approximately 3,500 patterns reported |

Primary analysis:
- https://1geki.jp/slot/s_shinhanabi/
- https://p.hisshobon.jp/machine/3661/1/83016

### INTERPRETATION

The machine is not a collection of isolated reach eyes followed by two bonus mini-games. It is one continuous physical-reel language whose **responsibility changes by phase**.

Normal:
`protect value + classify candidate role + search for contradiction`

Bonus discovery:
`confirm which bonus remains possible + minimize detection delay`

BIG:
`execute a one-time adjustment, then collect and sample setting-relevant outcomes`

REG:
`choose an execution difficulty and repeatedly convert physical accuracy into payout`

RT1:
`use the same stop system to avoid JAC-IN until transition timing changes`

RT2:
`return toward lower-duty reel reading while the same reels continue to carry bonus / setting information`

This is the complete loop studied in this run.

## 2. Reel arrays and valid lines remain a rule surface, not an image sheet

### PUBLISHED ANALYSIS

Run 1 recorded the published 21-symbol-per-reel array and valid-line difference between 3BET and 1BET play. Public strategy material exposes landmarks including 暖簾/BAR, red 7, Don, ice, cherry, wind bell and replay-related symbols, with several legitimate normal-play aiming routes.

References:
- https://1geki.jp/slot/s_shinhanabi/2/
- https://1geki.jp/slot/s_shinhanabi/

### INTERPRETATION — `REEL ARRAY = CONSTRAINT NETWORK`

Run 2 sharpens the earlier `ARRAY AS PLAYFIELD` principle:

A reel array matters because it constrains:
- what can be covered from a chosen first-stop area;
- which small role remains alive after STOP1;
- which line the role can still use;
- whether STOP2 creates a natural role template or contradiction;
- how much uncertainty STOP3 resolves;
- which bonus can be efficiently checked after a suspicious result.

Therefore the array is not only a database of final pictures. It is a **network of future possibilities after every partial stop**.

Reusable principle:

`GOOD REEL DEPTH EXISTS BETWEEN STOPS, NOT ONLY AFTER STOP 3.`

## 3. Published stop-control evidence now exists for all three first-stop choices

### PUBLISHED ANALYSIS

一撃 publishes separate first-stop control pages for:
- first stop LEFT;
- first stop MIDDLE;
- first stop RIGHT.

Each page distinguishes at least these states:
- bonus not yet established;
- Don BIG established;
- red-7 BIG established;
- REG established.

Sources:
- https://1geki.jp/slot/s_shinhanabi/47/
- https://1geki.jp/slot/s_shinhanabi/48/
- https://1geki.jp/slot/s_shinhanabi/49/

The published explanatory examples explicitly show that the number of frames slipped can differ by internal condition / role for a specified pressed location. For example, the pages explain individual cases where the same indexed press position produces a different slip count for a miss versus replay.

### CRITICAL EVIDENCE BOUNDARY

This is stronger evidence than the field anecdotes used in Run 1, but it **does not authorize Chappy5 to fabricate a complete proprietary control model**.

We may safely record:
- public tables exist;
- first-stop control is state/role sensitive;
- slip count at a fixed press point can change with the underlying condition;
- left-, middle- and right-first routes genuinely offer different information structures.

We do **not** claim:
- these strategy tables are manufacturer source code;
- the hidden priority algorithm is known;
- second- and third-stop complete tables are known for every state;
- every reach eye can be reverse-generated from the published pages;
- exact internal tie-breaking logic is disclosed.

### INTERPRETATION — `SLIP IS EVIDENCE WITH PROVENANCE`

The important Game & Reel lesson is not "copy these slip numbers." It is:

`same physical press position + different internal truth → different mechanical response → player inference`

That means physical reel movement itself can carry state evidence before the final picture resolves.

Reusable principle:

`IF SLIP CARRIES INFORMATION, THE PLAYER MUST BE ABLE TO TRUST WHERE THEY AIMED.`

A visually beautiful stop that makes the pressed location ambiguous would destroy part of the game language.

## 4. Stop order is not merely ergonomic order

### PUBLISHED ANALYSIS

Normal-play material commonly recommends a left-first 暖簾 route with scissors stopping, while the machine also supports alternate red-7 and Don routes. Published specialist material and the new control pages demonstrate that middle-first and right-first play can expose other state-sensitive outcomes.

References:
- https://1geki.jp/slot/s_shinhanabi/2/
- https://1geki.jp/slot/s_shinhanabi/47/
- https://1geki.jp/slot/s_shinhanabi/48/
- https://1geki.jp/slot/s_shinhanabi/49/

### INTERPRETATION — `STOP ORDER = QUERY ORDER`

For a reel-reading machine, stop order changes **which question is asked first**.

Left-first typical question:
`What small role / bonus family survives my safe opening?`

Right-first or middle-first specialist question:
`Can I expose a bonus-sensitive stop / contradiction earlier, accepting a different follow-up burden?`

This gives a more precise interpretation than "different押し方 gives variety."

Reusable principle:

`ALTERNATE STOP ORDERS SHOULD REORDER INFORMATION, NOT JUST REORDER ANIMATION.`

## 5. Internal-role family versus visible stop family

### PUBLISHED ANALYSIS

Published small-role analysis distinguishes internal families including:
- wind bell A / B;
- ice A / B;
- cherry A1 / A2 / B;
- normal replay;
- several special roles / one-medal roles associated with bonus outcomes.

The same source explicitly notes that small-role type can be classified differently depending on where the player stops the reels, and gives observable tendencies:
- wind bell A tends to align without slipping from a specified left-BAR reference;
- wind bell B tends to appear after a one-frame slip from the same reference;
- ice A tends toward the parallel line where drawable;
- ice B tends toward the diagonal line where drawable;
- cherry family classification uses the left cherry position together with the right-reel middle symbol.

Sources:
- https://1geki.jp/slot/s_shinhanabi/4/
- https://1geki.jp/slot/s_shinhanabi/44/

### INTERPRETATION — `VISIBLE FORM IS A PROJECTION OF INTERNAL TRUTH`

A useful machine model is:

`internal role / bonus state`
`× press location`
`× stop order`
`× reel-control response`
`× valid-line geometry`
`= observed partial/final stop form`

The important word is **projection**. A visible result is not necessarily a one-to-one label for the internal flag.

This prevents a weak implementation habit in future work:

`internal event X → always display picture X`

Real reel depth can instead come from multiple visible consequences of a coherent rule set.

## 6. Wind bell is both payout and long-session sample

### PUBLISHED ANALYSIS

Setting-dependent normal frequencies are published. Example values from 一撃:

| Setting | Bell A | Bell B | Ice A | Cherry A2 | Cherry B |
|---|---:|---:|---:|---:|---:|
| 1 | 1/15.3 | 1/15.3 | 1/52.9 | 1/21.0 | 1/282.5 |
| 2 | 1/14.9 | 1/15.6 | 1/53.5 | 1/19.3 | 1/281.3 |
| 5 | 1/14.5 | 1/15.3 | 1/49.6 | 1/20.6 | 1/276.5 |
| 6 | 1/14.1 | 1/15.1 | 1/50.8 | 1/19.9 | 1/274.2 |

Normal replay is published around 1/7.3. The source notes that UniMemo can record exact role counts.

Source:
- https://1geki.jp/slot/s_shinhanabi/4/

### INTERPRETATION

The ordinary wind-bell event has at least three simultaneous functions:

1. **economic** — it is a small payout event;
2. **reel-reading** — its A/B form can be reflected through stopping behavior / visible form;
3. **session inference** — accumulated counts contribute to setting estimation.

Therefore an event can be low spectacle but high long-session utility.

Reusable principle:

`FREQUENT EVENTS CAN CARRY THREE VALUES AT ONCE: PAYOUT, REEL INFORMATION, SESSION INFORMATION.`

This is one reason a normal 500G stretch can remain cognitively populated without CZ milestones.

## 7. Cherry handling: safe collection first, deeper classification second

### PUBLISHED ANALYSIS

Basic normal play teaches a low-friction rule: aim around the left 暖簾/BAR area; if cherry stops, the remaining reels can normally be stopped freely for ordinary collection. Deeper analysis distinguishes cherry A1/A2/B using the left cherry position and right-reel middle symbol relationship.

Sources:
- https://1geki.jp/slot/s_shinhanabi/2/
- https://1geki.jp/slot/s_shinhanabi/4/

The machine's delayed-start cue is also publicly associated with `cherry or bonus` candidates.

Source:
- https://1geki.jp/slot/s_shinhanabi/

### INTERPRETATION — `SAFE ROUTINE CAN CONTAIN OPTIONAL DEPTH`

A novice can execute the important collection behavior without immediately understanding every cherry subtype. A skilled player can use the same stop to extract more information.

This produces a valuable layered-access pattern:

`avoid obvious loss → recognize role → classify subtype → relate to presentation → relate to bonus / setting evidence`

Reusable principle:

`DO NOT REQUIRE MAXIMUM INTERPRETATION TO ACHIEVE MINIMUM SAFE PLAY.`

This aligns with Playtest & QA's `SAFE PLAY ACCESS != MEANING ACCESS`: the two layers should be distinguished, not collapsed.

## 8. Ice is a recurring responsibility window

### PUBLISHED ANALYSIS

The common 暖簾 scissors procedure allows the player to free-stop the right reel after the first stop, then aim the middle reel only when an ice template remains. Published strategy uses red 7 as a visual guide to cover the middle-reel ice.

Source:
- https://1geki.jp/slot/s_shinhanabi/2/

Ice A is published around 1/52.9 at setting 1 while ice B is much rarer; observable line tendency differs where the chosen press position allows the role to be drawn.

Source:
- https://1geki.jp/slot/s_shinhanabi/4/

### INTERPRETATION — `ATTENTION WINDOW, NOT CONSTANT MAXIMUM AIMING`

The player does not need peak precision on all three reels every game. The opening routine creates a condition:

`if ice possibility survives → spend attention on the middle reel`

otherwise:

`release attention and complete the stop`

That creates a physical attention rhythm inside the base game itself.

Reusable principle:

`REEL RESPONSIBILITY SHOULD OPEN AND CLOSE WITH INFORMATION NEED.`

This is the Game & Reel counterpart to the integrated Machine principle `THE MACHINE MUST MANAGE WHAT THE PLAYER CAN IGNORE`.

## 9. Reach-eye families should be studied as resolution mechanisms

### PUBLISHED ANALYSIS

The machine is widely documented at approximately 3,500 reach-eye patterns. Public presentation rules add another layer of candidate contracts:
- delayed reel-start sound: cherry or bonus candidate;
- blackout count changes the set of compatible roles;
- flash types have role relationships;
- contradictions can therefore produce bonus knowledge.

Sources:
- https://1geki.jp/slot/s_shinhanabi/
- https://pachiseven.jp/articles/detail/14698

### INTERPRETATION — four useful resolution families

Without copying protected exact reach-eye art, the following abstract families explain much of the repeated value:

1. `ROLE SURVIVES → FINAL STOP DENIES IT`
2. `AIMED HERE → REEL MOVED THERE → ORDINARY MISS NO LONGER FITS`
3. `PRESENTATION PROMISES ROLE X → REELS CONTRADICT X`
4. `TWO REELS ALREADY OVER-CONSTRAIN THE THIRD`

The reusable point is not the exact pattern count. It is that ordinary rules create **proof-like resolution**.

Reusable principle:

`A STRONG REEL REVEAL FEELS PROVEN, NOT MERELY ANNOUNCED.`

## 10. Bonus detection is a second game nested inside discovery

### PUBLISHED ANALYSIS

Published bonus-detail pages distinguish Don BIG, red-7 BIG and REG and show many internal trigger categories, including standalone bonus, replay-related triggers, wind-bell/cherry related triggers and special roles. Published first-stop control pages also separate control by which bonus has already been established.

Sources:
- https://1geki.jp/slot/s_shinhanabi/43/
- https://1geki.jp/slot/s_shinhanabi/47/
- https://1geki.jp/slot/s_shinhanabi/48/
- https://1geki.jp/slot/s_shinhanabi/49/

### INTERPRETATION — `DISCOVERY != ENTRY`

A player can know "bonus is present" before knowing which bonus to align. That creates two successive uncertainties:

1. **truth discovery** — is a bonus established?
2. **identity resolution** — which bonus can be efficiently entered?

A reach eye therefore need not end reel play. It can **change its objective**.

Reusable principle:

`WHEN THE PLAYER DISCOVERS THE WIN, GIVE THE REELS A NEW QUESTION BEFORE THE REWARD BEGINS.`

This adds continuity between normal play and reward instead of cutting immediately to a separate presentation game.

## 11. BIG: technical adjustment and setting observation coexist

### PUBLISHED ANALYSIS

BIG has a maximum published acquisition of 202 medals. Published procedure requires a one-time adjustment using a precise left-reel red-7 target, followed by an ice aim on the middle reel after successful positioning; after the adjustment the remaining BIG can be consumed with a simpler reverse-stop routine.

Published BIG analysis also documents outcome forms used as setting evidence, including diagonal wind-bell behavior and a rare scattered result / flash condition.

Sources:
- https://1geki.jp/slot/s_shinhanabi/
- https://1geki.jp/slot/s_shinhanabi/62/

### INTERPRETATION

BIG has an elegant responsibility contour:

`high-focus one-time task → lower-focus repeated collection → occasional observation for setting evidence`

It does not demand identical precision every BIG game.

Reusable principle:

`A REWARD PHASE CAN FRONT-LOAD EXECUTION DUTY, THEN RETURN ATTENTION TO OBSERVATION.`

This supports long-session endurance while preserving skill meaning.

## 12. REG: difficulty selection turns the same reels into an explicit skill instrument

### PUBLISHED ANALYSIS

REG provides three published methods:
- beginner: normal left-first / simple stopping;
- intermediate: reverse stopping with 3-Don target on the left;
- advanced: middle first, then ice target on all reels with approximately two-frame accuracy allowance.

The published maximum is 112 medals, with termination after 8 wins or 12 games. Published strategy-output rates show material differences by REG procedure. At setting 1, examples are approximately:
- baseline market value: 98.1%;
- intermediate / reverse REG procedure under complete strategy: 100.1%;
- advanced / middle-first complete strategy: 102.0%.

Source:
- https://1geki.jp/slot/s_shinhanabi/63/

The REG panel-flash procedure also changes responsibility: the player is advised to avoid a 1-medal-role loss of an available win where possible, using a scissors routine and aiming for ice only when the shape requires it.

### FIELD / VIDEO OBSERVATION

Public beginner-oriented actual-play programming explicitly frames delayed-start reverse stopping and JAC-IN avoidance as skills to learn and improve rather than pre-existing knowledge.

Source:
- https://www.niconana.net/movie/%E3%80%90%E6%96%B0%E3%83%8F%E3%83%8A%E3%83%93%E3%80%91%E6%94%BB%E7%95%A5%E3%81%B8%E3%81%AE%E9%81%93-%E9%81%85%E3%82%8C%E9%80%86%E6%8A%BC%E3%81%97%E3%81%A8%E3%83%8F%E3%82%BA%E3%82%B7%E3%81%AE%E4%B8%8A/

### INTERPRETATION — `SKILL CHOICE IS PART OF GAME STATE`

The selected REG method effectively changes the game rules the player chooses to accept:

`lower execution burden / lower expected reward`
versus
`higher execution burden / higher expected reward`

This is not a cosmetic difficulty menu. It changes the economic value of successful stopping.

Reusable principle:

`WHEN SKILL HAS ECONOMIC CONSEQUENCE, THE MACHINE MUST DISTINGUISH CHOSEN DIFFICULTY FROM FORCED DIFFICULTY.`

## 13. 花火チャレンジ: same STOPs, opposite purpose

### PUBLISHED ANALYSIS

After BIG, 花火チャレンジ lasts at most 20G and has published pure increase around 0.3 medals/G. During the earlier part of the remaining-game window, an arrow cue asks the player to reverse stop and finish by aiming the left 暖簾 with about two-frame tolerance to avoid JAC-IN. Later, the instruction changes so the player intentionally allows JAC-IN and transitions to 花火GAME.

Source:
- https://1geki.jp/slot/s_shinhanabi/64/

### INTERPRETATION — `THE SAME ROLE CAN CHANGE FROM THREAT TO DOOR`

The key Game & Reel idea is temporal revaluation:

Early RT1:
`JAC-IN now = undesirable because it ends the extension opportunity`

Later RT1:
`JAC-IN now = desired because it opens the second RT phase`

The role did not need a new button or new reel set. **Time remaining changed its value.**

Reusable principle:

`STATE CAN CHANGE THE VALUE OF AN EXISTING REEL EVENT WITHOUT CHANGING THE INPUT DEVICE.`

This is a concrete real-machine example of `CHANGE RESPONSIBILITY BEFORE ADDING CONTROLS`.

## 14. 花火GAME: lower technical burden, continued sampling

### PUBLISHED ANALYSIS

花火GAME begins when the JAC-IN replay is taken and continues 20G. Published analysis gives approximately 0.6 medals/G. RT replay is dominant, while the pure miss rate has substantial setting difference:

| Setting | Published 花火GAME miss rate |
|---|---:|
| 1 | 1/13.4 |
| 2 | 1/12.4 |
| 5 | 1/10.1 |
| 6 | 1/9.5 |

The same source notes that the ratio between RT replay and miss can be used as setting information. BGM stopping is documented as a bonus cue.

Source:
- https://1geki.jp/slot/s_shinhanabi/65/

### INTERPRETATION — `RECOVERY DOES NOT MEAN INFORMATIONLESS`

Compared with the JAC-IN avoidance window, 花火GAME reduces direct precision duty but preserves:
- reel observation;
- small-role handling;
- bonus discovery;
- RT miss / replay setting sampling.

This is a useful long-session rhythm:

`execute intensely → recover physically → continue learning`

Reusable principle:

`LOWER DUTY PHASES CAN PRESERVE INFORMATION VALUE WHILE RETURNING HUMAN ATTENTION CAPACITY.`

## 15. Setting and skill are separate axes and must not be conflated

### PUBLISHED ANALYSIS

The machine has setting-dependent bonus frequencies and setting-dependent small-role / RT samples. Separately, published strategy values differ according to technical execution method, especially REG.

Sources:
- https://1geki.jp/slot/s_shinhanabi/
- https://1geki.jp/slot/s_shinhanabi/4/
- https://1geki.jp/slot/s_shinhanabi/63/
- https://1geki.jp/slot/s_shinhanabi/65/

### INTERPRETATION — two uncertainty axes

`SETTING UNCERTAINTY`
- What machine condition am I sitting at?
- Learn through accumulated bonus / small-role / RT evidence.

`EXECUTION UNCERTAINTY`
- How much of the machine's available value can I personally realize?
- Learn through aiming accuracy, procedure knowledge and self-selected pace.

These axes interact economically but are psychologically different.

Reusable principle:

`DO NOT USE PLAYER SKILL TO HIDE MACHINE-STATE UNCERTAINTY, OR MACHINE STATE TO EXCUSE BAD SKILL FEEDBACK.`

## 16. Reconstructed normal 100G loop

### PUBLISHED / STRUCTURAL BASIS

At setting 1, published frequencies mean that across an ordinary 100G stretch the player can expect many replays, many wind bells, several cherries, occasional ice and a meaningful but not guaranteed chance of a bonus, without any CZ milestone requirement.

Source:
- https://1geki.jp/slot/s_shinhanabi/4/

### INTERPRETATION

A practical 100G cognitive loop is:

1. settle into chosen aiming route;
2. STOP1 classifies the candidate set;
3. release attention if nothing remains demanding;
4. spend attention when ice/cherry/presentation contracts require it;
5. compare press point with slip;
6. read STOP2 relationship;
7. STOP3 either pays, denies, contradicts or proves;
8. when proof appears, switch from `is it a bonus?` to `which bonus?`;
9. if no proof, immediately return to stable routine.

The value is not a guaranteed dramatic event every few games. The value is **repeatable question generation with recoverable attention cost**.

## 17. Reconstructed 500G no-bonus loop

### INTERPRETATION

A 500G dry spell removes the machine's large reward but does not remove:
- role collection;
- aimed-location / slip comparison;
- ice responsibility windows;
- cherry cue interpretation;
- blackout / flash / delayed-start contracts;
- setting sample accumulation;
- optional aiming-route changes;
- near-proof and false-candidate resolution.

However, Game & Reel must preserve the QA warning:

`these events existing != the dry spell being enjoyable.`

The meaningful test is whether the ordinary STOP relation still causes the player to ask a current-game question around game 450, not whether the player merely continues because of 102% published full-strategy expectation or because they want relief after finally hitting a bonus.

Reusable principle:

`REEL DEPTH MUST SURVIVE PAYOFF REMOVAL, NOT JUST EXPLAIN CONTINUATION.`

## 18. Reconstructed 3-hour reel workload

### FIELD / VIDEO EVIDENCE

Public long-session examples exist at several-thousand-game scale, including reports/videos around 7,800G and expert sessions centered on REG high-skill attempts. Beginner programming separately shows skills being practiced over time.

Examples:
- https://yutura.net/channel/98894/video/-uhM0NgM1pY/
- https://yutura.net/channel/3934/video/UHi1cInu2tM/
- https://www.niconana.net/movie/%E3%80%90%E6%96%B0%E3%83%8F%E3%83%8A%E3%83%93%E3%80%91%E6%94%BB%E7%95%A5%E3%81%B8%E3%81%AE%E9%81%93-%E9%81%85%E3%82%8C%E9%80%86%E6%8A%BC%E3%81%97%E3%81%A8%E3%83%8F%E3%82%BA%E3%82%B7%E3%81%AE%E4%B8%8A/

### INTERPRETATION

Three-hour reel quality is not simply "does the player still perform the routine?"

It should be understood as the drift of four variables:

`AIMING PRECISION`
`× RULE RECOGNITION`
`× SELF-SELECTED PACE`
`× CURIOSITY PER ORDINARY STOP`

Mastery can lower some costs:
- landmark acquisition gets faster;
- non-relevant outcomes can be ignored sooner;
- ice duty can be identified earlier;
- bonus candidates can be resolved more efficiently.

Mastery can also raise chosen difficulty:
- alternate stop routes;
- deeper subtype classification;
- advanced REG procedure;
- more detailed setting sampling.

Therefore:

`MASTERY SHOULD COMPRESS ROUTINE COST WHILE EXPANDING OPTIONAL QUESTIONS.`

This extends the existing cross-case principle `THE MACHINE MUST MANAGE WHAT THE PLAYER CAN IGNORE`.

## 20. What remains unresolved

Do not promote the following to fact without stronger evidence:

- manufacturer-authored complete stop-control source tables;
- complete second-/third-stop control for every internal role, press location, bonus state and stop order;
- exact priority/tie-break rules used by the main control;
- exact full 21-symbol indexed array reproduced as Chappy5 data — third-party machine layout is study evidence only;
- exhaustive mapping from every one-medal role to every observed reach eye;
- exact slip-distribution frequency under each normal aiming style over thousands of games;
- measured novice versus expert role-miss rates by hour;
- measured three-hour decline in frame-aim accuracy;
