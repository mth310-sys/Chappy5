Question received from Game & Reel Run 4:

**What visible/tactile ownership cues around STOP, reel-window depth, button state and partial-stop continuity let Human perceive “my press was accepted and this reel physically resolved from that action,” while also making platform/input/render discontinuities visibly distinguishable from legitimate machine behavior?**

## Key change

Add **causal geometry / action-graph coherence** to physical presence.

A visually convincing cabinet is not only a stable scene graph. It also needs an action graph that agrees with the apparent physical structure:

`hand → STOP control → cabinet/machine → reel response → settled reel result`

Research-only decomposition:

1. `CONTROL OWNERSHIP`
2. `REEL RESPONSE OWNERSHIP`
3. `MOTION CONTINUITY`
4. `FINAL-STATE TRUST`
5. `SOURCE ATTRIBUTION`

## Main principles

- `ACKNOWLEDGE INPUT LOCALLY, THEN PRESERVE THE CAUSAL TRAJECTORY TO THE REMOTE OUTCOME.`
- `BUTTON OWNERSHIP AND REEL-RESULT OWNERSHIP ARE DIFFERENT PERCEPTUAL CLAIMS.`
- `OCCLUSION CAN HIDE A CAUSAL TRAJECTORY; IT SHOULD NOT RESET IT.`
- `A SURPRISING STOP SHOULD STILL LOOK LIKE THE END OF THE SAME PHYSICAL MOTION.`
- `A THREE-STOP GAME SHOULD ACCUMULATE PHYSICAL EVIDENCE; EACH STOP SHOULD NOT RESTART THE SCENE.`
- `PARTIAL-STOP HISTORY IS A VISUAL-MECHANICAL STATE, NOT ONLY A GAME-LOG STATE.`
- `THE CABINET MAP IS PART OF THE ACTION-EFFECT MODEL.`
- `PLATFORM DISCONTINUITY MUST NOT BE ALLOWED TO MASQUERADE AS MACHINE LAW.`
- `RESPONSIVE ADAPTATION MAY CHANGE SCALE; IT SHOULD NOT CHANGE CAUSAL OWNERSHIP.`
- `PHYSICAL PRESENCE REQUIRES ACTION-GRAPH COHERENCE AS WELL AS SCENE-GRAPH COHERENCE.`

## Research evidence delta

External perceptual/HCI evidence used in this run supports:

- touch-feedback latency affects perceived button quality / simultaneity;
- agency depends on temporal contingency and visual integrity, not timing alone;
- spatial/temporal mismatch can weaken attribution of an outcome to one's own action;
- motion can remain perceptually continuous across temporary occlusion when pre/post trajectory is coherent.

These results are not converted into production constants.
