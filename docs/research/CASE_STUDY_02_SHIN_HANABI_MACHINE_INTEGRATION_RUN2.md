## 1. Machine-level delta: depth is not only information density — it is managed attention debt

Run 1 established:

`AIM → CLASSIFY → RESOLVE → DISCOVER → EXECUTE → EXTEND / TRANSITION → RETURN WITH MORE KNOWLEDGE`

Run 2 adds a second axis: what that loop costs the human over hundreds or thousands of repetitions.

Visual Run 2 shows that the cabinet can spend physical complexity on presence while protecting a calm central reel work surface. Sound Run 2 shows that ordinary audio and timing dominate exposure and that unused acoustic space can itself be functional. QA Run 2 shows that technical depth can become obligation, pace reduction, regret and fatigue if the player must maintain high attention continuously.

Integrated principle:

`DEPTH = LEARNABLE MEANING - UNSUSTAINABLE ATTENTION DEBT`

A machine is not deeper merely because more can be noticed. The useful depth is the portion that remains discoverable and rewarding at a sustainable visual, auditory and motor cost.

---

## 2. Three simultaneous budgets

### 2-1. Visual budget

Visual evidence supports a split between peripheral presence and central precision:

- cabinet identity can live in large static masses, reflection, translucency, grille geometry and side-light surfaces;
- reel reading needs a stable, recessed, visually coherent central work plane;
- hand plane and gaze plane need not compete;
- not every lamp needs game-state semantics.

Machine abstraction:

`VISUAL BUDGET = PRESENCE OUTSIDE / PRECISION INSIDE`

The machine may be physically rich while ordinary play remains perceptually disciplined.

### 2-2. Audio budget

Sound Run 2 shows that baseline BET/lever/reel/STOP/result sound exposure is far greater than rare reward sound exposure. Delay, omission and BGM interruption only retain information value while the normal timing/sound field is stable.

Machine abstraction:

`AUDIO BUDGET = ROUTINE CONFIRMATION + RESERVED HEADROOM FOR MEANINGFUL DEVIATION`

Not every sound must request conscious attention. Body-rhythm confirmation, state atmosphere, rule-bearing cue and reward release are different responsibilities.

### 2-3. Human attention budget

QA Run 2 shows that a player can be highly attentive for reasons that are not intrinsic enjoyment: loss avoidance, setting/economic sampling, technical-intervention fear, or sunk-cost relief seeking.

Machine abstraction:

`ATTENTION BUDGET = CURIOSITY + NECESSARY DUTY - AVOIDABLE OBLIGATION`

The target is not maximum attention. It is sustainable attention with recovery windows.

---

## 3. Sparse presentation is active load management

The previous conclusion `SPARSE PRESENTATION = INFORMATION BUDGET` is strengthened.

Sparse presentation is not simply aesthetic restraint. It actively protects:

- reel visibility;
- stop timing perception;
- small timing/light/audio deviations;
- player self-generated prediction;
- long-session sensory headroom.

Integrated principle:

`QUIET SPACE IS NOT EMPTY SPACE WHEN THE PLAYER IS READING THE MACHINE.`

This applies visually and acoustically. A calm central reel field and acoustic headroom both preserve room for the player to notice a small difference.

---

## 4. Cabinet presence and game readability are separate products that must coexist

Visual Run 2 sharpens a two-resolution requirement.

At aisle distance, fine reel symbols and mini-display information disappear; silhouette, large luminance blocks, speaker/grille openings, reflective/translucent framing and panel massing remain. At seated distance, the importance reverses and reel relations / STOP result must dominate.

Integrated machine test:

`TWO-RESOLUTION MACHINE TEST`

1. `AISLE RESOLUTION`: if text and reel detail vanish, does the machine still read as one coherent physical object?
2. `SEATED RESOLUTION`: if branding and decorative identity are ignored, can the core game be read without visual competition?

A machine does not need one element to solve both jobs.

---

## 5. State escalation should first reassign meaning, not occupy more space or attention

Run 1 already established `CHANGE RESPONSIBILITY BEFORE ADDING CONTROLS`.

Run 2 extends the same principle across Visual and Sound:

- Visual: escalate which existing plane matters before physically expanding the presentation.
- Sound: escalate listening context before loudness/density.
- QA: preserve lower-load recovery windows between high-responsibility actions.

Integrated principle:

`ESCALATE RESPONSIBILITY / CONTEXT BEFORE ESCALATING VOLUME / DENSITY / DUTY`

This is a cross-discipline rule, not a directive to imitate 新ハナビ.

---

## 6. Skill is a pacing system as well as a payout system

Run 1 treated skill as both agency and tax. Run 2 adds real field evidence that repeated execution misses can cause a player to intentionally slow play to protect accuracy.

Therefore technical intervention changes more than expected return:

`PLAY SPEED ↔ EXECUTION ACCURACY ↔ FATIGUE ↔ ECONOMIC RESULT ↔ ENJOYMENT`

Machine consequence:

`SKILL SYSTEMS MUST BE TESTED AT SELF-SELECTED HUMAN PACE.`

Maximum machine throughput is not automatically the correct experience target. A technically responsive system can still create a bad human rhythm if optimum play requires chronic hesitation or tension.

---

## 7. Attention must be classified by motive

A player staring at reels is not sufficient evidence of engagement.

Machine-level attention classes retained from QA:

- `INTRINSIC / DISCOVERY`: the player wants to know what this stop means;
- `LOSS AVOIDANCE`: the player fears missing value;
- `ECONOMIC / SETTING SAMPLING`: the player is collecting information for rational continuation;
- `PRESENTATION-PROMPTED`: the machine explicitly requests attention;
- `RELIEF SEEKING`: the player mainly wants a drought to end.

Integrated principle:

`ATTENTION != ENJOYMENT; CONTINUATION != BASE-GAME QUALITY.`

This is especially important in a 500G bonus drought. A rational player can continue a strong strategy through a weak moment-to-moment experience.

## 8. Normal 100G / 500G / 3-hour model — Run 2 revision

### First 5 minutes

The onboarding problem is a simultaneous obligation stack, not merely rule count. The player may need to aim at a landmark, notice role-follow needs, preserve stop order, notice presentation and interpret the result at once.

Machine requirement for later human-approved testing:

`SAFE PLAY ACCESS` and `MEANING ACCESS` must be evaluated separately.

A player can avoid major mistakes while still failing to see why the game is interesting.

### Normal 100G

Judge not only whether the player watches reels, but why. Track whether observation is driven by curiosity or economic duty.

### 500G dry spell

Retain `DRY-SPELL WITHOUT PAYOFF TEST`, now strengthened by `DROUGHT MOTIVE AUDIT`:

sample early / middle / late sections and detect whether current-stop curiosity survives after novelty and optimism decay.

### 3 hours

The correct endurance question is not simply “was the player tired at the end?” but whether performance and motive drift over time.

Future human-approved QA should compare hour buckets for:

- self-selected pace;
- hesitation/correction;
- execution misses;
- missed cues;
- strategy variation;
- posture/hand resets;
- eye/hand/audio fatigue;
- curiosity-driven versus loss-avoidance-driven attention.

`LONG-SESSION QA SHOULD MEASURE DRIFT, NOT ONLY FINAL FATIGUE.`

No claim is made that these values are already measured for 新ハナビ.

## 9. Information completion should release the player

Sound Run 2 notes that presentation can be cancelled when the result is already understood. This combines with reel-centered self-discovery.

Integrated principle:

`WHEN THE PLAYER ALREADY KNOWS, DO NOT FORCE THE MACHINE TO KEEP EXPLAINING.`

Once game information is resolved, repeated audiovisual confirmation should justify its remaining duration through reward sustain or necessary state communication. Otherwise it becomes dead exposure and rhythm obstruction.

This is not permission to copy any proprietary cancellation implementation.

---

## 10. Physical complexity does not require perceptual complexity

Run 2 Visual evidence shows a physically layered cabinet: rear body, front shell, recessed reel plane, speaker cavities, translucent/reflective areas, projecting operation deck and forward STOP plane.

Yet that physical complexity does not have to become a new rule every game.

Integrated principle:

`PHYSICAL COMPLEXITY CAN CREATE PRESENCE WITHOUT CREATING PER-GAME COGNITIVE COMPLEXITY.`

This is important for Chappy5 reality study because `REALITY_PRESENCE` should not be confused with constant animation or constant information density.

## 11. Cross-case synthesis after Run 2: 北斗 × 新ハナビ

The two cases continue to support common principles without collapsing into one formula:

1. `STABLE BODY GRAMMAR` — repeated lever/reel/STOP coordinates anchor play.
2. `BASELINE TRUST BEFORE DEVIATION` — timing/light/sound differences require a trusted normal state.
3. `PLAYER INTERPRETATION IS PRODUCT SURFACE` — future-state reading in 北斗, present-stop reading in 新ハナビ.
4. `REWARD NEEDS SUSTAIN` — entry impact alone is insufficient.
5. `RELIEF != QUALITY` — eventual reward cannot retroactively validate the drought.
6. `RETURN LOOP MATTERS` — post-reward recovery into the base game is part of quality.
7. `PRESENTATION SHOULD SERVE THE PRIMARY WORK SURFACE`.
8. `STATE CHANGE CAN REFRAME EXISTING INPUTS BEFORE ADDING NEW ONES`.
9. `LONG-PLAY QUALITY REQUIRES ATTENTION RELEASE / RECOVERY WINDOWS`.
10. `HUMAN PACE IS A DESIGN VARIABLE`.

New cross-case meta-principle:

`THE MACHINE MUST MANAGE WHAT THE PLAYER CAN IGNORE.`

北斗 showed that experienced players compress attention around meaningful observation windows. 新ハナビ shows that a skill/reel machine also needs lower-load windows and stable non-message baselines. Mastery is partly learning what deserves attention and what does not.
