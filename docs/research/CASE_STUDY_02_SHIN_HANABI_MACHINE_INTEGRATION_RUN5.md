## 1. Run 5 synthesis — the machine manages attention debt, not only game state

The specialist Run 5 findings converge on one product-level model:

`HOME → CLAIM → TEMPORARY RESPONSIBILITY → RESOLUTION → RELEASE → RE-ANCHOR → HOME`

Game & Reel shows that partial reel results can both open and close responsibility. Visual shows the same physical reel surface can be progressively reinterpreted without being replaced. Sound shows that timing deviation, continuity and absence can carry meaning without continuous escalation. Playtest shows that mastery includes learning when careful reading can stop.

### REUSABLE PRINCIPLE

`A DEEP MACHINE DOES NOT MAXIMIZE ATTENTION; IT TEACHES THE PLAYER HOW TO SPEND AND RECOVER ATTENTION.`

### REUSABLE PRINCIPLE

`MASTERY SHOULD LOWER MANDATORY ATTENTION COST WHILE PRESERVING OPTIONAL DISCOVERY.`

This is the strongest shared learning from 新ハナビ and is intentionally not treated as a requirement for every future machine family.

## 2. The ordinary state is a product, not an absence

Across Game/Reel, Visual, Sound and QA, the ordinary state is now understood as an active learned contract:
- stable aim/STOP routine;
- recognizable baseline timing and operation sounds;
- protected physical reel-reading surface;
- known deviations that matter;
- known conditions where extra precision is required;
- known conditions where that responsibility has ended.

### REUSABLE PRINCIPLE

`ORDINARY PLAY QUALITY = READABLE HOME CONTRACT + MEANINGFUL DEVIATION + TRUSTED RETURN.`

Sparse presentation works only when ordinary play itself has something to read/do and when the player trusts that ordinary moments are genuinely ordinary.

## 3. Skill and discovery are distinct reward channels

新ハナビ demonstrates two non-identical player-owned reward channels:

1. `DISCOVERY` — recognizing slip, role denial, reach-eye relation, timing/flash contradiction.
2. `EXECUTION` — performing a required aiming procedure correctly and receiving economic/functional consequence.

These must not be collapsed into one generic “technical depth” category.

### REUSABLE PRINCIPLE

`DISCOVERY REWARDS UNDERSTANDING; EXECUTION REWARDS CONTROL. A MACHINE MAY USE EITHER OR BOTH, BUT QA SHOULD MEASURE THEM SEPARATELY.`

## 4. Long-session lesson — continuation is not proof of enjoyment

The 500G/3-hour research repeatedly found that rational continuation, setting inference, technical discipline, collection goals and relief-seeking can all produce continued play.

### REUSABLE PRINCIPLE

`CONTINUATION MOTIVE MUST BE CODED, NOT ASSUMED.`

A long session can be strategically correct while experientially tiring. Future case studies should keep intrinsic loop satisfaction separate from payout expectation, sunk cost, setting expectation and rare-reward relief.

## 5. Cross-case learning: 北斗 vs 新ハナビ

Case Study 01 showed a strong forward-projection architecture:

`state inference → rare-role value → precursor observation → BB continuation → possible value upgrade`

Case Study 02 showed a strong present-interaction architecture:

`aim → stop → read/slip → contradiction/discovery → bonus → technical/RT duty → return`

Common learning:

`RETURN ARCHITECTURE IS UNIVERSAL EVEN WHEN REWARD ARCHITECTURE IS NOT.`

Different learning:

`REPEATED VALUE CAN LIVE IN FUTURE STATE PROJECTION OR IN PRESENT REEL INTERPRETATION.`

Two cases are not enough to decide which architecture Chappy5 should use.

## 6. Why the Reality Baseline remains incomplete

Two deliberately different machines have improved the baseline, but major lineages remain under-covered. The highest-value next gap is **A+ART**, because it combines independently meaningful real bonuses with a longer reward state, state-dependent reel/role meaning, CZ/entry routes, game-count extension and post-bonus/ART transitions.

This directly tests a missing question:

`HOW DOES ONE MACHINE KEEP BONUS, ART, REEL PLAY, STATE INFERENCE AND PRESENTATION COHERENT WITHOUT REDUCING NORMAL PLAY TO TRANSPORT?`

Other future gaps remain: full-announcement Okinawa-type, game-number/zone-led, CZ-breakthrough, pseudo-bonus, modern high-pure-increase smart-slot and other families.
