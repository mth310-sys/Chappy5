## 1. Audio question for Run 3

Game & Reel Run 3 showed that motor HOME is comparatively stable while consequence questions can remain open for multiple games. Visual Run 3 showed that persistent context can remain visible without requiring permanent maximum gaze.

Sound therefore asks:

**Can an old unresolved question remain acoustically present without continuously owning attention, and can a new reel event arrive without producing semantic pile-up?**

The working model is:

`AUDIO HOME -> LOCAL CLAIM -> QUESTION REMAINS OPEN -> ATTENTION RELEASE -> NEW EVENT -> RESOLUTION OR RE-ANCHOR -> AUDIO HOME`

This is different from a simple excitement ladder.

---

## 2. SOURCED FACT — machine architecture supports overlapping temporal layers

The official Universal Entertainment product page identifies the machine as a 2016 bonus+ART machine using the BAZOOKA II cabinet and a full touch LCD. The official page emphasizes both audiovisual presentation and multiple bonus/ART reward layers rather than a single AT ladder.

Source:
https://www.universal-777.com/product/slot/slot_madoka_magica2/

Ichigeki currently summarizes the machine as a real BIG + approximately 1.5 coins/G ART system, with ART entered through CZ, rare roles, bonus and other routes. ART is 50G+α and includes temporary high-consequence zones such as Magica Quest and Walpurgis Night.

Sources:
https://1geki.jp/slot/s_madomagi2/
https://1geki.jp/slot/s_madomagi2/81/

The same strategy corpus documents that normal/CZ presentation can extend across multiple games before the final consequence resolves.

Source:
https://1geki.jp/slot/s_madomagi2/53/

### INTERPRETATION

Because physical play continues while a prior consequence is still unresolved, audio must support two clocks at once:

1. `CURRENT MOTOR CLOCK` — lever / reel / STOP / payout now.
2. `PERSISTENT CONSEQUENCE CLOCK` — what the previous rare role / CZ / state question may still become.

If the persistent clock monopolizes audio every game, the current motor clock loses clarity. If the persistent clock disappears completely, the state can feel forgotten.

### REUSABLE PRINCIPLE

`PERSISTENT CONTEXT SHOULD NOT REQUIRE PERSISTENT ACOUSTIC FOREGROUND.`

## 3. Question-prolonging audio and question-closing audio must be distinguished

### SOURCED FACT

Published normal-play analysis shows multi-game development and battle presentation whose result may become CZ, ART or BIG. This confirms that uncertainty can remain active after the initiating game.

Source:
https://1geki.jp/slot/s_madomagi2/53/

### INTERPRETATION

For audio QA, every non-routine cue should be classified by function rather than strength:

- `OPEN` — creates a new question.
- `PROLONG` — confirms the question is still active but does not resolve it.
- `NARROW` — reduces possible outcomes.
- `CLOSE` — resolves the question.
- `RE-ANCHOR` — gives acoustic ownership back to normal / ART HOME.

A high density of `PROLONG` cues without enough `CLOSE` or `RE-ANCHOR` cues creates listening duty even if each individual sound is short.

### REUSABLE PRINCIPLE

`QUESTION-PROLONGING AUDIO ACCUMULATES ATTENTION DEBT UNLESS CLOSURE OR RELEASE ARRIVES QUICKLY.`

---

## 4. CONTEXT PRESENT is not the same as ATTENTION CLAIM ACTIVE

### INTERPRETATION

Visual Run 3 established the same distinction visually. Sound requires the equivalent separation.

A persistent state may remain acoustically identifiable through a low-demand bed, recurring but predictable loop, or stable background context while the player safely returns primary attention to reels and STOP timing.

The important states are therefore:

`AUDIO CONTEXT PRESENT`

versus

`AUDIO ATTENTION CLAIM ACTIVE`.

A state can be present without continuously demanding interpretation.

### REUSABLE PRINCIPLE

`STATE PRESENCE MAY BE CONTINUOUS; LISTENING DUTY SHOULD BE INTERMITTENT.`

This is especially important in ART and CZ where the state lasts longer than any single required input.

## 5. New reel evidence should outrank stale unresolved audio

### SOURCED FACT

Game & Reel Run 3 records a stable normal routine with relatively sparse extra precision duty. New rare-role evidence can arrive while previous consequence questions remain open.

Repository source:
`docs/research/CASE_STUDY_03_MADOKA_MAGICA_2_GAME_REEL_RUN3.md`

### INTERPRETATION

If a previous question is still represented by foreground audio and a new physical role event occurs, both cannot demand equal semantic priority without increasing ambiguity.

The audio hierarchy should make the newer immediate action/result readable while preserving old context at lower demand.

This does not mean the new event must always be louder. Priority can come from onset timing, brief subtraction of the old layer, spectral separation, silence, or clean sequencing.

### REUSABLE PRINCIPLE

`NEW ACTION-RELEVANT EVIDENCE SHOULD TEMPORARILY OUTRANK STALE UNRESOLVED CONTEXT.`

and

`QUESTION OVERLAP SHOULD BE MIXED AS PRIORITY, NOT STACKED AS EQUAL FOREGROUND.`

## 6. BIG provides a strong test of foreground ownership and return

### SOURCED FACT

The machine uses a real BIG while ART can remain a persistent future-game state. Existing Case Study 03 research documents selectable BIG notification styles that move certainty to different motor boundaries, including lever/reel/payout-related timing.

Repository source:
`docs/research/CASE_STUDY_03_MADOKA_MAGICA_2_SOUND_EXPERIENCE_RUN2.md`

### INTERPRETATION

BIG is therefore a useful foreground-interruption test:

`PREVIOUS HOME -> BIG CLAIM -> BIG SUSTAIN -> BIG END -> RETURN ADDRESS`.

The return is successful only when the player can again hear what state they are in and what action duty is current.

### REUSABLE PRINCIPLE

`AUDIO RE-ANCHOR IS COMPLETE ONLY WHEN STATE IDENTITY AND ACTION DUTY ARE BOTH RESTORED.`

---

## 7. ART music can carry context, but action cues must own required input

### SOURCED FACT

ART is a persistent 50G+α state. Walpurgis Night and other temporary states can interrupt the base ART flow. Public analysis also documents that a BGM change during Walpurgis Night can carry actual continuation/stock information rather than being purely decorative.

Sources:
https://1geki.jp/slot/s_madomagi2/81/
https://www.p-world.co.jp/machine/database/8129
https://xn--mckza4ard4ttb2d.com/madokamagica2-warupurugisu

### INTERPRETATION

This confirms two distinct audio jobs:
- persistent state identity;
- discrete game information.

When music itself acquires game meaning, entry timing becomes information. But once that information is learned, the music should not require constant re-decoding every game.

### REUSABLE PRINCIPLE

`AUDIO CAN CARRY STATE MEMORY CONTINUOUSLY WHILE INFORMATION DUTY OCCURS ONLY AT ENTRY OR CHANGE.`

## 8. Long-form real-play evidence: use for repetition topology, not cabinet acoustics

### VIDEO SOURCE

A verified DMM Pachitown long-form real-play program exists for this exact machine, published 2016-10-14 and framed as a one-day practical-play recording:
https://www.youtube.com/watch?v=BkBa5TGXHek

The accessible indexed evidence confirms the session context and machine identity, but not clean isolated game-by-game audio stems.

### DIRECT OBSERVATION LIMITATION

Compressed hall recordings contain microphone AGC, environmental noise, commentary, editing and unknown machine volume settings. Therefore this pass does not claim:
- exact cue count per 100G;
- exact SPL or frequency response;
- exact speaker count/location;
- exact low-frequency transducer behavior;
- exact duration of every routine SE.

### INTERPRETATION

Long-form footage remains useful for **topology**:
- routine stretches exist between foreground events;
- foreground events occur in clusters around state/reward transitions;
- persistent states sustain context while the player repeatedly returns to lever/STOP operation;
- the experience alternates routine, temporary claim, resolution and return rather than remaining at a single escalation level.

### REUSABLE PRINCIPLE

`LONG-FORM VIDEO CAN SUPPORT ATTENTION-TOPOLOGY CLAIMS WITHOUT SUPPORTING CABINET-ACOUSTIC MEASUREMENT.`

## 9. Audible REST inside an open question

### INTERPRETATION

Visual Run 3 introduced `REST CAN EXIST INSIDE AN OPEN QUESTION`. Sound has the same requirement.

An unresolved consequence does not justify continuous warning-like audio. The player should be allowed to hear a stable, predictable state bed or ordinary operating cadence while the question remains open.

This creates:

`QUESTION OPEN + AUDIO REST`.

The question remains semantically alive without consuming maximum auditory attention.

### REUSABLE PRINCIPLE

`AN OPEN QUESTION DOES NOT REQUIRE AN OPEN ATTENTION CLAIM.`

and

`GOOD SUSPENSE ALLOWS ATTENTION RELEASE BEFORE FINAL RESOLUTION.`

## 10. Run 3 measurement frame handed to QA

Sound & Experience hands forward these metrics:

- `AUDIO CONTEXT PRESENT`
- `AUDIO ATTENTION CLAIM ACTIVE`
- `ATTENTION RELEASE INTERVAL`
- `QUESTION-PROLONG CUE COUNT`
- `QUESTION-CLOSE CUE COUNT`
- `AUDIBLE RE-ANCHOR LATENCY`
- `CONCURRENT AUDIO CLAIM COUNT`
- `NEW-EVIDENCE PRIORITY`
- `ROUTINE-RETURN CLARITY`
- `OPTIONAL LISTENING DUTY` vs `MANDATORY ACTION AUDIO`

For a dry/low-reward sequence and a reward-rich sequence, QA should ask:

1. How long can a consequence remain unresolved without requiring continuous listening?
2. When a new reel event occurs, does audio clearly reprioritize the new immediate evidence?
3. After CZ/BIG/ART foregrounds, how quickly is HOME recognizable by ear?
4. Does reward-rich play increase meaningful closure, or merely increase simultaneous claims?
5. Does dry play preserve routine comfort, or turn every small cue into vigilance duty?

## 11. Provisional Run 3 verdict

Available evidence supports the following provisional conclusion:

`THE MACHINE PLAUSIBLY PROTECTS AUDIO HOME BY LETTING PERSISTENT STATES CARRY CONTEXT WHILE DISCRETE CUES CLAIM ATTENTION AT ACTION OR RESOLUTION BOUNDARIES; THE MAIN FAILURE RISK IS NOT LACK OF SOUND BUT ACCUMULATION OF PROLONGING CUES AND UNRESOLVED LISTENING DUTY WHEN QUESTIONS OVERLAP.`
