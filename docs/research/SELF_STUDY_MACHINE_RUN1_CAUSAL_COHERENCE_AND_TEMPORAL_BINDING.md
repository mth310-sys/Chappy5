# Machine Director Self-Directed Study Run 1 — Causal Coherence and Temporal Binding

> Question: What makes independently correct reel, visual, mechanism and audio responses feel like one physical machine caused them?
> Stage: Stage 1 research only

## 1. Why this topic was chosen
The audits repeatedly identify deterministic reel law, visual motion, audio timing, touch latency and Human evidence as separate gaps. Machine Director's deeper uncertainty is the integration boundary: Chappy5 can improve each subsystem and still fail to feel like one machine if their event timing, causal order and settling behavior disagree.

## 2. What was not understood before
Prior research established that timing matters, but did not sufficiently distinguish numerical simultaneity from perceived causality, nor define whether “perfectly simultaneous” cross-modal output is always the correct target.

## 3. What was investigated
Cross-modal synchrony/causality research, interactive sound-feedback timing, game latency/jitter evidence, action-effect temporal binding, and prior Chappy5 findings on STOP rhythm, mechanism settling and causal audio.

## 4. Newly learned
### SOURCED FACT
Vroomen & Keetels (Cognition, 2020) found that the timing producing strongest audiovisual causal bounce and the timing judged maximally synchronous were not identical; causality also changed the temporal binding window. Therefore perceived cause and perceived simultaneity are distinct targets.

Uchiyama et al. (2009) reported that delayed sound feedback degraded operation performance and that the effect depended not only on delay magnitude but on relation to the visual beat.

Normoyle et al. (2014) separated constant latency from jitter in game responsiveness; variable delay impaired adaptation/performance and perceived motion quality more strongly than a stable delay condition in their task.

Research on multisensory recalibration shows repeated exposure to audiovisual asynchrony can shift perceived simultaneity, meaning a player can adapt to timing error rather than the system becoming objectively correct.

### INTERPRETATION
For a pachislot-like repeated motor loop, a single global “everything at t=0” rule is too crude. STOP input, reel deceleration, stop impact, lamp response, mechanism impulse and sound onset can form a causal micro-sequence. The important property is that the sequence reads as one event with stable authorship, not that all channels share identical onset timestamps.

Repeated timing consistency is itself part of machine identity. A player may tolerate or adapt to a stable offset while variable subsystem drift weakens learnability and ownership.

## 5. What changed from prior understanding
Previous working language emphasized synchronization. The stronger model is **causal choreography**: author an event's causal order, then measure the distribution of each boundary. Synchrony is one possible relationship inside that choreography, not the universal goal.

## 6. Reusable design principles
`ONE MACHINE FEEL REQUIRES ONE CAUSAL STORY, NOT MERELY MANY CORRECT SUBSYSTEMS.`

`PERCEIVED CAUSALITY AND PERCEIVED SIMULTANEITY ARE DIFFERENT ACCEPTANCE TARGETS.`

`CONSISTENT EVENT RELATIONSHIPS ARE PART OF MACHINE IDENTITY; JITTER IS NOT JUST A PERFORMANCE METRIC.`

`AUTHOR THE CAUSAL MICRO-SEQUENCE FIRST; THEN ASSIGN VISUAL, AUDIO AND MECHANICAL ONSETS TO IT.`

`ADAPTATION TO BAD TIMING IS NOT PROOF OF GOOD TIMING.`

## 7. Conditions / misuse risks
- Do not import timing thresholds from unrelated lab tasks as pachislot pass/fail numbers.
- Deliberate anticipation/delay can be meaningful, but only when it preserves causal legibility; arbitrary lag should not be romanticized as “weight.”
- Stable delay is not automatically acceptable merely because jitter can be worse.
- Phone audio/display/touch pipelines differ, so desktop measurements cannot certify target iPhone experience.

## 8. What remains unknown
- Chappy5-specific perceptual tolerance windows for STOP→reel→visual→sound sequences on the target iPhone;
- whether different event classes need different causal timing contracts;
- how mechanism-like visual mass and audio transient timing interact when no physical mechanism exists;
- how much long-session adaptation hides timing defects.

## 9. Worth studying next
A future research-only measurement design for a `CAUSAL_EVENT_CONTRACT`: event classes, intended causal order, target-device timestamp capture, jitter distributions and Human causal-coherence judgments. This remains a future consideration, not implementation.

## 10. Possible future production value
If later Human-approved production begins, this model can keep Game/Reel/Visual/Mechanism/Audio from becoming five independently polished products. It provides a way to judge whether BET, START and each STOP cause a coherent whole-machine response and can guide integration priorities before decorative escalation.
