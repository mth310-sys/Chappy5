# 開始ホール130台 機種構成 v0.1

更新日: 2026-09-01

目的: 5号機時代をモデルにしたゲーム開始時点について、最大216台の建物に130台だけ設置された「近隣大型店に客を奪われて弱っている地方ホール」の初期機種構成を、実機DBを研究基準として仮置きする。

**位置づけ:** 仮決定前の計算用構成。実在機名は研究用。製品版では架空機種・架空メーカーへ変換する。

## 1. 前提

- 最大設置能力: 216台
- 開始設置: 130台
- 空き能力: 86台
- 20円スロット中心
- 開始時代: 実在5号機初期〜普及期をモデルにした架空時代
- 実機DB進捗正本: `docs/real_machine_db/LATEST_HANDOFF.md`
- 現在の研究範囲: 2005年〜2007-09-10、LATEST_HANDOFF基準156件

## 2. 130台のタイプ構成

| 区分 | 台数 | 構成比 | 役割 |
|---|---:|---:|---|
| 25Φ 完全告知ノーマル | 30 | 23.1% | 常連の土台・低コスト運用・設定期待の中心 |
| 30Φ 沖スロ系ノーマル | 28 | 21.5% | 地方/沖縄モデル店の地域色・固定客 |
| A+RT / ボーナス+RT 主力 | 32 | 24.6% | 5号機らしい主力集客群 |
| 新しめのART/CZ系 | 12 | 9.2% | 新台感・話題性。ただし導入数は少ない |
| 旧台・バラエティ | 28 | 21.5% | 資金不足で撤去し切れず残っている多品種群 |
| **合計** | **130** | **100%** | |

この構成ではノーマル/沖スロが58台、約44.6%。弱った地方店でも固定客を支える軸を残しつつ、5号機特有のRT/ARTへの世代移行が見える。

## 3. 実機DBを使った代表配置

### 25Φ 完全告知ノーマル 30台

代表基準:
- `アイムジャグラーEX` 18台
- その他の5号機ノーマル/告知系 12台

アイムジャグラーEX DB確認値:
- systemType: ノーマル / 完全告知 / ボーナス主体
- 設定別機械割の一系統: 96.91%〜106.55%
- BIG約324〜325枚 / REG約104枚
- 50枚ベース補助値: 約34.5G、設定6約35.8G

開始店では最も台数の多い単一主力候補とする。

### 30Φ 沖スロ系ノーマル 28台

代表基準:
- `ニューハナハナ-30` 14台
- `ビッグハイビ-30` 8台
- その他30Φ/沖スロ系 6台

ニューハナハナ-30 DB確認値:
- systemType: ノーマル / 完全告知 / 30Φ
- 市場掲載機械割: 95%〜107%
- BIG約300枚 / REG約150枚

沖スロ比率を高めにすることで、ゲーム開始店の地域的な個性を出す。

### A+RT / ボーナス+RT 主力 32台

代表基準:
- `スパイダーマン2` 10台
- `リングにかけろ1` 10台
- 2005年版`新世紀エヴァンゲリオン`等のRT/ボーナス系 6台
- その他A+RT系 6台

スパイダーマン2 DB確認値:
- ボーナス+RT / パンク回避型・技術介入
- 設定1〜6機械割: 96.7%〜117.3%
- RT純増約+0.4枚/G

リングにかけろ1 DB確認値:
- A+RT
- 設定1〜6機械割: 98.0%〜119.5%
- RT純増約+0.4枚/G

高設定域が非常に強いため、設定投入時の粗利負担がノーマル以上に大きくなる機種群として扱う。

### 新しめのART/CZ系 12台

代表基準:
- `戦国無双` 4台
- `マジカルハロウィン` 4台
- `恐怖新聞` 4台

最新研究境界の恐怖新聞:
- A+ART / ボーナス+CZ+ART
- CZ 30G
- ART 100G
- ART純増資料に約+0.4〜+0.6枚/GのCONFLICTあり

この12台は「近隣大型店には大量導入で負けているが、何とか新しい流れにも追随している」ことを表す。

### 旧台・バラエティ 28台

- 2005〜2006年導入機を中心に1〜4台ずつ残存
- 人気低下機、低稼働機、中古導入機を混在
- 撤去してもすぐ新台に交換できない資金不足を表現
- ゲーム開始後の中古売買・撤去・島再編チュートリアルに使う

## 4. 初期設定配分 v0.1

弱ったホールの計算開始点として、130台全体を以下で仮置きする。

| 設定 | 台数 | 比率 |
|---:|---:|---:|
| 1 | 80 | 61.5% |
| 2 | 28 | 21.5% |
| 3 | 14 | 10.8% |
| 4 | 6 | 4.6% |
| 5 | 2 | 1.5% |
| 6 | 0 | 0% |
| **合計** | **130** | **100%** |

これは「全台ベタ1」ではないが、客から見れば弱い店という状態。

設定4以上8台は完全ランダム配置ではなく、主力ノーマル・沖スロ・RT主力へ分散させる。設定5の2台は客に見つかる可能性はあるが、店全体を強いと評価させるほどではない。

## 5. 経年状態 v0.1

130台を機械状態でも分ける。

| 状態 | 台数 | 意味 |
|---|---:|---|
| 比較的新しい | 20 | 2007年中盤〜9月付近、新台感が残る |
| 主力現役 | 50 | 2006後半〜2007前半、稼働の中心 |
| 古い | 40 | 2005〜2006前半、人気低下 |
| かなり古い/整理候補 | 20 | 撤去・売却・バラエティ整理の対象 |
| **合計** | **130** | |

経年は故障率・人気・中古価値・客の新鮮味へ影響させる候補とする。

## 6. 初期ホールの狙う状態

開始日は「潰れる寸前」ではなく、まだ営業継続できるがジワジワ客を失っている状態とする。

特徴:
- 130台あるが空き能力86台が目立つ
- ノーマル/沖スロ固定客が店を支える
- RT主力にも一定の客はいる
- 最新ART系は12台しかなく、競合に物量で負ける
- バラエティ28台の一部はほぼ動かない
- 設定1比率が高く、店の設定期待が低い
- しかし高設定を完全に使っていないわけではない

これによりプレイヤーは初日から、

`中古で安く入替える / 旧台を残す / 主力へ設定を使う / 新台資金を貯める / 沖スロを強くする / RT・ARTへ投資する`

など複数の再建ルートを取れる。

## 7. 次の計算

次段階では130台をタイプ別に一括平均せず、少なくとも5区分に分けて以下を計算する。

1. 区分別の初期OUT
2. 機種人気補正
3. 設定配分による理論出玉率
4. コイン単価特性
5. 売上
6. セーフ
7. ホール差枚
8. 粗利
9. 営業中に見える出玉から客AIが設定期待を更新
10. 翌日稼働へ反映

最終的には130個のmachineInstanceを生成し、1台ごとに `machineId / setting / age / condition / popularity / out / safe / sales / grossProfit` を持たせる。
