## 現時点の比較結論

### SIGNAL//3
最も“遊創舎らしい未知感”を作れる候補。Signature SoundとVisual/Audio同期の独自性は3案中最上位級。一方、パチスロ初心者が5分で理解できるかが最大の壁。Game & Reelが「波形を読む面白さ」を出目として成立させられない場合、液晶計器ゲームへ転落する。

### FORGE//HEART
STOP操作の身体感覚とREALITY/PRESENCEは最も強く作りやすい。ただし強い打撃音・赤熱色・可動物を多用すると30分では爽快でも3時間で疲れる。通常時の静かな“余白”と、役物を動かさないゲームでもリール単体が面白いことが生存条件。

### VAULT://3
現時点で最も「なぜリールを止めるのか」が一文で伝わる。円形LOCK RINGの看板性、3rd STOP直後の解放感、4段階解除音も強い。最大の危険は分かりやすすぎて浅くなること。出目のニアミス、階層ごとのルール、通常100Gの変化が作れなければ“毎G同じ鍵合わせ”になる。

## Machine Director暫定順位

**順位は未確定。採択判断ではない。**

1. `VAULT://3` — 現時点でパチスロ必然性と完成機の想像しやすさが最も高い。
2. `SIGNAL//3` — 独自性とSoundの看板性で最も伸びしろがある。
3. `FORGE//HEART` — REALITYは強いが長時間疲労リスクが最も大きい。

ただし次DirectorのGame & Reel検証で順位が逆転し得る。特にVAULTの出目が浅い、SIGNALの同期出目が具体化できる、FORGEが通常時を静かに成立できる、のいずれかで評価は変わる。

## 次に解くべき共通問題

**3案とも、内部当選後の見せ方として3STOPを使うだけでは失格。**

Game & Reel Directorは、各案について以下を具体化する。

1. 1st STOPで何が分かるか。
2. 2nd STOPで期待がどう変化するか。
3. 3rd STOPで何が確定するか。
4. 液晶を隠しても出目だけで“惜しい／強い／異常”が読めるか。
5. 通常100Gを回したとき、同じ3段演出の反復にならないか。
6. 初心者と熟練者の両方にSTOP理由があるか。

この6問を通過できない候補は、テーマが強くても看板機候補から落とす。
