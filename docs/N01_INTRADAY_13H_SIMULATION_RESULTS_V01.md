## 4. 確認できた挙動

### 朝は設定配分が見えない
10時台の平均着席は全配分1.77〜1.79台でほぼ同じ。客AIは内部設定を読んでいないため、開店直後から全台系だけ満席になる不自然な挙動は発生していない。

### 時間とともに差が生まれる
19-20時では:
- A 2.77台
- B 3.01台
- C 3.10台
- D 3.43台

公開データが育った後に強い配分ほど客から評価される方向が確認できた。

### 閉店前でも履歴の影響が残る
22-23時は全配分で着席が落ちるが、A 1.07台に対しD 1.44台。closingPenaltyだけで全店一律に同じ稼働へ潰れず、その日の評価差が残っている。

### 高設定投入は単日利益を保証しない
Dは島アウトが最大だが、暫定モデルでは期待粗利 -50,106円。高設定の価値は同日島粗利だけでは回収できず、翌日来店・他島波及・常連化まで含めて評価する必要がある。

## 5. 問題点

今回のモデルでは配分差による島アウト差がA→Dで約14%に留まった。これは一日の公開結果だけで来店母数を急激に変えない設計としては妥当候補だが、高設定投入コストに対する翌日以降の価値を検証するには複数日モデルが必要。

また現在のアウトは `gamesPlayed × 3` の簡易換算であり、リプレイ・小役・ボーナス中投入を含む厳密なアウト計数ではない。N-01の最終経済モデルではゲーム数とアウトを独立して生成する。

客AIも現段階では集団近似。個々の客について資金、滞在可能時間、持ちメダル、設定推測精度、常連度をまだ持たせていない。

## 6. 設計上の重要結論

固定アウト方式から、`設定配分 → 公開結果 → 客の推測 → 時間別着席 → 実稼働` という因果へ移行できる見込みが確認できた。

特に朝の時点では配分差がほぼなく、午後以降に観測データから差が生じることは、営業フェーズを眺めるゲームとして重要。

ただしこのv0.1結果を正式バランス値として採用しない。

## 7. 次の検証

次は単日を閉じず、同じ店舗で7営業日を連続させる。

追加する最小状態:
- storeExpectation の日跨ぎ保持
- 前日島評価
- 常連客の再来店傾向
- 新規客の基礎流入
- 営業方針変更による期待の上昇/低下

比較例:
1. 7日間ずっと低設定中心
2. 低設定中心5日 + 週末メリハリ2日
3. 中間中心を継続
4. 1日だけ全台系を実施し、その後回収

これにより「今日赤字を出して設定を使うことが、数日後の稼働と利益に返ってくるか」を初めて検証できる。
