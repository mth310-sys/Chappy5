# N-01 7日連続営業シミュレーション v0.1

更新日: 2026-08-31

目的: 単日13時間モデルの結果を日跨ぎさせ、設定投入による当日損失と翌日以降の稼働価値を初めて同じ尺度で比較する。

注意: これは構造検証用。正式バランス値ではない。単日基礎値は `N01_INTRADAY_13H_SIMULATION_RESULTS_V01.md` の各5,000日試験平均を使用する。

## 1. 日跨ぎモデル

開始時店舗期待 `storeExpectation = 0.0`。

前日までの期待による翌日の来店母数補正を暫定的に:

`trafficFactor = clamp(1 + 0.35 * storeExpectation, 0.70, 1.30)`

とする。

当日のout / sales / grossProfitは単日基礎値にtrafficFactorを掛ける。

閉店後:

`nextExpectation = oldExpectation * 0.75 + todayObservedStrength * 0.25`

単日観測強度は前回試験の閉店時期待指標を暫定利用:
- A 低設定中心: -0.156
- B 中間中心: +0.067
- C メリハリ: +0.210
- D 全台系: +0.474

このモデルでは客は実設定を知らず、公開結果から形成された店への期待だけを翌日へ持ち越す。

## 2. 比較営業方針

1. 7日間すべてA低設定中心
2. Aを5日 + 週末Cメリハリを2日
3. 7日間すべてB中間中心
4. 初日D全台系 + その後A低設定中心を6日

曜日固有の客数増減はまだ入れない。ここでは設定営業の記憶効果だけを分離して見る。

## 4. 読み取れること

### 低設定7日は短期利益最大
この暫定モデルでは7日低設定が約99,800円で最大の期待粗利。ただしstoreExpectationは -0.135まで低下し、翌週へ悪い状態を持ち越す。

つまり一週間だけ切り取ると強いが、長期では来店母数を削り続ける可能性がある。

### 平日回収→週末メリハリは黒字を残して期待を戻せる
A×5 + C×2は約24,600円の黒字を残しつつ、期待を +0.025まで戻した。

「毎日高設定」ではなく、回収日と還元日を組み合わせる経営判断が成立する可能性を示す。

### 中間継続は稼働最大だが赤字
7日中間はアウト約316,000で4案中最大。ただし粗利は約-36,400円。

N-01暫定値では中間設定配分がまだ甘すぎる可能性がある。実ゲームでは機種構成、交換条件、他島粗利を含めて評価する必要がある。

### 全台系1日→回収は一部を取り戻す
初日に大きな赤字を出してDを実施し、その後Aへ戻すと7日累計では約+37,700円まで回復した。

しかし7日終了時期待は -0.107。強い営業1日だけでは、その後6日間の回収営業によって信用をかなり失う。

これは「一度出せば永久に人気店」という不自然な挙動を避けられる。

## 5. 重要な設計結論

設定投入は単日の粗利だけで評価しない。

経営上の価値を:

`当日粗利 + 将来来店価値 + 他島への波及価値`

として考える必要がある。

一方で、現在のモデルではstoreExpectationが店舗全体の1変数しかない。これだけでは「ノーマルは強いがATは弱い」「週末だけ期待できる」「この島だけ強い」といった客の記憶を表現できない。

## 6. 次に分解する記憶

次段階ではstoreExpectationを最低でも以下へ分解する。

- `storeTrust`: 店全体への長期信用
- `normalExpectation`: ノーマル機への設定期待
- `islandExpectation`: 対象島への期待
- `dayPatternExpectation`: 曜日/特定日の期待

客ごとに記憶量を変える。

常連:
- 過去数日〜数週を比較的強く記憶
- 曜日傾向を学習
- 島ごとの強弱を学習

一見客:
- 当日の稼働感や目立つ出玉を重視
- 長期履歴の影響は弱い

## 7. 現段階で採用しない値

以下はすべて調整対象:
- trafficFactorの0.35
- expectation更新0.75/0.25
- 単日観測強度
- N-01コイン単価
- N-01設定別出玉率

今回採用候補なのは数値そのものではなく、`設定営業 → 公開結果 → 客の記憶 → 翌日来店 → 将来粗利` の因果構造。

## 8. 次の検証

7日では低設定営業の長期ペナルティがまだ十分に見えないため、次は30日営業へ拡張する。

比較候補:
- 常時低設定
- 毎週末メリハリ
- 月に数回の強い日
- 安定中間営業
- 強い日直後に急回収
