# ゲーム開始時代モデル

更新日: 2026-08-31
状態: **採用確定**

## 決定事項

パチスロホール経営ゲームのゲーム開始時代は、**現実の5号機時代をモデルにした架空のパチスロ業界**とする。

- ゲーム開始時の機種環境・市場・ホール設備・経営環境は、現実の5号機時代の研究データを基礎に設計する。
- 現実の実機・メーカー・規則名称をそのまま最終ゲームへコピーするのではなく、遊創舎独自の架空機種・架空メーカー・架空規則へ変換する。
- 実機データベースは、架空機種の性能・市場特性・時代変化を作るための研究基盤として使用する。
- ゲーム進行に伴い、現実の5号機後期、5.5/5.9号機、6号機、6.5号機、スマスロ等の変遷を研究し、架空世界の世代交代・規則変更として表現する方向とする。
- 規則変更、旧世代機の撤去期限、新世代機の登場などをホール経営へ影響する時代イベントとして扱える設計を目指す。
- ゲーム開始時のホールは古い機種も抱えた状態とし、中古機を活用しながら立て直していく経営と相性を持たせる。

## 関連する仮決定

ホールレイアウトは現時点で仮決定。
- 最大設置容量: 216台
- 開始時設置: 130台
- 4遊技ブロック
- 各ブロック3島、合計12島
- 1島18台（片面9台×両面）を最大容量計算の基準とする

レイアウトの細部寸法・設備寸法等は今後調整する。
