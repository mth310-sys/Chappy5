## 今回追加

### `machines/2007-01-08_battle-leaguer-x.md`
- バトルリーガーX / SANKYO / SANKYO初の5号機。
- SANKYO公式と当時グリーンべると資料で2007年1月、4段階設定、通常時100Gごとのリーガーチャンス抽せん、RT「ジェットゾーン」純増約0.8枚/Gを確認。
- 当時業界記事では納品2007-01-08開始予定、リーガーチャンス→RT 15%、BIG後スーパーリーガーチャンス→RT 30%。
- 公式スペックは設定1〜4でBB/RB各1/546→1/442。
- 5号機クロニクルには設定1〜6のSUPER BIG/BIG/MIDDLE表があり、公式の4段階設定と矛盾。平均・統合せずCONFLICTとして保存。
- resetBehaviorは設定変更時の100G周期/RT関連状態の扱いを十分再探索したが高信頼資料で確定できずPARTIAL。

### `machines/2007-01_im-juggler-ex.md`
- アイムジャグラーEX / 北電子 / 5号機ノーマル完全告知。
- パチビーでは導入2007-01-09、北電子担当者の後年回顧では2007-01-07リリース。月単位2007-01で保持し日付差はCONFLICT。
- パチマガスロマガでBIG 1/287.44→1/268.59、REG 1/455.11→1/268.59、合算1/176.17→1/134.30、シミュレートPAYOUT 96.91〜106.55%。
- BIG約324〜325枚、REG約104枚。
- 5号機アイム系の50枚コイン持ちは補助資料で設定1〜5約34.5G、設定6約35.8G。初代単独値とは断定せず補助扱い。
- resetBehaviorは天井・通常時モード・ART/AT・有利区間が非該当。朝一ガックンは後年解析単一系統で確認したためANALYSIS_SINGLE扱い。
