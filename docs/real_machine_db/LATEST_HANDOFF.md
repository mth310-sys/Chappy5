## v0.7 resetBehavior

- 初代 `シスタークエスト / SNKプレイモア / 2007` と `設定変更 / リセット / 朝一 / 据え置き / 電源OFF / 天井 / 宵越し / ガックン` を組み替え、業界記事、当時解析、古いDB、当時スロット板テンプレ保存資料、後年5号機DBを横断。
- 当時スロット板テンプレ保存資料では、**設定変更しても天井までのG数を引き継ぐ / 宵越し可能**と明記。初代固有情報として採用するが、メーカー公式/業界一次で同挙動を再照合できていないため `ANALYSIS_SINGLE / CONTEMPORARY_COMMUNITY_ARCHIVE` とした。
- 通常時天井はボーナス間999G消化後に次回ボーナスまでの救済RT。パチマガスロマガには「ボーナス間1000Gハマリ」の表記があり、突入境界の表現差として両方保持。
- 同当時資料では、設定変更の有無にかかわらず**電源OFFで2時間放置すると液晶ストーリーが1話へ戻る**。これは液晶表示の初期化であり、天井カウンタリセットとは扱わない。
- 滞在ステージによる設定変更判別は不可能との当時記述あり。
- 天井RT滞在中そのものを設定変更/電断した際のRT状態継続可否、本機固有のリールガックンは十分再探索後も `UNVERIFIED`。
- 設定変更専用モード、短縮天井、朝一当選率優遇、公開リセット恩恵率は `NONE_CONFIRMED`。
- 有利区間は `NOT_APPLICABLE`。
