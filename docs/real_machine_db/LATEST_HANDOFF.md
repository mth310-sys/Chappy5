## 今回の確認・追加

### 熊酒場

- ネット5号機第2弾。グリーンべると/P-WORLD当時記事で2007-04-15納品開始予定を確認。
- 設定1/3/5/7の4段階。
- K-Naviで機械割98.8/100.2/104.5/108.4%、BIG 1/277→1/235、REG 1/452→1/381、合算1/172→1/146を取得。
- 当時記事でBIG純増約312枚、REG約117枚、1000円あたり約33〜35Gを取得。
- 設定7 BIGは当時記事約1/239、K-Navi 1/235でCONFLICT。平均化せず双方保持。
- resetBehaviorは設定変更/据え置き/電源OFF ON/天井/モード/ガックンまで再探索したが、本機固有の高信頼な変更判別や電断処理は未確認。通常時天井・朝一専用モード・有利区間は確認されず。

### ダンス☆マン

- アリストクラートテクノロジーズ。グリーンべると当時記事で2007年4月中旬納品予定。
- BIG約280枚、REG/CT相当約110枚、2ART「アンコールタイム」「ダンスライブ」を確認。
- 5号機クロニクルで設定1〜6機械割95.0〜118.0%、BIG合算1/397.2〜1/280.1、REG/CT 1/1191.6、合算1/297.9〜1/226.8を取得。別系統資料でも照合。
- 後年回顧資料ではART純増約0.8枚/G。
- 50枚ベースは表記揺れ/1000円/50枚/コイン持ち等で再探索したが比較可能な確定値に到達せずUNVERIFIED。
- resetBehaviorは設定変更/据え置き/電断/天井/モード/ガックン/ART持越しまで再探索したが、本機固有のART状態処理・変更判別は高信頼資料で確定できずPARTIAL。
