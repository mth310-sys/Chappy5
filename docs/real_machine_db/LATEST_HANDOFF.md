### QA修正点

前引継ぎの入口情報には「BIG最大416枚 + 50G RT / REG最大104枚」とする記述があったが、当時のP_Style777とパチマガスロマガ系資料では4種ボーナス構成、払い出し345/240/240/120枚、赤7後200G・白7後50G RTで整合する。入口情報は別定義または別機混同の可能性が高いため、新レコードでは採用せず `conflicts` に残した。
