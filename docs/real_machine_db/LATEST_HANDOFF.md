### resetBehavior（297）

- `settingChangeBehavior`: `UNVERIFIED_AFTER_RESEARCH` — パチマガスロマガ機種メニューに「攻め時・ヤメ時・設定変更時」項目の存在は確認したが本機固有本文を取得できず、変更時の天井カウンタ/RT状態を確定できない。
- `carryOverBehavior`: `UNVERIFIED_AFTER_RESEARCH` — 据え置き時に天井カウンタを引き継ぐか直接確定できず。
- `powerCycleBehavior`: `UNVERIFIED_AFTER_RESEARCH` — 電源OFF→ONのみの場合の天井カウンタ/RT状態処理を直接確定できず。
- `gameCounterReset`: `UNVERIFIED_AFTER_RESEARCH` — 通常時救済天井が存在するため重要だが、設定変更時リセット/据え置き引継ぎを一般論で補間しない。
- `ceilingAfterReset`: `NONE_CONFIRMED_AFTER_RESEARCH` — リセット専用短縮天井/朝一専用天井数値は確認なし。ただし通常天井カウンタ自体の変更時処理は未確定。
- `modeAfterReset`: `NOT_APPLICABLE_OR_NONE_CONFIRMED` — 朝一専用モード振り分けは確認なし。
- `stateAfterReset`: `UNVERIFIED_AFTER_RESEARCH` — 天井RT状態の変更/据え置き/電断時処理を本機固有資料で確定できず。
- `advantageousSectionReset`: `NOT_APPLICABLE`（5号機・有利区間制度前）。
- `resetBenefits`: `NONE_CONFIRMED_AFTER_RESEARCH`。
- `resetPenalties`: `NONE_CONFIRMED_AFTER_RESEARCH`。
- `resetDetection`: `UNVERIFIED_AFTER_RESEARCH` — 機種名/型式/メーカー/全日遊連と設定変更・リセット・朝一・据え置き・電源OFF ON・天井短縮・ガックン・初期出目・変更判別・RTを組み替え、当時業界記事・パチマガ系・旧DB・回顧資料を横断したが本機固有判別条件を確定できず。
- `numericResetData`: 通常天井候補BIG後700G / REG後500G（低信頼単一資料）。リセット専用数値は `NONE_CONFIRMED_AFTER_RESEARCH`。
