## resetBehavior v0.7

- **設定変更**: BG→ART非当選回数で管理される救済天井進捗、選択済み天井、ART/RT/CZ状態が設定変更でクリア・再抽選・引継ぎのどれになるかを本機固有の確定資料で回収できず `UNVERIFIED_AFTER_RESEARCH`。
- **据え置き**: BG非当選連続回数とART関連状態の翌日持越しを直接確定できず `UNVERIFIED_AFTER_RESEARCH`。一般論からの推測は採用しない。
- **電源OFF→ON**: BG非当選回数、ART/RT/CZ状態、初期出目・ステージ等の復帰処理を確定できず `UNVERIFIED_AFTER_RESEARCH`。
- **ゲーム数・天井**: 通常G数天井は `NOT_APPLICABLE`。通常仕様としてBG→ART非当選5〜12連続の救済天井あり。設定変更時の進捗処理・再抽選は未確定。
- **モード・状態**: 長期の通常G数モードは確認せず。ART継続率・救済天井内部値・ART/RT/CZ状態のreset時処理は未確定。
- **有利区間**: `NOT_APPLICABLE`（5号機・制度前）。
- **朝一恩恵/不利**: 設定変更専用の短縮天井、ART優遇、朝一当選率等は `NONE_CONFIRMED_AFTER_RESEARCH`。BG非当選回数進捗消失も根拠がないため不利と断定しない。
- **変更判別**: ガックン、初期出目、液晶/ステージ等を多段再探索したが、本機固有の確定根拠を回収できず `UNVERIFIED_AFTER_RESEARCH`。
