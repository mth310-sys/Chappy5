- **リセット短縮天井**: `NOT_APPLICABLE`。

- **状態**: RT/ART/CZ状態は非搭載。詳細ボーナスフラグ処理等は完全再現用のため収集外。

- **変更判別**: `ガックン / 初期出目 / CHANCEランプ / 朝一挙動` を含め再探索したが `UNVERIFIED_AFTER_RESEARCH`。
