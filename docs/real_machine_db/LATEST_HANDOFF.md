## 今回の確認・追加

### スロットチャンネルTV

- アビリット。グリーンべると/P-WORLD当時記事で2007-04-01納品開始を確認。HAZUSEの2007年2月表記は発表/解析掲載時期として分離し、実導入基準では4月へ配置。
- 設定1/2/5/6の4段階。
- パチマガスロマガで赤7BIG 1/1057.03〜1/936.23、青7BIG 1/736.36〜1/541.62、REG 1/1057.03〜1/936.23、合算1/307.68〜1/251.10を取得。
- 1000円あたり44.81/45.34/45.88/46.93Gを取得。HAZUSEの約44Gとも整合。
- 赤7BIG約380枚、青7BIG約310枚、REG約108〜110枚。青7BIG/REG後に50G RT「ゴールデンタイム」。
- 機械割はパチマガスロマガのシミュレート値97.29/100.63/103.85/107.18%とHAZUSE当時解析96.1/99.2/102.1/105.1%が競合するため平均化せずCONFLICT保持。
- RT純増/Gは再探索後も比較可能な確定値に到達せずUNVERIFIED。
- resetBehaviorは設定変更/据え置き/電断/天井/モード/ガックン/RT持越しまで検索語を分岐したが、本機固有のRT状態処理・変更判別は高信頼資料で確定できずPARTIAL。通常時ゲーム数天井・朝一専用モード・有利区間は確認されず。

### スーパーボム

- SNKプレイモア。グリーンべると/P-WORLD当時記事で2007-04-08納品開始を確認。GitHub既存検索で未登録だったため4月漏れとして新規追加。
- 設定1〜6。pacnkでBIG 1/376.60〜1/280.10、CB 1/753.30〜1/560.10、PAYOUT 96〜109%を取得。
- パチマガスロマガで1000円あたり34.70〜35.94Gを取得。
- BIG約250枚、CB/RB約204枚。
- BIG後32Gの「ボンバーチャンス」からRT「ボンバーゾーン」へ約25%、CB/RB後128Gの高確から約11%。RTは次回ボーナスまで、最大5000G、純増約0.6枚/G。
- 業界記事では204枚側をREG、解析サイトではCBと表記するため役名称差を保持。獲得性能は約204枚で一致。
- resetBehaviorは設定変更/据え置き/電源OFF ON/RT/ボンバーゾーン/ガックン等へ再探索したが、RT/CZ状態の変更時・電断時処理や変更判別は本機固有資料で確定できずPARTIAL。通常時ゲーム数天井・朝一専用モード・有利区間は確認されず。
