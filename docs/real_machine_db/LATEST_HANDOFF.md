## 今回新規追加

### アストロ球団

- `docs/real_machine_db/machines/2007-05-06_astro-kyudan.md`
- JPS（ジェイピーエス） / 総発売元トレード。正式型式名 `モエロアストロキュウダン2`。
- 2007-03-19発表会、当時グリーンべるとで **2007-05-06納品開始予定**を確認。
- 5号機初期のボーナス+RT機。通常状態72G消化後およびBB/CT後に通常RTへ移行し、通常RT中のアストロチャンス成功で `アストロタイム` へ。アストロタイムは3種類のチェリーをナビしてパンクを回避し、ボーナス成立までRTを延命する方式。
- BIG合成 1/425.56〜1/277.69、CT合成 1/1424.70〜1/668.73、ボーナス合成 1/327.68〜1/196.22。
- BIG: 規定払い出し300枚 / 純増約265枚。CT: 規定払い出し59枚 / 純増約52枚。当時業界記事の概数約260枚/約50枚とも整合。
- ノーマルRT純増はK-Naviで約+1.0枚/G。
- 設定別機械割は5号機クロニクルで、設定1 96.2〜98.9%、設定2 99.3〜102.5%、設定3 102.0〜105.7%、設定4 105.9〜109.7%、設定5 109.5〜113.6%、設定6 110.1〜112.6%。単一値ではなく攻略条件差を含む可能性があるため、平均せずレンジのまま保持。
- 50枚あたりゲーム数は `アストロ球団 / モエロアストロキュウダン2 / JPS / 50枚 / 1000円 / ベース / コイン持ち / 回転数` 等へ検索語を変え、当時業界記事・パチマガスロマガ・K-Navi・5号機DB・回顧資料を横断したが、比較可能な値を確定できず `UNVERIFIED`。
- 性能コアは `PARTIAL`。欠損理由は50枚ベースと、機械割レンジの各条件定義の未確定。

## アストロ球団 resetBehavior

- 設定変更/据え置き/電源OFF→ON/朝一/ガックン/RT残存/72G進行を表記揺れ・正式型式名込みで再探索。
- 後年実戦回顧に「設定変更でRT側の枚数上限が再セット」「据え置きで状態が残ればRT状態」という趣旨の記述を確認したが、一次/高信頼解析資料で照合できていないため `ANALYSIS_SINGLE` の参考情報に限定し、確定値として扱わない。
- 通常RT/アストロタイム、内部差枚上限、72G進行が設定変更/据え置き/電源OFF→ONでどう処理されるかは `UNVERIFIED`。
- 通常状態72G後にRTへ移る仕様は確定しているが、これはリセット短縮天井ではない。
- 朝一専用モード、設定変更専用の当選率/恩恵数値、ガックン等変更判別は `NONE_CONFIRMED / UNVERIFIED`。
- 有利区間は `NOT_APPLICABLE`。
- resetBehavior QAは `PARTIAL`。
