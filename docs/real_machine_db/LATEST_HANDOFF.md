### 3. `machines/2006-11_garou-densetsu.md`
- 餓狼伝説 / SNKプレイモア。
- 3種BIG + AT「餓狼チャンス」。
- RED/WHITE/BLUE BIGは各設定で同確率、1/624.2〜1/570.0、BIG合成1/208.1〜1/190.0。
- 機械割96.4〜110.6%。pacnk精密値と5号機クロニクルが丸め整合。
- 通常約33G/50枚、餓狼チャンス中は80G以上/50枚相当までベース改善する当時業界資料あり。
- 餓狼チャンスは増加型ATではなく3択ベルナビによるコイン持ち改善型。
- 各BIG獲得目安はRED約300枚 / WHITE約200枚 / BLUE約100枚（二次資料）。
