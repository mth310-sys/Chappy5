## 今回の確認・修正

### やったネ！はるみちゃん2

- BELLCO現存メーカー情報でヤーマ、2007年4月、4種類スペック同時展開の独立機種「やったネ!はるみちゃん2」を確認。
- 当時グリーンべるとで2007-04-15納品開始予定、3段階設定、BIG純増約310枚、FRT約+0.85枚/G、プレミアム3333G/都BIG後222G、合算設定1 1/468〜設定3 1/390、1000円約40Gを確認。
- パチマガスロマガで設定別BIG合算1/468.11・1/420.10・1/390.10、図柄別BIG確率、1000円あたり39.99・40.95・41.79G、PAYOUTシミュレート97.15・101.23・104.83%を取得。
- 5号機クロニクルの機械割96.5・100.5・104.0%とは差があるため平均せずCONFLICTとして双方を保持。
- resetBehaviorは「やったネ！はるみちゃん2 / やったネ!はるみちゃん2 / ヤッタネハルミチャン2 / ヤーマ」に設定変更・リセット・朝一・据え置き・電源OFF ON・天井・モード・ガックン・FRT持越し・RT残りGを組み合わせ、メーカー公式、業界記事、当時解析、古いDB、後年回顧まで横断。
- 設定変更/据え置き/電断時のFRT内部状態・残りゲーム数、ガックン等の本機固有高信頼資料は確認できず、十分な再探索後に該当項目のみUNVERIFIED/PARTIAL。
- 通常時ゲーム数天井、リセット短縮天井、朝一専用モード、有利区間は確認されず。有利区間は世代上非該当。
