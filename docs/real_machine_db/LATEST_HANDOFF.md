### resetBehavior v0.7
- settingChange: 朝一1G目ガックンが、対策されていない場合の変更濃厚/可能性上昇パターンとして公開。BGMによる前日履歴比較も変更/据え置き推測に使用可能。
- carryOver: 当日1・2回目BIGで `パイナップルラグ / Theエンターテイナー / 威風堂々`、またはゾロ目G数以外のBIGで `Theイージーウィナーズ` が流れれば据え置き濃厚とする当時解析あり。
- powerOFF→ON: 据え置きとは独立した純電断時のBGM履歴・リール/成立済みボーナス契約は、検索語・資料系統変更後も `UNVERIFIED_AFTER_RESEARCH_AS_DISTINCT_CONDITION`。
- gameCounter/ceiling: 通常天井非搭載のため天井カウンタ/短縮天井は`NOT_APPLICABLE`。BGM関連履歴カウンタの正式な初期化単位はUNVERIFIED。
- mode/state: 朝一専用モード/設定変更専用モード振り分け/初当たり優遇は`NONE_CONFIRMED_AFTER_RESEARCH`。
- advantageousSection: `NOT_APPLICABLE`。
- resetDetection: 1G目ガックン + BIG中BGM履歴で推測可能。ただしガックン発生率は公開確認できず、対策時は非決定的。
- numericResetData: 設定変更専用の短縮天井・モード振り分け・初当たり上昇率・ガックン発生率はいずれも公開値未確認。
