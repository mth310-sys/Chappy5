## resetBehavior 方針継続

- 新規機種はv0.7に従い性能コアとresetBehaviorを同時探索する。
- 既存レコードは性能コアのCOMPLETE_CORE/PARTIALを不用意に崩さず、resetBehaviorQAを別管理する。
- 設定変更、リセット、朝一、据え置き、電源OFF→ON、RT/ART/CZ/モード・状態引継ぎ、天井、ガックンへ検索語を分岐する。
- 高信頼で確認できないものだけUNVERIFIED。
- 有利区間は制度導入前の5号機では非該当。
