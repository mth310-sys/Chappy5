### CONFLICT（298）

- 機械割はK-Navi **96.54 / 97.76 / 99.97 / 102.13 / 104.06 / 107.30%** と5号機クロニクル **96.5 / 97.8 / 100.0 / 102.1 / 104.1 / 107.3%** が丸め差レベルで一致。
- パチマガスロマガのシミュレートPAYOUTは **97.31 / 98.53 / 100.98 / 103.48 / 105.56 / 109.12%** と別系列。平均せず `CONFLICT_PAYOUT_RATE` として双方保持。
- 豊漁チャンスG数は「最大4G」と「特殊リプレイ入賞後3GプチRT」の表記差を平均・断定せず保持。

### resetBehavior（298）

- `settingChangeBehavior`: `UNVERIFIED_AFTER_RESEARCH` — 本機固有の設定変更時初期状態を直接示す資料を確定できず。
- `carryOverBehavior`: `NOT_APPLICABLE_FOR_NORMAL_CEILING / UNVERIFIED_FOR_PETIT_RT_STATE` — 通常ゲーム数天井は確認されず、演出用プチRT残状態の据え置き処理のみ未確定。
- `powerCycleBehavior`: `UNVERIFIED_AFTER_RESEARCH` — 電源OFF→ONのみの場合のプチRT残状態/初期出目を確定できず。
- `gameCounterReset`: `NOT_APPLICABLE` — 通常ゲーム数/ボーナス間ゲーム数天井なし。
- `ceilingAfterReset`: `NOT_APPLICABLE` — 通常天井・リセット短縮天井とも確認なし。
- `modeAfterReset`: `NOT_APPLICABLE_OR_NONE_CONFIRMED` — 通常時モード管理・朝一専用モード振り分け確認なし。
- `stateAfterReset`: `UNVERIFIED_FOR_SHORT_PETIT_RT_ONLY` — 持続出玉RT/ART/ATはなく、特殊リプレイ後の短い演出用RTのみ。
- `advantageousSectionReset`: `NOT_APPLICABLE`（5号機・有利区間制度前）。
- `resetBenefits`: `NONE_CONFIRMED_AFTER_RESEARCH`。
- `resetPenalties`: `NONE_CONFIRMED_AFTER_RESEARCH`。
- `resetDetection`: `UNVERIFIED_AFTER_RESEARCH` — `豊漁 / 豊漁7 / ホウリョウ7 / 北電子` と `設定変更 / リセット / 朝一 / 据え置き / 電源OFF ON / ガックン / 初期出目 / 変更判別` を組み替え、公式・当時業界記事・攻略DB・回顧資料を横断したが本機固有条件を確定できず。
- `numericResetData`: リセット専用天井/モード振り分け/朝一当選率/恩恵発生率は `NONE_CONFIRMED_OR_NOT_APPLICABLE`。
