## resetBehavior v0.7

- **設定変更**: ボーナスのみのノーマル機で、通常天井・モード・CZ/ART/AT状態などの主要リセット対象を確認せず。設定変更専用の朝一恩恵/不利/公開当選率も確認できなかった。リール初期挙動等の物理的初期化は本機固有資料を確定できず `UNVERIFIED_AFTER_RESEARCH`。
- **据え置き / 宵越し**: 通常ゲーム数天井・規定ゲーム数管理・内部モードを確認せず、ゲーム進行カウンタの宵越し価値は `NOT_APPLICABLE`。周辺データ機器の履歴は実機内部DB対象外。
- **電源OFF→ON**: 天井/モード等の持越し対象は確認されないが、リール初期出目・CHANCE/バットランプ等の物理的復帰挙動は `UNVERIFIED_AFTER_RESEARCH`。
- **ゲーム数・天井**: `NOT_APPLICABLE / NONE_CONFIRMED`。
- **モード・状態**: 通常時モード、CZ/RT/ART/AT状態は確認されず `NOT_APPLICABLE`。
- **有利区間**: `NOT_APPLICABLE`（5号機・制度前）。
- **朝一恩恵/不利**: 設定変更専用の短縮天井、モード優遇、朝一当選率等は `NONE_CONFIRMED_AFTER_RESEARCH`。
- **変更判別**: ガックン、初期出目、告知ランプ等を多段再探索したが、本機固有の確定根拠を回収できず `UNVERIFIED_AFTER_RESEARCH`。
