## 294. キャッツ・アイ

- record: `docs/real_machine_db/machines/2008-09-16_cats_eye.md`
- manufacturer: オリンピア
- modelName: `キャッツアイY`
- generation: 5号機
- systemType: ボーナス+RT+ストック型ART
- releaseDate: **2008-09-16**。当時K-Naviの「9月16日導入予定」と、コムシードの同日「ホールデビュー」記載が一致。
- 設定体系: **1 / 2 / 3 / 4 / 5 / 6**。
- BIG合算: **1/455.11 → 1/358.12**。
- REG: **1/873.81 → 1/762.04**。
- ボーナス合算: **1/299.25 → 1/243.62**。
- BIG約258枚、REG約70枚。
- ART「キャッツタイム」は **50G/1ストック、約+1.0枚/G**。当時K-Naviでは平均約4セット、約200枚純増見込み。
- ボーナス/ART後の50G RT「予告状モード」中にミッションクリアでARTへ昇格。
- ARTストック10個以上で次回ボーナスまで継続する「スーパーキャッツタイム」へ昇格。
- 通常天井は **ボーナス間1000G**で天井状態（以後BIGでART2セット以上）、**1500G**で次回ボーナスまで継続する天井ART。
- 機械割は回顧DB **96.4/98.4/101.0/103.7/106.1/110.1%** と別DB **95.8/98.2/100.0/103.0/105.3/108.9%** が競合するため平均せず `CONFLICT_PAYOUT_RATE`。
- 50枚ベースは表記揺れ・型式名・50枚/1000円/ベース/コイン持ちまで変えて再探索したが2008年初代の直接値を確定できず、後継機値を流用しないため `UNVERIFIED_AFTER_RESEARCH`。

### resetBehavior（294）

- `settingChangeBehavior`: `UNVERIFIED_AFTER_RESEARCH` — 設定変更時の1000G/1500G天井カウンタ、低確/高確/超高確、RT/ART状態・ストック処理を本機固有資料で確定できず。
- `carryOverBehavior`: `UNVERIFIED_AFTER_RESEARCH` — 据え置き時の天井カウンタ・内部状態・ARTストックの引継ぎを直接確定できず。
- `powerCycleBehavior`: `UNVERIFIED_AFTER_RESEARCH` — 電源OFF→ONのみの場合の天井・RT/ART・ストック処理を直接確定できず。
- `gameCounterReset`: `UNVERIFIED_AFTER_RESEARCH` — 通常1000G/1500G天井自体は確認済みだが、設定変更時リセット/据え置き時引継ぎを一般論で補間しない。
- `ceilingAfterReset`: `UNVERIFIED_AFTER_RESEARCH` — リセット専用短縮天井・変更数値は確認できず、通常天井の初期化有無も直接資料未確認。
- `modeAfterReset`: `UNVERIFIED_AFTER_RESEARCH` — 低確/高確/超高確は確認済みだが、設定変更時の再抽選/引継ぎ・朝一専用モードは未確定。
- `stateAfterReset`: `UNVERIFIED_AFTER_RESEARCH` — RT「予告状モード」、ART「キャッツタイム」、スーパーキャッツタイム、ストックの変更/据え置き/電断処理を一般論で補間しない。
- `advantageousSectionReset`: `NOT_APPLICABLE`（5号機・有利区間制度前）。
- `resetBenefits`: `NONE_CONFIRMED_AFTER_RESEARCH` — 通常天井以外の朝一/設定変更専用恩恵は確認なし。
- `resetPenalties`: `NONE_CONFIRMED_AFTER_RESEARCH`。
- `resetDetection`: `UNVERIFIED_AFTER_RESEARCH` — `キャッツ・アイ / キャッツアイ / キャッツアイY / オリンピア` と設定変更・リセット・朝一・据え置き・電源OFF ON・天井・ガックン・初期出目・変更判別・ARTストックを組み替え、当時解析/旧DB/P-WORLD/K-Navi/回顧資料を横断したが本機固有条件を確定できず。
- `numericResetData`: 通常天井 **1000G / 1500G** は記録。リセット天井、朝一モード振り分け、朝一特定G数当選率、リセット恩恵率は `UNVERIFIED/NONE_CONFIRMED_AFTER_RESEARCH`。
