## v0.7 resetBehavior

- pacnk後年整理で、通常時250Gごとの周期マリックチャンス(CZ)と、3回連続スルーによる天井ATを確認。
- 同整理ではボーナス後CZは周期スルーに数えず、天井ATは次回ボーナスまでチェリーナビでコイン減少を抑える仕様。
- 設定変更時に250G周期カウンタ、CZスルー回数、CZ/ART状態をリセットするか引き継ぐかは高信頼資料で確定できず `UNVERIFIED`。
- 据え置き/電源OFF→ONのみの場合の周期・CZスルー回数・ART/CZ状態処理も `UNVERIFIED`。
- 設定変更専用モード、短縮天井、朝一ART、変更時専用当選率などは `NONE_CONFIRMED`。
- 本機固有ガックン/表示/周期挙動による変更判別は再探索後も `UNVERIFIED`。
- 有利区間は `NOT_APPLICABLE`。
