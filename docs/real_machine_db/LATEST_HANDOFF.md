## 今回の確認・修正

### やったネ！はるみちゃん4

- BELLCO現存メーカー情報でヤーマ、2007年4月、4種類スペック同時展開の独立機種「やったネ!はるみちゃん4」を確認。
- 当時グリーンべるとで2007-04-15納品開始予定、25Φ「4」と30Φ「-30」は共通のマイルド仕様、2種BIG+CB、BIG約312枚、CB約221枚、都BIG後は次回ボーナスまでMRT、はるみBIG後77G、合算設定1約1/248〜設定3約1/210、1000円約34Gを確認。
- パチマガスロマガで設定別都BIG 1/1489.45〜1/1260.31、はるみBIG 1/496.48〜1/420.10、CT 1/744.73〜1/630.15、合算1/248.24・1/227.56・1/210.05、1000円34.48・34.71・35.12G、PAYOUTシミュレート96.89・100.77・104.80%を取得。
- 5号機クロニクルの機械割96.5・100.5・104.0%とは差があるため平均せずCONFLICTとして双方を保持。
- HAZUSEでもBIG約312枚、CT約221枚、MRTは増加枚数を見込まない、都BIG後次回まで・はるみBIG後最大77Gを当時解析で照合。

### やったネ！はるみちゃん-30

- メーカー公式で「やったネ!はるみちゃん4」と別機種として表示される30Φ仕様のため、全機種方針に従い独立レコード化。
- HAZUSEは「シリーズ唯一の30パイ仕様」「4と同スペック」と明記し、パチマガスロマガも「4&30」共通解析。性能コアは4と同値として、同一性能を示す複数資料の根拠付きで保存。
- 30Φという販売区分自体を独立機種性として保持し、25Φレコードと混同しない。

### resetBehavior 共通確認

- 「やったネ！はるみちゃん4 / やったネ!はるみちゃん4 / ヤッタネハルミチャン4 / やったネ！はるみちゃん-30 / ヤッタネハルミチャン30 / ヤーマ / 30Φ」を軸に、設定変更・リセット・朝一・据え置き・電源OFF ON・天井・モード・ガックン・MRT持越し・RT残りGを組み合わせて再探索。
- メーカー公式、当時業界記事、パチマガスロマガ、HAZUSE、5号機クロニクル、後年回顧まで横断したが、設定変更/据え置き/電断時のMRT内部状態・残りゲーム数、ガックン等の本機固有高信頼資料は確認できず、十分な再探索後に該当項目のみUNVERIFIED/PARTIAL。
- 通常時ゲーム数天井、リセット短縮天井、朝一専用モードは確認されず。有利区間は5号機初期のため非該当。
