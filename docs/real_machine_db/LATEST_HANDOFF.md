## 2007年3月→4月境界監査

`やったネ！はるみちゃん`シリーズは3月に発表されたが、メーカー公式では「2007年4月登場」、当時グリーンべるとでは4機種すべて2007-04-15納品開始予定。したがって3月収録へ前倒ししない。

シリーズは「3スペック4機種」。独立性能差が大きいため、原則として以下を独立レコード化する方針候補:
- `やったネ！はるみちゃん`：6段階、約350枚BIG、ART +1.5枚/G、555G/1555G、1000円約33G。
- `やったネ！はるみちゃん2`：3段階、約310枚BIG、FRT +0.85枚/G、222G/3333G、1000円約40G。
- `やったネ！はるみちゃん4`：3段階、約312枚BIG + 約221枚CB、MRT、1000円約34G。
- `やったネ！はるみちゃん-30`：30Φ仕様。メーカー/当時資料では「4&30」を同一マイルドスペック群として扱うが、全機種方針上は型式・25/30Φ差を監査して独立レコード要否を最終決定する。
