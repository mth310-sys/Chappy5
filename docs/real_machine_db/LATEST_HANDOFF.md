## resetBehavior

- 通常時ボーナス天井: 確認なし。RT最大2000GはRT規定ゲーム数であり天井ではない。

- 設定変更時のRT内部状態/残ナビ回数処理: 高信頼資料で確定できず UNVERIFIED。
- 据え置き時のRT内部状態/残ナビ回数引継ぎ: 高信頼資料で確定できず UNVERIFIED。
- 電源OFF→ONのみのRT内部状態/残ナビ回数処理: 高信頼資料で確定できず UNVERIFIED。
- 朝一専用モード/設定変更専用モード: 確認できず。
- 本機固有のガックン等による変更判別: 高信頼資料で確定できず。
