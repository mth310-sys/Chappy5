### SASHIBA（サシバE-30）

- トリビー。P-WORLD/パチンコビスタ/5号機クロニクルで2007年5月導入を確認。厳密な初回納品日は今回確定できず、月単位で登録。
- P-WORLD掲示板には2007-05-08から投稿があり、少なくとも5月上旬には機種情報が流通していたことを補助確認。
- 30Φ沖縄限定、ノーマル/完全告知/天井RT。
- BIG 1/305.69〜1/258.38、REG 1/614.25〜1/434.07、合算1/204.11〜1/161.97。
- 1000円あたり36.42〜39.14G。
- BIG約300枚、REG/BABY約156枚。
- 機械割はP-WORLD/5号機クロニクル95.9〜107.5%と、パチマガスロマガのシミュレート95.66〜108.06%が差異。定義を分けてCONFLICT保持。
- 天井RT搭載は複数資料で確認。RT中リプレイ確率1/1.69〜1/1.78、「コイン持ちは現状維持程度」。
- 天井RTの**発動ゲーム数**、設定変更/据え置き/電源OFF→ON時のゲーム数・RT状態処理、変更判別は検索語/資料系統変更後も確定できずUNVERIFIED。推測で埋めていない。
- 有利区間は非該当。

- グリーンべると/P-WORLD当時記事で**2007-05-13納品開始予定**を確認。後年DBの2007-05-14導入表記は日差として併記。
- HBB448枚、BIG351枚、REG104枚。
- 設定別HBB/BIG/REGを取得。合算は設定1約1/290〜設定6約1/217で当時業界記事とも一致。
