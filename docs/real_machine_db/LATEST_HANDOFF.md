- ガオガオフェスティバルS / SANKYO。

- BIG: 設定1 1/445.82 → 設定6 1/348.60。
- REG: 設定1 1/590.41 → 設定6 1/409.60。
- 合算は当時業界丸め値で1/254 → 1/188。旧パチマガ解析、当時業界記事、P-WORLD機種DBで整合。
- 機械割は旧パチマガスロマガのシミュレート値 97.09〜110.62% と、後年整理資料 96.5〜109.0% が競合するため平均せずCONFLICT。
- 5号機クロニクルにはBIG/REG確率にも大きく異なる別値があるが、当時業界記事・旧パチマガ・P-WORLD機種DBの3系統一致を優先し、別値は競合根拠としてのみ保存。
- 50枚ベースは「50枚 / 1000円 / ベース / コイン持ち / 小役確率 / プレイ数」まで検索語を変え、公式・当時業界・旧解析・後年DBを横断したが今回確定できずUNVERIFIED。
- resetBehaviorは設定変更/据え置き/電源OFF→ON/朝一/ガックン/天井/モードまで再探索。ノーマル機でRT・天井・有利区間は非該当/確認なしだが、本機固有の変更判別・電断処理は高信頼資料未確認のため該当箇所のみUNVERIFIED。
