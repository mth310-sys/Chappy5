### settingChangeBehavior
- 設定変更で天井G数、内部状態、有利区間をRESET。
- 設定変更後は有利区間を新規開始するため、前日の999G天井進行は引き継がない。
- 設定変更専用のモード振り分け表は再探索後も高信頼の公開固定値を確認できずUNVERIFIED_AFTER_RESEARCH。

### carryOverBehavior
- 据え置き時は設定変更を伴わない電源OFF→ONと同様に、天井G数、内部状態、有利区間をCARRY_OVERする扱い。
- 7セグ表示の朝一見え方については単一攻略資料に判別手順があるが、高信頼複数照合がないため確定契約にはしない。

### powerCycleBehavior
- 純電源OFF→ON: 天井G数CARRY_OVER / 内部状態CARRY_OVER / 有利区間CARRY_OVER。
- ちょんぼりすたの朝一表で設定変更との差を直接確認。

### gameCounterReset
- 設定変更: RESET。
- 据え置き / 純電断: CARRY_OVER。
- 最大天井999G。

### ceilingAfterReset
- 設定変更後も最大天井は999G。
- 一律のリセット専用短縮天井は確認されていない。
- ただし朝一はゲーム数テーブルを0から進行するため、序盤ゾロ目ゲーム数が再度狙い目になる。

### modeAfterReset
- 規定ゲーム数テーブルは設定変更により新しい有利区間として開始。
- 設定変更専用の詳細テーブル振り分けは、機種名/型式/メーカー/朝一/リセット/モード/ゲーム数テーブル/振り分けを組み替えて再探索しても固定できずUNVERIFIED_AFTER_RESEARCH。

### stateAfterReset
- 設定変更: 内部状態RESET。
- 据え置き / 純電断: 内部状態CARRY_OVER。
- 通常/高確/超高確のどの状態から開始するかという設定変更専用初期振り分け値はUNVERIFIED_AFTER_RESEARCH。

### advantageousSectionReset
- 設定変更: RESET。
- 純電源OFF→ON: CARRY_OVER。
- ボーナスまたは1G連終了後にも有利区間をリセットする構造。
- 有利区間ランプはWIN表示右下のドットだが、通常時は消灯タイプ。

### resetBenefits
- リセット後のゲーム数テーブル再スタートにより、序盤のゾロ目ゾーンを再度踏む。
- 単一攻略資料ではリセット後112G以内約40%当選を朝一恩恵として扱うが、「リセット後はボーナス終了後と同様と思われる」という推定を含むため、確定的な専用値にはしない。
- より高信頼な複数資料で確認できるのは「ボーナス終了後128G以内40%超」であり、これは設定変更専用値ではない。

### resetPenalties
- 設定変更で前日の天井進行、内部高確/超高確、有利区間を失う。
- 前日深いハマリや高確以上を保持していた場合、据え置きと比べてその蓄積を失うことが不利要素。
- 独立した追加ペナルティの公開固定値は確認されていない。

### resetDetection
- 通常時は有利区間ランプが消灯するタイプのため、朝一ランプ消灯だけでは設定変更判別不可。
- 単一攻略資料には、朝一メダル1枚投入時の7セグ非表示/カウント表示差やデータ機との1G差を利用した判別法があるが、複数高信頼資料で再現確認できずANALYSIS_SINGLE_CLUE扱い。
- 本機固有のリールガックン条件/発生率は、表記揺れ・型式・メーカー・設定変更・朝一・据え置き・ガックンを組み替えて再探索しても高信頼固定値を確認できずUNVERIFIED_AFTER_RESEARCH。

### numericResetData / publicMorningNumbers
- 設定変更専用モード振り分け: PUBLIC_VALUE_NOT_FOUND_AFTER_RESEARCH。
- 設定変更専用短縮天井: NONE_CONFIRMED_AFTER_RESEARCH（最大999G）。
- 参考一般値: ボーナス終了後128G以内のボーナス期待度40%超（全設定共通）。設定変更専用値ではない。
- 朝一リセット狙いとして112G以内約40%とする単一攻略資料あり。ただし推定を含むためANALYSIS_SINGLE_REFERENCEとして保持。
