## basicPayout

- 初当たり後は「ターゲットチャンス」で初期ゲーム数を決定し「激走タイム」へ移行。
- パチマガスロマガ: 初期ゲーム数 **平均40G（30G保障）**。
- P-WORLD: 激走タイムを **1セット30G+α** と記載。同ページのボーナス仕様欄には40G+α表記もあり、これは初期獲得ゲーム数/表示定義差とみて単純統合しない。
- 物差し本線では **30G保障・初期平均40G / 純増約2.9枚/G** を保持。
- OPT（おしりペンペンタイム）は1PUSH 1～100G上乗せ、継続率90～99%系。
