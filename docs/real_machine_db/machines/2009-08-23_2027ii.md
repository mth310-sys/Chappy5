## modeSpecificMinimumData

- 通常時はチェリーを主契機に高確移行抽選。
- 高確中のボーナス成立でART突入確定。
- 低確中REGでもグリーンべると発表で約10%の自力ART突入期待。
- ART継続率は70〜95%。
- P-WORLD掲載ART初当たりは設定1 1/518.3 → 設定6 1/210.5。
- ART中ボーナス成立時は継続率格上げ抽選あり。
- 潜航/追跡などART継続率・高確に関係する内部モードを持つが、通常時全モード移行テーブルは物差し用途外のため収集しない。
