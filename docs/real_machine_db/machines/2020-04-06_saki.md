### settingChangeBehavior
- 設定変更時は **天井RESET / 内部状態RESET / 有利区間RESET**。
- 非有利区間を経て有利区間へ移行し、その際に清澄モードと内部状態を再抽選する。
- 有利区間移行時のモード/状態振り分けは公開値あり。

### carryOverBehavior
- 据え置き時は、設定変更を伴わない電源OFF→ONの公開契約に基づき **天井進行 / 内部状態をCARRY_OVER**。
- 前日のカン数も内部的に引き継ぐ挙動が朝一判別材料になる。
- 有利区間については設定変更時RESET。通常時ランプが消灯するため朝一ランプのみでは据え置き判別不可。

### powerCycleBehavior
- 電源OFF→ONのみ: **天井CARRY_OVER / 内部状態CARRY_OVER**。
- 朝一液晶右下のカン牌数は見た目上0個に戻るが、初回スイカ成立時に前日の内部カン数を加算した表示挙動を取り得る。
- 開始ステージは主要当時資料で調査中のままのため `UNVERIFIED_AFTER_RESEARCH`。

### gameCounterReset
- 設定変更: **RESET**。
- 据え置き / 電源OFF→ON: **CARRY_OVER**。
- 新有利区間での通常時最大天井は999G。

### ceilingAfterReset
- 設定変更専用の固定短縮天井は確認されていない。
- 有利区間移行時に清澄モードを再抽選するため、選択モードにより実質天井は99〜999Gへ変化する。
- これは「リセット専用短縮テーブル」ではなく有利区間移行時共通のモード抽選として分離する。

### modeAfterReset
- 設定変更後の有利区間移行時に清澄モードを再抽選。
- 設定1の全モード振り分け: 通常40.38% / 優希12.18% / まこ9.58% / 久13.53% / 和11.85% / 咲3.02% / のどっち9.45%。
- 高設定ほど優希・和モードが選ばれやすい。設定別公開値はnumericResetDataに保存。
- 覚醒のどっちは有利区間継続時に移行可能で、有利区間移行時の初期抽選には含まれない。

### stateAfterReset
- 設定変更: **RESET後、有利区間移行時に通常/ボーナス高確を再抽選**。
- 据え置き / 電断: **CARRY_OVER**。
- 有利区間移行時のボーナス高確スタート率は設定1 43.74%〜設定6 60.78%。

### advantageousSectionReset
- 設定変更: **RESET**。
- ラストチャンス失敗時・頂上決戦敗北時等にも有利区間リセット契機あり。一部はラストチャンス失敗時でも有利区間継続あり。
- 通常時から有利区間ランプが消灯している仕様のため、**朝一ランプ消灯だけでは設定変更/据え置き判別不可**。

### resetBenefits
- 有利区間移行時に清澄モードと内部状態を再抽選。
- 高設定ほど優希/和モードおよびボーナス高確開始率が優遇される。
- 設定変更だけに限定された専用ボーナス/CZ当選率や専用短縮天井は確認されていない。

### resetPenalties
- 設定変更で前日の天井進行・内部状態・有利区間・内部カン蓄積を消去する側面がある。
- その他の設定変更専用不利要素は `NONE_CONFIRMED_AFTER_RESEARCH`。

### resetDetection
- 有利区間ランプ: 通常時消灯タイプのため **朝一判別不可**。
- 朝一液晶のカン牌数は見た目上0個。初回スイカ成立時、据え置きなら前日内部カン数に加算した表示となる。
- 有利区間移行時にカン3個の振り分けはないため、**朝一最初のスイカでカン成立なら据え置き濃厚**とする当時解析あり。
- 本機固有のリールガックン発生条件/率は `咲-Saki- / S咲-Saki-SH / サンスリー / 三洋 / 設定変更 / リセット / 朝一 / 据え置き / 電源OFF ON / ガックン` で再探索したが固定できず `UNVERIFIED_AFTER_RESEARCH`。
