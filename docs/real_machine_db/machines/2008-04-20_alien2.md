### modeSpecificMinimumData

- 全ボーナス後に最大30GのCZ「デンジャーゾーン」へ突入。
- CZ中の特殊リプレイ成立でRTへ移行。
- 50G RT契機の特殊リプレイは目押しで回避可能で、1000G RT契機待ちを狙える技術介入設計。
- 当時業界一次記事とK-Navi、パチマガスロマガで基本構造が一致。
- 通常時のゲーム数天井は確認されていない。
