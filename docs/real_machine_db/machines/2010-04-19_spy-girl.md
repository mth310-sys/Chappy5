## modeSpecificMinimumData

- 通常時は規定ゲーム数消化、ボーナス後、ART後にCZ「スパイチャンス」へ移行。
- CZでは6択リプレイ押し順正解でART突入。ナビストックあり/継続率抽選クリア時は押し順ナビが発生しART確定。
- 通常時**333G消化ごとにCZへ突入し、3回目のCZは必ず押し順ナビ発生＝ART突入**。P-WORLDの直接記載を主根拠とする。
- ARTには「ナビストック」「継続率ストック（MAX88%）」「バトルボーナスストック」の3系統が存在。
- フリーウェイモードはART高確率状態。クライマックスモード中のボーナスはART4セット＋88%継続獲得。
- 詳細な通常時全状態移行率やストック抽選表は実機完全再現用途のため本DB必須外。

confidence: INDUSTRY_ANALYSIS_MULTI_SOURCE
