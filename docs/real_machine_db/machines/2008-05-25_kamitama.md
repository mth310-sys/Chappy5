### basicPayout

- BIG: 平均約308枚

### modeSpecificMinimumData

- 全ボーナス後・RT後・通常150G周期でCZへ移行。
- CZで特殊リプレイ入賞により50G完走型RT「みこし祭」へ突入。
- RT突入期待度は、BIG後約50%、REG後約25%、みこしチャンス後約75%。
- RT後・150G周期・設定変更後のCZは約25%。
- 通常時はCZ終了後150G消化で再びCZへ入る周期天井型の構造。

### resetBehavior調査メモ

- `神たま / カミタマX / SNKプレイモア / みこし祭` と `設定変更 / リセット / 朝一 / 朝イチ / 据え置き / 電源OFF ON / 電断 / 天井 / 150G / CZ / RT / ガックン / 初期出目` を組み替えて探索。
- P-WORLDは本機について `設定変更後もチャンスゾーンからスタート` と明記し、そのCZからRTへ入る期待度を約25%と掲載する。後年のシリーズ整理資料も `設定変更後なら約25%` と一致。
- したがって、設定変更後にCZスタートすることと朝一RT突入期待度約25%はv0.7の直接値として採用する。
- 通常時はCZ終了後150Gで再度CZへ入るが、設定変更操作が前日の周期カウンタをどう処理するかを内部カウンタ単位で説明した資料は今回確定できないため、`gameCounterReset` はCZスタートの事実までに限定する。
- 据え置き時の150G周期カウンタ/CZ/RT残状態、電源OFF→ON単独時の状態、RT中設定変更時の残G処理は直接資料を確定できず `UNVERIFIED_AFTER_RESEARCH`。
- 本機固有のガックン、初期出目、ランプ等による変更判別も直接根拠を確定できず `UNVERIFIED_AFTER_RESEARCH`。
- 有利区間は5号機初期のため `NOT_APPLICABLE`。
