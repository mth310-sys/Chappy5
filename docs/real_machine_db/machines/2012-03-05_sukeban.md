## modeSpecificMinimumData

- ART「スケバンRUSH」は1セット15～35Gの変動型、純増約+1.8枚/G。
- 当時グリーンべるとでは階層別に15 / 20 / 25 / 30 / 35Gと記録。
- 通常時にはCZ「乙女特訓」「飛翔の刻」が存在。
- 天井は「バトルMAP」15マス到達。通常リプレイ15回成立で1マス進行し、基準上はART間で通常リプレイ225回入賞相当で天井到達。
- 天井ARTはHP300%スタート。
- リプレイ連続成立時には天井までの残りリプレイ回数減算抽選があり、後年整理資料ではリプレイ5連成立で即天井到達とされる。

## conflicts

- パチマガスロマガのスペックページに「REG約30枚（36枚）」表記がある一方、K-Navi/P-WORLDは勇香★BONUSを297枚超払い出し、P-WORLD/中古実機資料は純増約204枚としている。別役/表記定義の混在可能性が高いため、勇香★BONUS約204枚を主値とし、約30枚表記はCONFLICT_OR_DIFFERENT_BONUS_DEFINITIONとして平均化しない。
- reset関連では「設定変更後は天井マップがリセット」と「設定変更でも天井リプレイ回数は引き継ぐ」が同一後年資料内に併記されるが、当時資料が液晶MAPのみ1マス目へ戻り内部回数は保持と明記するため、内部カウンタと表示MAPの定義差として整理し、数値競合とは扱わない。
