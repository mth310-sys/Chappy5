### settingChangeBehavior

- 本機固有の解析で **設定変更時はマップがリセットされ、天井マップ数が再抽選**されることを確認。
- したがって、前日の消化MAP進捗を設定変更後にそのまま引き継がない。
- 設定変更時の天井MAP再抽選について具体的な振り分け率は、表記揺れ・型式名・メーカー名と設定変更/リセット/朝一/天井MAP/振り分けを組み替えて再探索したが直接固定できず **UNVERIFIED_AFTER_RESEARCH**。
- confidence: ANALYSIS_HIGH_MACHINE_SPECIFIC_FOR_MAP_RESET_RESELECT__UNVERIFIED_FOR_EXACT_DISTRIBUTION

### carryOverBehavior

- 純据え置き時のMAP進捗、天井MAP、通常時の状態・職業等をどの範囲まで保持するかを本機固有に明示した直接資料は、据え置き/宵越し/朝一/MAP/天井で再探索したが固定できず **UNVERIFIED_AFTER_RESEARCH**。
- 設定変更時RESETの逆を据え置きKEEPとは推定しない。

### powerCycleBehavior

- 設定変更を伴わない単純 **電源OFF→ON** 時のMAP進捗、天井MAP、状態の保持/初期化契約を、本機固有資料として固定できず **UNVERIFIED_AFTER_RESEARCH**。
- 据え置きと純電断を自動同一視しない。

### gameCounterReset

- 本機の主要天井管理単位はゲーム数より **MAP進捗**。
- setting change: **MAP_PROGRESS_RESET_CONFIRMED__CEILING_MAP_RESELECT_CONFIRMED**。
- carry-over: **UNVERIFIED_AFTER_RESEARCH**。
- power OFF→ON only: **UNVERIFIED_AFTER_RESEARCH**。

### ceilingAfterReset

- 設定変更時はMAP進捗をリセットし、天井MAP数を再抽選。
- 通常仕様では最大40MAP、かつ10 / 15 / 20 / 25 / 30 / 35MAPにも天井MAPの選択余地がある。
- 設定変更専用に「必ずN MAP以内」とする固定短縮契約や、その具体的振り分け率は **NONE_CONFIRMED_AFTER_RESEARCH / UNVERIFIED_FOR_EXACT_DISTRIBUTION**。
- 通常時の天井MAP候補を設定変更専用恩恵とは扱わない。

### modeAfterReset

- 通常時の天井候補分布と設定変更時専用分布を混同しない。

## conflicts / safeguards

- 導入時期: グリーンべるとが **2013-12-02導入同時アプリ配信**を報道し、パチマガスロマガも2013年12月扱い。一方P-WORLD DBの導入開始欄は **2013年11月**。平均化せず `CONFLICT_RELEASE_PERIOD_2013_11_VS_EXACT_INDUSTRY_2013_12_02` とし、本線時系列キーは具体日を報じる業界資料の2013-12-02を採用。
- 「最大40MAP（約1200G）」の約1200GはMAP長による目安で、固定1200G天井ではない。
- 設定変更時の天井MAP再抽選から、据え置き/純電断時の保持を逆算しない。
- 通常時の10/15/20/25/30/35/40MAP候補を、設定変更専用の短縮天井テーブルとして断定しない。
