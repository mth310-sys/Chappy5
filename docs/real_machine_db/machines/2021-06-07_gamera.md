## basicPayout
- BIG BONUS: JAC5回保証+上乗せ、平均約560枚。
- REG BONUS: JAC1回、平均約90枚。
- BIG中の技術介入は2コマ目押し。技術介入精度により獲得性能/完全攻略出玉率が変動。
- サミー発表、業界記事、なな徹、パチマガスロマガ等で一致。
- reliability: OFFICIAL / INDUSTRY / ANALYSIS_HIGH

## modeSpecificMinimumData
- 通常時は表モード（通常 / ガメラ / 超ガメラ）と裏モード（通常 / 準備 / 裏ガメラ）を持つ。
- 表モードは確定役以外のボーナス当選率、裏モードはBIG/REG比率に影響。
- 裏ガメラモード中のボーナスはBIG濃厚。滞在は平均約200G以上。
- 通常天井は状況別で、BIG終了後1000G+α、REG終了後930G+α、設定変更後900G+α。恩恵はボーナス当選。

### settingChangeBehavior
- 設定変更時は天井、有利区間、内部モード、内部状態をRESET/再抽選。
- 新規有利区間移行時に表/裏モードの移行抽選を行う。
- reliability: ANALYSIS_HIGH

### carryOverBehavior
- 据え置き時は天井、内部モード、内部状態、有利区間ランプ状態をCARRY_OVER。
- 朝一有利区間ランプ点灯なら据え置き濃厚。ただし前日閉店時状態や店側対策の例外あり。
- reliability: ANALYSIS_HIGH

### powerCycleBehavior
- 純電源OFF→ONでは天井、内部モード、内部状態、有利区間ランプ状態をCARRY_OVER。
- HAZUSEは `設定変更 / 電源ON・OFF` 比較表で、電源ON・OFF時の天井・有利区間ランプ・内部モードをすべて「引き継ぐ」と明記。複数後年整理資料でも状態・ゲーム数引継ぎで一致。
- reliability: ANALYSIS_HIGH

### gameCounterReset
- 設定変更: RESET。
- 据え置き / 純電断: CARRY_OVER。
- 通常天井は前回ボーナス種別で異なり、BIG後1000G+α / REG後930G+α。

### ceilingAfterReset
- 設定変更後は **900G+α** に短縮。
- 通常のBIG後1000G+α、REG後930G+αより浅い設定変更専用天井。
- 天井恩恵はボーナス当選。
- reliability: ANALYSIS_HIGH

### modeAfterReset
- 設定変更時は内部モードを再抽選。
- 有利区間移行時は表モードと裏モードの移行抽選を行う。
- 裏モード初期振り分け: 通常86.4% / 準備3.1% / 裏ガメラ10.5%。これは設定変更専用だけでなく、新規有利区間移行時共通の公開値。
- 表モードについても有利区間移行時にガメラ/超ガメラモード移行チャンスがあるが、初期全振り分けの公開固定表は今回確認できず `UNVERIFIED_AFTER_RESEARCH`。
- reliability: ANALYSIS_HIGH / UNVERIFIED(partial table)

### stateAfterReset
- 設定変更: 内部状態RESET/再抽選。
- 据え置き / 純電断: 内部状態CARRY_OVER。
- 表モードのほか、チェリー/ギロン連による連高確が存在するが、設定変更専用の独立した連高確初期振り分けは確認できない。
- reliability: ANALYSIS_HIGH

### advantageousSectionReset
- 設定変更: RESET。
- 据え置き / 純電断: CARRY_OVER。
- 通常時は有利区間ランプ点灯型。
- 有利区間は基本的に、BIG後100GまたはREG後30G消化後、超ガメラモード非滞在かつリプレイ/中段ギャオス/右下がりギャオス成立時にクリア。上限等による例外あり。
- reliability: ANALYSIS_HIGH

### resetBenefits
- 設定変更専用天井が900G+αへ短縮。
- 新規有利区間移行時、裏ガメラモードを10.5%で選択。裏ガメラ中のボーナスはBIG濃厚で、平均約200G以上の滞在が期待されるため朝一の明確な恩恵。
- 表モード側もガメラ/超ガメラモード移行チャンスあり。
- reliability: ANALYSIS_HIGH

### resetPenalties
- 設定変更で前日の天井進行、内部モード、内部状態を失うため、前日が高確/有利なモードや天井接近状態ならその価値は消失。
- 設定変更専用の独立した定量的不利率は確認できない。

### resetDetection
- 有利区間ランプはWINセグ右下ドット。
- 通常時点灯型のため、未対策なら **朝一消灯=設定変更濃厚 / 朝一点灯=据え置き濃厚**。
- ただし前日が有利区間ランプ消灯中に閉店した場合や、店側が対策した場合は例外で確定判別ではない。
- 本機固有のリールガックン条件/発生率は `パチスロガメラ / SパチスロガメラKH / ガメラ6号機` と `ガックン / 設定変更 / リセット / 朝一 / 据え置き` を組み替え、1geki・HAZUSE・なな徹・旧解析系を再探索したが高信頼の直接資料を固定できず `UNVERIFIED_AFTER_RESEARCH`。

### numericResetData
- 設定変更後天井: **900G+α**。
- 有利区間移行時の裏モード振り分け: **通常86.4% / 準備3.1% / 裏ガメラ10.5%**。
- 裏ガメラモード: 当選ボーナスBIG濃厚、平均約200G以上滞在。
- 表モード初期全振り分け: `UNVERIFIED_AFTER_RESEARCH`。
- 設定変更専用の朝一特定G以内当選率: `NO_PUBLIC_RESET_SPECIFIC_RATE_FOUND_AFTER_RESEARCH`。

## missingFields
- 有利区間移行時の表モード（通常 / ガメラ / 超ガメラ）全初期振り分け率: `UNVERIFIED_AFTER_RESEARCH`。
- 本機固有のリールガックン条件/発生率: `UNVERIFIED_AFTER_RESEARCH`。
- 固定単一の純増枚数/G: `NOT_FIXED_SINGLE_RATE / NOT_DIRECTLY_COMPARABLE`。擬似ボーナス平均獲得枚数で比較する。

## conflicts
- 完全攻略時機械割のうち設定2・5に0.1pt資料差あり。HAZUSEは `102.5% / 106.5%`、別解析資料は `102.6% / 106.6%`。平均化せずHAZUSE値をcanonical、差異をCONFLICTとして保持。
- メーカー表記は資料により「Sammy」「銀座(サミー)」が混在。サミー公式が「製造元/株式会社銀座」と明記するため、製造元=銀座、発売・ブランド=サミーとして役割分離し、性能競合とは扱わない。
