### settingChangeBehavior
- 設定変更時はCZスルー回数天井を通常の6回目CZ到達から3回目CZ到達へ短縮。
- 内部状態を設定変更専用振り分けで再抽選。
- 押割ポイントを設定変更専用振り分けで再設定。
- 朝一実戦上の初期ステージは湖畔。
reliability: ANALYSIS_HIGH_MULTI_SOURCE

### carryOverBehavior
- 据え置き時はCZスルー天井進捗を引き継ぐ扱い。
- 内部状態も引き継ぎ扱いとする直接比較資料を確認。
- ボーナス成立ではCZスルー回数をクリアしないため、前日ART未当選のCZ進捗は据え置き時の朝一価値へ直結する。
reliability: ANALYSIS_HIGH_DIRECT_RESET_TABLE

### powerCycleBehavior
- 純電源OFF→ON時はCZスルー天井進捗を引き継ぐ。
- 内部状態も引き継ぐ。
- 設定変更時の天井短縮・状態再抽選とは区別する。
reliability: ANALYSIS_HIGH_DIRECT_RESET_TABLE

### gameCounterReset
- 固定G数天井ではなくCZスルー回数管理。
- 設定変更: CZスルー天井を3回へ短縮して再設定。
- 据え置き: 前日CZスルー回数進捗をCARRYOVER。
- 純電源OFF→ON: CARRYOVER。
reliability: ANALYSIS_HIGH_MULTI_SOURCE

### ceilingAfterReset
- 通常時: ART間CZ5スルー後、6回目CZでART確定。
- 設定変更後: CZ天井を3回目CZに短縮。
- 当時解析の試算では設定1のCZ出現率等を用いた平均到達目安が約645〜700G。これは固定ゲーム数天井ではなく解析上の平均値なので、天井G数として扱わない。
reliability: ANALYSIS_HIGH_MULTI_SOURCE

### modeAfterReset

- ゲーム数モード機として推測補完しない。
reliability: ANALYSIS_RESEARCH_EXHAUSTED

### resetPenalties
- 前日から深く進んでいたCZスルー回数は設定変更で消え、設定変更用3回天井へ置き換わるため、前日進捗が3回以上なら据え置き狙い価値は失われる。
- その他の設定変更専用不利要素は `NONE_CONFIRMED_AFTER_RESEARCH`。
reliability: ANALYSIS_HIGH_FOR_COUNTER / RESEARCH_FOR_OTHER_PENALTIES

### resetDetection
- ロデオ機の設定変更後ガックンを実機動画で確認する当時攻略資料があり、ガックン判別は有効と評価されている。

- 朝一湖畔ステージ単独は確定判別には使わない。
reliability: ANALYSIS_SINGLE_DIRECT_TEST_PLUS_MULTI_SOURCE_CONTEXT

- 2016年ロデオ機と2022年クロスアルファ製同名機を検索結果上で明示分離した。2022年の有利区間、666G天井、四魂ボーナス等は本レコードに使用していない。

- resetBehaviorは「犬夜叉 / パチスロ犬夜叉 / 犬夜叉ZX / 犬夜叉／ZX / ロデオ」と「設定変更 / リセット / 朝一 / 据え置き / 電源OFF ON / 天井 / CZ天井 / 状態 / ガックン」を組み替え、当時解析・旧DB・P-WORLD・K-Navi・業界記事・中古実機資料を横断した。
