## modeSpecificMinimumData

- ボーナスのみで通常出玉を増やすノーマルAタイプ。
- 技術介入あり。HYPER BIG/BIGは所定の14枚役取得で最大枚数を狙える。CHALLENGE BONUSも目押し成功で2択ベルナビを受けられる。
- 天井RT「サクラタイム」発動条件:
  - HYPER BIG / BIG後: **900G**
  - CHALLENGE BONUS後: **600G**
  - REG後: **700G**
- 天井RTは次回ボーナスまで継続、約+0.2枚/G。
- 通常時の長期モード、ART/AT/CZは確認されない。
