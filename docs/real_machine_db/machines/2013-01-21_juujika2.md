## basicPayout

- BR非搭載のAT機。
- AT「十字架RUSH」: 1セット30G+α、純増約+2.9枚/G。
- AT終了後は継続バトルで継続抽選。ゲーム数上乗せ特化ゾーンを複数搭載。
- 1セット30G部分の単純理論増加目安は約87枚だが、これは計算値であり実機の固定獲得枚数ではないためbasicPayoutの実測値としては採用しない。

## modeSpecificMinimumData

- 通常時の規定ゲーム数解除モードは **NORMAL A / NORMAL B / SUPER（リオナ）/ SUPER（ティナ）** の4種類。
- 小役解除も搭載。
- モード別天井は資料競合あり。
  - P-WORLD: NORMAL A **992G** / NORMAL B **944G** / リオナ **128G** / ティナ **32G**。
  - pacnk: 通常A **992G** / 通常B **944G** / リオナ **128G** / ティナ **32G**。
  - HAZUSE現行掲載: ノーマルA **1280G** / ノーマルB **944G** / リオナ **128G** / ティナ **32G**。
- NORMAL Aだけ 992G vs 1280G が競合するため平均せず `CONFLICT_NORMAL_A_CEILING_992_VS_1280` として保持。
- 193〜256G・481〜512G・897〜944Gでのゲーム数解除は通常B滞在の判別材料、945G以上ハマリは通常A滞在確定とする整理資料あり。

### settingChangeBehavior

- 設定変更時は **天井ゲーム数をリセット**する資料を確認。
- 設定変更後は **NORMAL Aが選択されず、NORMAL B以上からスタート**することを当時記事および後年整理資料で確認。
- したがって設定変更後の最大天井はNORMAL Bの **944G**（ペナルティ等の例外を除く）。
- K-Naviおよびパチマガスロマガにも本機専用の「設定変更時の挙動」「朝イチ・設定変更」解析項目が存在する。
- 設定変更時のNORMAL B / リオナ / ティナの具体的振り分け率は、表記揺れ・型式・メーカー・シリーズ名と「設定変更/リセット/朝一/モード移行率/振り分け」を組み替えて再探索したが直接数値を回収できず **UNVERIFIED_AFTER_RESEARCH**。

### carryOverBehavior

- 純据え置き時の規定ゲーム数カウンタ、内部モード、液晶ステージの完全な保持契約を本機固有の高信頼資料で直接確定できず **UNVERIFIED_AFTER_RESEARCH**。
- 設定変更後にNORMAL Aが選択されないことは確定しているが、その反対から純据え置き時の全内部状態保持を自動推定しない。

### powerCycleBehavior

- 設定変更を伴わない単純電源OFF→ON時の規定ゲーム数、内部モード、液晶ステージの契約は、検索語と資料系統を変えた再探索後も本機固有の直接仕様を確定できず **UNVERIFIED_AFTER_RESEARCH**。

### gameCounterReset

- 設定変更時: **CLEAR_CONFIRMED**。
- 据え置き時: **UNVERIFIED_AFTER_RESEARCH**。
- 電源OFF→ONのみ: **UNVERIFIED_AFTER_RESEARCH**。

### ceilingAfterReset

- 設定変更後はNORMAL Aが選択されないため、通常時の最深部候補から **最大944Gへ短縮**される。
- 通常A天井そのものは992G vs 1280Gで資料競合するが、設定変更後はNORMAL A非選択のため、リセット後最大944Gという朝一性能には影響しない。
- resetShortenedCeiling: **MAX_944G_CONFIRMED**。

### modeAfterReset

- 設定変更後: **NORMAL A非選択 / NORMAL B以上スタート**。
- 候補: NORMAL B（944G）/ SUPERリオナ（128G）/ SUPERティナ（32G）。
- 具体的振り分け率: **UNVERIFIED_AFTER_RESEARCH**。

### stateAfterReset

- 本DBで比較対象となる主要状態は規定G数解除モードで、設定変更時にNORMAL Aを除外して再セットされることを確認。
- これとは別の内部高低状態の設定変更時契約について、比較可能な直接資料は今回確認できず **UNVERIFIED_AFTER_RESEARCH**。

### advantageousSectionReset

- **NOT_APPLICABLE_5TH_GEN**。

### resetBenefits

- 最大の朝一恩恵は **設定変更後にNORMAL Aが選択されず、最大天井が944Gへ短縮**されること。
- リオナなら最大128G、ティナなら最大32Gとなるため、設定変更直後から浅い規定G数当選の可能性も存在。
- ただしリオナ/ティナ選択率そのものは今回未取得のため、朝一128G以内当選率などを推測計算しない。

### resetPenalties

- 設定変更で前日の規定ゲーム数進捗はクリアされるため、前日ハマリを利用した宵越し天井狙いには不利。
- それ以外の設定変更専用ペナルティ: **NONE_CONFIRMED_AFTER_RESEARCH**。

### resetDetection

- 設定変更後はNORMAL Aが選択されないため、**朝一からペナルティ等なしで945G以上ハマった場合は、設定変更後の通常挙動と矛盾する強い据え置き/非設定変更材料**となる。
- pacnkは945G以上ハマリを通常A滞在確定と整理している。
- 本機固有のリールガックン、初期出目、電源投入時液晶だけでの変更判別は再探索後も **UNVERIFIED_AFTER_RESEARCH**。

## conflicts

- 通常A天井: P-WORLD・pacnk・当時記事系の **992G** に対し、HAZUSE現行ページは **1280G**。NORMAL B 944G / リオナ128G / ティナ32Gは一致。平均せず `CONFLICT_NORMAL_A_CEILING_992_VS_1280` として保持。
- 設定変更後はNORMAL A非選択のため、本CONFLICTは「設定変更後最大944G」というresetBehaviorの結論には影響しない。
