### settingChangeBehavior
- 設定変更時は天井進行をRESETし、内部状態/モードを再抽選。
- 有利区間もRESETされ、有利区間移行時のモード抽選を受ける。
- 有利区間移行時は全設定共通で **50%以上が天国チャンスA / 天国チャンスB / パトランプ準備のいずれか** となる公開契約を確認。
- 正確な3モード個別振り分けは高信頼の直接資料で固定できないため推測しない。
- reliability: ANALYSIS_HIGH

### carryOverBehavior
- 据え置き時は天井進行、内部状態/モード、有利区間をCARRY_OVERとして扱う。
- 朝一有利区間ランプが点灯していれば据え置き濃厚材料となる通常時点灯型の挙動と整合。
- reliability: ANALYSIS_HIGH

### powerCycleBehavior
- 純電源OFF→ONでは天井進行と内部状態をCARRY_OVER。
- 有利区間も設定変更を伴わない純電断では引継ぎとして扱う。朝一ランプ判別資料とも整合する。
- reliability: ANALYSIS_HIGH

### gameCounterReset
- 設定変更: RESET。
- 据え置き / 純電断: CARRY_OVER。
- 通常天井は最大900Gまたはチェリー最大40回成立。公開リセット表は「天井RESET」と一括表記で、G数天井/チェリー天井を個別に分けた記述は確認できないため、天井進行全体のRESETとして保存。

### ceilingAfterReset
- 設定変更専用の固定短縮天井は確認できない。
- 設定変更後は通常天井進行が0から再開する。
- 朝一32G以内連チャン期待は有利区間移行時の優遇モード抽選によるものであり、「リセット後固定32G天井」とは扱わない。

### modeAfterReset
- 設定変更/有利区間リセット後にモードを再抽選。
- 全設定共通で **50%以上が天国チャンスA / 天国チャンスB / パトランプ準備**。
- 3モード個別の高信頼な設定変更専用振り分けは `UNVERIFIED_AFTER_RESEARCH`。
- 通常時のモード移行テーブルや低信頼まとめ値を朝一専用値として流用しない。

### stateAfterReset
- 設定変更: 内部状態をRESET/再抽選。
- 据え置き / 純電断: 内部状態をCARRY_OVER。
- reliability: ANALYSIS_HIGH

### resetBenefits

- これにより設定変更直後は32G以内連チャンにつながる上位寄りモード選択の機会が通常より明確に存在する。
- 固定の短縮天井や設定変更専用AT初当たり確率は確認できない。

### resetPenalties

- 設定変更専用の独立した定量的不利率は確認できない。

### resetDetection
- 通常時は有利区間ランプ点灯型。
- 朝一ランプ消灯なら設定変更濃厚、点灯なら据え置き濃厚。
- 前日が有利区間ランプ消灯状態で閉店した場合やホール側の対策等は例外となるため確定判別ではない。
- 本機固有のリールガックン条件/発生率は、`チバリヨ-30 / チバリヨ30 / SチバリヨZH-30 / オーゼキ / NET` と `設定変更 / リセット / 朝一 / 据え置き / 電源OFF ON / ガックン` を組み替えて再探索したが、高信頼の直接資料を固定できず `UNVERIFIED_AFTER_RESEARCH`。
