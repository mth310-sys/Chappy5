## resetBehavior

### settingChangeBehavior
- 本機の重要点は、**ボーナス高確率状態が設定変更でも引き継がれる**と当時の実戦攻略資料が明記していること。
- したがって前日ボーナス中またはボーナス高確率状態で閉店した台は、店側が状態転落まで回す等の対策をしない限り、設定変更後の翌朝もボーナス高確率状態から始まる可能性がある。
- これは一般的な「設定変更＝状態初期化」と異なるリノ系固有の挙動として保存する。
- 設定変更による専用ゲーム数モード、天井、初当たり優遇テーブルはNONE_CONFIRMED / NOT_APPLICABLE。
reliability: ANALYSIS_SINGLE_PERIOD_DIRECT_REPORT

### carryOverBehavior
- 前日ボーナス中/ボーナス高確率状態で閉店した台を翌朝狙えるという当時攻略記述があり、**ボーナス高確率状態の翌日CARRYOVERを支持**。
- 同資料は「リセット（設定変更）でも状態引き継ぎ」と明記しているため、据え置き時のみならず設定変更時にも高確率状態が消えない点が本機の朝一挙動の核心。
- 通常時のゲーム数天井・ゲーム数モードは非搭載。
reliability: ANALYSIS_SINGLE_PERIOD_DIRECT_REPORT

### powerCycleBehavior
- 純電源OFF→ONについて、一撃の当時ページは **「現在調査中」** としており、設定変更時の状態引継ぎから純電断の全内部契約を推定しない。
- ボーナス高確率状態、成立役、ランプ表示等の純電断時処理は **UNVERIFIED_AFTER_RESEARCH**。
reliability: UNVERIFIED_AFTER_RESEARCH

### gameCounterReset
- 通常時ゲーム数天井: **NOT_APPLICABLE / NONE**。
- 設定変更専用短縮天井: **NOT_APPLICABLE**。
- 高確率状態はゲーム数天井進捗ではなく、リノシステム上の内部状態として別管理。

### ceilingAfterReset
- **NOT_APPLICABLE**。通常天井自体を搭載しない。

### modeAfterReset
- ゲーム数管理型の朝一専用モード: **NONE_CONFIRMED / NOT_APPLICABLE**。
- ボーナス高確率状態は設定変更でも引き継ぐため、「設定変更時にモードを再抽選」とは扱わない。

### stateAfterReset
- **ボーナス高確率状態: CARRYOVER_EVEN_ON_SETTING_CHANGE_REPORTED**。
- 高確率状態中のボーナス確率目安は **約1/10**。
- 新台初日はメーカー出荷状態から高確率スタートとなる可能性があるとの当時攻略情報があり、朝一狙いとして注目されていた。
- ただし設定変更時の「高確率への新規移行率」を示す抽選値は確認されておらず、引継ぎと新規優遇を混同しない。
reliability: ANALYSIS_SINGLE_PERIOD_DIRECT_REPORT

### advantageousSectionReset
- **NOT_APPLICABLE_5TH_GEN_PRE_5_9**。

### resetBenefits
- 設定変更そのものによる天井短縮や高確率再抽選恩恵ではなく、**前日がボーナス高確率状態なら設定変更されてもその状態が残る**ことが朝一価値になる。
- 前日ボーナス中/高確率中閉店台、新台初日は店側対策がなければ朝一高確率スタートを狙える可能性がある。

### resetPenalties
- 設定変更で前日高確率状態を失うという不利は、当時攻略資料では否定方向（状態引継ぎ）。
- 設定変更専用のその他不利要素は **NONE_CONFIRMED_AFTER_RESEARCH**。

### resetDetection
- キャンドルランプはボーナス高確率状態を示唆し、ボーナス後は必ず点灯する。ただし当時資料はランプと内部状態の完全リンクを未確定としており、設定変更判別器としては扱わない。
- 設定変更でも高確率状態を引き継ぐため、高確率スタート自体は「設定変更された証拠」にならない。
- ガックン、初期出目、表示による本機固有の確定的設定変更判別は、検索語・資料系統を変えた再探索でも **NONE_CONFIRMED_AFTER_RESEARCH**。

### numericResetData
- 設定変更時モード振り分け: **NONE_CONFIRMED**。
- リセット短縮天井: **NOT_APPLICABLE**。
- リセット専用初当たり率: **NONE_CONFIRMED**。
- 参考状態値（リセット専用値ではない）: ボーナス高確率中ボーナス確率 **約1/10**、高確率ループ率目安 **約60%**。

## QA note
- 新規収集時に性能コア + resetBehavior v0.7を同時収録。
- リノ系の「高確率状態」はゲーム数モード/RT/ARTではなくリアルボーナス連チャン構造上の内部状態として分離した。
- 朝一価値は「リセットで新しく優遇される」のではなく「前日高確率状態が設定変更でも消えない」ことが中心。店側対策で状態転落まで回される場合は消失するため、ホール経営AIでは対策有無を別要因として扱える。
