### settingChangeBehavior
- 設定変更時は**天井ゲーム数RESET**。
- 内部モードは**RESET / 再抽選**とする直接比較資料を確認。
- 設定変更専用の短縮天井・専用CZ・公開された朝一モード振り分けは、検索語・資料系統を変えた再探索後も確認できない。

### carryOverBehavior
- 据え置きでは前日からの天井ゲーム数・内部モードを引き継ぐ挙動が基本と整理される。
- 直接比較資料は「設定変更 vs 電源OFF→ON」であり、据え置きについては電断のみ時の引継ぎ契約と宵越し構造から `CARRYOVER_SUPPORTED` とする。

### powerCycleBehavior
- 純電源OFF→ONのみでは**天井ゲーム数CARRYOVER**。
- 内部モードも**CARRYOVER**。
- 設定変更との差が明確にある。

### gameCounterReset
- 設定変更: **RESET**。
- 据え置き: **CARRYOVER_SUPPORTED**。
- 電源OFF→ONのみ: **CARRYOVER**。

### ceilingAfterReset
- 通常天井: **999G**。
- 設定変更後専用の固定短縮天井: **NONE_CONFIRMED_AFTER_RESEARCH**。

### modeAfterReset
- 設定変更: **RESET / 再抽選**。
- 電源OFF→ON: **CARRYOVER**。
- 設定変更時の通常A/B・チャンス・天国系各モードの具体的振り分け: **UNVERIFIED_AFTER_RESEARCH**。

### stateAfterReset
- AT機だが、モードとは別に朝一客行動へ影響する低確/高確等の専用内部状態振り分けは、当時解析・後年回顧・古DBを横断しても直接固定できず **UNVERIFIED_AFTER_RESEARCH**。

### advantageousSectionReset
- **NOT_APPLICABLE_5TH_GEN_PRE_5_9**。

### resetBenefits
- 設定変更専用の短縮天井、天国優遇率、朝一専用CZ、保証ボーナス等の公開恩恵: **NONE_CONFIRMED_AFTER_RESEARCH**。
- 通常時999G天井は設定変更時に0Gから再スタートするため、前日ハマリを失う点は朝一宵越し狙いには不利。

### resetPenalties
- 前日天井ゲーム数および高モード滞在を引き継がず再抽選となるため、据え置き時に存在した宵越し価値を失う可能性がある。
- 具体的な期待値・損失率は公開メーカー値として確認できず、数値化しない。

### resetDetection
- 「ミラクル / ミラクルMC / エレコ」×「設定変更 / リセット / 朝一 / 据え置き / 電源OFF ON / ガックン / リールガックン / 初期出目 / ランプ」を組み替え、当時解析・古DB・後年回顧を再探索。
- 本機固有の確定的なガックン、初期出目、ランプによる設定変更判別契約は **NONE_CONFIRMED_AFTER_RESEARCH**。
- 前日ゲーム数を把握していれば、据え置き時の999G天井到達挙動は事後的な推測材料になり得るが、朝一即時の確定判別ではない。

- `CONFLICT_PAYOUT_SETTING3_101_5_VS_101_6`: 期待値見える化・すろぱちくえすとは101.5%、pachislo-dataは101.6%。他設定は一致しており小数丸め/転記差の可能性が高いが平均せず保持。canonicalは複数一致の101.5%。
- `APPROX_PAYOUT_SETTING1_97_2_VS_97_3_LATER_MARKET_DB`: 後年中古実機DBに設定1=97.3%表記があるが、当時複数解析97.2%をcanonicalとする。
