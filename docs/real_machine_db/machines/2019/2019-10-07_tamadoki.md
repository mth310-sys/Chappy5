### settingChangeBehavior

- 同一正式型式 `Sオリスロ2AA` の当時解析で、設定変更時は **天井RESET / 内部状態再抽選 / モード再抽選**。
- 業界一次資料で各PB版はメイン基板・リール制御・ボーナス確率・出玉率が共通、サブ側の演出・設定示唆等が各社独自と確認できるため、メイン基板側reset契約として採用。

### carryOverBehavior

- タマどき！固有に「据え置き」を純電断から分離して規定する一次/当時専用資料は、表記揺れ・法人名・型式名を変えて再探索後も確認できず `UNVERIFIED_AS_DISTINCT_TAMADOKI_CONDITION`。
- 同一型式の電源OFF→ON契約では天井・内部状態・モード引継ぎ。

### powerCycleBehavior

- 同一正式型式の当時解析で **天井CARRY_OVER / 内部状態CARRY_OVER / モードCARRY_OVER**。
- コンチェルト版固有の朝一パネル/告知ランプ復帰表示は `PUBLIC_DETAIL_NOT_FOUND_AFTER_RESEARCH`。

### gameCounterReset

- 設定変更: RESET。
- 電源OFF→ONのみ: CARRY_OVER。
- 据え置き単独の直接記述は上記のとおり機種固有資料不足。

### ceilingAfterReset

- 通常最深1000G。
- 設定変更専用の短縮天井は `NONE_CONFIRMED_AFTER_RESEARCH`。

### modeAfterReset

- 設定変更: モード再抽選。
- 電源OFF→ON: モード引継ぎ。
- 設定変更時の各モード振り分け公開数値は `PUBLIC_NUMERIC_DISTRIBUTION_NOT_FOUND_AFTER_RESEARCH`。

### stateAfterReset

- 設定変更: 内部状態再抽選。
- 電源OFF→ON: 内部状態引継ぎ。
- タマどき！固有サブ演出状態の復帰契約は `UNVERIFIED_AFTER_RESEARCH`。

### advantageousSectionReset

- 6号機有利区間管理機。
- 同一型式解析で通常C非当選後の有利区間転落/再セット構造を確認。
- ただし **タマどき！固有の設定変更 / 据え置き / 純電断ごとの朝一有利区間ランプ状態を直接固定する資料** は `APPLICABLE_BUT_TAMADOKI_SPECIFIC_RESET_CONTRACT_PARTIAL`。
- 一般6号機仕様から追加推測はしない。

### resetBenefits

- 短縮天井、朝一専用高確、特定モード優遇率、朝一特定G以内当選率などの専用恩恵は `NONE_NUMERICALLY_CONFIRMED_AFTER_RESEARCH`。

### resetPenalties

### resetDetection
