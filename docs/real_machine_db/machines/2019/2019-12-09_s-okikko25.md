### settingChangeBehavior

- 設定変更時は **天井ゲーム数RESET**、有利区間もRESETされ非有利区間から再開するとする解析で一致。
- 新しい有利区間開始時にモードを選択。
- 設定1～5ではサンセットモードへの移行が約50%のため、朝一リセットが強い狙い目になる。

信頼度: ANALYSIS_HIGH_MULTI_SOURCE

### carryOverBehavior

- 据え置きでは **内部天井/有利区間進行を引き継ぐ**とする攻略運用が確認できる。
- 通常BではBONUS後も有利区間を引き継ぐことがあり、前日分を含む有利区間消化Gが狙い目に影響する。
- 前日閉店時に有利区間ランプ点灯なら、翌朝点灯継続は据え置き濃厚材料。

信頼度: ANALYSIS_HIGH

### powerCycleBehavior

- 純電源OFF→ONのみの場合は、攻略資料上 **設定変更されなければ内部天井/有利区間をCARRY_OVERする据え置き挙動**として扱われる。
- 本機固有の液晶表示・内部モードを項目別に明示した一次表は固定できず、内部モードの純電断単独契約は `PUBLIC_DIRECT_MODE_CONTRACT_NOT_FOUND_AFTER_RESEARCH`。

信頼度: ANALYSIS_HIGH_FOR_CARRY_OVER / PARTIAL_FOR_DISPLAY_DETAIL

### ceilingAfterReset

- リセット時専用の短縮天井は `NONE_CONFIRMED_AFTER_RESEARCH`。
- リセットの価値は天井短縮ではなく、有利区間再移行時のサンセットモード高選択率にある。

### modeAfterReset

- 有利区間移行時にモードを選択。
- 設定1～5: モードA 約15～25% / モードB 約25～35% / サンセット 約49.6～50%。
- 設定6: モードA 約66% / モードB 0% / サンセット 約34%。
- これらは有利区間移行時の公開モード比率として朝一リセットに直接関係するため保存。

### stateAfterReset

- 設定変更後は新規有利区間としてモード選択から開始。
- モードとは別の高確/低確等について、設定変更専用の独立状態テーブルは `PUBLIC_VALUE_NOT_FOUND_AFTER_RESEARCH`。

### advantageousSectionReset

- 設定変更: **RESET / 非有利区間経由**。
- 据え置き/純電断: **CARRY_OVER**。
- 通常時の有利区間ランプは状況により点灯/消灯があるため、前日閉店時状態との比較が必要。

### resetBenefits

- 最大の朝一恩恵は **有利区間再移行時に設定1～5で約50%がサンセットモード**。
- サンセットモードは **111G以内BONUSを3セット保証**、業界記事の期待獲得は約500枚。
- 後年攻略では0Gから111Gまでをリセット狙い対象とするほど強い朝一特性として扱われる。

### resetPenalties

- 設定変更専用の主要不利要素は `NONE_CONFIRMED_AFTER_RESEARCH`。

### resetDetection

- 前日閉店時に有利区間ランプが **点灯**していたことを確認できる場合:
  - 翌朝消灯 = 設定変更濃厚
  - 翌朝点灯 = 据え置き濃厚
- 前日消灯の場合はランプだけでは判別困難。
- 本機固有のリールガックン条件/発生率は検索語変更後も固定できず `PUBLIC_GAKKUN_CONTRACT_NOT_FOUND_AFTER_RESEARCH`。
