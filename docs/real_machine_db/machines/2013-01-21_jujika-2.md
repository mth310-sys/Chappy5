## basicPayout

- AT「十字架RUSH」: 1セット30G+継続バトル+上乗せ分、純増約+2.9枚/G。
- ATは全10セット構成。10セット到達後は20Gのエンディングを経由し、次回32G以内当選のSUPER MODEティナへ移行する資料あり。
- 上乗せ特化: リオナチャンス / CROSS CHARGE MODE / CROSS DRIVE MODE / TRIPLE COMBO MODE。
- 青7フリーズ: 十字架RUSH 5連以上濃厚。
- confidence: ANALYSIS_HIGH_MULTI_SOURCE

## modeSpecificMinimumData

- 通常時は **NORMAL MODE A / NORMAL MODE B / SUPER MODEリオナ / SUPER MODEティナ** の4モード。

### settingChangeBehavior

- 設定変更後は **NORMAL Aを選択しない**ことを2013年導入直前の当時記事で確認。
- 後年設定判別DBも **設定変更後はNORMAL B以上スタート、天井ゲーム数リセット** と整理しており、設定変更時は前日のゲーム数進捗を引き継がず、モードを再選択する扱いとする。
- ただし設定変更時のNORMAL B / SUPERリオナ / SUPERティナの具体的振り分け率は今回回収できず **UNVERIFIED_AFTER_RESEARCH**。

### carryOverBehavior

- 純据え置き時に前日ゲーム数・モードをそのまま保持することを、本機固有の高信頼資料で独立条件として直接確定できず **UNVERIFIED_AFTER_RESEARCH**。

### powerCycleBehavior

- 設定変更を伴わない単純電源OFF→ON時のゲーム数、モード、液晶状態の保持/初期化を本機固有資料で直接確定できず **UNVERIFIED_AFTER_RESEARCH**。
