## basicPayout

- BR非搭載のAT機。
- AT「十字架RUSH」: 1セット30G+継続バトル+上乗せ分、純増約+2.9枚/G。
- 上乗せ特化: リオナチャンス / CROSS CHARGE MODE / CROSS DRIVE MODE / TRIPLE COMBO MODE。

## modeSpecificMinimumData

- 通常時は **NORMAL MODE A / NORMAL MODE B / SUPER MODEリオナ / SUPER MODEティナ** の4モード。
- P-WORLD・pacnk主系列: A **992G** / B **944G** / リオナ **128G** / ティナ **32G**。
- HAZUSE現行整理ページのみNORMAL A **1280G**。B/リオナ/ティナは944/128/32Gで一致。
- NORMAL Aは平均せず `CONFLICT_NORMAL_A_992_VS_1280` として保持。
- pacnkは193〜256G・481〜512G・897〜944G解除を通常B、945G以上ハマリを通常A確定と整理。

### settingChangeBehavior

- 設定変更時は **天井ゲーム数CLEAR_CONFIRMED**。
- 設定変更後は **NORMAL A非選択 / NORMAL B以上スタート CONFIRMED**。2013年導入直前記事と後年設定判別DBで照合。
- 変更後候補は NORMAL B / SUPERリオナ / SUPERティナ。
- B / リオナ / ティナの設定変更専用振り分け率は、機種名・十字架II・型式名・NETと「設定変更/リセット/朝一/モード移行率/振り分け」を組み替えて再探索したが直接数値を回収できず **UNVERIFIED_AFTER_RESEARCH**。

### carryOverBehavior

- 純据え置き時の前日ゲーム数・モード・液晶状態を独立条件として直接明示する本機固有高信頼資料は、再探索後も確定できず **UNVERIFIED_AFTER_RESEARCH**。
- 設定変更後A非選択の反対から全内部状態保持を推測しない。

### powerCycleBehavior

- 設定変更を伴わない単純電源OFF→ON時のゲーム数、モード、液晶状態の保持/初期化は、本機固有資料で直接確定できず **UNVERIFIED_AFTER_RESEARCH**。
