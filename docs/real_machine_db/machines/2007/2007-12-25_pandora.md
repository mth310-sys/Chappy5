## identification

- マルハン50周年記念の同社チェーン専用機。
- グリーンべると/P-WORLD業界ニュースで、アリストクラートテクノロジー社製、2007年12月25日からマルハン各チェーン店舗へ設置開始と確認。
- 4ラインの準完全告知機。下部パネルに `50th Anniversary` 表記。
- マルハン全店での総導入台数は366台、1店舗あたり1〜5台と当時業界記事に記録される。

## modeSpecificMinimumData

- 基本は小役同時当選メインのノーマルタイプ。
- 「ツボ」（0枚役）や「スイカ」（特殊リプレイまたは中段揃い0枚役）の成立後、次ゲームから5G RT「パンドラチャンス」へ入り、上部7セグで抽選演出。
- 当時回顧記事でも「演出用プチRTを搭載した基本ノーマルタイプ」と整理されている。
- 通常時ゲーム数天井、ART/AT、CZ初当たり構造は確認されない。

## resetBehavior

### settingChangeBehavior
`UNVERIFIED_AFTER_RESEARCH`。

`パンドラ アリストクラート 設定変更 / リセット / 朝一 / RAM / 初期化` 等で当時解析・旧DB・回顧資料を横断したが、本機固有の設定変更時内部処理を直接説明する資料を確定できなかった。

### carryOverBehavior
`UNVERIFIED_AFTER_RESEARCH`。

通常時天井や蓄積型モードの公開仕様は確認されないが、据え置き時の5G RT残Gや成立済みボーナス/内部状態の扱いを本機固有に説明する資料は確定できないため一般論から推定しない。

### powerCycleBehavior
`UNVERIFIED_AFTER_RESEARCH`。

電源OFF→ONのみでのRT残G、初期出目、表示状態等を本機固有に説明する現存資料を確認できなかった。

### gameCounterReset
- 通常時ゲーム数天井: `NONE_CONFIRMED`。
- 天井用ゲーム数カウンタの設定変更時リセット/引継ぎ: `NOT_APPLICABLE_OR_NONE_CONFIRMED`。

### ceilingAfterReset
- リセット短縮天井: `NONE_CONFIRMED`。
- 朝一専用天井: `NONE_CONFIRMED`。

### modeAfterReset
設定変更専用モード、朝一専用モード、公開モード振り分け: `NONE_CONFIRMED`。

### stateAfterReset
5G RT「パンドラチャンス」中の設定変更/電断時状態処理は `UNVERIFIED_AFTER_RESEARCH`。通常時に比較可能な高確/ART/ATモードは `NONE_CONFIRMED`。

### advantageousSectionReset
`NOT_APPLICABLE`（2007年5号機、有利区間制度前）。

### resetBenefits
朝一/設定変更専用の天井短縮、当選率優遇、専用RT/CZ恩恵: `NONE_CONFIRMED`。

### resetPenalties
設定変更時のみの主要な公開不利要素: `NONE_CONFIRMED`。

### resetDetection
ガックン、初期出目、7セグ/ランプ表示等による本機固有の設定変更/据え置き判別法: `UNVERIFIED_AFTER_RESEARCH`。

### numericResetData
公開された朝一専用数値、設定変更専用モード振り分け、短縮天井G数、リセット恩恵率: `NONE_CONFIRMED`。
