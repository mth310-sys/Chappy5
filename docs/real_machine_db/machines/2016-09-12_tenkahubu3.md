### settingChangeBehavior
- ART間天井ゲーム数: RESET。
- 信長 / 秀吉 / 家康の3武将モード: RESELECT。
- 設定変更後は3つの武将モードのうち最低1つが高確以上で開始する公開解析が複数系統で一致。
- 朝一表示ステージは解析資料で信長ステージ / 信長(夕方)ステージと整理されている。

### carryOverBehavior
- 据え置きではART間天井ゲーム数を引き継ぐ扱い。
- 3武将の内部モードも引き継ぐ扱い。
- モードは各武将CZ当選まで転落しない仕様のため、前日状態が高確以上なら据え置き朝一の価値が残り得る。

### powerCycleBehavior
- 純電源OFF→ON時: ART間天井ゲーム数 CARRYOVER。
- 内部モード: CARRYOVER。
- 一撃の2016年当時ページは状態を当時「調査中」としていたが、後発当時解析複数では内部モード引継ぎで一致。古い未確定表記と後発確定解析を時系列分離し、後発一致をcanonicalとする。

### gameCounterReset
- 設定変更: RESET。
- 据え置き / 純電源OFF→ON: CARRYOVER。
- ART間999Gカウンタは天下ボーナス / 決戦ではリセットされない。

### ceilingAfterReset
- 通常天井: ART間999G。
- 設定変更専用の固定短縮天井: NONE_CONFIRMED_AFTER_RESEARCH。
- 朝一の価値は天井短縮ではなく、武将モード再抽選による高確以上スタート保証に由来する。

### modeAfterReset
- 3つの武将モードを再抽選。
- 抽選順そのものは以下3通りが1:1:1。
  - 信長→秀吉→家康
  - 家康→信長→秀吉
  - 秀吉→家康→信長
- 抽選順1番目は必ず高確以上となるため、設定変更後は最低1武将が高確以上。

### stateAfterReset
- 本機の朝一主要状態は3武将モードで表現されるため、独立した別高確状態として二重計上しない。
- ART継続状態は通常営業の設定変更時には持ち越し対象として扱う根拠を今回の公開資料から固定していないため、実機完全再現用の補完はしない。

### advantageousSectionReset
- NOT_APPLICABLE_5TH_GEN_PRE_5_9。

### resetBenefits
- 設定変更後は3武将モードのうち最低1つが高確以上確定。
- 高確以上のモードは対応CZ当選まで転落しないため、朝一0Gから最初のCZまでを狙う立ち回りが当時解析で推奨されていた。
- 低設定帯ほど抽選順1番目が超高確になりやすい公開振り分けとなっている。

### resetPenalties
- ART間天井進捗は設定変更で消失。
- 据え置き時に残る前日高確以上モードも設定変更では再抽選されるため、前日状態の保持価値は失われる。
- その他の設定変更専用不利要素は NONE_CONFIRMED_AFTER_RESEARCH。

### resetDetection
- 当時解析複数で設定変更時ガックンあり / 電源ON-OFFのみではなしと整理されている。
- 山佐筐体のガックンは幅が小さく難易度が高いとされ、ホール側対策の影響も受けるため、メーカー保証の確定契約ではなく `GACKUN_REPORTED_USEFUL_NOT_MANUFACTURER_GUARANTEE` として扱う。
- 朝一ステージは信長ステージ系で共通化されるため、ステージ単独を確定判別には採用しない。

## dataQualityNotes
- 一撃の2016-10-12時点では設定変更/電断後の「状態」を調査中としていたが、その後の当時解析では3武将内部モードの再抽選/引継ぎと詳細振り分けが公開されている。古い調査中表記を欠損確定として扱わず、後発解析を採用。
- 「信長ステージ」と「信長(夕方)ステージ」の朝一表示表記揺れがある。内部モード振り分けとは独立の表示項目として扱う。
- ART純増約1.7枚/Gとボーナス込み約1.9枚/Gは定義差でありCONFLICTではない。
- CZスルー回数管理はゲーム数天井とは別契約。物差しDBでは主要リセット挙動をART間999Gと3武将モードに置き、スルー回数は補助情報に留める。
