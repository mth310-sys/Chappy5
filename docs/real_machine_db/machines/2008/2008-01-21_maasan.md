## releaseDateEvidence

- 2008-01-21付のサミーネットワークス発表文（4Gamer転載）で、ラスターの実機「まぁさん」を「ホールへの実機導入に併せて1月21日（月）に同時配信」と明記。日精度の一次発表に近い資料として、本DBの主releaseDateは `2008-01-21` とする。
- 一方、P-WORLDは「導入開始：2007年12月」、5号機クロニクルも「導入時期：2007/12」と掲載。さらにP-WORLD掲示板には2007-12-05/08付の機種言及が残る。
- 2007-12と2008-01-21は平均・丸めず `CONFLICT_DATE_MONTH_VS_ANNOUNCED_HALL_INTRODUCTION` として双方を保持する。

## conflicts

- `CONFLICT_DATE_MONTH_VS_ANNOUNCED_HALL_INTRODUCTION`: 4Gamer掲載サミーネットワークス発表文は2008-01-21を実機導入同時日として明記する一方、P-WORLD/5号機クロニクルは2007-12。P-WORLD掲示板にも2007年12月上旬の機種言及が残る。平均せず双方保持し、本DB主日付は日精度の発表文 `2008-01-21`。
- `CONFLICT_PAYOUT_METHOD_OR_SOURCE`: K-Navi `97.1 / 99.2 / 103.2 / 108.5%` と5号機クロニクル `97.6 / 99.7 / 103.9 / (設定7欠落)`。設定1/3/5は0.5〜0.7pt差。平均せず双方保持。
- `P_WORLD_PAYOUT_TEXT_FORMAT_NOTE`: P-WORLD検索表示はボーナス純増の行対応が崩れて見えるため、獲得枚数主値はパチマガスロマガの赤7 336枚 / 青7 312枚 / MID 104枚を採用し、P-WORLDは確率照合に使用。
