## 性能コア

### payoutRateBySetting

設定構成は `1 / 3 / 5 / 6`。

- パチマガスロマガ シミュレート値: `96.81 / 99.91 / 103.98 / 109.98%`
- K-Navi: `95.97 / 99.80 / 104.83 / 111.78%`
- 5号機クロニクル: `96.0 / 99.8 / 104.8 / 111.8%`
- 特に設定5・6は単純な丸めでは説明できない差があるため平均化せず `CONFLICT_PAYOUT_RATE` として全系列を保持する。

### initialHitBySetting

主系列はパチマガスロマガおよびP-WORLDの一致値を採用する。

- BIG: `1/228.35 / 1/214.17 / 1/199.80 / 1/177.12`
- REG: `1/358.12 / 1/318.14 / 1/297.89 / 1/271.93`
- ボーナス合成: `1/139.44 / 1/128.00 / 1/119.59 / 1/107.26`

K-Naviのみ設定1 BIGを `1/222.35` と掲載する一方、パチマガスロマガ、P-WORLD、2008年当時攻略記事は `1/228.35` 系列で一致する。K-Navi値は消さず `CONFLICT_BIG_SETTING1_222.35_VS_228.35` として残す。

### baseGamesPer50

パチマガスロマガ 1000円あたりゲーム数（設定1/3/5/6）:

- `35.59 / 35.68 / 36.55 / 36.94G`

50枚貸し1000円基準として本DBの比較用 `baseGamesPer50` に採用。

### netIncrease

- RT「SHOOTING TIME」: 約 `+0.1枚/G`
- 継続77G、ボーナス成立でも終了。

### basicPayout

- BIG: 規定払い出し253枚超で終了、純増約200枚。
- REG: 規定払い出し65枚超で終了、純増約50枚。
- K-NaviはBIGを「235枚を超える払い出しで終了」と掲載しており、パチマガスロマガの253枚表記と競合するため `CONFLICT_BIG_PAYOUT_THRESHOLD_235_VS_253` として保持する。

### modeSpecificMinimumData

- ボーナス終了後は必ず7GのCZへ移行。
- CZ中に特殊リプレイ入賞で77GのRT「SHOOTING TIME」へ突入。
- RT期待度は当時攻略記事でBIG後約60%、REG後約30%。
- RT純増約+0.1枚/G。
- 通常時・ボーナス成立時・ボーナス中とも目押し不要を売りにした設計。
- 通常ゲーム数天井は今回確認できず、公開攻略構造上もボーナス後CZ→RTが中心。

### resetBehavior調査メモ

- `ドキューン / PSドキューンGB / 三洋物産` と `設定変更 / リセット / 朝一 / 朝イチ / 据え置き / 電源OFF ON / 電断 / CZ / RT / 77G / SHOOTING TIME / 天井 / ガックン / 初期出目` を組み替えて探索。
- パチマガスロマガ現存インデックスに「攻め時・ヤメ時・設定変更時」項目の存在は確認できるが、検索結果から本機固有の設定変更本文を直接取得できず、推測で補完しない。
- ボーナス後7G CZ・77G RTという通常時状態遷移は複数資料で確認できるが、設定変更・据え置き・電源OFF→ON時にCZ/RT残状態を初期化するか引き継ぐかは直接資料を確定できなかった。
- 通常ゲーム数天井、朝一専用短縮天井、設定変更専用モード、設定変更固有恩恵/不利、公開朝一数値は十分な再探索後も確認できず `NONE_CONFIRMED`。
- ガックン、初期出目、ランプ等による本機固有の変更判別も直接資料を確定できず `UNVERIFIED_AFTER_RESEARCH`。
- 有利区間は5号機初期のため `NOT_APPLICABLE`。
