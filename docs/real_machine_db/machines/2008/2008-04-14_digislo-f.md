- 25φのデジスロFは実質ボーナス主体で、RTはハマリ救済用。

### resetBehavior調査メモ

- 通常時のボーナス間777G天井RT自体は確認済み。
- `設定変更 / リセット / 朝一 / 朝イチ / 据え置き / 電源OFF ON / 電断 / 777G / 天井RT / 天井短縮 / ガックン / 初期出目` を機種名・メーカー名と組み替えて再探索したが、設定変更時に777Gカウンタがリセットされるか、据え置き・電源OFF→ONで引き継ぐかを直接説明する本機固有資料は確定できなかった。
- 朝一専用モード、短縮天井、設定変更専用恩恵/不利、公開朝一数値は確認できず、一般的な5号機の挙動を流用しない。
