- 設定1/4/6の3段階。
- 通常時から突入する100Gの「クランキーチャレンジ」系RTを搭載。
- RT契機役出現率は全設定共通1/655.36とする複数資料あり。
- RT中にボーナス成立しても規定ゲーム終了まで継続する完走型RTとして後年の専門記事で確認。
- 技術介入性が高く、REG相当中は目押し手順が出玉へ影響。
