### modeSpecificMinimumData

- ボーナス終了後は必ずCZへ移行。
- CZ中に通常リプレイまたは1枚役の終了契機より先に特殊リプレイが入賞すると無限ART「クローズチャンス」へ。
- CZ終了後は100G消化で再度CZへ。通常時も100G周期でCZ突入。
- 特殊リプレイはCZ中なら基本的にART、通常時ならボーナス確定。
- ART中の詳細内部抽選・小役別抽選は本DB対象外。

### resetBehavior詳細

- P-WORLDは「設定変更後は内部的にチャンスゾーンからスタート」と明記。
- 朝一にいきなりARTへ突入した場合は設定変更濃厚とされ、客側からの変更判別に直接影響するためresetDetectionへ保存。
- 通常時はCZ終了から100G消化で再度CZへ入るため、設定変更時のCZスタートは通常の100G周期を待たず朝一からART機会を持つ主要恩恵。
- 据え置き時の100G周期カウンタ引継ぎ/初期化、電源OFF→ONのみでの周期/CZ/ART状態、設定変更での周期カウンタ具体処理は本機固有の直接資料を十分再探索しても確定できず一般論で補完しない。
- 設定変更後CZからのART突入率など、比較可能な朝一専用確率は現存公開資料で未確認。
