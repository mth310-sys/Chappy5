## modeSpecificMinimumData

- 通常時はART期待度に関わる低確・高確・超高確の内部状態が存在。
- 別系統としてカプセル獲得期待度の低確・高確・超高確「カプセルモード」が存在。
- カプセル7個でART。第1カプセル7個でゼロスアタック、第2カプセル7個で次回ボーナスまで継続するHYPERゼロスアタック。
- ART「ゼロスアタック」の基本セットG数は資料競合あり。P-WORLD/パチビーは「1セット30G以上+α」、パチマガスロマガは「1セット40G」。平均・補正せずCONFLICT保持。
- ART中はCHANCE POINT/CHARGE GAMEによるゲーム数上乗せ。グリーンべるとでは40Gごとの上乗せ抽選、最大200G周期を説明。
- VICTORYラッシュはグリーンべると/HAZUSEでART初当たり約6回に1回とされる。
