## conflicts

1. **設定5機械割**
   - P-WORLD 30φ、みんスロ30φ、K-Navi 25φ: 110.0%
   - crankyseven: 111.0%
   - 多系統一致の110.0%を主値とし、111.0%は `CONFLICT_SINGLE_SECONDARY_SOURCE` として保持。平均しない。

2. **導入日の定義**
   - 沖縄先行導入: 2012-08-09（グリーンべると、30φ固有）
   - 全国ホール導入: 2012-09-24（みんスロ）
   - 全国導入予定: 2012年9月下旬（グリーンべると2012-08-09）
   - 納品開始: 2012-09-23（グリーンべると2012-07-27）
   - メーカー公式: 2012年9月発売
   - 地域先行/全国導入/納品/発売月という定義差として全て保持。時系列本線キーは全国導入2012-09-24。

3. **REGゲーム数**
   - 2012年当時天井攻略記事: REG 33G
   - 既存25φレコード: REG 22G、平均約45枚
   - P-WORLD/業界記事は平均約45枚を明示するがゲーム数を直接固定していないため、30φでは平均獲得約45枚を主値とし、33G/22Gは解消せず `CONFLICT_OR_DEFINITION_DIFFERENCE` として保持。
