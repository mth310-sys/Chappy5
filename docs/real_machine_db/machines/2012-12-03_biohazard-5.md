## resetBehavior

### settingChangeBehavior

- **天井までのゲーム数は再セット**。
- **通常時モードは再抽選**。
- **内部状態も再抽選**。
- 朝一表示は **集会場ステージ / サブ液晶クリス**。
- 当時解析資料が設定変更と電源ON/OFFを並列表で直接区別しているため、本機固有契約として採用。

### carryOverBehavior

- 「据え置き」という語で独立明記された契約は今回の高信頼資料では回収できず **UNVERIFIED_AFTER_RESEARCH_AS_EXPLICIT_WORDING**。
- ただし、設定変更を伴わない単純な電源ON/OFFでは、天井G・モード・内部状態をすべて引き継ぐ直接契約を確認。

### powerCycleBehavior

- **電源OFF→ONのみでは、天井までのゲーム数を引き継ぐ。**
- **通常時モードを引き継ぐ。**
- **内部状態を引き継ぐ。**
- 表示上は設定変更時と同じく集会場ステージ / サブ液晶クリスとなるため、表示だけでは設定変更か純電断かを確定できない。

### gameCounterReset

- 設定変更: **CLEAR / RESET**。
- 電源OFF→ONのみ: **CARRY_OVER**。
- 据え置き: 明示語としては **UNVERIFIED_AFTER_RESEARCH**。ただし純電断契約はCARRY_OVER。

### ceilingAfterReset

- 設定変更後は天井ゲーム数が再セットされる。
- 設定変更専用の999G未満への短縮天井は **NONE_CONFIRMED_AFTER_RESEARCH**。
- 通常A～Cは最大999G、天国/超天国は99G。
- リセット時は天国選択25%が公開されているため、結果として25%は短い99G系モードから開始するが、これを「リセット専用短縮天井」とは定義しない。

### modeAfterReset

- 設定変更時のモード振り分け:
  - 通常A: **0%**
  - 通常B: **62.5%**
  - 通常C: **12.5%**
  - 天国A: **25.0%**
  - 天国B/超天国相当: **0%**（当該資料表記に従う）
- 当時解析資料は「103GまでにART当選する天国モードが25%」と説明。
- 電源OFF→ONのみ: **モード引継ぎ**。

### stateAfterReset

- 設定変更時の高確前兆抽選状態:
  - ロー: **0%**
  - ミドル: **25.0%**
  - ハイ: **37.5%**
  - スペシャル: **37.5%**
- よって設定変更時は **ハイ以上75.0%**。
- 電源OFF→ONのみ: **内部状態引継ぎ**。

### advantageousSectionReset

- **NOT_APPLICABLE_5TH_GEN**。

### resetBenefits

- 設定変更時は **天国モード25.0%**。
- 設定変更時は高確前兆抽選状態 **ハイ以上75.0%**。
- 通常Aが選択されない公開振り分けのため、朝一は通常営業中のモード分布とは異なる明確な専用再抽選契約を持つ。

### resetPenalties

- 設定変更で前日の天井進捗・前日モード・前日内部状態を失うため、宵越し天井/高状態狙いには不利になり得る。
- ただしリセット時の天国25%・ハイ以上75%という朝一優遇も同時に存在するため、単純に不利のみとは扱わない。

### resetDetection

- 集会場ステージ / サブ液晶クリスは設定変更時にも電源ON/OFF時にも共通の初期表示となるため、**表示単独では変更判別不可**。
- 103G以内のART当選は天国25%というリセット時公開値から設定変更期待を上げる材料にはなるが、当選しただけで設定変更確定ではない。
- ガックン・リール出目等の本機固有の確定/濃厚判別契約は、表記・資料系統を変えた再探索後も **UNVERIFIED_AFTER_RESEARCH**。

### publicMorningNumbers

- 設定変更時モード: **通常B62.5% / 通常C12.5% / 天国25.0%**。
- 設定変更時内部状態: **ミドル25.0% / ハイ37.5% / スペシャル37.5%**。
- **ハイ以上75.0%**。
- 朝一天国は103G以内ART当選の目安として当時資料に掲載。
