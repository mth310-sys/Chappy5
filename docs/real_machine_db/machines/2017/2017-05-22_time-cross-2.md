### settingChangeBehavior
- ノーマルAタイプで天井・AT/ART・CZ・ゲーム数管理型モードを搭載しないため、設定変更による天井再セット/短縮やAT系朝一モード優遇はNOT_APPLICABLE。
- 設定変更専用の当選率優遇・不利、朝一専用性能状態は、機種名/型式/山佐と「設定変更」「リセット」「朝一」「据え置き」「電源OFF ON」「ステージ」「ガックン」を組み替え、業界資料・当時解析・機種DBを横断したがNONE_CONFIRMED_AFTER_RESEARCH。
reliability: ANALYSIS_HIGH_FOR_SYSTEM; NONE_CONFIRMED_FOR_SPECIAL_RESET_EFFECT

### resetDetection
- すろぱちくえすとは設定変更時について「山佐なのでガックンする可能性大」と記載しており、これはメーカー傾向に基づく推測表現で本機固有確定情報ではない。
- 2-9伝説には本機の「ガックンリール動画」項目が存在し、実機リール挙動の観察資料があったことを確認できる。ただし取得可能テキストには「設定変更時のみ必ずガックン」「据え置きなら発生しない」等の決定的契約が明記されていない。
- よって本DBでは `GAKKUN_OBSERVATION_AVAILABLE_BUT_NOT_DETERMINISTIC` とし、ガックン単独で設定変更確定とは扱わない。
reliability: ANALYSIS_SINGLE_OBSERVATIONAL_FOR_GAKKUN; NOT_DETERMINISTIC
