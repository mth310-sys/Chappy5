## modeSpecificMinimumData
- 通常時は **1周期99G+α** の周期管理。1周期でミタマを集め、周期到達時の「滅ノ刻」でミタマ1個ごとにART抽選。
- 通常時の最大天井: **12周期**。実戦上の到達帯はおおむね1400～1500G付近との解析資料あり。
- 12周期目は **モードD（極モード）確定**。極モードでは周期内で獲得したミタマが全てマグマ柄となる。
- ART当選時に未消化ミタマが残っていればART終了後に再度抽選へ回る。
reliability: ANALYSIS_HIGH_MULTI_SOURCE

### settingChangeBehavior
- 設定変更で **周期天井RESET**、**周期モード再抽選**、**ミタマ保留RESET**。
- 設定変更時は通常時とは別の天井周期振り分けとなり、設定1～5は最大7周期へ短縮。設定6のみ12周期選択が12.5%存在する。
- 周期モードは設定変更時にモードAを選ばず、全設定でモードD（極モード）が25.0%。
reliability: ANALYSIS_HIGH_MULTI_SOURCE_DIRECT_TABLES

### carryOverBehavior
- 据え置き時は、設定変更が行われていない前提で **周期天井・周期進行・周期モードを引き継ぐ**扱いが解析資料の純電断表と整合。
- ミタマ保留は純電源OFF→ONでは一時非表示となるが、周期到達で再表示するため内部的には引継ぎ。
- 「据え置き」という独立操作の別契約ではなく、設定変更なし＋電源OFF→ONの公開表を基礎に記録。
reliability: ANALYSIS_HIGH_FOR_POWER_CYCLE_CARRYOVER / ANALYSIS_INFERRED_EQUIVALENT_FOR_STAY_SETTING_OPERATIONAL_CONTEXT

### powerCycleBehavior
- 純電源OFF→ON: **周期天井CARRYOVER / 周期到達G数CARRYOVER / 周期モードCARRYOVER**。
- ミタマ保留は **非表示になるが周期到達で再表示**。
- 朝一ステージは設定変更・電断とも **ウタカタの里 or モノノフ本部** とする解析表があり、ステージ単独では確定判別材料にならない。
reliability: ANALYSIS_HIGH_DIRECT_TABLE

### gameCounterReset
- 設定変更: **RESET**。
- 据え置き/純電源OFF→ON: **CARRYOVER**。
- 本機はG数ではなく周期天井管理が中心で、1周期99G+α。
reliability: ANALYSIS_HIGH_MULTI_SOURCE

### ceilingAfterReset

  - 設定3: **1周期12.5% / 3周期37.5% / 7周期50.0% / 12周期0%**
  - 設定4: **1周期12.5% / 3周期43.8% / 7周期43.8% / 12周期0%**
  - 設定5: **1周期12.5% / 3周期37.5% / 7周期50.0% / 12周期0%**

### modeAfterReset
- 設定変更時の周期モード振り分け:

- **モードD = 極モード**。したがって全設定共通で設定変更後25.0%が極モード開始。

### resetBenefits
- **最大天井短縮**: 設定1～5は最大7周期。設定6も87.5%は7周期以内。
- 設定変更後は **1周期または3周期が合計50.0%～56.3%**（設定により差）で選択され、通常ART終了後より浅い周期が大幅優遇。
- **全設定25.0%でモードD（極モード）**。
- 解析資料では0Gから狙えるほど強いリセット恩恵として扱われているが、期待値額は機種性能コアに不要なため保存しない。
reliability: ANALYSIS_HIGH_MULTI_SOURCE

### resetPenalties
- 設定変更専用の主要不利要素: **NONE_CONFIRMED_AFTER_RESEARCH**。
- ただし据え置きなら保持される前日ミタマ保留・周期進捗を設定変更では失うため、前日状況次第では「引継ぎ価値の消失」が実務上の不利になり得る。固定的な朝一ペナルティとしては扱わない。
reliability: NONE_CONFIRMED_AFTER_RESEARCH_FOR_FIXED_PENALTY

### resetDetection
- ガックンについて資料競合あり。期待値見える化は **「おそらく可能」**、後年リセット一覧は **「ガックン判別不可」** とするため、平均/断定せず **CONFLICT_GAKKUN_DETECTION**。
- 朝一約10Gで極モードを確認できれば設定変更の可能性が高いとする攻略資料あり。ただし前日の周期モード引継ぎでも極モード滞在の可能性を完全排除できないため、確定判別ではなく **RESET_LIKELIHOOD_HINT** とする。
- 朝一ステージは設定変更・電断ともウタカタの里/モノノフ本部のため、ステージ単独判別は不可。
- 設定変更後に12周期天井が選ばれるのは設定6のみであり、これは設定変更が既知の場合の設定推測要素で、設定変更そのものの判別には使わない。
reliability: CONFLICT_FOR_GAKKUN / ANALYSIS_HIGH_FOR_MODE_HINT_AND_STAGE_NON_DETERMINISM
