## netIncrease

- 通常のボーナス後RTはなし。
- 特殊1枚役「赤7・赤7・BAR」を取りこぼすことで6GのRT「ワイルドゾーン」へ突入。
- HAZUSEではワイルドゾーン中リプレイ確率が設定1〜5で1/1.44、設定6で1/1.46。
- 1Gあたり純増枚数として比較可能な公表値は今回確定できず。

信頼度: ANALYSIS_HIGH / 純増G値のみUNVERIFIED

## modeSpecificMinimumData

- ボーナスはBIGとMIDDLE/REGの計2種類。
- 小役同時抽選機能あり。
- ボーナス後のRT機能はなし。
- 特殊1枚役取りこぼし時に6G RT「ワイルドゾーン」へ突入。
- HAZUSEではワイルドゾーン中は約1/3でボーナスが期待できると記載。
- 有利区間制度導入前。
