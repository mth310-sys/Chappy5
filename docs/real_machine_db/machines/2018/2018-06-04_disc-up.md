## resetBehavior

### settingChangeBehavior
- HAZUSEの機種固有解析で、設定変更時は有利区間が `非有利区間へ` と明示。
- 朝一リールバックライトは点灯。バックライト点灯なら設定変更濃厚とされるが、メニュー操作や1G以上回すことで対策可能。
- 朝一1G目のリールガックン判別が有効で、ガックン時は設定変更の可能性が高い。
- ART残Gや各RT状態の個別処理を直接固定する十分な公開記述は確認できないため、一般論から補完せず `ART_RT_SPECIFIC_UNVERIFIED_AFTER_RESEARCH`。

### powerCycleBehavior
