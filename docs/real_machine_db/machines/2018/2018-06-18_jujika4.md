## resetBehavior

### settingChangeBehavior
- 設定変更時は**内部状態リセット**。
- 朝一ステージは**教会（ロットンチャーチ）**。
- 有利区間ランプは**消灯**。
- 設定変更後に有利区間を引き継ぐことはないと当時解析に明記。

### carryOverBehavior
- 前日有利区間ランプ点灯状態で閉店し、翌朝も点灯している場合は**据え置き濃厚**（対策時を除く）。
- 据え置き時の低レベル内部状態を純電断とは別条件で完全に固定する直接資料は今回確認できず、`UNVERIFIED_AFTER_RESEARCH_AS_DISTINCT_CONDITION`。

### powerCycleBehavior
- 設定変更を伴わない電源OFF→ONでは**有利区間ランプを引き継ぐ**。
- 内部状態も**引き継ぐ**。
- 基本ステージは教会。ただしディーキャッスルステージ滞在中に電源OFF→ONした場合は同ステージを引き継ぐ。
