## resetBehavior

resetBehaviorQA: PARTIAL

settingChangeBehavior:
- パチマガスロマガ当時解析で **「設定変更をしても天井RTまでのゲーム数は引き継ぐ」** と明記。
- よって設定変更はBIG後998G / REG後573Gの天井到達カウンタをリセットしない。
- 朝一の前日ハマリが設定変更を挟んでも天井狙い対象になり得る、ホール経営/客AI上の重要特性。
- 天井以外の内部通常状態、成立済みボーナス、RT中そのものの設定変更時処理は高信頼資料で確定できず `UNVERIFIED`。

carryOverBehavior:
- 据え置きでは少なくとも天井までのゲーム数を引き継ぐと扱う。設定変更でも引き継ぐことが公開されているため、据え置きで消去される根拠はない。
- ただし天井RT突入済み状態の閉店→翌日据え置き時にRT状態/残状態そのものがどうなるかは本機固有資料で確定できず `UNVERIFIED`。

powerCycleBehavior:
- `電源OFF→ON / 電断 / 電源再投入 / 天井RT / ゲーム数` で再探索したが、本機固有に「電源のみで天井カウンタを消去/維持」と直接明記した高信頼資料は今回確定できず `UNVERIFIED`。
- 設定変更でもカウンタを引き継ぐ事実から電断挙動を推定転記しない。

gameCounterReset:
- **設定変更時: RESETされず引継ぎ。**
- BIG後カウンタ: 998G到達で天井RT。
- REG後カウンタ: 573G到達で天井RT。
- 設定変更による短縮/再抽選ではなく、前回ボーナス種別に応じた既存カウンタを継承する。

ceilingAfterReset:
- 設定変更後も天井ゲーム数自体は変化せず、残りGを引き継ぐ。
- BIG後998G / REG後573G。
- リセット専用短縮天井は `NONE_CONFIRMED`。

modeAfterReset:
- 通常時モード管理、朝一専用モード、設定変更専用モード振り分けは `NONE_CONFIRMED / NOT_APPLICABLE`。

stateAfterReset:
- 天井カウンタは設定変更でも引継ぎ。
- 天井RT突入済み状態、ボーナス成立済み状態などの設定変更時処理は `UNVERIFIED`。

advantageousSectionReset:
- `NOT_APPLICABLE`（5号機・有利区間制度導入前）。

resetBenefits:
- 設定変更そのものによる短縮や優遇は確認されない。
- ただし**前日ハマリを設定変更しても天井カウンタが残る**ため、朝一客側には宵越し天井狙いが成立し得る。これはリセット恩恵というより「設定変更で消えない狙い目」として記録。

resetPenalties:
- 設定変更で天井残Gが消える不利はなし。
- その他の設定変更固有不利要素は `NONE_CONFIRMED`。

resetDetection:
- 天井カウンタを設定変更でも引き継ぐため、朝一の天井到達G数だけでは設定変更/据え置きを区別できない。
- 本機固有ガックン、液晶、ランプ、出目による変更判別は検索語・資料系統を変えて再探索したが確定できず `UNVERIFIED`。

numericResetData:
- 設定変更時天井カウンタ: 引継ぎ
- BIG後天井RT: 998G
- REG後天井RT: 573G
- 天井RT継続: 次回ボーナス成立まで
- RT中1000円あたり: 152.64 / 153.64 / 154.08 / 154.33 / 154.12 / 154.10G（設定1〜6）
- リセット専用短縮天井: NONE_CONFIRMED
- 朝一専用モード振り分け: NONE_CONFIRMED
- 朝一特定G以内当選率/期待度: NONE_CONFIRMED
