## modeSpecificMinimumData

- 3種類BIG + 2種類CT
- 赤7BIG / 白7BIG / 赤7系CT後などからAT「爆ちゃんタイム」
- AT中15枚役ナビ + リプレイ確率上昇
- 攻略資料では30〜300G継続
- 規定ゲーム数到達で次回ボーナスまでATとなるハマリ救済あり（業界記事）
