### settingChangeBehavior

- 本機はRT、通常時ゲーム数天井、モード管理を持たないシンプルなノーマル完全告知機として確認。
- 設定変更時に引き継ぐべき天井G数・RT残G・モードはNONE_CONFIRMED / NOT_APPLICABLE。
- 設定変更時の固有初期出目、リール制御、告知ランプ初期化等の直接資料はUNVERIFIED。

### carryOverBehavior

- 据え置き時に維持される通常時天井・RT/AT/ART・モード: NOT_APPLICABLE / NONE_CONFIRMED。
- ボーナス成立中など特殊状態の営業日跨ぎ挙動は本DB目的外の細かな内部再現に当たるため収集対象外。

### powerCycleBehavior

- 電源OFF→ONのみで天井・RT・モード差が生じる構造はNONE_CONFIRMED。
- 電断復帰時の本機固有初期出目/ランプ等の見た目挙動はUNVERIFIED。

### gameCounterReset

- 天井機能: **非搭載**（pacnk）。
- よって通常時天井ゲーム数の設定変更リセット/据え置き引継ぎはNOT_APPLICABLE。

### ceilingAfterReset

- リセット短縮天井: NONE / NOT_APPLICABLE。

### modeAfterReset

### stateAfterReset
