### resetBehavior 調査メモ

- 本機にはボーナス間999Gの救済ATがあるため、朝一の内部ゲーム数/天井カウンタ処理はホール経営・客AI上重要だが、設定変更時に999Gカウンタを初期化するか、据え置き時に引き継ぐか、電源OFF→ONのみで維持されるかを断定できる本機固有資料は確認できなかった。
- `256 / ジゴロ / SNKプレイモア` と `設定変更 / リセット / 朝一 / 朝イチ / 据え置き / 電源OFF ON / 999G / 天井 / ガックン / 初期出目` を組み替えて再探索したが、直接根拠は発見できず一般論から補完しない。
- 設定変更/電源断時のチャンスRT・256タイムの残G、内部状態、ART権利の扱いも直接根拠なし。
- 設定変更固有の短縮天井、朝一専用モード、リセット恩恵率/不利、公開モード振り分け等は確認できないため `NONE_CONFIRMED`。
- ガックン、出目、ランプ/液晶等による本機固有の変更判別資料も確定できず。
- 有利区間制度導入前の5号機のため `advantageousSectionReset: NOT_APPLICABLE`。
