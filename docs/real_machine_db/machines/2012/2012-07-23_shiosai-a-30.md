## conflicts

- 後年単一DB「みんスロ」はBIG 1/318～1/256、REG 1/655～1/496、機械割94.0～108.2%、BIG322枚、REG207枚、50枚35～36.7G、1300G天井RTとする。
- P-WORLDはBIG 1/336～1/287、REG 1/636～1/524、機械割97～107%、BIG最大325枚、REG最大104枚で、ボーナスのみのノーマルタイプとする。機械割97～107%は5号機クロニクルも一致。
- 後年単一DB側は獲得枚数・天井構造まで本線資料と同時に大幅不一致のため、単純な解析差や丸め差ではなく SOURCE_MISMATCH_OR_MISATTRIBUTION_CONFLICT として隔離し、本線性能値・天井・ベースには採用しない。
