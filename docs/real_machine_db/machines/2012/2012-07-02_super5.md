## modeSpecificMinimumData

- ボーナス非搭載のART専用機。
- 通常時またはCZ中の「超5」絵柄3つ揃いが主なART突入契機。
- 順押しではART初当りが軽い代わりに継続率50%/80%、逆押しでは初当りが重い代わりに80%ループ確定。
- ART終了後は小役取りこぼし目出現まで引き戻しチャンス。
- ナビ発生時以外の中押しはペナルティがあるため、通常時は順押し/逆押しで消化する仕様。
