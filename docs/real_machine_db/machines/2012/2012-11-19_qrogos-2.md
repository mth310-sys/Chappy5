## resetBehavior

### settingChangeBehavior

- **天井までのゲーム数はクリア**。
- **ART抽選状態は再抽選**。
- 液晶背景は1G目が昼ステージ、2G目のBETでステージ移行の可能性あり。
- DMMぱちタウンが設定変更時と電源OFF→ON時を同一表で明示しており、本機固有の直接契約として採用。

### carryOverBehavior

- 純据え置き時の天井ゲーム数・ART抽選状態の厳密な契約を「据え置き」と明記した独立資料は今回確認できず **UNVERIFIED_AFTER_RESEARCH**。
- ただし設定変更を伴わない電源OFF→ONについてはDMMぱちタウンが天井ゲーム数・ART抽選状態とも引継ぎと明記している。

### powerCycleBehavior

- **電源OFF→ONのみでは、天井までのゲーム数を引き継ぐ。**
- **ART抽選状態も引き継ぐ。**
- 液晶背景は設定変更時と同じく1G目が昼ステージ、2G目のBETでステージ移行の可能性あり。
- よって朝一液晶背景だけでは設定変更/純電断を区別できない。

### gameCounterReset

- 設定変更: **CLEAR**。
- 電源OFF→ONのみ: **CARRY_OVER**。
- 据え置き: **UNVERIFIED_AFTER_RESEARCH_AS_EXPLICIT_WORDING**。

### ceilingAfterReset

- 設定変更で天井ゲーム数はクリアされる。
- 設定変更専用の短縮天井数値は、検索語・資料系統を変えた再探索後も **NONE_CONFIRMED_AFTER_RESEARCH**。
- 通常時最大天井はDMM基準で最大1280G。別の当時攻略資料は通常A最大1240Gとするため定義差注意。

### modeAfterReset

- 通常A / 通常B / 天国 / 超天国のゲーム数モードが存在する。
- 設定変更時にこれらのモードを再抽選するか、具体的な振り分け数値がどうなるかを直接明示した本機固有資料は、パチマガスロマガの「朝イチ・設定変更」項目の存在を含め再探索したが本文値を回収できず **UNVERIFIED_AFTER_RESEARCH**。
- 電源OFF→ON時に「ART抽選状態」は引き継ぐが、これをゲーム数モードそのものと同一視しない。

### stateAfterReset

- 設定変更: DMMぱちタウン表の **ART抽選状態は再抽選**。
- 電源OFF→ON: **ART抽選状態を引き継ぐ**。
- 通常時の高低状態とゲーム数モードの定義を混同しない。
