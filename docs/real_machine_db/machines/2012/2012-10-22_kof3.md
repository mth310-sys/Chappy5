### settingChangeBehavior

- **CONFIRMED_CLEAR_GAME_COUNTER_RELOT_GAME_NUMBER_MODE__DISPLAY_STAGE_RESELECTED**
- 2012年当時攻略資料で、設定変更時は天井ゲーム数がリセットされ、内部モード移行抽選を行い、液晶ステージを再選択すると記載。
- confidence: CONTEMPORARY_ANALYSIS_DIRECT_SINGLE__CEILING_CLEAR_MULTI_SOURCE

### carryOverBehavior

- **UNVERIFIED_AFTER_RESEARCH**
- 純据え置き時に前日の規定ゲーム数進捗・ゲーム数モード・CZ関連状態を個別にすべて保持するという本機固有の直接記述は今回確定できず。
- 一般的な5号機挙動から推測補完しない。

### powerCycleBehavior

- **CONFIRMED_DISPLAY_STAGE_RESELECTED_ONLY__INTERNAL_COUNTER_MODE_CONTRACT_UNVERIFIED**
- 当時攻略資料は、液晶ステージについて設定変更時だけでなく電源ON/OFF時も再選択されると明記。
- したがって液晶開始ステージだけでは設定変更判別に使えない。
- 単純電源OFF→ON時の規定ゲーム数カウンタ、ゲーム数モード、内部状態の完全な保持/再抽選契約は **UNVERIFIED_AFTER_RESEARCH**。
- confidence: CONTEMPORARY_ANALYSIS_DIRECT_SINGLE_FOR_DISPLAY_STAGE

### gameCounterReset

- **CONFIRMED_CLEAR_ON_SETTING_CHANGE**
- 当時攻略資料に「天井ゲーム数は設定変更でリセット」と明記。
- 別の当時天井解析資料も設定変更で天井までのゲーム数リセットを掲載。
- confidence: CONTEMPORARY_ANALYSIS_MULTI_SOURCE

### ceilingAfterReset

- **RESET_TO_NEW_MODE_TABLE__NO_FIXED_SHORTENED_RESET_CEILING_CONFIRMED**
- 設定変更で天井進捗をCLEARし、ゲーム数モードを再抽選。
- 通常時のモード別最大は1280G / 896G / 128G / 128G。
- 設定変更専用の固定短縮天井値は、表記揺れ・型式名・メーカー名と「設定変更/リセット/朝一/天井短縮/モード」を組み替えて再探索したが **UNVERIFIED_AFTER_RESEARCH**。

### modeAfterReset

### resetBenefits

- **MODE_RELOTTERY_CONFIRMED__NUMERIC_MORNING_ADVANTAGE_UNVERIFIED**
- 設定変更時にゲーム数モードを再抽選するため、128G天井の天国/超天国が選択される可能性自体は構造上存在する。
- ただし設定変更時の天国以上選択率など比較可能な公開数値を今回安全に回収できなかったため、朝一優遇率として数値化しない。

### resetPenalties

- **PREVIOUS_GAME_NUMBER_CEILING_PROGRESS_LOST_ON_SETTING_CHANGE**
- 設定変更で天井ゲーム数がリセットされるため、前日の規定ゲーム数進捗は失われる。

### resetDetection

- **DISPLAY_STAGE_NOT_USEFUL_FOR_CHANGE_DETECTION__OTHER_MACHINE_SPECIFIC_METHODS_UNVERIFIED**
- 設定変更時も単純電源ON/OFF時も液晶ステージが再選択されるため、開始液晶ステージだけでは変更判別に使えない。
- 本機固有のリールガックン、初期出目、その他確定的な変更判別契約は、検索語・資料系統を変えて再探索後も **UNVERIFIED_AFTER_RESEARCH**。
