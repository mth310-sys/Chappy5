## modeSpecificMinimumData

- 通常時は鋼牙ステージ / カオルステージ / 魔界道ステージなどがあり、魔界道は高確示唆側。
- 天井: **ボーナスまたはART終了後1280G消化で天井状態**。その後、特定レア小役成立で牙狼RUSH当選が確定するとする当時攻略資料あり。
- 天井ARTは呀CHANCEを経由せず牙狼RUSHへ直接突入するとする当時資料あり。
- ART終了後はベルこぼし目出現まで引き戻し抽選があるとする後年整理資料あり。
- 細かな通常時小役別抽選、上乗せ振り分け等は本DB対象外。
