## modeSpecificMinimumData

- CZ「ミッションSLOT」搭載。HAZUSEではART期待度約20%。
- ARTは通常時のCZ/特定小役、ボーナス中抽選等から突入。
- ART中はBIKINI RUSH → SUPER BIKINI RUSH → ULTRA BIKINI RUSHの3段階。SUPERは上乗せ高確/昇格、ULTRAは強上乗せ状態。
- 通常時に内部高確状態が存在し、夕方ステージは高確示唆、夜ステージは高確または前兆の強い示唆として当時攻略資料に掲載。

### settingChangeBehavior

- **設定変更時に天井ゲーム数はリセット**。
- **内部モードは再セット**されるとする当時攻略資料あり。
- 液晶ステージは設定変更後も前日の表示を引き継ぐため、単純な液晶ステージ初期化では変更判別できない。
- ARTストック等の全内部契約は今回確定できず、実機完全再現用の細部は推測しない。

### carryOverBehavior

- 純据え置き時のボーナス間天井進捗について、設定変更時リセットの反対として単純推定は行わない。
- 当時天井攻略資料に「宵越し×」「宵越し天井狙いは調査中」という併存表記があり、純据え置き時の1200G進捗の直接契約は **UNVERIFIED_AFTER_RESEARCH** とする。
- 液晶ステージは少なくとも設定変更でも引継ぎとされるため、据え置き判別には使いにくい。

### powerCycleBehavior

- **単純電源OFF→ONでも液晶ステージを引き継ぐ**。
- 天井G、内部モード、ARTストック等の電断のみでの保持/初期化は直接資料を確定できず **UNVERIFIED_AFTER_RESEARCH**。

### gameCounterReset

- 据え置き時: **UNVERIFIED_AFTER_RESEARCH**。
- 電源OFF→ONのみ: **UNVERIFIED_AFTER_RESEARCH**。

### ceilingAfterReset
