### settingChangeBehavior

- **CONFIRMED_CLEAR_GAME_COUNTER_RELOT_INTERNAL_MODE_INITIAL_STAGE_FAR_DISTANCE**
- 当時系攻略資料で、設定変更後は天井消化ゲーム数をリセット、内部モード移行抽選あり、液晶は遠距離ステージからスタートと記載。
- confidence: CONTEMPORARY_ANALYSIS_DIRECT_SINGLE

### carryOverBehavior

- **PARTIAL_POWER_CYCLE_STAGE_CARRYOVER_CONFIRMED; FULL_COUNTER_MODE_CONTRACT_UNVERIFIED**
- 電源ON/OFF時は液晶ステージを引き継ぐと当時系攻略資料に記載。
- 据え置き時のART天井999Gカウンタ、CZ間510Gカウンタ、内部モードをすべて保持するとの本機固有の直接記述までは今回確定できず。
- したがって、電断時の表示ステージ引継ぎ以外を一般論で補完しない。

### powerCycleBehavior

- **CONFIRMED_STAGE_CARRYOVER_ONLY**
- 電源OFF→ONのみでは液晶ステージを引き継ぐ。
- ゲーム数・CZ間カウンタ・内部モードの電断時契約は **UNVERIFIED_AFTER_RESEARCH**。
- confidence: CONTEMPORARY_ANALYSIS_DIRECT_SINGLE_FOR_STAGE

### gameCounterReset

- **CONFIRMED_CLEAR_ON_SETTING_CHANGE**
- 設定変更で「天井消化ゲーム数はリセット」と当時系攻略資料に明記。
- ART天井999GおよびCZ間天井510Gの双方が設定変更でどのように個別処理されるかは、後者について直接文言を確定できず、ART天井側の確定契約を主として保存。
