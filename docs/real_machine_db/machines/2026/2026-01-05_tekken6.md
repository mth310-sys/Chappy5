- 天井・モード・CZモード・内部ポイント各項目を独立して値付き比較した公開表は取得できず、一般仕様から推測補完しない。

## conflicts
- 機械割、CZ/ボーナス/AT初当たり、ベース、純増はG-net・必勝本・1geki・なな徹系で重大CONFLICTなし。
- 一部後発サイトに「リセット0Gから期待値プラス」とする記載があるが、なな徹独自シミュレーターは設定1等価0Gで-922円。条件差を平均化せず、canonicalの数値期待値は算出条件が明示されたなな徹値を採用し、0Gプラス表現は一般化しない。
- 純電源OFF→ONの有利区間を一般スマスロ仕様から推測する二次記述は採用せず、機種固有公開比較が取得できるまでUNVERIFIEDを維持。
