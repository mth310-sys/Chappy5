## modeSpecificMinimumData
- 通常時は規定ゲーム数、チェリー規定回数、小役直撃等で擬似ボーナスを抽選。
- 通常ゲーム数天井は最大999G+α。別にチェリー最大45回の規定回数天井を持つ。
- 通常系モードは通常A / 通常B / チャンスA / チャンスB / 天国準備など。天国・パトランプ系は32G以内の連チャン管理。
- 設定1の通常時ゲーム数天井振り分けは、通常Aが319～350G 25.00% / 968～999G 75.00%、通常B・チャンスA・チャンスBが319～350G 13.28% / 968～999G 86.72%、天国準備は319～350G 100%。これは通常時モード別値であり、設定変更専用の350/600G振り分けとは混同しない。
- チェリー回数天井は通常A/B最大40回、チャンスA最大45回、チャンスB最大25回、天国準備最大10回。

- 2025年の `チバリヨ2プラス` は別型式・別機種であり、本機の性能/リセット値へ混入させない。
