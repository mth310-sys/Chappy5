### settingChangeBehavior
- 設定変更時は **天井RESET / 内部状態RESET / 有利区間RESET**。
- 設定変更後は非有利区間から開始し、スコープモードへ。
- 有利区間移行時に公開されているCZ/アイテム/OPT関連抽選を実施。

### carryOverBehavior
- 据え置き時は、設定変更を伴わない電源OFF→ON契約に基づき **天井進行 / 内部状態 / 有利区間をCARRY_OVER**。
- コイン枚数・アイテム等の細部については電断時も内部的に保持されるとする実機アプリ利用者報告があるが、攻略一次表で項目別に明示された範囲を超えて確定しない。

### powerCycleBehavior
- 電源OFF→ONのみでは **天井 / 内部状態 / 有利区間をCARRY_OVER**。
- 開始ステージはスコープモード。
- 表示演出が初期化されても内部進行は引き継ぐ契約として整理。

### gameCounterReset
- 設定変更: **RESET**。
- 据え置き / 電源OFF→ON: **CARRY_OVER**。
- ゲーム数天井は有利区間移行後710G。

### ceilingAfterReset
- 設定変更専用の短縮天井は確認されていない。
- 新有利区間のゲーム数天井は710G。
- コイン枚数天井は最大71枚でアミヤバトル。

### modeAfterReset
- 有利区間移行時にAT内部モード（通常 / スナイプ / バズーカ）を抽選する公開値あり。
- これは設定変更専用テーブルではなく、有利区間移行時共通値として分離保存。

### stateAfterReset
- 設定変更: **RESET / 非有利区間へ**。
- 据え置き / 電断: **CARRY_OVER**。
- 朝一開始ステージはスコープモード。

### advantageousSectionReset
- 設定変更: **RESET、朝一ランプ消灯**。
- 据え置き / 電源OFF→ON: **CARRY_OVER、ランプ状態引継ぎ**。
- 通常時から有利区間ランプ点灯タイプのため、朝一 **点灯=据え置き濃厚 / 消灯=リセット濃厚**。

### resetBenefits
- 有利区間移行時 **4.7%でCZ抽選**。
- 有利区間移行時にアイテムを **100%獲得、平均約1.9個**。
- 有利区間移行後1G目の一部でOPT抽選。
- ただし攻略資料は「リセット狙い目なし（ボーナス/AT終了後と同じ状態）」としており、設定変更だけの専用優遇ではなく有利区間移行時共通恩恵として扱う。

### resetPenalties
- 設定変更で前日の天井進行・内部状態・有利区間を消去。
- その他の設定変更専用不利要素は `NONE_CONFIRMED_AFTER_RESEARCH`。

### resetDetection
- 有利区間ランプ: **朝一点灯=据え置き濃厚 / 消灯=リセット濃厚**。
- 筐体色は設定奇偶そのものを示す（青=奇数、赤=偶数）ため、前日と筐体色/モードが変われば設定変更の強い手掛かりになるが、店舗運用や設定変更手順を含むため「ランプ判別」とは別項目として保持。
- 本機固有のリールガックン発生条件/率は表記揺れ・型式・メーカー・リセット・朝一・据え置きで再探索したが固定できず `UNVERIFIED_AFTER_RESEARCH`。
