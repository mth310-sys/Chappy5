## basicPayout

- BIG BONUS: **最大約195枚**。

- BIG終了後は必ず **直撃ZONE 20～200G**へ移行。
- 直撃ZONE中は内部BIG成立＝即放出。BIGと直撃ZONEのループ率は最大 **86%**とされる。
- confidence: ANALYSIS_HIGH_MULTI_SOURCE

## modeSpecificMinimumData

- 64種類のBIG組み合わせを搭載し、内部的にはBIGが高確率 **1/102.4**で成立。
- 通常時にBIGが内部成立すると、基本的に規定ゲーム数を経てボーナスの組み合わせを告知する擬似ストック的ゲーム性。
- 前兆期待演出「64TIME」を搭載。
- BIG後は直撃ZONEへ入り、ゾーン中はBIG成立時に即放出。
- 全規定G数振り分けや内部抽選詳細は実機完全再現用のため本DB対象外。

## ceiling

- BIG内部成立後、最大 **218G**消化でBIG告知/放出確定。
- 後年解析では **内部成立後218G またはハズレ32回**で天井と整理される。
- 本機の「天井」は通常AT機のボーナス間天井とは異なり、**既に内部成立しているBIGの告知までの最大潜伏契約**として扱う。
- confidence: ANALYSIS_HIGH_MULTI_SOURCE

## conflicts / safeguards

- 通常掲載機械割 96.5～112.5%と、パチマガスロマガの「ボーナス狙い / 適当打ち」シミュレートPAYOUTは定義が異なるためCONFLICT扱いにせず別指標として分離。
- 「最大218G」はボーナス間ゲーム数天井ではなく、BIG内部成立後の告知/放出までの最大潜伏ゲーム数。一般的なAT天井として誤登録しない。
- 後年解析の「ハズレ32回」天井は複数当時一次資料で完全照合できていないため、218G契約より信頼度を一段下げて保持。
- 同社の別機種、後年6号機のresetBehaviorは混入させない。
