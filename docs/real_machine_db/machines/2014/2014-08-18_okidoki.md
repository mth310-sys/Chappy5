### resetBenefits

- 最大の公開朝一恩恵は **33.20%でチャンスモード**へ移行すること。
- チャンスモード最大天井は199G（200G以内表記）で、初回ボーナス後は通常B以上濃厚。
- 通常Bも9.77%で選択されるため、通常A以外のスタートは合計42.97%。
- これは設定変更後に必ず200G以内当選するという意味ではなく、チャンス選択時のみ。

### resetPenalties

- 設定変更により前日からの天井進捗・内部モードが消去されるため、前日ハマリや高モードを据え置く価値は失われる。
- ただし前日モードは客側から確定不能なことが多く、独立した「リセット冷遇」抽選は `NONE_CONFIRMED_AFTER_RESEARCH`。

### resetDetection

- 初代沖ドキ解析整理では **ガックン判別不可**。

- 前日最終Gと当日当選位置を使った推測は可能だが、モード天井が複数あり毎ゲーム抽選もあるため確定判別にはならない。
