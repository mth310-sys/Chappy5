## modeSpecificMinimumData

- 約500Gを境にAT当選構造が変化する **TAGゲームシステム**。
- 1～約500G: ゲーム数解除「鉄拳ZONE」と自力CZ「鉄拳CHANCE」が主要契機。
- 約500～777G: ゲーム数解除/CZが消失し、リバースロックとデビルバトル中心。フリーズ発生率は前半比約20倍とされる。
- 鉄拳CHANCEのAT期待度は約50%以上（P-WORLDでは約50～100%）。
- 通常時の全ゾーン振り分けや小役別解除率は完全再現用詳細となるため収集しない。

## ceiling

- 通常時最大天井: **AT間777G + 前兆**。
- P-WORLDでは通常時777G消化でAT確定、パチ7では777Gでデビルバトル突入し勝利なら神鉄拳RUSH・敗北なら鉄拳RUSHと説明。
- 解析資料ではモードB相当の500G+α、天国相当の128Gとする整理もあるが、全モード解析表は物差し用途を超えるため最低限の最大天井のみ主値として保持。
- 設定変更時は別途 **500G+前兆へ短縮**（resetBehavior参照）。
