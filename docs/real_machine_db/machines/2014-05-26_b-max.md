## netIncrease

- BIG中のJAC INハズシ成功状態を維持してBIGを終了するとRTへ移行。
- RTは **純増約0.7枚/G、平均約30G**。チェリー入賞またはボーナス成立で終了。
- 2014年当時のグリーンべると、娯楽産業、パチマガスロマガで整合。
- confidence: INDUSTRY_PLUS_ANALYSIS_HIGH

## basicPayout

- BIG: **385枚を超える払い出しで終了**。当時業界発表の実獲得目安は **約316枚 + RT**、パチマガスロマガは約320枚と表記。
- REG: **12Gまたは8回入賞で終了**。技術介入成功時 **最大112枚**。
- BIG中はJAC INハズシ等の技術介入で終了後RT獲得を狙う。
- REG中もビタ押し成功数で獲得枚数が変化。
- confidence: INDUSTRY_PLUS_ANALYSIS_HIGH

## modeSpecificMinimumData

- ノーマルAタイプ。通常時にAT/ART/CZや規定ゲーム数解除モードは確認されない。
- BIG後RTはボーナス中の技術介入結果により獲得する付加状態で、通常時のゲーム数天井ではない。
- RTは平均約30G、チェリー入賞またはボーナス成立で終了。
- 約2100種類以上のリーチ目を搭載すると当時発表。

## ceiling

- **天井機能非搭載**。HAZUSEが明記。
- BIG後RTの最大/平均継続や終了条件は救済天井ではない。
- confidence: ANALYSIS_HIGH_DIRECT

## conflicts / safeguards

- 完全攻略時101.5〜108.5%と平均的手順97.3〜104.1%は **プレイ条件が異なる**。機械割競合として平均せず、完全攻略系列を条件明示の主系列、平均系列を参考値として保持。
- BIG獲得表現は資料に「約316枚」「約320枚」「最大333枚」「MAX375枚」等が混在する。払い出し終了条件・技術介入・RT分・最大/平均の定義差があるため、主値は当時業界記事の **約316枚+RT** とし、異なる最大値を平均しない。
- 1998年4号機B-MAXの仕様/resetBehaviorを混入しない。
