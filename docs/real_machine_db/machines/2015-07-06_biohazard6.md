## resetBehavior

### settingChangeBehavior

- 設定変更時は **ART間天井ゲーム数をリセット**。
- 内部モードを再抽選し、通常Aを除いた通常B/通常C/天国/超天国へ移行。天国が優遇される。
- 内部状態を再抽選。
- 朝一ステージは **カタコンベ**。
- confidence: ANALYSIS_HIGH_FOR_PERIOD_RESET_DATA

### carryOverBehavior

- 設定変更判別資料では、ベルこぼし目が出る前に「一見ハズレ目に見えるリプレイ」が出現すると **据え置き確定** とされ、内部RT由来の朝一挙動が据え置き判別材料になる。
- 一方、ART間999G進捗・通常モード・内部状態それぞれについて、据え置き時の完全なCARRY_OVER契約を独立して明記した本機固有資料は今回の再探索で安全に固定できなかった。
- ceilingProgressOnCarryOver: `UNVERIFIED_AFTER_RESEARCH`。
- modeOnCarryOver: `UNVERIFIED_AFTER_RESEARCH`。
- stateOnCarryOver: `UNVERIFIED_AFTER_RESEARCH`。
- 一般的な5号機挙動から自動補完しない。

### powerCycleBehavior

- 「パチスロ バイオハザード6 / バイオ6 / バイオハザード6ZY / エンターライズ」と「電源OFF ON / 電断 / 電源オンオフ / 据え置き / 朝一 / 宵越し / 設定変更」を組み替え、当時解析・攻略DB・後年回顧資料を再探索したが、**設定変更を伴わない純電源OFF→ONのみの本機固有内部契約を独立して固定できなかった**。
- `UNVERIFIED_AFTER_RESEARCH`。
- バイオハザード5や後継スマスロの挙動は流用しない。

### gameCounterReset

- **設定変更時: ART間天井ゲーム数RESET**。
- 通常営業中は実ボーナスを挟んでもART間天井は継続する。
- 据え置き/純電断時のART間G引継ぎは本機固有の直接契約を今回固定できず `UNVERIFIED_AFTER_RESEARCH`。

### ceilingAfterReset

- 設定変更後に固定の一律短縮天井が設定されるという直接資料は確認できない。
- ただしモード再抽選で天国/超天国へ移行し得るため、**天国選択時は99G+前兆**でART当選となる。
- `NO_FIXED_SHORTENING_CONFIRMED_MODE_BASED_EARLY_CEILING_EXISTS`。
