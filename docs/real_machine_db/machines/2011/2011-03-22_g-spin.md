## basicPayout

- MB: 通常時 **平均約50枚**
- ART中MB: P-WORLDで **平均約70枚**
- ART「G-SPLASH」: 初当たり時は準備状態後「G-SPIN」で初期ゲーム数を決定するゲーム数上乗せ型。
- G-SPIN中の代表的上乗せ: 赤7揃い300G / 緑BAR150G / 黄BAR100G / 青BAR50G / チェリー20G / 異色BAR10G（物差し最低限の構造確認用。内部抽選率は収集対象外）。

confidence: ANALYSIS_HIGH_CROSSCHECKED_FOR_MB_AND_ART_STRUCTURE

## modeSpecificMinimumData

- 通常時はMBをART突入契機/CZ的に利用。
- 通常ゲームからMB非経由でARTへ突入するルートも存在。
- ART「G-SPLASH」はゲーム数上乗せ型、約+1.6枚/G。
- ART初当たり時の基本継続G数は固定ではなく、開始時のG-SPINで獲得したゲーム数による。
- 有利区間制度導入前の5号機。

## conflicts

- netIncrease: **CONFLICT**。ユニバーサル公式/P-WORLDはART純増約+1.6枚/G。5号機クロニクルは約+2.2枚/G。メーカー公式を主値にし、平均しない。
- MB確率: P-WORLDとみんスロで1/161〜1/164の軽微な丸め/系列差あり。精密値を平均しない。
- system description: ユニバーサル公式は「ボーナス+ART」、P-WORLDはMB約50枚+ART。5号機クロニクルの「リアルボーナスを一切搭載せず」はMBの法的/ゲーム上の扱いと齟齬があるため、公式/P-WORLDを優先。
