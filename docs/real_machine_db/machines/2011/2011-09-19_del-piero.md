## modeSpecificMinimumData

- 通常時は **通常 / 高確 / 超高確** の3内部状態。
- 特殊リプレイで高確「ワルピエロゾーン」、高確中の特殊リプレイで超高確「ドルピエロゾーン」へ移行する構造。
- 天井は固定MAX777Gだけではなく **1 / 111 / 222 / 333 / 444 / 555 / 666 / 777G** の8候補から規定ゲーム数が選ばれるゲーム数振り分け方式。
- 規定天井ゲーム数到達後の次回ART当選は **88%継続モード**。
- P-WORLDは天井到達後にリプレイ入賞音変化が頻発しやすいと記載しており、遊技中の天井到達示唆として保存するが、設定変更判別とは区別する。
- 完全再現用の天井振り分け率、全状態移行率、ストック抽選詳細は収集対象外。
