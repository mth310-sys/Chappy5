## modeSpecificMinimumData

- 18.5インチ全面液晶+タッチパネルの「マルチリール」を搭載したノーマルタイプ。
- 通常ゲーム数天井、ART/AT、規定G数当選モードは確認されない。
- BIG中はチャレンジモード/PVモードを選択可能。これは遊技演出/技術介入モードであり、朝一内部モードとは区別する。
- slothistory回顧資料ではホール側がタイマーでパネル/LED、告知音、リールガックン等を発動可能な機能を本機の特徴として記録。これは設定変更ガックンとは別機能なので、変更判別根拠へ流用しない。

## resetBehavior — v0.7

settingChangeBehavior: **NO_GAME_COUNT_CEILING_OR_LONG_TERM_MODE_CONFIRMED / OTHER_MACHINE_SPECIFIC_EFFECTS_UNVERIFIED_AFTER_RESEARCH**。本機はノーマルタイプで、公開資料上ゲーム数天井・規定G数当選・ART/AT状態は確認されない。設定変更時の液晶カスタマイズや一時演出状態等の固有挙動は直接資料を確定できず。

carryOverBehavior: **NO_CEILING_PROGRESS_APPLICABLE / OTHER_TRANSIENT_STATE_UNVERIFIED_AFTER_RESEARCH**。据え置きで引き継ぐ天井ゲーム数や長期モードは確認されない。液晶カスタマイズ等の保持は直接根拠なし。

powerCycleBehavior: **UNVERIFIED_AFTER_RESEARCH_FOR_DISPLAY_CUSTOMIZATION_AND_TRANSIENT_STATE**。単純電源OFF→ONのみでの液晶設定、表示、演出カスタマイズ等の保持/初期化を本機固有資料で確定できず。天井ゲーム数についてはそもそも該当天井を確認していない。

gameCounterReset: **NOT_APPLICABLE_TO_GAME_COUNT_CEILING_AFTER_RESEARCH**。通常ゲーム数天井・規定G数当選を確認できないため、朝一天井進捗のCLEAR/RETAIN比較は非該当。

ceilingAfterReset: **NOT_APPLICABLE_NO_GAME_COUNT_CEILING_CONFIRMED_AFTER_RESEARCH**。設定変更専用短縮天井も確認されない。

modeAfterReset: **NOT_APPLICABLE_TO_PERSISTENT_GAME_COUNT_MODE_AFTER_RESEARCH / DISPLAY_MODE_UNVERIFIED**。通常A/B等の長期当選モードは確認されない。BIG中のチャレンジ/PVモードは朝一モードではない。

stateAfterReset: **UNVERIFIED_AFTER_RESEARCH_FOR_MACHINE_SPECIFIC_TRANSIENT_DISPLAY_STATE**。高確/超高確等の出玉抽選状態は確認されないが、電断/設定変更時の表示・カスタマイズ状態まで断定しない。

advantageousSectionReset: **NOT_APPLICABLE**。有利区間制度導入前の5号機。

resetBenefits: **NONE_CONFIRMED_AFTER_RESEARCH**。短縮天井、朝一専用当選率、リセット専用ボーナス優遇等の公開値は確認できず。

resetPenalties: **NONE_CONFIRMED_AFTER_RESEARCH**。前日天井進捗消失のような比較対象となるゲーム数天井自体を確認できない。

resetDetection: **UNVERIFIED_AFTER_RESEARCH / DO_NOT_CONFUSE_TIMER_GACKUN_FUNCTION_WITH_SETTING_CHANGE_DETECTION**。本機にはホール側タイマーで「リールガックン」等を発動できる機能の回顧記録があるため、朝一1G目のガックンを設定変更判別と短絡できない。本機固有の設定変更/据え置き判別法は直接確定できず。

numericResetData:
- 通常ゲーム数天井: **NONE_CONFIRMED_AFTER_RESEARCH**
- 設定変更専用短縮天井: **NONE_CONFIRMED_AFTER_RESEARCH**
- 朝一特定G以内ボーナス当選率/期待度: **NONE_CONFIRMED_AFTER_RESEARCH**
