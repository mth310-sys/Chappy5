## modeSpecificMinimumData

- 30φ完全告知ノーマルタイプ。
- 演出は「NORMAL MODE」と「MAX MODE」を1BETボタンで任意選択。これは遊技演出モードであり、出玉抽選上の内部モードとしては扱わない。
- 通常ゲームのボーナス間**1200G**で救済天井RTへ突入。
- 天井RTは次回ボーナスまで継続し、リプレイ確率が上昇して**ほぼコイン増減なし**で消化可能。
- ART/AT/CZは非搭載。
- 有利区間制度前の5号機。
