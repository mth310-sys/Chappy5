## modeSpecificMinimumData

- 前作までのRT系からART機へ移行したシリーズ第3弾。
- ART「SKY RUSH」は1セット40G、約+1.4枚/Gのストック型ART。
- CZ/高期待ゾーンとしてストーリータイム、エリシオンゾーン、大エリシオンゾーンを搭載。
- 通常時は低確 / 高確 / 超高確の内部状態が存在。
- ゲーム数天井: **通常時800G / 1000G / 1200Gのいずれか**でART当選、**ストック3個以上**。
- 天井振り分け: **800G 25% / 1000G 25% / 1200G 50%**。
- 天井は **ARTとボーナス間の合算ゲーム数**で管理。
- CZ/準備天井: SKY RUSH告知以降、**50G間CZに突入しなければ大空賊モードから開始**。
