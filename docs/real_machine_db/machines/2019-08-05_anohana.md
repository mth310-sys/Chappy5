## resetBehavior

- settingChangeBehavior: 設定変更時は天井G数をリセットし、非有利区間へ移行。なかよしメーターはリセット、リーチボードは非表示（見た目1ライン相当）。朝一ステージは夕方の神社。
- carryOverBehavior: 据え置きでは天井G数・内部状態・有利区間を引き継ぐ。メーターとリーチボードも表示上は初期化される部分があるが内部値は引き継ぐ解析あり。
- powerCycleBehavior: 純電源OFF→ONでは据え置き同様に天井G数・内部状態・有利区間を引き継ぐ。有利区間ランプも引き継ぐ。
- gameCounterReset: 設定変更で内部天井G数RESET。据え置き・純電断でCARRY_OVER。
- ceilingAfterReset: 設定変更専用の短縮天井は確認されず `NONE_CONFIRMED_AFTER_RESEARCH`。通常どおり有利区間移行後500G仮天井、1000G+前兆本天井。
- modeAfterReset: 設定変更後はAT終了後と同様に非有利区間から開始する。設定変更専用モード振り分けの公開固定値は確認できず `PUBLIC_VALUE_NOT_FOUND_AFTER_RESEARCH`。
- stateAfterReset: 設定変更で非有利区間へ。純電断・据え置きは内部状態引継ぎ。朝一専用高確などは確認されず。
- advantageousSectionReset: 設定変更で非有利区間。有利区間ランプ消灯。純電断・据え置きは有利区間およびランプ状態を引き継ぐ。ただし本機は有利区間ランプと実際の有利区間が完全連動せず、CZ突入まで点灯しない仕様があるため消灯単独では変更確定にならない。
- resetBenefits: 非有利区間中はレア小役経由のAT直撃チャンスがある。設定1でも弱チェリー/スイカ経由有利区間移行時AT直撃5.0%、強チェリー/チャンス目50.0%。ただしこれは設定変更専用抽選ではなくAT終了後の非有利区間も共通で、主要解析も『朝一恩恵は特に無し／おまけ程度』と評価。
- resetPenalties: 設定変更で前日の天井G数、内部メーター/リーチ蓄積、有利区間状態を失う。設定変更専用の追加ペナルティ数値は確認されず。
- resetDetection: 朝一有利区間ランプ点灯は据え置き濃厚。前日点灯状態を確認した上で朝一消灯ならリセット濃厚。朝一1G目のリールガックンも変更濃厚とする攻略解析あり。一方、前日消灯なら朝一消灯だけでは判別不可。『有利区間ランプ点灯+リーチボード非表示』も当日初当たり前なら据え置き濃厚材料。
- publicMorningNumbers: 設定変更後の非有利区間平均滞在は約15G。非有利区間→有利区間移行時のAT直撃率は弱チェリー/スイカで設定1 5.0%、2 6.2%、3 7.9%、4 9.9%、5 11.1%、6 12.3%、強チェリー/チャンス目で50.0 / 50.5 / 51.3 / 51.7 / 52.2 / 53.0%。中段チェリー・フリーズベル経由はAT確定。これは設定変更専用値ではなく非有利区間共通値として保存。
