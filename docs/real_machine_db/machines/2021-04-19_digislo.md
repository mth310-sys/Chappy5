### settingChangeBehavior
- 本機は天井・周期・AT/CZ・規定G数モードを持たないノーマルタイプであり、これらのリセット契約は `NOT_APPLICABLE`。
- 設定変更時の本機固有の内部ボーナス成立状態、初期出目、デジタル表示等の挙動を直接説明する高信頼公開資料は、機種名・型式・メーカー名と「設定変更 / リセット / 朝一 / 据え置き / 電源OFF ON / ガックン」を組み替えて再探索しても固定できず `UNVERIFIED_AFTER_RESEARCH`。
- reliability: ANALYSIS_HIGH（非搭載項目） / UNVERIFIED_AFTER_RESEARCH（本機固有内部挙動）

### carryOverBehavior
- 天井G数、周期、AT/CZ状態、モード等の翌日引継ぎ対象は存在せず `NOT_APPLICABLE`。
- 設定据え置き時に、成立済みリアルボーナスフラグやデジタル表示/出目が営業日をまたいでどう扱われるかを本機固有に固定できる公開資料は確認できず `UNVERIFIED_AFTER_RESEARCH`。

### powerCycleBehavior
- 電源OFF→ONのみの場合について、天井・モード・有利区間等はゲーム性上 `NOT_APPLICABLE`。
- 成立済みボーナスフラグ、出目、デジタル表示の保持/初期化について本機固有の直接資料を固定できず `UNVERIFIED_AFTER_RESEARCH`。一般的なノーマル機の挙動から推測補完しない。

### gameCounterReset
- 天井到達に用いる内部ゲーム数カウンタは非搭載のため `NOT_APPLICABLE`。
- 外部データカウンターやホール設備側の表示は実機内部契約ではないため対象外。

### ceilingAfterReset
- 天井非搭載。設定変更時の短縮天井も `NOT_APPLICABLE`。
- 1geki / HAZUSEで天井非搭載を確認。
- reliability: ANALYSIS_HIGH

- 設定変更専用モード振り分け・朝一専用モードの公開値は存在を確認できない。

### stateAfterReset

- リアルボーナス成立状態の設定変更/電断時契約は `UNVERIFIED_AFTER_RESEARCH` とし、推測しない。

### advantageousSectionReset

### resetDetection
