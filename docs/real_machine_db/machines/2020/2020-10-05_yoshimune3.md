### settingChangeBehavior
- 設定変更時は有利区間RESET→非有利区間。
- 天井までのゲーム数RESET。
- 通常時モード再抽選。
- 千両ポイントRESET（0pt）。
- 内部状態RESET。
- 必勝本では設定変更時のステージは殿の間（昼）。
- reliability: ANALYSIS_HIGH

### carryOverBehavior
- 据え置き時は純電源OFF→ONと同系統として、内部天井ゲーム数・有利区間・千両ポイント・内部状態をCARRY_OVERする。
- 千両ポイントは見た目上0ptになる場合があるため、表示と内部値を分離して扱う。
- reliability: ANALYSIS_HIGH

### powerCycleBehavior
- 純電源OFF→ONでは天井ゲーム数CARRY_OVER。
- 有利区間CARRY_OVER。
- 内部状態CARRY_OVER。
- 千両ポイントCARRY_OVER（見た目は0pt）。
- 必勝本初期資料ではモード/千両ptの電断時挙動が「調査中」だったが、後発解析で引継ぎを確認できたため後発値を採用。
- reliability: ANALYSIS_HIGH

### gameCounterReset
- 設定変更: 天井G RESET。
- 据え置き / 純電源OFF→ON: 天井G CARRY_OVER。

### ceilingAfterReset
- 設定変更専用の固定短縮天井は `NONE_CONFIRMED_AFTER_RESEARCH`。
- モード再抽選後の各モード天井が適用される。
- 通常A 約799G / 通常B 約663G / 通常C 約363G / 天国 約193G。

### modeAfterReset
- 設定変更: 通常時モード再抽選。
- 据え置き / 純電源OFF→ON: モード/内部進行CARRY_OVERとして後発解析を採用。
- 公開されている通常A/B/C振り分けはボーナス後等を含む通常モード解析値であり、設定変更専用振り分け表としては固定しない。

### stateAfterReset
- 設定変更: 内部状態RESET。
- 据え置き / 純電源OFF→ON: 内部状態CARRY_OVER。
- 設定変更後は非有利区間から有利区間移行時に「千両回胴」ストック抽選が行われる。

### advantageousSectionReset
- 設定変更: RESET→非有利区間。
- 据え置き / 純電源OFF→ON: CARRY_OVER。
- 通常時はREG後を除き有利区間ランプ基本消灯タイプのため、朝一消灯だけでは設定変更判別不可。

### resetBenefits
- 設定変更後は非有利区間となり、朝一数ゲームで内部的に千両回胴へ移行する挙動がある。
- 実際の画面で千両回胴へ移行するのは約50%で、残りは見た目上通常画面のままという対策仕様があると後発解析で説明。
- 固定天井短縮やボーナス直撃保証は `NONE_CONFIRMED_AFTER_RESEARCH`。

### resetPenalties
- `NONE_DIRECTLY_PUBLISHED`。
- 据え置きなら保持される天井進行・千両ポイント等が設定変更で消去されるが、設定変更専用の定量的不利は確認できない。

### resetDetection
- 朝一数ゲームで千両回胴へ突入すれば設定変更の可能性大。ただし非突入でも設定変更を否定できない。
- 通常時は有利区間ランプ基本消灯のため、朝一消灯では設定変更判別不可。
- 越後屋＆悪代官ランプが朝一1～66Gで点灯した場合は「設定変更+設定2以上」が濃厚。設定2以上へ変更された際の約25%で点灯。
- 点灯タイミング44G=設定4以上、55G=設定5以上、66G=設定6の示唆が公開されている。
- 本機固有リールガックン条件/発生率は十分な再探索後も直接契約を固定できず `UNVERIFIED_AFTER_RESEARCH`。

### numericResetData / publicMorningNumbers
- 設定2以上へ変更された場合の越後屋＆悪代官ランプ点灯率: **約25%**。
- 朝一ランプ点灯タイミング: **44G=設定4以上 / 55G=設定5以上 / 66G=設定6**。
- 設定変更後の千両回胴: 非有利区間移行由来で朝一に発生し、解析上は見た目に現れる割合 **約50%**。
- 通常A/B/C/天国の天井目安: **約799 / 663 / 363 / 193G**。
