## netIncrease
- NOT_APPLICABLE_AS_AT_NET_INCREASE。
- AT/ARTで増加させる機種ではなく、リアルボーナス高確状態でボーナスを連チャンさせるタイプ。
- 有利区間非搭載とする当時解説があり、2400枚有利区間上限に依存するAT機とは区別する。

## basicPayout
- BIG: 210枚超の払い出しで終了。
- REG: 74枚超の払い出しで終了。
- 実獲得枚数は当時報告に幅があり、BIG約120〜140枚程度とする資料もあるため、払い出し終了条件と実獲得を同一視しない。
- reliability: ANALYSIS_HIGH_FOR_PAYOUT_END_CONDITION / ANALYSIS_SINGLE_FOR_NET_TAKE

## modeSpecificMinimumData
- 通常時の3択ベル成功を契機にボーナス高確率状態「流星タイム」へ移行するリノタイプ相当の構造。
- 当時攻略では流星タイム中のボーナス成立率約1/10、状態転落率約1/40〜1/50、ループ約80%以上とされる。
- 見かけ上の流星タイム演出は50G固定だが、内部高確状態の継続とは必ずしも一致しないとする解説あり。
- 通常時ゲーム数天井は確認されていない。
