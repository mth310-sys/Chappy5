### settingChangeBehavior
- 設定変更時は **天井RESET / 内部状態RESET** とする後発解析を確認。
- 設定変更後は非有利区間から有利区間へ移行する6号機AT契約として整理。

### carryOverBehavior
- 据え置き時は天井G・内部状態・有利区間をCARRY_OVER契約として整理。
- 独立した据え置き専用表は限定的だが、純電断側の公開表と整合。

### powerCycleBehavior
- 電源OFF→ONのみでは **天井引継ぎ / 内部状態引継ぎ**。
- 液晶/ステージの電断復帰位置は主要解析で未確定のため `UNVERIFIED_AFTER_RESEARCH`。

### gameCounterReset
- 設定変更: **RESET**。
- 据え置き / 電源OFF→ON: **CARRY_OVER**。
- 通常天井は有利区間移行後777G。

### ceilingAfterReset
- 設定変更後も通常最大777G。
- 設定変更専用の数値的天井短縮は `NONE_CONFIRMED_AFTER_RESEARCH`。
- 天国モード111Gはモード由来であり、設定変更専用短縮とは扱わない。

### modeAfterReset
- 設定変更時の全モード振り分けは公開固定値を確認できず `UNVERIFIED_AFTER_RESEARCH`。
- 設定変更専用の天国移行率等は見つからず、通常モード表から推測しない。

### stateAfterReset
- 設定変更: **RESET**。
- 電源OFF→ON: **CARRY_OVER**。

### advantageousSectionReset
- 設定変更: **RESET / 非有利区間から再開**。
- 据え置き / 電源OFF→ON: **CARRY_OVER**。
- 本機固有の有利区間ランプ位置/朝一点灯判別の直接契約は十分に固定できず `UNVERIFIED_AFTER_RESEARCH`。

### resetBenefits
- **非有利区間中のレア役成立でAT（ボーナス）確定**とする当時攻略を確認。
- 設定変更後は非有利区間を経由するため、朝一1〜2G程度のレア役が恩恵対象になりうる。

### resetPenalties
- 設定変更で前日の天井G・内部状態・有利区間進行を消去。
- その他の設定変更専用不利要素は `NONE_CONFIRMED_AFTER_RESEARCH`。

### resetDetection
- 朝一挙動・有利区間ランプによる変更判別は当時資料で長期間「調査中」。
- 本機固有のガックン発生条件/率、ランプ消灯=変更等の確定契約は検索語・資料系統変更後も固定できず `UNVERIFIED_AFTER_RESEARCH`。

### numericResetData / publicMorningNumbers
- 通常天井: 有利区間移行後 **777G**。
- 非有利区間中レア役: **AT確定**（当時攻略）。
- 非有利区間平均滞在の実戦目安: **1〜2G程度**とする攻略記述あり。メーカー公表値ではないため解析値として分離。
- 111G以内トータル当選率: 設定1約30%とする解析、業界評価資料では自力込み34%表記があり定義差/時点差として保持。
