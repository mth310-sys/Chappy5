### settingChangeBehavior
- 設定変更で有利区間、天井進行、COUNT/ptカウンターをRESET。
- 朝一は夜ステージ（ランプエフェクト紺）、ドラゴンランプ白から開始。
- 設定変更時は内部的に約33%で龍宮ゾーンへ移行。非突入時は9G間のフェイク前兆へ移行する。
- 設定変更後（龍宮ゾーン非経由）は通常/ミドル/連/ドラゴンを設定別に再抽選する。

### carryOverBehavior
- 据え置き時は設定変更を伴わない電源OFF→ONと同様に、天井進行、有利区間、内部ptカウンターをCARRY_OVERする扱い。
- 朝一表示や見た目は初期化される要素があるため、表示0だけを内部リセットと解釈しない。

### powerCycleBehavior
- 純電源OFF→ON: 天井CARRY_OVER / 有利区間CARRY_OVER / ptカウンター内部値CARRY_OVER。
- ドラゴンランプは白、ステージは夜から開始するため、見た目だけでは設定変更との差が小さい。
- 電源ONから9G間はドラゴンランプの色変化やチェリーによるG数開放が見た目上発生しないが、内部抽選は行われるとする解析あり。

### gameCounterReset
- 設定変更: RESET。
- 据え置き / 純電断: CARRY_OVER。
- カウンターは設定変更時0から開始。通常時の最大消化G天井は991G+α、COUNTセグ最大は1279pt+α。

### ceilingAfterReset
- 一律の専用短縮天井は確認されていない。
- ただし設定変更時にモードを再抽選し、連モードなら127G、ミドルなら767Gとなるため、モード抽選結果による実質的な短縮は発生する。

### stateAfterReset
- 設定変更時は内部朝一抽選を新規実施し、約33%で内部龍宮ゾーンへ移行。非突入時は9Gフェイク前兆。
- 据え置き/純電断の通常内部状態の細部は本DBの完全再現範囲外。天井・有利区間・ptのCARRY_OVERを主要契約として保存。

### advantageousSectionReset
- 設定変更: RESET。
- 純電源OFF→ON: CARRY_OVER。
- ボーナス終了後は数ゲームの非有利区間を経由し、龍宮ゾーンへ移行する構造。

### resetBenefits
- 設定変更時、内部的に約33%で龍宮ゾーンへ移行することが最大の公開朝一恩恵。
- 龍宮ゾーンは7Gのボーナス超高確率ゾーンで、解析上のボーナス期待度は約62%とされる。
- 設定変更後モード抽選で連モードが選ばれれば127G以内のボーナスが確定。

### resetPenalties
- 設定変更で前日の天井進行、COUNT/ptカウンター、有利区間進行を失う。
- 前日ハマリや内部pt蓄積が大きい場合は、据え置きと比べてその蓄積を失うことが不利要素。
- 独立した追加ペナルティの公開固定値は確認されていない。

### resetDetection
- 設定変更時と純電源OFF→ON時はいずれもドラゴンランプ白・夜ステージ開始のため、これら単独では判別困難。
- 有利区間ランプはPAY OUT右下のドット。本機資料では「朝一消灯なら設定変更？」とされる一方、当時解析が調査中表記を残しており、確定判別契約にはしない。
- 本機固有のリールガックン発生条件・発生率は、機種名/型式/メーカー/設定変更/朝一/据え置き/ガックンを組み替えて再探索しても高信頼の公開契約を固定できずUNVERIFIED_AFTER_RESEARCH。

### numericResetData / publicMorningNumbers
- 設定変更時の内部龍宮ゾーン移行: 約33%。
- 龍宮ゾーン: 7G、解析上のボーナス期待度約62%。
- 非龍宮時: 9Gのフェイク前兆。
- 設定変更時モード振り分け: 上表の通り。
- モード別天井: 通常991G/1247pt、ミドル767G/991pt、連127G/127pt、ドラゴン991G/1279pt。
