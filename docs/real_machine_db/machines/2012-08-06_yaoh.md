## modeSpecificMinimumData

- ART高確率抽選ゾーン「夜王CHALLENGE」は10G / 20G / 無限。トータルART期待度50%超。
- 通常時は規定ゲーム数到達でも夜王CHALLENGEへ移行。
- 通常時の規定ゲーム数は100G刻みで選択される資料があり、設定1〜5は最大1000G、設定6のみ1100G選択あり。
- P-WORLDは最大1100G+αで無限夜王CHALLENGEと整理。
- BIG/PREMIUM BONUS成立は通常時なら無限夜王CHALLENGE契機となる。

reliability: ANALYSIS_HIGH_PLUS_OFFICIAL_FAN_SITE

## conflicts

- 「高モード」と「高確」の表記が資料により揺れる。朝一客行動に必要な粒度として50%の高状態スタートは保持するが、通常時全モード移行テーブルへ拡張しない。
- 天井の表現は「最大1100G+α」と「設定6のみ1100G、設定1〜5は最大1000G」が併存。矛盾というより設定別最大値の説明粒度差として保持。
