## modeSpecificMinimumData

- 通常時の主要状態は **通常 / Zゾーン / スーパーZゾーン**。
- ABナビは狙うボーナス色と押し順を案内し、ナビ保有時は約1/7でボーナスを獲得する連続性を形成。
- Zゾーンはナビ獲得高確、スーパーZゾーンはABナビストック保有が確定する状態。
- 天井1: **ボーナス間333G**でABナビ獲得。
- 天井2: **ABナビ間のW Z揃い20回**で到達。
- 天井到達時は最低 **7個以上**のABナビ。解析掲載の平均ナビ数は設定1/2/3/4/5/6 = **12.5 / 8.5 / 12.5 / 8.5 / 19.5 / 8.5個**。

## evidencePolicy

- 5号機一般論から設定変更/据え置き/電源OFF→ON挙動を推定しない。
- 通常時の333G天井・W Z揃い20回天井と、設定変更時のリセット挙動を明確に分離。
- ABナビによる約+2.2枚/Gは比較用の出玉速度として保持し、一般ARTの純増と同一内部方式とは扱わない。
- 5号機クロニクルは説明混入があるため補助照合のみ。
