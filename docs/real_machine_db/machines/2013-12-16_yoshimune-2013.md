- 当時2013-12-29の攻略記事で **G数リセット＆モード再抽選（宵越し不可）**を確認。
- confidence: ANALYSIS_HIGH_DIRECT_MODE / CONTEMPORARY_SECONDARY_GAME_COUNTER

### carryOverBehavior

- 純据え置き時の天井G・モード・状態を項目別に列挙した本機専用の直接契約は、機種名・型式名・メーカー名と「据え置き / 宵越し / 朝一 / 天井 / モード」を変えて再探索したが今回固定できず **UNVERIFIED_AFTER_RESEARCH**。
- 設定変更時の「宵越し不可」だけから据え置き保持を自動補完しない。

### powerCycleBehavior

- 設定変更を伴わない **電源OFF→ONのみ**の天井G・モード・状態の直接契約は、表記揺れと「電源OFF ON / 電源ON OFF / 電断 / 朝一」を組み替えて再探索したが **UNVERIFIED_AFTER_RESEARCH**。
- 後年の吉宗3/スマスロ吉宗/真打吉宗の電断仕様は混入しない。

### gameCounterReset

- 純据え置き / 電源OFF→ON: **UNVERIFIED_AFTER_RESEARCH**。

### ceilingAfterReset
