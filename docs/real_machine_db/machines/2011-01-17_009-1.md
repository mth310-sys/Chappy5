## modeSpecificMinimumData

- 各ボーナス後はCZ「セレクトミッション」へ移行。
- CZで6択押し順に正解またはナビ発生でARTへ。
- 通常時はART期待度に関わる**低確 / 高確**の2状態。
- P-WORLDでは高確中BIGはART抽選優遇、REGならART突入確定と整理。
- 通常天井: **CZ終了後1200G消化**で次回ボーナスまで継続するARTへ突入し、そのボーナス後は**90%継続以上のART**へ。
- ボーナス後ART突入率の公開目安: BIG後約40%、REG後約50%、S-BIG後約70%（パチマガスロマガ）。

confidence: ANALYSIS_HIGH
