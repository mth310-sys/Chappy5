## modeSpecificMinimumData

- ART「メタスラッシュ」: ゲーム数管理・上乗せ型。ART中ボーナスでも残りゲーム数は保持される構成。
- ART「サウザンドシステム」: メタスラッシュ終盤の抽選を契機に発動し、既獲得分を含む約1000枚到達まで継続する波形管理ART。
- ART「無敵ラッシュ」: 主にREG抽選から突入し、次回ボーナスまで継続。権利は最大100個ストック可能とP-WORLD掲載。
- METAL BONUS: 最低77G〜最大777GのART突入確定。
- 通常時には高確/超高確があり、P-WORLDではスクランブルモード＝高確濃厚、スーパースクランブルモード＝超高確濃厚。
- 天井: ボーナス間 **111G / 333G / 555G / 777G / 999G / 1111G** の奇数ゾロ目到達時に段階的な突入抽選。天井状態で次のBIGなら押し順ナビ100%、REGなら無敵ラッシュ確定。
