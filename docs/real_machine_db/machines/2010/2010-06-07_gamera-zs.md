## modeSpecificMinimumData

- RT「ガメラモード」は押し順リプレイとパンク役をナビする無限RTで、基本的に**次回ボーナスまで継続**。
- RT突入は主にBIG中バトル勝利、MIDDLE BONUS中の毎ゲーム抽選、ボーナス終了時など。
- RTループ率は **9 / 50 / 66 / 75 / 82 / 88%** の6種類（K-Navi）。最大88%。
- RT中に次回継続非当選状態でもギロン成立時に引き戻し抽選あり。
- 天井: **ボーナス間1000G以上**ハマった後のボーナス終了後はRT「ガメラモード」突入確定。P-WORLDで直接確認。
- 通常時の特定1枚役取得にはペナルティがあることをK-Naviが明記。天井カウントへの具体影響値は高信頼本文で確定できないため、resetBehaviorのゲーム数処理とは分離する。

confidence: INDUSTRY_ANALYSIS_MULTI_SOURCE
