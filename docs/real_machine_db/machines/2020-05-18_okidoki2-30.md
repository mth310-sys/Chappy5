### settingChangeBehavior
- 設定変更時は非有利区間へ移行することを1gekiの後期解析で確認。
- 天井進行はリセット扱い。
- 非有利区間中、ハズレでは有利区間へ移行せず、ハズレ以外の成立役を参照してモード振り分けを行う。
- したがって「設定変更直後に固定1モードへ直接セット」ではなく、設定変更後の非有利区間→有利区間移行時の成立役別抽選として扱う。

### carryOverBehavior
- 本機固有で「設定据え置き」を独立条件として、天井・内部モード・有利区間の全項目について直接固定した高信頼公開表は、表記揺れ/型式/朝一/据え置き/設定変更/有利区間を変えて再探索しても確認できず `UNVERIFIED_AFTER_RESEARCH_AS_DISTINCT_CONDITION`。
- 朝一に有利区間ランプが点灯している場合は据え置き挙動を示す攻略資料が複数あるが、通常時は基本消灯型のため、消灯だけで変更を断定できない。

### powerCycleBehavior
- 1gekiの2020-05-21時点「設定変更/電源OFF・ON時」比較表は、電源OFF・ON時の天井G数/モードをともに「現在調査中」としている。
- 後期の本機固有公開資料を再探索しても、純電源OFF→ON時の天井・モード・有利区間の直接契約を十分な信頼度で固定できず `UNVERIFIED_AFTER_RESEARCH`。
- 後継機の契約を本機へ転記しない。

### gameCounterReset
- 設定変更: RESET。設定変更後は非有利区間から新たに有利区間移行抽選を開始する。
- 据え置き: 本機固有の直接公開契約はUNVERIFIED_AFTER_RESEARCH。
- 純電断: 本機固有の直接公開契約はUNVERIFIED_AFTER_RESEARCH。
- canonical最大規定G数: 通常A/B 999G。

### ceilingAfterReset
- 高信頼解析のcanonicalは、設定変更後も有利区間移行後に選ばれたモードの規定G数に従う。通常A/Bなら999G、チャンス256G、天国準備500G。
- 一部の2020年初期攻略記事は「朝一リセット台の実質天井967G（有利区間32Gぶん早まる）」とする。ただし後期解析のモード/非有利区間構造との定義整合が明確でなく、単一系統の立ち回り表現であるため `PROVISIONAL_DEFINITION_CONFLICT_967G_VS_MODE_REGULATION` として分離し、999Gを一律967Gへ上書きしない。

### modeAfterReset
- 設定変更後は非有利区間。
- 有利区間移行時に成立役に応じてモード抽選。
- ベル/リプレイ成立時の設定1〜6振り分け:
  - 通常A: 76.2 / 64.1 / 74.2 / 64.1 / 74.2 / 55.5%
  - 通常B: 16.8 / 25.0 / 18.8 / 25.0 / 18.8 / 31.2%
  - チャンス: 6.2 / 10.1 / 6.2 / 10.1 / 6.2 / 12.5%
  - 天国準備: 全設定0.8%
- チェリー/スイカ/確定役/中段チェリーでは別の優遇振り分けが公開されているが、物差しDBでは完全再現用の全小役表までは保存せず、朝一成立役でモード分布が変わる点のみ採用。

### stateAfterReset
- 本機は通常A/B・チャンス・天国準備等の「モード」が朝一挙動の主要状態変数。
- モードとは別の低確/高確等について設定変更専用初期状態の公開固定値は、今回の再探索では確認できず `PUBLIC_STATE_VALUE_NOT_FOUND_AFTER_RESEARCH`。

### advantageousSectionReset
- 設定変更時: 非有利区間へ移行 = 有利区間RESET。
- 終了モードで32G経過後にも有利区間終了→非有利区間へ移行。
- 通常時は有利区間ランプが基本消灯するタイプ。ボーナス当選時から点灯し、32G後に区間終了すれば消灯するという実戦/攻略資料がある。

### resetBenefits
- 設定変更後は非有利区間からモードを再選択するため、成立役と設定次第で通常B/チャンス/天国準備から始まる可能性がある。
- 特にベル/リプレイ移行でも設定1で通常B以上23.8%、設定6で通常B以上44.5%（通常B+チャンス+天国準備の単純合計）。これは公開表からの算術要約であり、独立したメーカー公表「朝一期待度」ではない。
- チャンス選択時は規定G数256G、天国準備なら500Gで次回天国以上が期待されるため、朝一の主要恩恵として扱える。

### resetPenalties
- 設定変更で前日の有利区間/天井進行を持ち越す契約ではないため、前日深いハマリを狙う観点ではリセットが不利になり得る。
- 独立した設定変更専用ペナルティ数値は確認されていない。

### resetDetection
- 通常時は有利区間ランプが基本消灯型のため「朝一ランプ消灯」だけでは変更判別不可。
- 朝一に有利区間ランプが点灯していれば、前日から有利区間が残った据え置き挙動を強く示す資料が複数ある。ただし店舗対策等を考慮し確定万能条件とはしない。
- リールサイドランプ/投入ランプはモード示唆に用いられるが、純電断時の演出履歴保持条件が未固定なので、設定変更確定判別には使用しない。
- 本機固有のリールガックン条件/発生率は再探索後も高信頼固定値を確認できず `UNVERIFIED_AFTER_RESEARCH`。

### numericResetData / publicMorningNumbers
- 設定変更後の有利区間移行時・ベル/リプレイ成立時モード振り分け（設定1→6）:
  - 通常A: 76.2 / 64.1 / 74.2 / 64.1 / 74.2 / 55.5%
  - 通常B: 16.8 / 25.0 / 18.8 / 25.0 / 18.8 / 31.2%
  - チャンス: 6.2 / 10.1 / 6.2 / 10.1 / 6.2 / 12.5%
  - 天国準備: 0.8%（全設定）
- チェリー/スイカ成立時は通常B以上がさらに優遇される公開表あり。
- 一律設定変更専用短縮天井: CONFIRMED_FIXED_VALUE_NONE。選択モードにより256/500/999G等。
- 早期攻略資料の「リセット後実質967G」は `PROVISIONAL_DEFINITION_CONFLICT` として別保持。
