### settingChangeBehavior

- 設定変更時は **有利区間RESET / 天井RESET / 内部モードRESET**。
- 内部状態についても解析比較表でRESETとされる。
- 設定変更後は約10%で引き戻しモードへ移行する。
- 設定Lを除き、固定の短縮天井は確認されていない。

### carryOverBehavior

- 据え置き時は **有利区間 / 天井 / 内部モード / 内部状態をCARRY_OVER**。

### powerCycleBehavior

- 純電源OFF→ON時は **有利区間 / 天井 / 内部モード / 差枚数をCARRY_OVER**。
- 内部状態の独立項目については、機種固有の電源OFF→ON比較表で直接固定できなかったため **UNVERIFIED_AFTER_RESEARCH**。ただし主要モード・天井・有利区間は引継ぎが直接確認されている。

### gameCounterReset

- 設定変更: 天井ゲーム数RESET。
- 据え置き: 天井ゲーム数CARRY_OVER。
- 純電源OFF→ON: 天井ゲーム数CARRY_OVER。

### ceilingAfterReset

- 通常A / 通常B / 引き戻し: 最大777G+αでボーナス。
- シリウスA / シリウスB: 最大200G+αでボーナス。
- 設定変更後の固定天井短縮: **NONE_CONFIRMED**。
- 約10%で引き戻しモードへ移行する恩恵はあるが、引き戻しモード自体の天井は777G+αであり「短縮天井」とは扱わない。

### modeAfterReset

- 設定変更時: 内部モードRESET、約10%で引き戻しモードへ移行。
- 据え置き / 純電源OFF→ON: 内部モードCARRY_OVER。
- 設定変更後の引き戻し移行率は約10%（全設定共通扱いの解析）。

### stateAfterReset

- 設定変更: RESET。
- 据え置き: CARRY_OVER。
- 純電源OFF→ON: 独立した内部状態項目は **UNVERIFIED_AFTER_RESEARCH**。

### advantageousSectionReset

- 設定変更: 有利区間RESET。
- 据え置き / 純電源OFF→ON: 有利区間CARRY_OVER。
- ボーナス終了時の一部で有利区間RESET。
- 有利区間ランプはボーナス開始〜終了時のみ点灯するタイプで、通常時は基本消灯。よって朝一ランプによる設定変更判別は不可。

### resetBenefits

- 設定変更後は **約10%で引き戻しモードへ移行**。
- 引き戻しモードのボーナス確率は約1/99.9。
- 固定の短縮天井・設定変更専用シリウスモード直行は確認されていない。

### resetPenalties

- 設定変更時の独立した公開ペナルティ: **NONE_CONFIRMED**。
- 前日モード・差枚数・有利区間を失う点は通常のリセット挙動として扱う。

### resetDetection

- 有利区間ランプは通常時基本消灯のため、朝一の点灯/消灯だけで設定変更判別はできない。
- 設定Lはデモ画面中の下パネル消灯で判別可能だが、これは設定変更判別ではなく設定L識別。
- 本機固有のリールガックン条件・発生率は、機種名・正式型式・メーカー名と「ガックン / 設定変更 / リセット / 朝一 / 据え置き」を変えて再探索したが直接資料を固定できず **UNVERIFIED_AFTER_RESEARCH**。

### numericResetData

- 引き戻しモードのボーナス確率: **約1/99.9**。
- 通常A/B/引き戻し天井: **777G+α**。
- シリウスA/B天井: **200G+α**。
- 設定変更専用の固定短縮天井: **NONE_CONFIRMED**。

### publicMorningNumbers

- 朝一設定変更時の主要公開数値は **引き戻しモード移行 約10%**。
- 引き戻しモード滞在時のボーナス確率は **約1/99.9**。
- 通常時の一般モード振り分けやシリウスモード移行率33.3%は通常のボーナス後抽選であり、設定変更専用値には混入しない。
