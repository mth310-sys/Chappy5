## resetBehavior

### settingChangeBehavior

- 設定変更時は **有利区間RESET / 天井RESET / 内部モードRESET / 内部状態RESET**。
- 通常状態なら朝一は瞳ステージ開始。
- 前日がキャッツ目成立後の内部ボーナス状態であっても、設定変更時は瞳ステージ開始。
- 固定の天井短縮や設定変更専用の当選率上昇は確認されず、リセット後の主要恩恵は **NONE_CONFIRMED**。

### carryOverBehavior

- 据え置き時は **有利区間 / 天井 / 内部モード / 内部状態をCARRY_OVER**。
- 通常状態なら朝一は瞳ステージ。
- 前日キャッツ目成立後の内部ボーナス状態を跨いだ場合、朝一は泪ステージ開始となり、据え置き濃厚材料になる。

### powerCycleBehavior

- 純電源OFF→ON時は **有利区間 / 天井 / 内部モード / 内部状態をCARRY_OVER**。
- 通常状態なら瞳ステージ開始。
- キャッツ目成立後の内部ボーナス状態で閉店し純電断のみなら、翌朝は泪ステージ開始。

### gameCounterReset

- 設定変更: 通常時天井999Gのゲーム数をRESET。
- 据え置き: 天井ゲーム数をCARRY_OVER。
- 純電源OFF→ON: 天井ゲーム数をCARRY_OVER。

### ceilingAfterReset

- 通常天井: 999G消化でAT「キャッツ・タイム」当選。
- 設定変更後も天井は999Gで、短縮天井は **NONE_CONFIRMED**。
- 天井到達時のキャッツ・チャレンジは配当テーブル4以上、30G以上上乗せ保証とする解析あり。

### modeAfterReset

- 設定変更時: 内部モードRESET。
- 据え置き / 純電源OFF→ON: 内部モードCARRY_OVER。
- 朝一専用モードや設定変更専用モード振り分けの公開数値は **NONE_PUBLISHED_CONFIRMED**。

### stateAfterReset

- 設定変更時: 内部状態RESET。
- 据え置き / 純電源OFF→ON: 内部状態CARRY_OVER。
- キャッツ目成立後の内部ボーナス状態を据え置き・純電断で跨ぐと泪ステージ開始という外見上の判別材料がある。

### advantageousSectionReset

- 設定変更時: 有利区間RESET。
- 据え置き / 純電源OFF→ON: 有利区間CARRY_OVER。
- AT「キャッツ・タイム」終了時は毎回有利区間RESET。
- 本機は6.5号機で、有利区間ランプそのものを搭載しないためランプによる変更判別は不可。

### resetBenefits

- 固定のリセット恩恵: **NONE_CONFIRMED**。
- 天井短縮: **NONE**。
- 設定変更専用のCZ/AT優遇・朝一高確率状態の公開値: **NONE_CONFIRMED**。

### resetPenalties

- 設定変更時の主要な不利要素: **NONE_CONFIRMED**。
- 前日キャッツ目成立後の内部状態はリセットされるため、据え置きなら残る状態を設定変更では失う点は状態初期化として扱い、独立したペナルティ値にはしない。

### resetDetection

- 有利区間ランプ: **非搭載のため判別不可**。
- 朝一が泪ステージ開始なら、前日キャッツ目成立後状態の据え置き / 純電源OFF→ONが濃厚。
- 朝一瞳ステージは設定変更・据え置き双方で起こるため、それだけでは判別不可。
- 本機固有のリールガックン条件・発生率は、機種名・型式 `SキャッツアイH6`・メーカー名と「ガックン / 設定変更 / リセット / 朝一 / 据え置き」を変えて再探索したが、高信頼の機種固有契約を固定できず **UNVERIFIED_AFTER_RESEARCH**。

### numericResetData

- 設定変更後短縮天井: **なし**。
- リセット専用恩恵発生率: **NONE_PUBLISHED_CONFIRMED**。
- 朝一専用モード振り分け: **NONE_PUBLISHED_CONFIRMED**。
- 設定変更専用AT/CZ当選率: **NONE_PUBLISHED_CONFIRMED**。

### publicMorningNumbers

## resetBehavior QAメモ

- なな徹は設定変更 / 据え置きの比較表で、有利区間・天井・内部状態をRESET/CARRY_OVERと明記。
- スロパチクエストは設定変更 / 電源OFF→ONの比較表で、有利区間・天井・内部モード・内部状態をRESET/CARRY_OVERと明記し、リセット後恩恵「なし」と掲載。
- ちょんぼりすたも設定変更時は天井・内部状態RESET、電源OFF→ONは引継ぎとし、キャッツ目中閉店後の泪ステージ開始を据え置き濃厚材料としている。
- 6.5号機のため有利区間ランプ非搭載。設定変更判別をランプに依存させない。

## conflicts

- 正式型式は業界発表・P-WORLD系・HAZUSE・実機取扱資料で `SキャッツアイH6` が優勢。一方P-BOMB記事のみ `SキャッツアイHG` と記載。**MODEL_NAME_CONFLICT / H6_CANONICAL** として保持し、HGへ置換しない。
- 機械割は技術介入成功率により97.7〜102.4%等のレンジとなる。P-WORLDは完全攻略側102.4〜108.5%のみを掲載するため、数値競合ではなく **TECHNIQUE_ASSUMPTION_DIFFERENCE** として分離。
