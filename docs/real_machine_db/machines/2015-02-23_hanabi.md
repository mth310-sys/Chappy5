### settingChangeBehavior

- 一撃の本機専用「天井/設定変更」解析は **設定変更時詳細: 特になし** と明記。
- 天井・規定Gモード等を持たないため、朝一だけのゲーム数恩恵/短縮天井は該当しない。
- 設定変更でのボーナス確率そのものは選択設定に従うが、朝一専用の特別当選優遇は確認されない。

### carryOverBehavior

- 天井カウンタ・規定Gモード・AT状態は非搭載のため `NOT_APPLICABLE`。
- 据え置き専用の朝一恩恵/不利要素は `NONE_CONFIRMED_AFTER_RESEARCH`。
- 前日成立済みボーナスやRT中閉店など特殊な跨ぎ状態の完全な実機内部契約は、本DBの比較粒度を超えるため一般論で補完しない。

### powerCycleBehavior

- 設定変更なしの単純電断復帰による天井短縮・モード再抽選等は該当なし。
- confidence: ANALYSIS_HIGH_CONTEMPORARY
