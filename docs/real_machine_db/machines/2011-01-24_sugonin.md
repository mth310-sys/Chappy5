## modeSpecificMinimumData

- ART「凄忍タイム」は押し順ART。50/100/150/300G。
- ART突入契機は通常時チャンス目、ボーナス中抽選、3択チャレンジ成功等。
- ART中はチャンス目出現率が通常時約1/80から約1/40へ上昇。
- ART終了後に「引き戻しゾーン（超高確）」へ入るループ構造がある。
- K-Navi/P-WORLDは本機を「天井」搭載機として扱うが、今回取得可能本文から通常天井の正確な起算点・G数・恩恵を複数系統で安全に確定できず、数値はUNVERIFIEDとする。pacnkの現行補助表示に「約1000G」の自動抽出目安があるが、原解析本文を独立確認できないため主値へ昇格しない。

confidence: ANALYSIS_HIGH for ART; UNVERIFIED for exact ceiling
