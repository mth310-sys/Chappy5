## modeSpecificMinimumData

- 32G周期で必ずレア役以上が成立する「スパイラルZERO」を搭載。
- CZは少なくとも「急速潜航MODE」「追跡MODE」「急襲MODE」を搭載。
- 急襲MODEは20Gの自力CZ。K-Navi掲載のトータル突入率は設定1～6で 1/158.9 / 1/147.7 / 1/152.7 / 1/138.2 / 1/140.9 / 1/127.1。
- 通常時の全内部抽選は本ミッション対象外。

## ceiling

- ART間天井は **600G / 900G / 1200Gのいずれか**。
- 600Gまたは900G選択時はBATTLE MODE確定。
- 1200G選択時は **継続率80%のBATTLE MODE** が確定。
- 別系統整理では「スパイラルZERO規定回数でART」「CZ間450GでCZ」の天井要素も掲載されるが、物差し主軸はART間600/900/1200Gを採用。
- confidence: INDUSTRY_DATABASE_HIGH + ANALYSIS_HIGH
