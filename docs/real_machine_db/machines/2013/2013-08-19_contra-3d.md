### settingChangeBehavior

- **設定変更時は天井到達までのゲーム数がクリアされる**ことを、パチスロ解析DBと「パチスロ立ち回り講座」の旧天井DBで独立確認。
- 設定変更時のモードについては、2014年の実戦回顧記事に **「設定変更時の約33%で天国or真天国」** との記述がある。
- ただし、この約33%は今回の検索で高信頼解析表・公式/業界一次資料へ二重照合できなかったため、**SINGLE_LOW_CONFIDENCE_RESET_MODE_REPORT** としてのみ保持し、高信頼確定値へ昇格しない。
- 設定変更時の通常A/Bを含む完全なモード振り分け、内部高確/低確等の状態初期化仕様は **UNVERIFIED_AFTER_RESEARCH**。

### carryOverBehavior

- 純据え置き時に、天井ゲーム数・モード・内部状態をどの粒度で保持するかを直接明示した本機専用資料は、表記揺れ・メーカー名・シリーズ名と「据え置き / 宵越し / 天井 / モード」を組み替えて再探索したが **UNVERIFIED_AFTER_RESEARCH**。
- 設定変更時のゲーム数クリアから据え置き時保持を逆算しない。

### powerCycleBehavior

## conflicts / safeguards

- 2013-08-18は当時業界記事等の **納品開始予定**、2013-08-19は複数DBの **ホール導入開始日**。定義が異なるためCONFLICTにはせず、本DBのreleaseDateは2013-08-19を採用。
- 「AT間999Gの通常最大天井」と「通常A/B/天国/真天国の999/640/128/32G」は階層の違う同一仕様でありCONFLICTではない。
- 設定変更時「約33%で天国or真天国」は単一回顧資料のみ。通常AT終了後のモード移行率と混同せず、低信頼の朝一数値として分離保存。
- 魂斗羅シリーズのゲーム作品、他年度のKONAMI/KPE機種のリセット仕様を本機へ混入させない。
