### resetBenefits

- 設定変更後は全設定で **通常B 50%**。通常Bの最大天井は **768G**。
- 設定1～3でも天国 **20%**、設定4～6では天国 **30%**。天国最大128G。
- したがって朝一は通常A以外が設定1～3で70%、設定4～6で80%となるが、これはモード選択率の単純合計でありART当選率ではない。

### resetPenalties

- 設定変更すると前日の天井消化ゲーム数を失うため、前日深いハマリ台の**宵越し天井進捗は消失**。
- 前日モードの継続も期待せず、設定変更後モード再抽選となる。

## conflicts

- **機械割**: P-WORLD / パチマガスロマガ / 5号機クロニクルは **96.7 / 98.3 / 99.9 / 104.2 / 108.5 / 113.1%**。2013年当時の天井ハイエナ生活は **97.0 / 98.6 / 100.3 / 104.6 / 109.0 / 113.6%**。平均せず前者を主系列、後者を `CONFLICT_PAYOUT_SERIES` として保持。
- パチマガスロマガの一部検索インデックス表示には設定5/6 ART合成値やPAYOUTの先頭桁が崩れた表示があるが、同サイトの詳細ページ `h-1.php`、K-Navi、P-WORLD、HAZUSEとの照合で正規値を採用。検索表示崩れを実性能競合とは扱わない。
- LackLuckLifeはART基本50Gと記載するが、業界記事・K-Navi・P-WORLD・パチビー・パチマガスロマガが40G+αで一致するため、50G記載を `CONFLICT_SINGLE_SECONDARY_APPARENT_SPEC_ERROR` として保持。
