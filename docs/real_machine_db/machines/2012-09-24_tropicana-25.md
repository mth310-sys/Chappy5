## variantRelation

- ユニバーサル公式製品ページは同一「トロピカーナ」製品として25Φ/30Φの両筐体を掲載。
- 2012-07-27グリーンべると記事は25φ仕様と30φ仕様の2タイプ同時発売と明記。
- 現存する25φ/30φ性能資料では機械割、合算、擬似BIG/REG、純増、天井の主要性能は同一。
- 一方、30φは沖スロ市場仕様で2012-08-09沖縄先行導入が確認できるため、市場・導入履歴の比較価値を残す目的で独立レコード化する。
