## modeSpecificMinimumData

- 「鉄拳チャンス」は毎ゲーム約1/11でボーナス抽選、期待度約63%。終了後はTC高確滞在濃厚。
- 天井は有利区間移行後1000G+前兆。天井到達時はバトルボーナス+勝利ストック1個。
- ボーナス後高確中は前の大当たりの有利区間を引き継ぐため、データカウンター上の単純1000G到達と内部天井到達は一致しない場合がある。PUSH長押しで内部消化G数確認機能あり。

## resetBehavior

resetBehaviorVersion: v0.7
resetBehaviorQA: COMPLETE_PUBLIC_RESET_CORE
resetQaLastUpdated: 2026-09-11

- settingChangeBehavior: 設定変更時は天井までのゲーム数をリセット。ボーナス高確・TC高確を終了し、非高確状態へ。内部状態を再抽選し、有利区間は非有利区間から開始。
- carryOverBehavior: 据え置きでは天井までのゲーム数、ボーナス高確、TC高確、内部状態、有利区間を引き継ぐ。
- powerCycleBehavior: 純電源OFF→ONでは天井までのゲーム数、ボーナス高確、TC高確、内部状態、有利区間を引き継ぐ。設定変更と明確に異なる。
- gameCounterReset: 設定変更で内部天井G数リセット。据え置き・純電断では引継ぎ。
- ceilingAfterReset: 設定変更後も天井は有利区間移行後1000G+前兆。リセット専用の短縮天井は主要資料で確認されず `NONE_CONFIRMED_AFTER_RESEARCH`。
- modeAfterReset: 設定変更時は高確関連をリセットして非高確状態へ。朝一専用モードの公開固定振り分けは今回確認できず `PUBLIC_VALUE_NOT_FOUND_AFTER_RESEARCH`。
- stateAfterReset: 設定変更時は内部状態再抽選。純電断・据え置きでは引継ぎ。朝一の実戦上ステージはユグドラシル1人またはシリウス昼が確認されるが、公開振り分け値は確認できない。
- advantageousSectionReset: 設定変更時は非有利区間スタート。据え置き・純電断は有利区間を引継ぐ。有利区間ランプも引継ぎ対象だが、通常時は基本消灯のため朝一ランプだけでの判別は通常は困難。前日点灯状態を把握している場合は据え置き材料になる。
- resetBenefits: 明確な設定変更専用出玉恩恵は主要資料で `なし` とされる。有利区間移行後に目立った朝一優遇ゾーンは確認されず。
- resetPenalties: 設定変更で前日天井G数、高確状態を失うため、前日ハマリ/高確を据え置く場合と比較するとリセットされる点が不利要素。ただし専用の数値ペナルティは確認されず。
- resetDetection: ガックン判別が有効とされ、リールがガックンすれば設定変更濃厚。BIG終了画面「木人」は設定変更確定という解析情報あり。有利区間ランプは通常時基本消灯なので常用判別には不向き。PUSH長押しの内部G数表示も前日情報があれば据え置き判別材料になる。
- publicMorningNumbers: 設定変更専用のモード振り分け・朝一特定G以内当選率・短縮天井数値は主要資料で確認できず `PUBLIC_VALUE_NOT_FOUND_AFTER_RESEARCH`。天井自体は有利区間移行後1000G+前兆。

## qualityNotes / conflicts

- 型式 `Sパチスロ鉄拳4CC`、検定番号 `9S0147` はHAZUSEとP-WORLDで一致。
- 導入日2019-07-22はK-Navi、P-WORLD、一撃、日刊スポーツ導入カレンダーで一致。
- 天井は「1000G+前兆」。ボーナス後の高確は前有利区間を引き継ぐため、データカウンターの単純G数と内部天井G数が一致しない点を注記。
- 有利区間ランプについて「据え置きなら引継ぎ」は確認できるが、通常時は基本消灯のため、点灯していないこと自体をリセット根拠にはしない。
