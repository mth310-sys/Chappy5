## modeSpecificMinimumData

- 通常時はボーナス後のゲーム数に応じて高確率状態が周期的に配置される。
- P-WORLD掲載の主な高確率帯:
  - **1〜64G**
  - **193〜288G**
  - **417〜512G**
  - **641〜736G**
  - **865〜960G**
  - **1089〜1184G**
- ART「操LIVE BONUS」は1セット50G。AT状態を経由し、ART突入リプレイ成立後からゲーム数を消化する構成。
- SUPER 操LIVE BONUSは次回ボーナスまで継続。
- 通常時 **1281G以降**は救済用の高確率ゾーンとなり、次回ボーナスまでARTストック抽選が大幅に優遇される。到達だけで最低1セットが確定する仕様ではないとP-WORLDが注意しているため、「1281GでART当選確定」とは記録しない。

## conflicts

- payoutRateBySetting: フル設定系列97.4/98.9/99.8/104.6/108.1/113.1%は後年単一二次資料。K-Naviは設定6 113.1%のみ照合可能で設定1〜5は未発表表記。数値競合ではないが、設定1〜5の一次/当時解析系照合待ち。
