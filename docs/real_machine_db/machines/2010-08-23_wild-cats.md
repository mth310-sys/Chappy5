## modeSpecificMinimumData

- ボーナス後はチャンスゾーンを経由し、**必ず60G完走型ART「貯金ゾーン」へ突入**。
- ART中にボーナス成立した場合も告知を保留し、ART完走後に1G連のようにボーナスへつなぐ擬似ストック的ゲーム性。
- ART中にボーナス非成立の場合は完走後CZへ移行。
- CZ中、転落特殊リプレイ成立前に3択押し順ベルの取りこぼし目（ART突入目）が出れば再度ARTへ突入。
- ボーナス後CZでは転落特殊リプレイが成立しないためART突入が保証される。
- 通常ゲーム数型の固定天井は、K-Navi攻略/天井ページ、P-WORLD、パチビー、当時業界記事を再探索しても本機固有の確定仕様を回収できず `NONE_CONFIRMED_AFTER_RESEARCH`。
