## modeSpecificMinimumData
- 通常時ゲーム数天井: **961G到達以降の前兆を経由し、最大999GまでにAT**。
- P-WORLDは「961G+α」、一撃は「通常時ハマリ960G〜999Gの間に前兆経由でAT」と整理。
- CZ「ロザリークロスゾーン（RCZ）」は内部モードで規定G数を管理。
- 最深RCZ規定G数: ハマリ896G / 通常768G / チャンス128G。
- レア役による規定G数短縮があるため、見た目ゲーム数と内部RCZ進捗がずれる場合がある。
- 有利区間制度導入前。

## resetBehavior

### settingChangeBehavior
- **天井ゲーム数 RESET**。
- **内部モード RESET / 再抽選**。
- **内部状態 RESET / 再抽選**。
- 液晶ステージは **ボルーゴ峠** から開始。
- 一撃およびすろぱちくえすとで直接比較を確認。

### carryOverBehavior
- 据え置き時は、純電源OFF→ON時の直接比較資料および通常の据え置き定義から **天井進捗 / 内部モード / 内部状態をCARRYOVER** とする。
- 液晶表示は電源投入時に峠へ戻るため、内部状態と表示ステージを分離して扱う。
reliability: ANALYSIS_HIGH_DIRECT_FOR_POWER_CYCLE_PLUS_CARRYOVER_INFERENCE

### powerCycleBehavior
- 純電源OFF→ON:
  - 天井ゲーム数: **CARRYOVER**
  - 内部モード: **CARRYOVER**
  - 内部状態: **CARRYOVER**
  - 液晶ステージ: **峠ステージ（AT中以外）**
  - 見た目ゲーム数カウンタ: **RESET**
- 一撃の設定変更/電源OFF→ON直接比較表で確認。
reliability: ANALYSIS_HIGH_DIRECT

### gameCounterReset
- 設定変更: **内部天井ゲーム数 RESET**。
- 純電源OFF→ON: **内部天井ゲーム数 CARRYOVER**。
- 外部/見た目ゲーム数カウンタは電源投入で0表示となりうるため、内部進捗と分離。

### ceilingAfterReset
- 設定変更後も通常天井仕様を0Gから再カウント。
- **設定変更専用の固定短縮天井は NONE_CONFIRMED_AFTER_RESEARCH**。
- 通常天井は961G以降〜最大999GでAT。

### modeAfterReset
- 設定変更時はRCZモード（ハマリ / 通常 / チャンス）を再抽選。
- AT終了時と同じ初期移行テーブル。
- チャンスモードならRCZは128G以内。
- 設定別振り分けを numericResetData に保存。

### stateAfterReset
- 設定変更時は全設定共通で再抽選:
  - 低確 **50.00%**
  - 通常 **39.84%**
  - 高確 **10.16%**
- 純電源OFF→ONでは状態を引き継ぐ。

### advantageousSectionReset
- **NOT_APPLICABLE_5TH_GEN_PRE_5_9**。

### resetBenefits
- 設定変更時はチャンスモードが選ばれれば **128G以内にRCZ**。
- 設定1でもチャンスモード **25.78%**、設定5では **43.75%**、設定6では **37.50%**。
- 高確スタートは全設定共通 **10.16%**。
- ただし複数当時解析は「強いリセット恩恵ではない」と評価しており、固定短縮天井のような強恩恵は確認できない。

### resetPenalties
- 天井進捗は設定変更で消去されるため、前日深いハマリを据え置けば得られた宵越し天井期待は失われる。
- モード初期振り分けは設定1でハマリ64.06%など、設定により朝一が必ず優遇とはいえない。
- 新台初日実戦値を用いた二次資料には「リセット後が特別強く見えない/冷遇可能性」の考察があるが、実戦値由来のため確定仕様にはしない。

### resetDetection
- 設定変更時も純電源OFF→ON時も液晶は峠ステージから始まり得るため、**峠スタート単独では変更判別不可**。
- 純電源OFF→ONでは内部天井/モード/状態が引き継がれる一方、見た目ゲーム数カウンタがリセットされるため、表示0Gだけでは内部リセットを意味しない。
- 本機固有のメーカー保証ガックン・初期出目・ランプ確定判別は、表記揺れを変えて再探索しても直接固定できず **NONE_CONFIRMED_AFTER_RESEARCH**。
