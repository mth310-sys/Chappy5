## resetBehavior

### settingChangeBehavior

- 設定変更時は **天井までのゲーム数をリセット**。
- **内部状態を再抽選**。
- **内部モードを再抽選**。
- **先走りパトランランポイントを再抽選**。
- 液晶ゲーム数は **0G**。
- 液晶ステージは **さやか / まどか / あやかステージのいずれかへ再抽選**。
- 必勝本の「天井&設定変更」と2015年当時の複数解析資料で主要挙動が一致。

### carryOverBehavior

- 据え置き時は、当時解析資料で **天井ゲーム数・内部モード・内部状態・先走りパトランランポイントを引き継ぐ**契約が確認できる。
- 液晶ステージのみ朝一に再抽選されるため、ステージだけでは据え置き/変更を断定できない。
- confidence: ANALYSIS_HIGH_MULTI_SOURCE

### powerCycleBehavior

- 設定変更なしの電源OFF→ON:
  - 天井までのゲーム数: **引き継ぐ**
  - 内部状態: **引き継ぐ**
  - 内部モード: **引き継ぐ**
  - 先走りパトランランポイント: **引き継ぐ**
  - 液晶ゲーム数: **0G**
  - 液晶ステージ: **さやか / まどか / あやかへ再抽選**（AT・CZ中は状態を引き継ぐとの必勝本記載）
- 必勝本に設定変更との対照表があり、期待値見える化でも主要4内部項目が同様に整理されている。
- confidence: ANALYSIS_HIGH_MULTI_SOURCE

### gameCounterReset

- 設定変更時: **RESET**。
- 据え置き / 純電源OFF→ON: **CARRY_OVER**。
- 液晶表示ゲーム数は電源OFF→ONでも0Gへ戻るため、表示G数と内部天井Gを混同しない。

### ceilingAfterReset

- 設定変更後も通常A/B/Cの最大天井は **1500G + 最大35G前兆**。
- リセット専用の固定短縮天井は確認されず、当時解析でも通常と同じ狙い目と整理されている。
- `NONE_CONFIRMED_FOR_RESET_SPECIFIC_SHORTENING`。

- 据え置き / 純電源OFF→ONでは内部状態引き継ぎ。

### advantageousSectionReset

- `NOT_APPLICABLE_5TH_GEN_PRE_5_9`。

### resetBenefits

- 設定変更時はモード再抽選で **天国A/B合算10.0%**。
- 状態再抽選により、高確以上スタートは **奇数設定25.0% / 偶数設定40.0%**。
- 先走りパトランランポイントも再抽選される。
- 一方、固定の天井短縮は確認されず、当時解析では「リセットだから400G/800Gゾーンが強くなるわけではない」とされるため、強い朝一専用天井恩恵はなし。

### resetPenalties

- 設定変更により前日の **天井進捗・内部モード・内部状態・先走りパトランランポイントの蓄積を失う**。
- 宵越し天井/ポイント狙いの観点では設定変更が不利要素になる。

### resetDetection

- **ガックン判別は不可能**とする2015年当時解析資料あり。
- 据え置き時も液晶ステージは再抽選されるため、朝一ステージのみでは変更判別不可。
- 「朝一8G以内のレア役でリセット確定？」という当時の要検証情報があるが、確定解析として固定できないため **UNVERIFIED_WEAK_DETECTION_HINT** として扱う。
- 液晶ゲーム数は設定変更でも純電断でも0Gとなるため、液晶G数単独では変更判別不可。

### numericResetData

- 設定変更時モード: **通常A55.0 / 通常B25.0 / 通常C10.0 / 天国A9.5 / 天国B0.5%**。
- 設定変更時高確以上スタート合算: **設定1/3/5 = 25.0% / 設定2/4/6 = 40.0%**。
- 内訳: 奇数 **高確12.5 / 超高確10.0 / 無限高確2.5%**、偶数 **高確20.0 / 超高確12.5 / 無限高確7.5%**。
- 天国A/B最大: **150G消化後レア役成立でAT**。
- リセット専用短縮天井: **NONE_CONFIRMED**。

### publicMorningNumbers

- 天国A/B合算: **10.0%**（全設定共通）。
- 高確以上スタート: **奇数設定25.0% / 偶数設定40.0%**。
- 超高確以上: **奇数12.5% / 偶数20.0%**。
- 無限高確: **奇数2.5% / 偶数7.5%**。
- 初日1回目の初当たり427件を用いた実戦集計記事は存在するが、解析値と混同せずDBの公開朝一数値本線には採用しない。

## conflicts

- 導入時期に実質的な競合なし。**2015-03-15は納品予定日**、**2015-03-16はホール導入開始日**として定義を分離。
- 天井恩恵について一部個人解析に「AT終了後引き戻し確定」とする記述があるが、HAZUSE・必勝本の天井記述ではAT当選を主要恩恵としており、物差しDBには追加恩恵を確定値として採用しない。
