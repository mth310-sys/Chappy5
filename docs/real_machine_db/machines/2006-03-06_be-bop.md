## netIncrease

RT「BE-BOP TIME」搭載。メーカー公式ではBIG終了後に突入し、100G消化で約60枚増加と説明されているため、100G完走時の平均増加目安から約+0.6枚/G相当。ただしこれは公式説明からの単純換算であり、DBの直接公表値としては「100Gで約60枚増加」を保持する。

信頼度: OFFICIAL

## basicPayout

メーカー公式:
- BIG: 約230枚（345枚超の払い出しで終了）
- チャレンジボーナス「ビーバップチャンス」: 約168枚（243枚超の払い出しで終了）

後年5号機クロニクルにはBIG約260枚 / REG約104枚との記載があり、公式値と定義・構成が競合するため公式値を本線に保持。

## modeSpecificMinimumData

- BIG終了後にRT「BE-BOP TIME」へ突入
- RTは100Gまたは次回ボーナス当選まで
- 公式説明では100G消化で約60枚増加
- 小役とボーナスの同時抽選を採用
