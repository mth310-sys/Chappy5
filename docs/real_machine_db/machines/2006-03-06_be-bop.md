## basicPayout

- BIG: 約230枚（345枚超の払い出しで終了）
- チャレンジボーナス「ビーバップチャンス」: 約168枚（243枚超の払い出しで終了）

## conflicts

- 導入時期: メーカー公式「発売2006年2月」に対し、ALL7のホール導入予定日は2006-03-06。本DBの時系列リレーではホール導入予定日を進捗基準として2006-03-06に配置し、公式発売月も保持する。
- 獲得枚数/ボーナス構成: メーカー公式 BIG約230枚 + チャレンジボーナス約168枚に対し、5号機クロニクルはBIG約260枚 / REG約104枚。平均化せず公式を本線としCONFLICT保持。
- RT継続G数: メーカー公式はBIG後RT「BE-BOP TIME」を **100Gまたは次回ボーナスまで** と明記する一方、5号機クロニクルは **50G** と記載。一次資料を優先して100Gをcanonicalとし、50G説はCONFLICTとして保持。
