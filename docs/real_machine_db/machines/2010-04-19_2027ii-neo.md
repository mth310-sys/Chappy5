## modeSpecificMinimumData

- BIG当選時はART突入確定。P-WORLDはART3セット以上確定と説明。
- REG後は必ず高確へ移行。K-Navi/当時グリーンべるとで確認。
- 通常時は海中系状態のほか街（高確確定）、追跡、潜航、超潜航を持つ。
- BMS（バトルモードストック）を搭載し、ARTを内部ストック可能。
- ARTは次回ボーナスまで継続し、継続率抽選ハズレかつストックなしで終了する構造。
- 当時パチマガスロマガはART継続率33〜90%と整理。後年資料には95%を含む記載もあるため、完全な全継続率テーブルは本DB用途外として固定しない。

confidence: INDUSTRY_ANALYSIS_MULTI_SOURCE
