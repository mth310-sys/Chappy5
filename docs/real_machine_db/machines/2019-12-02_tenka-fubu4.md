### settingChangeBehavior

- 設定変更後は **非有利区間へ移行**。
- **天井ゲーム数RESET**。
- **内部モード再抽選**。
- 有利区間ランプは消灯。ただし通常時も実戦上常時消灯のため、消灯だけでは変更判別不可。
- 解析表には「内部状態RESET」表記もあるが、低確/高確等の具体的な開始状態・振り分けは公開契約を固定できないため `UNVERIFIED_AFTER_RESEARCH`。
- 設定変更直後の液晶ステージは主要当時資料で調査中のまま。

信頼度: ANALYSIS_HIGH_MULTI_SOURCE / 詳細内部状態はUNVERIFIED

### carryOverBehavior

- 据え置き時は **天井ゲーム数CARRY_OVER**。
- **内部モードCARRY_OVER**。
- 有利区間ランプ状態も引継ぎとする解析。ただし通常時常時消灯型のため判別には使いにくい。
- 低確/高確等の詳細内部状態は「引継ぎ」とする一般解析表がある一方、具体状態の独立契約を固定できないため詳細は `UNVERIFIED_AFTER_RESEARCH`。

信頼度: ANALYSIS_HIGH

### powerCycleBehavior

- 純電源OFF→ONは、当時解析表で据え置きと同列に扱われ、**天井ゲーム数・内部モードをCARRY_OVER**。
- 設定変更を伴わない単純電断で有利区間を強制RESETする根拠は確認できない。
- 電断前後の具体的液晶ステージは当時主要資料で調査中のため `UNVERIFIED_AFTER_RESEARCH`。

信頼度: ANALYSIS_HIGH

### gameCounterReset

- 設定変更: **RESET**。設定変更直後は液晶G数が「???」表示となる非有利区間を経由。
- 据え置き / 純電断: **CARRY_OVER**。
- AT後は覚醒消化分などによりデータカウンターと内部/液晶ゲーム数がずれるため、天井判断は液晶表示基準とする解析。

### ceilingAfterReset

- 設定変更後の最深は通常系モードで **768G+前兆（最大803G）**。
- 天国選択時は **136G以内**、超天国選択時は **36G以内**。
- 「設定変更専用の固定短縮天井」は確認できず `NONE_CONFIRMED_AFTER_RESEARCH`。ただしリセット後のモード再抽選で天国/超天国が選ばれれば結果として浅い天井になる。

### modeAfterReset

- 設定変更で **モード再抽選**。
- 抽選契機は有利区間移行時。設定変更直後を含む非有利区間中の成立役で振り分けが変化。
- 公開された設定別振り分けは `numericResetData` に保存。
- 天国と超天国の内訳は公開表では合算で、内訳不明。

### stateAfterReset

- ちょんぼりすた等の朝一表では設定変更時「内部状態リセット」、電源OFF→ON時「引き継ぐ」。
- ただし「内部状態」がモードとは別の低確/高確等をどこまで包含するか、具体的開始状態/振り分けは固定できない。
- よってホールAI用の契約は **RESET/CARRY_OVERの方向性のみ採用**し、詳細値は `UNVERIFIED_AFTER_RESEARCH`。

### advantageousSectionReset

- 設定変更: **RESET → 非有利区間**。
- 据え置き / 純電断: **CARRY_OVER** とする解析。
- 通常時の有利区間ランプは実戦上常時消灯のタイプとされ、朝一ランプだけで設定変更を判別できない。

### resetBenefits

- リセット後は非有利区間を経由し、有利区間移行時にモードを再抽選する。
- 非有利区間中に **チェリー / 巻物 / チャンス目**を引くと天国・超天国選択率が大幅に上昇。
- 設定1ではレア役以外の天国+超天国 **19.5%** に対し、レア役時 **40.6%**。設定6では **48.0% → 75.8%**。
- この恩恵は「設定変更専用抽選」というより **非有利区間→有利区間移行時の共通契約**。朝一設定変更で必ず非有利区間を経由するため朝一行動には重要。

### resetPenalties

- 設定変更では前日までの天井ゲーム数・内部モードを失うため、深いハマリや有利なモードを据え置き狙いする観点では不利。
- それ以外の設定変更専用ペナルティは `NONE_CONFIRMED_AFTER_RESEARCH`。

### resetDetection

- 有利区間ランプは通常時も実戦上常時消灯のため、**ランプ単独では判別不可**。
- 設定変更後の1G目にガックンを確認した動画ベースの二次資料があり「おそらく有効」とされるが、メーカー/解析の確定契約ではない。したがって **`EMPIRICAL_WEAK_SIGNAL_NOT_DETERMINISTIC`** として保持。
- ガックン発生率・対策時挙動・確定条件は `PUBLIC_VALUE_NOT_FOUND_AFTER_RESEARCH`。
- 液晶G数「???」は非有利区間の表示であり、ボーナス/AT後にも発生し得るため、それだけを変更確定条件にしない。

## qualityNotes / conflicts

- メーカー表記は資料により「山佐」「セブンリーグ」「山佐（製造元セブンリーグ）」が混在。当時業界記事で **セブンリーグ製・山佐が販売/リリース** と確認できるため、manufacturerはセブンリーグ、山佐は販売・ブランドとして分離。
- 純増 **約3.0枚/G** と **約2.8枚/G** は競合ではなく、疑似ボーナスとAT「天雅ラッシュ」の区間差。
- ベースは約51G/50枚と約51.5G/50枚の表記差。後者を精密側canonical、前者を丸めと扱う。
- 天井の「768G+α」と「最大803G」は定義差（規定G到達+前兆）でありCONFLICTではない。
- ガックンは動画観察ベースの「おそらく有効」という弱い根拠のみ。確定仕様に格上げしない。
