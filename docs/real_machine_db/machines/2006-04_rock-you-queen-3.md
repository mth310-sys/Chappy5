## modeSpecificMinimumData

- 設定は1と6の2段階。
- QUEEN BIG後、または通常時RT図柄成立で最大1000GのRT「QUEEN GAME」へ突入。
- RTは1000G消化またはBIG成立で終了。
- 通常時RT突入率は業界発表で約1/1638、HAZUSEでは設定1約1/1600・設定6約1/1200の整理があり定義差/解析差として保持。
