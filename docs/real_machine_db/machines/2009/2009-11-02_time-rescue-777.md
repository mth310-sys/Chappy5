## researchSummary

- 2009-10-26同日群〜10/31を具体日付きで再監査し、安全に追加すべき未登録機を確定できなかったため11月初旬へ接続。
- 性能コアは公式/当時業界/P-WORLD/旧パチマガで高整合。機械割のみ市場掲載値と旧パチマガシミュレート値が競合するため平均せずCONFLICT。
- 50枚ベースは旧パチマガの直接値を取得でき、推定計算なし。
- v0.7では設定変更後も777G天井進捗を引き継ぐという直接解析を取得。単一資料なので信頼度を抑え、単純電源OFF→ON、既に天井RT中の設定変更、変更判別は再探索後もUNVERIFIEDとした。
