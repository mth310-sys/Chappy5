## modeSpecificMinimumData

- 通常時は通常A / 通常B / 天国の3モードを持ち、ゲーム数に応じてCZ「スカイチャンス」抽選状態が変化。
- ART「スカイラッシュ」への通常時メインルートはCZ「スカイチャンス」。SCは15G / 30G / ART当選まで継続の種別を確認。
- 天井相当の無限SC到達ゲーム数はモード別。通常Aは999G、通常Bは768G、天国は256G。最大32Gの前兆を経由する整理資料あり。
- ARTは1セット50G、約+1.7枚/G。
- 通常時の全SC抽選率や上乗せ詳細は完全再現用途のため収集対象外。

## conflicts

- payoutRateBySettingは系列A 96.9/98.7/99.9/104.2/109.3/114.3% と系列B 97.2/99.0/100.3/104.6/109.8/114.8% が競合。平均しない。
- 旧解析サイトに設定1機械割「69.9%」表記があるが、同ページの設定2〜6が系列Aと一致し、他ソースとも大幅乖離するため明白な誤記候補として採用値から除外。ただし原文存在は品質メモとして残す。
- 天井表現は「999G天井」と単純記載する回顧資料もあるが、本機のモード別解析では通常A999G / 通常B768G / 天国256G。定義を潰さずモード別値を優先保持。
