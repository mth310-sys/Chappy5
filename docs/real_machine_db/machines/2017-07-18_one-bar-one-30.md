## conflicts
- releaseDateは表面上 **2017-07-18 / 2017-07-24 / 2017年8月** が存在するが、当時ベルコ内覧会記事が「沖縄7/18・その他地域7/24」と地域差を直接説明しており、7/18と7/24はCONFLICTではない。公式現行ページの8月は月単位整理の粒度差として保持。
- ちょんぼりすた本文上部は7/18とする一方、導入日表に7/28表記がある。パチビー当時業界記事の地域別日程、HAZUSE/Pachibee機種DBの7/24、PiDEA Xの7/23納品予定と整合しないため **CONFLICT_SECONDARY_RELEASE_DATE_2017-07-28** としてcanonicalから除外。
- P-WORLD/パチビーに「天井」カテゴリ表示がある一方、具体的天井値を示さず、すろぱちくえすとは天井非搭載と明記。本DBでは具体値のないカテゴリタグを根拠にせず **NO_GAME_COUNT_CEILING** をcanonicalとする。
