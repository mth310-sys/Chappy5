- 2005年についてメーカー別5号機一覧・業界回顧を再監査し、既存9レコード以外の新たな確定漏れは発見できなかった。ただし全機種方針のため、後続QAでもメーカーアーカイブ等から新証拠が出れば遡って追加する。
- 2006年1月は美麗II以外の新たな確定導入機を今回のメーカー別一覧・当時業界資料監査では発見できなかった。はいさい潮姫・ど根性ガエルSには月境界資料差があるため既存レコードで保持。
- 2006年2月の再監査で**人造人間キカイダーK**の漏れを発見し追加。さらにBE-BOPはメーカー公式発売2006年2月とホール導入予定2006-03-06の境界差を確認し、独立レコード化した。
- 2006年3月導入予定一覧のうち、POWER BOMB・俺の空等は4号機資料で確認し5号機本線から除外。パロットも本線外。5号機としてBE-BOP、剣豪！武蔵、ゴルゴ13 ザ・プロフェッショナルJを登録済み。
