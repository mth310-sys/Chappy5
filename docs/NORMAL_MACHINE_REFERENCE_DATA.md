## 2. ノーマル機のコイン単価実例

ハナハナホウオウ～天翔～について、全国ホールデータ1週間分として掲載された参考値:

| 設定 | 解析出玉率 | ホールデータ機械割 | コイン単価 |
|---:|---:|---:|---:|
| 1 | 97% | 96.3% | 2.04円 |
| 2 | 99% | 98.2% | 1.72円 |
| 3 | 101% | 100.3% | 1.45円 |
| 4 | 103% | 102.3% | 1.20円 |
| 5 | 106% | 105.1% | 0.87円 |
| 6 | 109% | 107.7% | 0.65円 |

参考:
- スロタイガー「Sハナハナホウオウ～天翔～」
  https://slotiger-course.com/hanahana-houou/

重要な示唆:
- ノーマル機のコイン単価を全設定で固定値にするのは、現実の挙動を簡略化しすぎる可能性が高い。
- 高設定ほどボーナス・小役等で持ちメダル遊技が増え、実績コイン単価が低下する例がある。
- したがってゲーム内部では「機種固有の固定コイン単価」ではなく、少なくとも設定または実績出玉状況によって変動可能な設計を検討する。

## 3. N-01の初期仮値との比較

従来N-01仮値:

97.5 / 98.5 / 100.0 / 102.0 / 104.0 / 107.0%

実在例を見ると:
- 設定1は概ね96〜97%台の例がある。
- 設定2は98%前後。
- 設定3は99〜101%程度。
- 設定4は101〜104%程度。
- 設定5は104〜107%程度。
- 設定6は109〜112%程度の例が確認できる。

したがって従来N-01は低〜中設定は現実例の範囲に近いが、設定6の107%は「標準的なノーマル機」を想定するならやや低め。

## 4. N-01 v0.2 調整候補（未採用）

実在機をコピーせず、標準的な架空ノーマル機として中間的に置く候補:

| 設定 | 理論出玉率候補 |
|---:|---:|
| 1 | 97.0% |
| 2 | 98.2% |
| 3 | 99.8% |
| 4 | 102.2% |
| 5 | 105.0% |
| 6 | 109.5% |

これはゲーム採用確定値ではない。

設定差の見せ方については、ノーマル機では単に出玉率だけを変えるのではなく、BB/RB/小役等の確率差を内部性能として持たせ、営業結果に自然なブレを発生させる方式を検討する。

## 5. フル稼働売上モデルへの修正提案

従来の検証ではN-01を「20,000アウト × コイン単価2.00円 = 40,000円」と置いた。

しかし実在ホールデータでは同一ノーマル機でも設定によりコイン単価が大きく変化する例があるため、最終モデルでは:

`実アウト × 当日の実績コイン単価 = 台売上`

とし、実績コイン単価を
- 機種のベース特性
- 設定
- ボーナス/小役結果
- 持ちメダル遊技状況

等から変動させる方向が現実に近い。

ゲームとして重すぎる場合は、機種ごとに「設定別基準コイン単価」を持ち、日次乱数で微調整する簡略モデルも候補とする。

## 6. 現段階の結論

N-01を作る際に最低限分離すべき性能:

1. 設定別理論出玉率
2. 設定別ボーナス確率（ノーマル機の場合）
3. 基準コイン単価（固定ではなく変動可能にする）
4. 最大/基準アウト
5. 当日の実アウト
6. 当日の実績出玉率
7. 当日の実績コイン単価
8. 売上・粗利・客側差枚

これにより「同じ設定1でも毎日同じ利益」「設定6なら必ず赤字」という単純なゲーム化を避けられる。
