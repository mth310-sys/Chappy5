# Game Systems Finding GS-010 — one-step adaptive benchmark undervalues resonance chain carryover

- `director`: Game Systems Analysis Director
- `status`: INVESTIGATE_BEFORE_SYSTEMS_CLEARANCE
- `severity`: 4
- `confidence`: MEDIUM-HIGH
- `verification`: SIMULATED
- `finding`: The existing state-conditioned benchmark that supported current route-role health is a one-step visible-value policy. That benchmark values the immediate survive-then-extract outcome well, but it does not fully price the future option value created by an active resonance chain. A simple fixed-resonance policy with its own one-step extraction rule outperformed that adaptive benchmark in repeated Monte Carlo runs, so the earlier conclusion that there is no meaningful universal-route exploit is not yet robust enough.
- `evidence`: A new simulator reproduced current `game.js` route generation, costs, gains, anomaly bonus, cumulative threat, calm recovery, resonance chain growth, collapse, partial-payment Energy and forced extraction. For each policy, voluntary extraction occurred when that policy's selected route had no greater one-step survive-then-extract expected value than extracting immediately. In a 100,000-run comparison using seed 123, the existing-style adaptive best-one-step policy produced mean permanent bank ≈10.95/run, mean ending depth ≈2.86, collapse ≈53.48%, voluntary extraction ≈40.65%, forced extraction ≈5.87%. A fixed `always choose resonance when continuing` policy produced mean permanent bank ≈12.13/run, mean ending depth ≈3.19, collapse ≈46.52%, voluntary extraction ≈44.23%, forced extraction ≈9.25%. That is roughly +10.8% mean permanent bank with materially lower collapse. Three additional 50,000-run seed checks reproduced the direction: adaptive ≈10.88/10.93/10.92 bank versus resonance ≈12.13/12.10/12.03, with resonance collapse ≈46.6/46.5/46.8% versus adaptive ≈53.7/53.4/53.5%.
- `impact`: This does not prove that always-resonance is globally optimal, because both policies still use a one-step stopping rule rather than an exact dynamic-programming optimum. It does prove that the current benchmark can rank a fixed route policy below a supposedly adaptive policy even when the fixed policy earns substantially more. The likely cause is that resonance's payoff is stateful: establishing and preserving a chain increases later route value, while the one-step selector mainly prices the current card. If this survives a stronger multi-step policy comparison, the core three-choice system still contains a fixed-strategy pressure and should not be considered Systems-cleared solely from aggregate route-share diversity.
- `recommended_action`: Do not patch the frozen `HUMAN_CANDIDATE_01` from this result alone. Before the next Executive treats the core economy as AI-cleared, run a stronger policy comparison that explicitly values future chain state: at minimum compare fixed resonance, fixed calm, fixed deep, current one-step adaptive, and a short-horizon rollout/DP approximation under the same extraction rule. If fixed resonance remains materially superior after future-state value is priced correctly, Executive should revisit resonance chain reward/persistence rather than globally buffing or nerfing all routes. Human play can still proceed for feel, but its result should not be interpreted as evidence that the strategic economy lacks a fixed optimum.
- `human_verification_needed`: NO for the benchmark weakness and simulated performance gap; YES later for whether players discover or enjoy any resonance-heavy strategy.
- `last_updated`: 2026-08-26

## Systems handoff

This finding changes the confidence level of the prior state-role conclusion without invalidating the observed role mechanics themselves. Deep can still be strongest early, calm can still be rational at high threat, and resonance can still gain value with an active chain. The new issue is that a one-step policy is not a sufficient optimality test for a stateful chain mechanic. Executive should therefore keep the current human candidate stable, but treat `GS-010` as an AI-resolvable strategic-balance question that remains open.
