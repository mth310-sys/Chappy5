# ゲームセンター倶楽部 参考規格メモ

この文書は『スロットパチ朗』の Stage 1–3 における視覚・配置基盤の参考規格。カイロソフト固有素材・コード・UIを複製せず、公開されているゲーム画面と公式説明から、箱庭経営SLGとしての空間設計原理を抽出して本作へ翻訳する。

## 確認できる原則

- DX版はゲーム機の自由配置と4方向配置を持つ。
- 店内は小さい論理グリッドの集合として読め、ゲーム機・通路・壁・客が同じ縮尺体系に入る。
- 配置は見た目だけでなく、専門コーナー発見、人気、料金、来客など経営値へ接続される。
- 大型設備も接地セルと向きが明確で、通路は設備間の残余空間ではなく利用導線として読める。
- 背面側の壁は空間を示し、手前側は箱庭の内部を隠し過ぎない読みやすさが優先される。

## 本作へ落とし込む視覚規格

### 1. 基準セル
- 画面投影は約 2:1 の菱形。
- 1セルは『部屋そのもの』ではなく、設備・客・通路を高密度に載せる最小単位として小さく見せる。
- Cell Lab では床菱形を 144×64px 相当へ縮小し、従来の 168×88px より密度を上げる。

### 2. 壁
- 背面 N/E 壁の立ち上がりは床1セル奥行きより小さくし、床面を主役にする。
- 前面 S/W はさらに低くしてカットアウェイ性を確保する。
- 壁厚は数pxの明暗帯で表し、滑らかな立体表現よりブロック状の読みやすさを優先する。
- ドア・窓・仕切りは壁エッジから独立させず、必ず同一セル辺に従属させる。

### 3. 設備
- 1セル設備は床菱形の中央〜60%以内を基本占有率とする。
- 2セル以上の設備は単純拡大ではなく footprint を増やして表現する。
- 向きは N/E/S/W の論理方向から描画へ変換し、任意CSS座標をゲーム状態にしない。

### 4. キャラクターとの将来比率
- キャラクターは1セルを完全に埋めない。
- 壁高 > キャラ身長 > 低設備、ただし前面壁はキャラ・設備を隠さないカットアウェイ表現にする。
- 客の立ち位置は施設 access port / service port にスナップする。

### 5. 情報密度
- カイロ系の読みやすさは『大きいオブジェクト』ではなく、小さいセルに設備・人物・床種・効果を重ねても識別できることから生まれる。
- 本作ではアンチエイリアス前提の滑らかな巨大CSS面を避け、2–4px単位の縁・ハイライト・影で面を分ける。

## Cell Lab の合格条件

1. 床が約2:1の共通投影で固定される。
2. N/E/S/W の壁下端が床四辺と一致する。
3. N/E 背面壁より S/W 前面壁が低く、内部が読める。
4. door/window/divider の種類変更で接地辺が動かない。
5. 床家具はセル中心基準でスナップし、セル外へ逃げない。
6. 壁家具は選択した壁面に従属する。
7. iPhone 12でプレビュー・操作UI・状態表示が欠けない。
8. 1セルを複製した時、同じ投影ピッチで隣接できる。

## 次段階

この規格を単一セルで固定した後、2×2→4×4の小区画へ拡張し、通路・入口・設備 footprint と描画順を確認する。ホール全体への展開はその後に行う。
