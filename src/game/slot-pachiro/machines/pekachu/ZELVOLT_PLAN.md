# ZELVOLT（ゼルヴォルト）リニューアル計画

## 位置づけ

現行 `ペカチュウ Ver.0.6.2` を原型として、名称・筐体・演出・内部構造を刷新する次世代機。

- 開発名称 / 正式名称候補: **ZELVOLT**
- 読み: **ゼルヴォルト**
- 原型: ペカチュウ Ver.0.6.2
- 現行ペカチュウは動作基準として保持し、段階的にZELVOLTへ更新する
- パチ朗ホールでは現在 `I01-L01` の1台のみが原型機と接続済み

## 確定しているゲーム性

ZELVOLTは **技術介入なしのノーマルタイプ** とする。

### 入れないもの

- AT / ART
- CZ
- ストック放出
- 天井
- 内部連チャンモード
- ボーナス後の優遇状態
- 押し順
- 目押しによる獲得差
- 取りこぼしによる技術介入

### 基本思想

- 毎ゲーム独立抽選
- ボーナスそのものの獲得性能を大きくする
- BIGが短期間に重なった場合の爆発力は、内部モードではなく純粋な抽選の偏りで発生させる
- 低設定でも短期的な一撃は起こり得る
- 長期では設定差が結果へ反映される設計を目指す

コンセプト:

> **ノーマルタイプの構造を維持したまま、一撃性を持つ大量獲得型。**

## 暫定スペック v0.6

### ボーナス獲得枚数

- BIG: **純増600枚**
- REG: **純増120枚**
- 通常時: 3枚掛け
- BIG / REG終了後は即通常状態へ戻る
- ボーナス後の確率優遇・内部高確率状態は存在しない

「純増」はボーナス消化中の投入を差し引いた後にプレイヤーの手持ちが増える枚数を指す。

### ボーナス消化ゲーム数

- BIG: **約42Gで純増600枚**
- REG: **約14Gで純増120枚**
- ボーナス中もゲーム進行を持つ
- ボーナス中の内部投入は3枚/Gを基準として機械割計算に含める
- 純増枚数はボーナス中の投入を差し引いた最終差枚として固定する

### 既存図柄の継承

現行ペカチュウの7図柄をZELVOLTでも再利用する。内部の図柄ID / 役割は継承し、ビジュアルはZELVOLT用に順次リニューアルする。

| 図柄 | ZELVOLTでの役割 |
|---|---|
| 赤7 | BIG |
| 白紫7 | BIG別図柄 |
| BAR | REG |
| ベル | 通常小役 |
| ブドウ | 通常小役 |
| チェリー | 通常小役 |
| STAR | レア小役 |

- 赤7 / 白紫7のどちらでもBIG性能は同じ純増600枚
- 白紫7は上位モードや性能差を持たせず、演出・見た目上の特別感を担当する
- BARはREG純増120枚
- STARは独立したレア小役とし、成立時に雷フラッシュ等の演出起点として利用可能
- STAR成立後の高確率状態やボーナス優遇は設けない

BIG成立時の図柄振り分けは当面 **赤7 80% / 白紫7 20%** を基準案とする。性能差はない。

### 通常時小役・リプレイ v0.2

BIG / REGの性能と確率を維持したまま設定1を100%未満へ落とすため、小役側を調整する。小役確率は全設定共通。

| 役 | 確率 | 払い出し |
|---|---:|---:|
| リプレイ | 約1/7.3 | 再遊技 |
| ベル | **1/60** | 10枚 |
| ブドウ | **1/50** | 8枚 |
| チェリー | **1/80** | 2枚 |
| STAR | **1/150** | 15枚 |
| その他 | 残り | 0枚 |

調整前はベル1/45、ブドウ1/32、チェリー1/80、STAR1/120だった。チェリーは維持し、ベル・ブドウ・STARを重くすることでZELVOLTの「回らないが当たれば大きい」を強める。

通常時の小役期待払出は約 **0.452枚/G**。リプレイを投入不要の再遊技として扱った実質投入期待値は約 **2.589枚/G**。通常時の期待減少は約 **2.137枚/G**で、単純な50枚ベースは約 **23.4G/50枚**。

## 出玉設計の狙い

- BIG 1回で純増600枚を獲得する大量獲得型
- BIG 3回が短期間に重なれば約1,800枚、5回なら約3,000枚、8回なら約4,800枚規模
- 連チャンは内部モードではなく完全に独立抽選の偏りで発生する
- 設定1でも短期的な爆発が可能
- 設定5・6は意図的に強い領域とする
- 特に設定6はホール経営上の「祭り用 / 強力な設定」として扱える性能を許容する
- 通常時は約23.4G/50枚を基準とし、コイン持ちの悪さとBIG600枚の落差を機種個性にする

## 機械割再計算 v0.2

### 計算前提

- 通常時3枚掛け
- リプレイは再遊技として実質投入0枚相当
- BIG / REG / リプレイ / 各小役は1ゲームにつき排他的に1役を抽選
- BIGは42G、REGは14G
- ボーナス中は3枚/Gを投入として計上
- BIG区間は最終差枚+600枚、REG区間は最終差枚+120枚
- ボーナス中に追加ボーナス抽選なし
- ボーナス終了後は即通常

|---|---:|---:|
| 1 | **約97.9%** | **-0.06枚/G** |
| 2 | **約102.5%** | **+0.07枚/G** |
| 3 | **約107.6%** | **+0.20枚/G** |
| 4 | **約113.5%** | **+0.36枚/G** |
| 5 | **約120.1%** | **+0.54枚/G** |
| 6 | **約134.8%** | **+0.93枚/G** |

設定1を100%未満へ落としながら、設定6は別格という従来の方向性を維持できる。設定2からプレイヤー側の長期期待値がプラスになるため、パチ朗では設定1を通常営業の利益設定、設定2以上を還元・集客側へ寄せた設定として扱える。

### 評価

- **設定1でも8,000Gで+5,000枚以上が約2.9%**発生するため、低設定でも「純粋なヒキで噴く」というコンセプトは残っている。
- 設定1の8,000G勝率は約42%で、平均差枚は約-482枚。通常営業の利益設定として機能しつつ、見た目上は十分に荒れる。
- 設定2はほぼ五分からややプレイヤー有利、設定3以降は明確に還元側。
- 設定6は8,000Gで+5,000枚以上が約77%となり、意図した「祭り設定」として非常に強い。
- 全設定で標準偏差が約2,800〜3,100枚あり、設定差とは別に抽選の偏りによるブレが大きい。

この結果から、現行の小役v0.2はZELVOLTの狙いである **低設定でも爆発可能 / 高設定ほど急激に強い / 設定6は別格** を満たしているため、現段階では再調整せず基準スペックとして維持する。

## ビジュアル刷新方針

旧ペカチュウの外観をそのまま名称変更するのではなく、ZELVOLTとして筐体をフルリニューアルする。

継承候補:

- 黄 × 黒を基調とした配色
- 雷 / 電撃モチーフ
- 発光告知を機種の象徴にする
- 赤いSTOPボタンとLEDリング

刷新対象:

- ZELVOLTロゴ
- 上部ユニット
- リール窓
- 告知ランプ
- 側面LED
- 操作パネル
- CREDIT / PAY表示
- 下パネル
- BONUS時の筐体発光

旧名称・既存キャラクターIPを連想させる意匠には依存せず、独立した雷系パチスロ機として設計する。

## 技術刷新方針

ゲーム性はシンプルなノーマルタイプのまま、実装は今後の機種へ流用可能な構造へ段階的に整理する。

想定モジュール:

- state: CREDIT、BET、ゲーム数、ボーナス履歴等
- lottery: 毎ゲームの独立抽選
- reel: リール進行・停止制御
- effects: 告知、雷、LED、フラッシュ等
- audio: SE / BGM
- ui: 筐体表示・操作UI
- bridge: パチ朗ホールとの状態同期

一括リライトはせず、現行の動作を基準に1機能ずつ移行する。

## パチ朗連携

現在のホール側接続経路:

`ホール → I01-L01に着席 → 実機画面を直接起動 → ホールへ戻る`

中間の簡易リール画面は使用しない。

将来的にホールへ同期する主な値:

- CREDIT / 所持メダル
- 総ゲーム数
- BIG回数
- REG回数
- 差枚
- 設定
- ボーナス履歴
- 現在の遊技状態
