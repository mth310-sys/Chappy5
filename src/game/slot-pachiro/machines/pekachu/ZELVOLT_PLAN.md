# ZELVOLT（ゼルヴォルト）リニューアル計画

## 位置づけ

現行 `ペカチュウ Ver.0.6.2` を原型として、名称・筐体・演出・内部構造を刷新する次世代機。

- 開発名称 / 正式名称候補: **ZELVOLT**
- 読み: **ゼルヴォルト**
- 原型: ペカチュウ Ver.0.6.2
- 現行ペカチュウは動作基準として保持し、段階的にZELVOLTへ更新する
- パチ朗ホールでは現在 `I01-L01` の1台のみが原型機と接続済み

## 確定しているゲーム性

ZELVOLTは **技術介入なしのノーマルタイプ** とする。

### 入れないもの

- AT / ART
- CZ
- ストック放出
- 天井
- 内部連チャンモード
- ボーナス後の優遇状態
- 押し順
- 目押しによる獲得差
- 取りこぼしによる技術介入

### 基本思想

- 毎ゲーム独立抽選
- ボーナスそのものの獲得性能を大きくする
- BIGが短期間に重なった場合の爆発力は、内部モードではなく純粋な抽選の偏りで発生させる
- 低設定でも短期的な一撃は起こり得る
- 長期では設定差が結果へ反映される設計を目指す

コンセプト:

> **ノーマルタイプの構造を維持したまま、一撃性を持つ大量獲得型。**

## 暫定スペック v0.2

現時点では以下をZELVOLTのスペック基準として採用する。

### ボーナス獲得枚数

- BIG: **600枚**
- REG: **120枚**
- 通常時: 3枚掛け
- BIG / REG終了後は即通常状態へ戻る
- ボーナス後の確率優遇・内部高確率状態は存在しない

### 設定別ボーナス確率

| 設定 | BIG | REG | 合算（概算） |
|---|---:|---:|---:|
| 1 | 1/330 | 1/470 | 約1/194 |
| 2 | 1/310 | 1/430 | 約1/180 |
| 3 | 1/290 | 1/390 | 約1/166 |
| 4 | 1/270 | 1/350 | 約1/152 |
| 5 | 1/250 | 1/310 | 約1/138 |
| 6 | 1/210 | 1/270 | 約1/118 |

### 既存図柄の継承

現行ペカチュウの7図柄をZELVOLTでも再利用する。内部の図柄ID / 役割は継承し、ビジュアルはZELVOLT用に順次リニューアルする。

| 図柄 | ZELVOLTでの役割 |
|---|---|
| 赤7 | BIG |
| 白紫7 | BIG別図柄 |
| BAR | REG |
| ベル | 通常小役 |
| ブドウ | 通常小役 |
| チェリー | 通常小役 |
| STAR | レア小役 |

- 赤7 / 白紫7のどちらでもBIG性能は同じ600枚
- 白紫7は上位モードや性能差を持たせず、演出・見た目上の特別感を担当する
- BARはREG 120枚
- STARは独立したレア小役とし、成立時に雷フラッシュ等の演出起点として利用可能
- STAR成立後の高確率状態やボーナス優遇は設けない

BIG成立時の図柄振り分けは当面 **赤7 80% / 白紫7 20%** を基準案とする。性能差はない。

### 通常時小役・リプレイ

全設定共通とし、小役確率による設定判別要素は持たせない。

| 役 | 確率 | 払い出し |
|---|---:|---:|
| リプレイ | 約1/7.3 | 再遊技 |
| ベル | 1/45 | 10枚 |
| ブドウ | 1/32 | 8枚 |
| チェリー | 1/80 | 2枚 |
| STAR | 1/120 | 15枚 |
| その他 | 残り | 0枚 |

この小役構成の通常時ベースは、単純期待値計算で **50枚あたり約25.4G**。

計算上の1Gあたり小役期待払出は約0.622枚。リプレイを投入不要の再遊技として扱うと、1Gあたり実質投入期待値は約2.589枚、通常時の期待減少は約1.967枚/Gとなる。

## 出玉設計の狙い

- BIG 1回で600枚を獲得する大量獲得型
- BIG 3回が短期間に重なれば約1,800枚、5回なら約3,000枚、8回なら約4,800枚規模
- 連チャンは内部モードではなく完全に独立抽選の偏りで発生する
- 設定1でも短期的な爆発が可能
- 設定5・6は意図的に強い領域とする
- 特に設定6はホール経営上の「祭り用 / 強力な設定」として扱える性能を許容する
- 通常時はコイン持ちを軽くしすぎず、「回らないが当たれば大きい」という性格を明確にする

## 機械割について

BIG 600枚 / REG 120枚をそのまま通常ゲーム1回あたりの期待払出へ加算し、リプレイ時は3枚投入が不要、小役確率は上記で全設定共通、という **簡略モデル** で再計算すると以下になる。

| 設定 | 簡略モデル上の概算機械割 |
|---|---:|
| 1 | 約104.1% |
| 2 | 約109.6% |
| 3 | 約115.8% |
| 4 | 約123.1% |
| 5 | 約131.7% |
| 6 | 約151.6% |

この結果では設定1から100%を超える。したがって、この数値を最終的な実機仕様上の機械割として確定しない。

理由は、現在の「BIG 600枚 / REG 120枚」が **純増枚数なのか総払出枚数なのか**、またボーナス消化中に何ゲーム・何枚投入するのかが未定だからである。正式な機械割はボーナス中の消化仕様まで確定した後に再算出する。

現時点では以下の設計思想を維持する。

- 上位設定ほど急激に強くする
- 設定6は別格の祭り設定を許容する
- ただし設定1が長期で恒常的に100%超となるかは、ボーナス消化仕様を決めて最終判断する

## ビジュアル刷新方針

旧ペカチュウの外観をそのまま名称変更するのではなく、ZELVOLTとして筐体をフルリニューアルする。

継承候補:

- 黄 × 黒を基調とした配色
- 雷 / 電撃モチーフ
- 発光告知を機種の象徴にする
- 赤いSTOPボタンとLEDリング

刷新対象:

- ZELVOLTロゴ
- 上部ユニット
- リール窓
- 告知ランプ
- 側面LED
- 操作パネル
- CREDIT / PAY表示
- 下パネル
- BONUS時の筐体発光

旧名称・既存キャラクターIPを連想させる意匠には依存せず、独立した雷系パチスロ機として設計する。

## 技術刷新方針

ゲーム性はシンプルなノーマルタイプのまま、実装は今後の機種へ流用可能な構造へ段階的に整理する。

想定モジュール:

- state: CREDIT、BET、ゲーム数、ボーナス履歴等
- lottery: 毎ゲームの独立抽選
- reel: リール進行・停止制御
- effects: 告知、雷、LED、フラッシュ等
- audio: SE / BGM
- ui: 筐体表示・操作UI
- bridge: パチ朗ホールとの状態同期

一括リライトはせず、現行の動作を基準に1機能ずつ移行する。

## パチ朗連携

現在のホール側接続経路:

`ホール → I01-L01に着席 → 実機画面を直接起動 → ホールへ戻る`

中間の簡易リール画面は使用しない。

将来的にホールへ同期する主な値:

- CREDIT / 所持メダル
- 総ゲーム数
- BIG回数
- REG回数
- 差枚
- 設定
- ボーナス履歴
- 現在の遊技状態

## 名称確認メモ

`ZELVOLT / ゼルヴォルト` を正式名称候補として採用。

ユーザー確認ではJ-PlatPatの `ZELVOLT` 商標（検索用）完全一致は0件で、類似検索についても問題は見当たらないとの確認。ただし、これは法的な非侵害保証ではない。販売・商標出願など正式な商用段階では必要に応じて再調査する。
