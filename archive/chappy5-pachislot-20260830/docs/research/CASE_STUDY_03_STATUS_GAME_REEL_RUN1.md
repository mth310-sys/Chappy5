## What this run established

- Case Study 02 新ハナビ is closed; Case Study 03 is the current shared object.
- Real machine only. Smartphone-app study remains deferred to Phase B.
- Published machine structure was reconstructed as A+ART with real BIG and persistent ART sharing the same physical lever/reels/STOP controls.
- Published normal procedure uses a BAR landmark on the left reel, with intermittent cherry/watermelon precision branches; ART navigation changes the player's STOP responsibility without changing the physical control map.
- A single right-upward valid line is published.
- The visible rare-role result is not the whole internal event: simultaneous BONUS, hidden-state edits, CZ entry/direct ART and state-relative reward value can continue after the reel result.
- The same role vocabulary is repriced across normal / hidden state / CZ / BONUS / ART / extension / ART-end preparation.
- BONUS during persistent ART can reinforce the current ART contract rather than merely interrupt it.
- Setting inference is multi-channel: weak-role frequency, selected BONUS combinations, direct ART behavior and other documented samples.
- No undisclosed stop-control table was invented and no protected reel artwork was copied.

## Key principles handed forward

- `THE SAME REEL EVENT CAN BECOME A DIFFERENT GAME RESOURCE IN DIFFERENT STATES.`
- `ROLE IDENTITY MAY BE STABLE WHILE ROLE VALUE IS STATE-RELATIVE.`
- `AIMING DUTY SHOULD SPIKE WHEN A ROLE OR STATE REQUIRES IT; IT DOES NOT NEED TO BE MAXIMUM EVERY GAME.`
- `STOP RESPONSIBILITY CAN SHIFT WITHOUT MOVING THE PLAYER'S BODY MAP.`
- `A+ART REELS CONNECT PARALLEL REWARD ECONOMIES: IMMEDIATE BONUS VALUE AND PERSISTENT ART VALUE.`
- `REEL DEPTH DOES NOT HAVE TO MEAN REACH-EYE DENSITY. IT CAN ALSO COME FROM STATE-RELATIVE CONSEQUENCE.`
