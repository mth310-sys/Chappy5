## Latest completed work

`VISUAL_MECHANISM_SELF_STUDY = COMPLETE_RUN3`

Research:
`docs/research/SELF_STUDY_VISUAL_MECHANISM_RUN3_PERCEPTUAL_PERSISTENCE_UNDER_TOUCH_AND_INTERRUPTION.md`

Question: what visual/physical anchors must remain stable so finger occlusion, viewport disturbance and interruption/resume do not make a learned pachislot scene collapse into ordinary mobile UI?

Key change: replace a rigid “keep the screen identical” model with **relational persistence**. Touch occlusion, visual-search interruption and object-continuity evidence support treating controls and machine layers as persistent objects whose spatial roles should survive temporary obstruction and re-entry. Real-machine Case Study 02 already demonstrates a stable reel / information / operation-deck map across changing player duty.

Main principles:
- `TOUCH SHOULD OCCLUDE A CONTROL MORE OFTEN THAN IT REDEFINES THE CONTROL'S LOCATION.`
- `PERSISTENCE IS RELATIONAL, NOT PIXEL-IDENTICAL.`
- `THE PRIMARY REEL / INFORMATION / CONTROL ORDER SHOULD SURVIVE INTERRUPTION.`
- `RE-ENTRY SHOULD FIRST RESTORE THE MACHINE MAP, NOT OPEN A NEW TUTORIAL LAYER.`
- `STABLE PHYSICAL LANDMARKS CAN FUNCTION AS RETRIEVAL CONTEXT.`
- `A CONTROL THAT DETACHES INTO MOBILE-UI SPACE RISKS LOSING MACHINE OWNERSHIP.`
- `VIEWPORT ADAPTATION SHOULD PRESERVE SCENE-GRAPH ORDER EVEN WHEN SCALE OR CROP MUST CHANGE.`
- `TEMPORARY FINGER OCCLUSION IS NOT THE SAME AS VISUAL DISAPPEARANCE.`
- `STATE CHANGE MAY REALLOCATE ATTENTION WITHOUT RELOCATING THE PLAYER'S BODY MAP.`
- `RETURNING TO THE SAME MACHINE SHOULD REQUIRE RECOGNITION BEFORE RE-LEARNING.`
