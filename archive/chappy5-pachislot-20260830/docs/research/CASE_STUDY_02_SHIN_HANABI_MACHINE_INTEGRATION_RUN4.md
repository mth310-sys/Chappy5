# 1. Re-confirmed machine identity and inheritance

## SOURCED FACT

Universal's 2021 official app release describes 新ハナビ as a July 2021 machine whose bonus-driven game flow fully inherits the 5th-generation ハナビ, while retaining JAC-IN avoidance in 花火チャレンジ and changing reel arrangement / blackout laws.

Source:
- Universal Entertainment, 2021-07-29: https://www.universal-777.co.jp/news/20210729001510/

Major machine/strategy references document the reward loop as:

- BIG maximum 202枚
- REG maximum 112枚

- JAC-IN avoidance can extend 花火チャレンジ
- JAC IN → 花火GAME, 20G

- 花火GAME approximately +0.6枚/G

## INTERPRETATION

The lineage is preserved primarily as a repeated contract rather than a frozen surface:

`ordinary aiming / reading → discovered bonus → bonus execution → RT responsibility change → return to the same physical reel grammar`

The machine modernizes branches, skill tiers and presentation while leaving physical reel stopping as the repeated center.

## REUSABLE PRINCIPLE

`LINEAGE CONTINUITY IS STRONGEST WHEN THE REPEATED PLAYER CONTRACT SURVIVES, NOT WHEN PROTECTED SURFACE DETAILS ARE COPIED.`

# 2. Run 4 synthesis: RETURN QUALITY is part of state quality

Machine Run 3 established:

`ATTENTION IS A STATE VARIABLE.`

Run 4 specialist work reveals the missing second half: attention state is not complete when the special cue/task merely stops. The player must recover the ordinary contract.

Visual Run 4:
- temporary information should have a short gaze-return path to the reel precision surface;
- the normal view should be easy to find again;
- state change can preserve the player's spatial map.

Sound Run 4:
- audio claims need a short semantic return path;
- ordinary reel/STOP listening should become recognizable again;
- `CLAIM → RESOLVE → RELEASE → RE-ANCHOR` is stronger than simple escalation/release.

Playtest Run 4:
- `RETURN IS A TASK SWITCH, NOT AN EMPTY GAP`;
- novice onboarding must teach the home state, not only exceptions;
- `RE-ANCHOR COST` can be measured behaviorally;
- reward afterglow must not contaminate base-loop evaluation.

## NEW MACHINE MODEL

`HOME → CLAIM → TEMPORARY RESPONSIBILITY → RESOLUTION → RELEASE → RE-ANCHOR → HOME`

The important addition is `RE-ANCHOR`.

A special event can be perfectly legible while active and still be poor repeated-play design if the player must reconstruct what ordinary play means afterward.

## REUSABLE PRINCIPLES

`RETURN QUALITY IS PART OF STATE QUALITY.`

`A STATE IS NOT FULLY ENDED UNTIL ORDINARY PLAYER RESPONSIBILITY IS RECOVERED.`

`SPECIAL-STATE QUALITY = ENTRY CLARITY + ACTIVE DUTY CLARITY + EXIT CLARITY + RE-ANCHOR QUALITY.`

# 3. The HOME STATE is an active machine asset

## INTERPRETATION

Run 4 makes the ordinary state more precise. `HOME` is not simply "no bonus / no RT / no effect." It is a learned multi-modal contract consisting of:

- stable reel location and readable aperture;
- stable lever / BET / STOP motor map;
- safe ordinary aiming routine;
- expected baseline operation sound/timing;
- visual surfaces that are allowed to remain quiet;
- known conditions that open additional responsibility;
- known conditions that close it again.

This explains why experienced play can become faster and less cognitively expensive without becoming less deep.

## REUSABLE PRINCIPLES

`THE HOME STATE IS A LEARNED SENSORIMOTOR CONTRACT.`

`A DEEP MACHINE NEEDS A HOME STATE STRONG ENOUGH TO RETURN TO.`

`MASTERING A MACHINE INCLUDES MASTERING ITS RETURNS, NOT ONLY ITS EXCEPTIONS.`

# 4. Physical layout, sound and rules cooperate to reduce re-orientation cost

## DIRECT OBSERVATION / SHARED RESEARCH

Visual Run 4 observes a compact central stack in real-unit photography: recessed physical reels, immediately adjacent information band, projecting operation deck and fixed horizontal STOP row. It also observes dark framing regions and peripheral illumination that can provide identity without invading the exact reel-reading interior.

The observation is structural only. Exact dimensions, materials, luminance and speaker topology remain unresolved.

## INTERPRETATION

The physical cabinet can lower cognitive switching cost because the meaning of surfaces changes more often than their location.

- the reel chamber remains where precision is performed;
- temporary information appears close to the reel task;
- the hand returns to the same STOP map;
- RT changes stop-order/aim responsibility without relocating controls;
- audio can signal a temporary rule and then restore the familiar baseline;
- quiet/dark regions create perceptual reserve rather than competing continuously.

## REUSABLE PRINCIPLES

`PRESERVE THE SPATIAL MAP WHEN TEMPORARY PRECISION DEMANDS INCREASE.`

`INFORMATION ARCHITECTURE SHOULD REDUCE RE-ORIENTATION COST, NOT MERELY REDUCE SCREEN CLUTTER.`

`PHYSICAL STABILITY CAN SUPPORT SEMANTIC VARIABILITY.`

# 5. Session memory without an upper-state ladder

## SOURCED FACT

Sound Run 4 records published BIG music conditions tied not only to the current BIG but to recent RT/bonus continuity, cumulative payout and short game-history boundaries. This means audio context can acknowledge recent session history without creating a CZ→AT→upper-state progression.

Repository source:
- `docs/research/CASE_STUDY_02_SHIN_HANABI_SOUND_EXPERIENCE_RUN4.md`

## INTERPRETATION

This provides another form of long-session continuity:

`CURRENT EVENT + RECENT HISTORY → DIFFERENT CONTEXTUAL MEANING`

The player's recent session can matter to presentation even though the gameplay state ladder remains shallow.

This is important because it separates two ideas that should not be conflated:

- vertical reward-state escalation;
- continuity / memory across repeated ordinary and reward cycles.

## REUSABLE PRINCIPLES

`SESSION CONTINUITY DOES NOT REQUIRE AN UPPER-STATE LADDER.`

`MEMORY CAN DEEPEN REPEAT VALUE WITHOUT ADDING A NEW PLAYER OBLIGATION.`

The second principle is bounded by Playtest Run 4's `PHANTOM DUTY CHECK`: history-linked feedback fails if players infer a hidden task or state that does not actually exist.

# 6. Skill failure: recovery is a system property

## SOURCED FACT

Published 新ハナビ references document difficulty-dependent REG procedures and a material relationship between technical execution and return. Published setting-1 references also differ substantially between nominal play and complete-strategy assumptions.

Sources:
- https://kenslo65536.com/kaiseki/hanabi-new.html
- https://www.pachibee.jp/machines/about/221050000

Field evidence in Playtest Run 4 includes a long session in which repeated REG misses led the player to deliberately slow play because those misses had economic cost. This is field evidence, not universal behavior.

Repository source:
- `docs/research/CASE_STUDY_02_SHIN_HANABI_PLAYTEST_QA_RUN4.md`

## INTERPRETATION

When skill changes economic outcome, the machine creates a feedback loop beyond simple success celebration:

`attempt → result → attribution → pace/confidence change → next attempt`

A technically demanding machine can remain sustainable only if a miss does not permanently raise global vigilance or destroy ordinary rhythm.

## REUSABLE PRINCIPLES

`SKILL SYSTEM QUALITY INCLUDES POST-MISS RECOVERY DYNAMICS.`

`A LOCAL EXECUTION FAILURE SHOULD NOT FORCE GLOBAL DEFENSIVE PLAY.`

`WHEN FAILURE ALREADY COSTS VALUE, PRESENTATION SHOULD CLARIFY BEFORE IT PUNISHES.`

# 7. 100G / 500G / 3-hour model — Run 4 update

## 100G — re-anchor frequency matters

Run 3 focused on question density. Run 4 adds the number and cost of context rebuilds.

A meaningful cue is not free. Each one may require:

`notice → classify → act/read → resolve → return`

Therefore normal-play quality depends not only on cue frequency but on how cheaply the player returns to home state.

### Machine metric

`REPEATED-PLAY COST ≈ REQUIRED DUTY + FALSE VIGILANCE + RE-ANCHOR COST`

This is an interpretation/model, not a measured 新ハナビ formula.

## 500G drought — competence is not enjoyment

Long field reports document 500G+ first-BIG and near-900G BIG-interval examples while players continued sampling small roles and executing strategy. These reports demonstrate that competent/rational continuation can coexist with long reward absence; they do not prove intrinsic enjoyment throughout the drought.

Machine judgement must continue to separate:
- reel curiosity;
- setting/economic reason;
- technical self-improvement;
- sunk-cost / relief motive;
- simple discipline.

### REUSABLE PRINCIPLE

`CONTINUATION IS BEHAVIOR; ENJOYMENT IS A SEPARATE VARIABLE.`

## 3 hours — add re-orientation fatigue

Existing fatigue channels:
- sensory;
- decision;
- aiming precision;
- vigilance;
- motivation.

Run 4 adds:
- `RE-ORIENTATION FATIGUE` — repeated cost of rebuilding context after temporary duties/reward states.

### REUSABLE PRINCIPLE

`LONG-SESSION QUALITY DEPENDS ON HOW OFTEN CONTEXT MUST BE REBUILT AND HOW CHEAP EACH REBUILD BECOMES WITH MASTERY.`

# 8. Sparse presentation: the termination condition matters

## INTERPRETATION

Prior runs established:

`SPARSITY MULTIPLIES BASE-LOOP QUALITY; IT DOES NOT CREATE BASE-LOOP QUALITY.`

Run 4 adds a second condition. Sparse cues only preserve attention when the player trusts their boundaries.

A small deviation that begins clearly but ends ambiguously can create more vigilance debt than a larger explicit event.

## REUSABLE PRINCIPLES

`SPARSE PRESENTATION NEEDS TRUSTED BEGIN AND END BOUNDARIES.`

`QUIETNESS SAVES ATTENTION ONLY WHEN THE PLAYER KNOWS WHAT IS OVER.`

`VISUAL / AUDIO HEADROOM IS USEFUL ONLY WHEN TEMPORARY CLAIMS RETURN THAT BANDWIDTH.`

# 9. Cross-case update: 北斗 vs 新ハナビ

The contrast remains architectural, not aesthetic.

### 北斗 evidence direction
Repeated value often projects forward through state inference, rare-role value, precursor observation, BB continuation and possible higher-value transition.

### 新ハナビ evidence direction
Repeated value can remain inside the current physical reel interaction through aiming, slip/form inference, role denial, reach-eye discovery, execution and post-BIG RT responsibility.

### Run 4 common principle
Both architectures need a credible return contract.

A state-progression machine may return from battle/AT/upper states to ordinary state.
A reel-centric normal machine may return from a brief cue, technical task, bonus or RT to ordinary aiming/read rhythm.

Therefore:

`RETURN ARCHITECTURE IS UNIVERSAL EVEN WHEN REWARD ARCHITECTURE IS NOT.`

This is a cross-case research principle, not a concept selection rule.
