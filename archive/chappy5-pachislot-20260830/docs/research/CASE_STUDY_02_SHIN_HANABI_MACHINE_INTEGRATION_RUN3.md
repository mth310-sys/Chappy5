# 2. Why this machine exists — inheritance without freezing the old machine

## SOURCED FACT

Public launch coverage and the official-app description identify 新ハナビ as a 2021 6th-generation A PROJECT machine that deliberately inherits the 5th-generation ハナビ game flow while adding level-based RB technical intervention, `たまやチャレンジ`, changed reel arrangement / aiming points, and changed blackout laws.

Sources:
- P-WORLD / 遊技日本, 2021-07-05: https://news.p-world.co.jp/articles/17137/nippon
- Universal official app description: https://apps.apple.com/jp/app/%E7%8E%8B%E5%9B%BD-%E6%96%B0%E3%83%8F%E3%83%8A%E3%83%93/id1579639583

Published guides also identify the core reward structure as BIG / REG plus post-BIG RT, rather than CZ→AT→upper-state progression.

Sources:
- P-WORLD machine database: https://www.p-world.co.jp/machine/database/9401
- analysis summary: https://kenslo65536.com/kaiseki/hanabi-new.html

## INTERPRETATION

The design task was not simply “preserve an old nostalgic appearance.” The inherited value is a repeated interaction grammar:

`aim → stop → read slip/form → classify role/possibility → resolve → occasionally discover bonus → execute bonus/RT technique → return to normal with more knowledge`

Modernization occurs by adding new readable branches and skill tiers while preserving physical-reel primacy.

## REUSABLE PRINCIPLE

`LINEAGE VALUE LIVES IN THE REPEATED CONTRACT, NOT IN COPYING THE OLD SURFACE.`

A successor can preserve the reason people play while changing exact reel layout, rules, presentation, and difficulty structure.

# 3. The complete machine loop after Run 3 integration

Previous integrated model:

`AIM → CLASSIFY → RESOLVE → DISCOVER → EXECUTE → EXTEND / TRANSITION → RETURN WITH MORE KNOWLEDGE`

Run 3 adds the attention-routing layer:

`REST → OPTIONAL READ → TEMPORARY ATTENTION CLAIM → PLAYER ACTION / INFERENCE → INFORMATION RESOLUTION → ATTENTION RELEASE → REST`

The two loops operate simultaneously.

A normal game does not need to escalate into a new state to be meaningful. The same three STOPs may provide:
- safe small-role handling,
- slip information,
- role denial,
- reach-eye discovery,
- bonus suspicion/detection,
- long-session setting samples,
- or nothing exceptional at all.

A bonus/RT state does not require new controls. It changes the responsibility assigned to the already learned controls.

## REUSABLE PRINCIPLE

`STATE DEPTH CAN COME FROM RESPONSIBILITY REALLOCATION BEFORE CONTROL EXPANSION.`

# 4. New Machine-level synthesis: ATTENTION CONTRACT STATE MACHINE

Visual Run 3, Sound Run 3, Game/Reel Run 2 and QA Run 3 converge on one stronger abstraction.

## INTERPRETATION

The machine is not only changing game state. It is continually changing the player's **attention contract**.

### Ordinary low-duty state
The player can perform a stable aiming routine. Cabinet identity, normal audio and operation layout stay predictable.

### Conditional read state
A slip, blackout, timing deviation, small-role pattern, flash or partial reel form asks for more attention.

### Resolution state
The next STOP(s), role result or contradiction answer the question.

### Technical-duty state
During selected bonus/RT moments, precision becomes economically relevant.

### Recovery state
After the task resolves, presentation and cognitive duty should fall back instead of remaining elevated.

This is the shared structure behind:
- Game & Reel: `REEL RESPONSIBILITY SHOULD OPEN AND CLOSE WITH INFORMATION NEED`
- Visual: `TEMPORARY TASK PRIORITY SHOULD EXPIRE CLEANLY`
- Sound: `AUDIO PRIORITY SHOULD EXPIRE WHEN THE PLAYER'S RESPONSIBILITY EXPIRES`
- QA: `SKILLFUL PLAY REQUIRES ATTENTION SWITCHING, NOT PERMANENT MAXIMUM ATTENTION`

## REUSABLE PRINCIPLE

`ATTENTION IS A STATE VARIABLE.`

Do not model player attention as “high engagement = good.” The machine should deliberately open, intensify, resolve and release attention.

A stronger formulation:

`SUSTAINABLE DEPTH = MEANINGFUL ATTENTION SWITCHES - FALSE VIGILANCE - UNRELEASED DUTY`

# 5. What mastery actually changes

## SOURCED FACT

Public play guides show a low-complexity safe routine in which the player can aim a known point on the left reel, use the right reel more freely in common branches, and only target the middle reel when an ice line remains relevant. The machine also offers beginner/intermediate/advanced REG routes, while published complete-procedure figures show that technical execution materially changes return.

Sources:
- P-WORLD machine guide: https://www.p-world.co.jp/machine/database/9401
- P-WORLD / launch coverage: https://news.p-world.co.jp/articles/17137/nippon
- analysis summary: https://kenslo65536.com/kaiseki/hanabi-new.html

## INTERPRETATION

Mastery does not simply increase the amount of information a player consumes. It does two opposite things at once:

1. compresses routine cost — common branches become automatic;
2. expands optional questions — slip, stop order, role family, reach-eye relation, bonus type and setting samples become available when desired.

This resolves an apparent contradiction in technical machines: an expert can perceive **more** while actively monitoring **less**.

## REUSABLE PRINCIPLE

`MASTERY = ROUTINE COMPRESSION + OPTIONAL INFORMATION EXPANSION + ATTENTION SELECTIVITY.`

And:

`A DEEP MACHINE SHOULD LET EXPERTS IGNORE MORE SAFELY, NOT FORCE THEM TO WATCH EVERYTHING.`

# 6. Sparse presentation — what it can and cannot do

## DIRECT OBSERVATION / SHARED RESEARCH

Visual evidence shows a cabinet that remains identifiable through static massing, material/light contrast, recessed physical reels, an operation deck, repeated STOP row and large lower identity area without depending on a giant moving mechanism.

Sound research shows that ordinary timing continuity can carry value: a small timing deviation can be meaningful because the normal timing baseline is trusted. RT BGM can also act as a state surface where interruption itself carries information.

QA research adds the critical limit: sparse presentation is useful only when the ordinary reel game already contains readable value.

## INTERPRETATION

“Quiet” is not itself a product feature. It is a **contrast amplifier**.

If the underlying ordinary STOP has meaningful classification/discovery, restraint protects it.
If the underlying STOP is empty, restraint exposes the emptiness.

## REUSABLE PRINCIPLE

`SPARSITY MULTIPLIES BASE-LOOP QUALITY; IT DOES NOT CREATE BASE-LOOP QUALITY.`

This also means restrained presentation should never be treated as automatically superior to dense presentation. 北斗 demonstrates a different successful balance.

# 7. Visual / audio / reel integration without an AT ladder

## INTERPRETATION

新ハナビ demonstrates an integration architecture where the physical reel field remains the precision surface and other systems often modify **how it is read** rather than replacing it.

- Reel system supplies the physical evidence.
- Blackout/flash can change the condition or interpretation of that same evidence.
- Small display can add interpretation without becoming the primary game surface.
- Audio timing can narrow or alter attention without constant level escalation.
- Cabinet peripheral lighting can preserve hall presence while leaving central precision readable.
- Bonus/RT can change duty and continuity while retaining the same input grammar.

This differs from a progression machine where large portions of value come from reaching a higher state ladder. Here, depth can accumulate laterally inside the same ordinary interaction.

## REUSABLE PRINCIPLE

`LATERAL DEPTH = MORE WAYS TO READ / EXECUTE THE SAME CORE LOOP.`

`VERTICAL DEPTH = MORE VALUABLE STATES ABOVE THE BASE LOOP.`

Neither is inherently better. Reality study must understand both before Chappy5 chooses any architecture.

# 8. 100G / 500G / 3-hour Machine model

## 100G

The machine must be judged by whether ordinary games repeatedly create small, voluntary questions:
- what stopped and why,
- whether a role remains possible,
- whether the player needs to aim again,
- whether a deviation matters,
- whether the bonus has already been discovered before formal notification.

This is `QUESTION DENSITY`, not effect density.

## 500G dry spell

A long bonus drought is the critical falsification test because this machine lacks a CZ/AT milestone ladder to subdivide time for it.

Machine evaluation must separate:
- intrinsic desire to continue reading reels,
- economically rational continuation,
- setting inference motive,
- sunk-cost / “hit before quitting” motive,
- relief when a bonus finally appears.

A bonus at G500 cannot retroactively validate G1–499.

## 3 hours

Long play is not one fatigue channel. Shared QA now separates:
- sensory fatigue,
- decision fatigue,
- aiming-precision fatigue,
- vigilance fatigue,
- motivation fatigue.

Machine-level quality therefore depends on **recovery architecture**:
- low-duty ordinary branches,
- clearly bounded technical windows,
- presentation tails that end when information ends,
- RT phases that can lower duty while retaining informational value,
- self-selected pace.

## REUSABLE PRINCIPLE

`LONG-SESSION QUALITY IS NOT HOW LONG MAXIMUM ATTENTION CAN BE SUSTAINED; IT IS HOW WELL THE MACHINE ALTERNATES ATTENTION, EXECUTION AND RECOVERY.`

# 9. Reward structure and skill relationship

## SOURCED FACT

Published machine information gives:
- BIG maximum 202 medals,
- REG maximum 112 medals,
- post-BIG 花火チャレンジ up to 20G,
- 花火GAME 20G,
- JAC IN avoidance can extend 花火チャレンジ,
- BGM stop during RT is documented as bonus information,
- REG offers difficulty-dependent technical-intervention routes.

Sources:
- https://www.p-world.co.jp/machine/database/9401
- https://kenslo65536.com/kaiseki/hanabi-new.html

## INTERPRETATION

Reward is distributed across several layers rather than stored in a single upper-state jackpot:
- bonus payout,
- self-discovery before announcement,
- successful technical execution,
- RT extension,
- mastery confirmation,
- setting inference,
- return to a base game that may still be intrinsically worth reading.

Skill creates both pride and regret because execution affects economic result. This makes post-miss recovery a first-class machine concern, not only a QA concern.

## REUSABLE PRINCIPLE

`SKILL REWARD MUST BE DESIGNED WITH FAILURE RECOVERY, NOT ONLY SUCCESS PAYOFF.`

And:

`PLAYER-CHOSEN DIFFICULTY CAN PRESERVE ACCESSIBILITY WHILE RETAINING A HIGH SKILL CEILING.`

# 10. Cross-case correction: 北斗 vs 新ハナビ

The comparison should not collapse into “AT is flashy / normal is quiet.”

### 北斗
Primary repeated value often points forward:
`state inference → rare-role/state edit → observation window → BB → continuation judgement → possible value upgrade`

### 新ハナビ
Primary repeated value often points inward to the current stop sequence:
`aim → stop form/slip → role/bonus inference → optional technique → discovery → bonus/RT → return`

### Common machine truths surviving both

1. Stable input/body grammar allows state meaning to change without relearning the machine.
2. A deviation has value only when normal timing/light/sound is trusted.
3. Player interpretation is part of play, not an optional layer after the “real game.”
4. Reward entry and reward sustain are separate product duties.
5. Return to ordinary play is part of reward quality.
6. Relief after drought must not be mistaken for quality during drought.
7. Strong presentation should not erase the primary information surface.
8. Mastery includes knowing what can be ignored.
9. Long-session quality requires attention release.
10. A machine can be deep vertically through state progression or laterally through interpretation/technique.

## NEW MACHINE PRINCIPLE

`DEPTH ARCHITECTURE MUST DECLARE WHERE NEW VALUE COMES FROM: HIGHER STATES, DEEPER READING OF THE SAME STATE, OR A CONTROLLED COMBINATION.`

This is a research classification principle only. It is not a Chappy5 concept decision.
