## 2. Run 3 integration target

Run 3 asked:

`CAN THE MACHINE KEEP OPEN-QUESTION COUNT, ATTENTION CLAIMS AND OPTIONAL INFERENCE BELOW A TOLERABLE BACKLOG ACROSS BOTH DRY AND REWARD-RICH PLAY, WHILE RELIABLY RETURNING THE PLAYER TO A LOW-COST HOME ROUTINE?`

### Game & Reel
- normal motor HOME is cheap and stable;
- published rare-role frequencies imply branch exposure is periodic rather than constant;
- the clearest extra precision branch, suika, is much rarer than total rare-role exposure;
- role identity can close immediately while consequence meaning remains open on a later clock;
- mandatory play duty and optional expert/statistical inference are different burdens.

### Visual & Mechanism
- fixed `LCD → recessed reels → STOP row` hierarchy protects body-map continuity;
- delayed context can remain on the screen while new physical evidence arrives on reels;
- `CONTEXT PRESENT` is not the same as `ATTENTION CLAIM ACTIVE`;
- an open question can coexist with visual REST if the player can re-acquire reels/controls cheaply.

### Sound & Experience
- audio must support a current motor clock and a persistent consequence clock at once;
- cue roles separate usefully into `OPEN / PROLONG / NARROW / CLOSE / RE-ANCHOR`;
- persistent state does not justify persistent acoustic foreground;
- new action-relevant information should outrank stale unresolved context.

### Playtest & QA
- the dominant long-session risk is not the three-STOP routine itself;
- risk accumulates through question backlog, vigilance duty and optional statistical maintenance;
- reward density must increase closure as well as openings;
- motor mastery can reduce physical load while hiding increasing cognitive bookkeeping load.

## 3. Machine verdict

Run 3 answers the failure-boundary question qualitatively:

`THE HOME-RETURN ARCHITECTURE IS ROBUST AT THE MOTOR / BODY-MAP LEVEL, BUT ITS FAILURE BOUNDARY MOVES INTO QUESTION BACKLOG, VIGILANCE DUTY AND OPTIONAL INFERENCE WHEN TOO MANY CONSEQUENCES REMAIN OPEN ACROSS ORDINARY SPINS.`

The machine remains coherent when:
1. ordinary lever/STOP duty stays cheap;
2. role identity closes quickly enough;
3. persistent context does not keep full visual/audio foreground;
4. temporary reward/state layers return to a recognizable HOME;
5. optional setting/state inference can be ignored without breaking safe basic play.

The machine begins to fatigue when:
1. new questions open faster than old ones close;
2. multiple foreground cues compete across consecutive spins;
3. the player must remember too many unresolved consequence windows;
4. reward states open additional obligations without also closing prior ones;
5. expert inference becomes psychologically mandatory rather than optional depth.

## 4. Reusable cross-case principles

- `BRANCH FREQUENCY AND BRANCH COST MUST BE MEASURED SEPARATELY.`
- `ROLE CLASSIFICATION LATENCY ≠ CONSEQUENCE-RESOLUTION LATENCY.`
- `QUESTION PERSISTENCE SHOULD NOT REQUIRE MOTOR-MAP RECONSTRUCTION.`
- `REST CAN EXIST INSIDE AN OPEN QUESTION.`
- `AN OPEN QUESTION DOES NOT REQUIRE AN OPEN ATTENTION CLAIM.`
- `REWARD DENSITY MUST INCREASE CLOSURE AS WELL AS OPENINGS.`
- `AUTOMATED MOTOR SKILL CAN HIDE GROWING COGNITIVE LOAD.`
- `DEPTH REMAINS HEALTHY WHEN QUESTIONS OPEN, RESOLVE AND RELEASE ATTENTION; DEPTH TURNS INTO FATIGUE WHEN THE PLAYER MUST CARRY TOO MANY UNRESOLVED OBLIGATIONS INTO THE NEXT ORDINARY SPIN.`

These are abstractions only. No protected art, sound, characters, proprietary stop-control tables or machine-specific presentation assets are reusable.

## 6. Next-lineage selection criteria

The next machine must:
- materially differ from Hokuto's AT/state ladder, New Hanabi's normal/reach-eye/technical-intervention loop, and Madoka 2's A+ART parallel reward structure;
- have sufficient real-machine documentation, analysis and long-form play evidence;
- have an official or properly licensed smartphone app available for later study;
- produce a useful real-machine→smartphone translation problem.

Selected target: **ユニバーサルブロス「沖ドキ！GOLD」（2022）**.

Reason for selection:
- 30φ / pseudo-BONUS / mode-and-32G-chain lineage is deliberately different from the first three studies;
- repeated play centers on a simple physical routine, hibiscus notification, mode expectation and post-BONUS 32G continuation tension rather than CZ→AT→upper-state progression or reel-technical discovery;
- the machine uses restrained direct notification and a strong physical lamp identity, creating a different Visual/Sound/attention architecture;
- Universal Entertainment currently distributes an iPhone app `沖ドキ！ＧＯＬＤ`, described by the publisher as reproducing the real machine, with simulator-specific options such as auto, forced roles, setting change and wait cut. App behavior remains a separate object and must never be treated as proof of real-machine rules.
