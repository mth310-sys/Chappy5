## Central answer

Machine Run 8 asked how the same BET / START / STOP1 / STOP2 / STOP3 hardware can retire exactly one obsolete action law while preserving still-live inference and binding the next valid law without an ALL CLEAR overlay.

Game/Reel answer:

`CONTROL IDENTITY != ACTION-LAW IDENTITY.`

The physical STOP can remain identical while one local action law loses authority.

A local action law is genuinely retired when:

`ITS TARGET QUESTION IS RESOLVED + NO REMAINING VALID STOP CAN IMPROVE THAT QUESTION BY FOLLOWING THE OLD LAW.`

This distinguishes retirement from a merely dormant duty.

## Main delta

- `ACTION-LAW CLOSURE != INFERENCE CLOSURE.`
- one stop result can retire a small-role/handling law while leaving contradiction or bonus inference alive;
- `DORMANT != RETIRED`: if the unresolved target will govern a later stop in the same episode, the old law is still active;
- repeated skill tasks should close per attempt and reopen as new episodes rather than remain one continuous vigilance obligation;
- temporary play should normally be a delta over a stable parent grammar, so return does not require a second lesson;
- state transition is valid closure evidence only when it changes which action family can govern the next input.

Research abstraction:

`NEXT-GRAMMAR BINDING = OLD QUESTION EXHAUSTED + CURRENT STATE OWNERSHIP LEGIBLE + BASE MOTOR GRAMMAR PRESERVED`

This is not an implementation formula.
