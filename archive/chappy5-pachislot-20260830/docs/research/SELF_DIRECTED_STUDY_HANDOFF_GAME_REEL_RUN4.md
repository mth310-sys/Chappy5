Question received from Machine Run 4:

**When a player sees a surprising stop/result, what evidence lets them distinguish their own aiming/timing error, chosen stop order/action route, legitimate internal-role/control consequence, and platform/input/render artifact without disclosing or inventing undisclosed stop-control tables?**

## Key change

Add **causal diagnosability** to meaningful reel agency.

A mathematically correct stop law is not sufficient if Human cannot classify why a surprising result occurred. Attribution should separate:

`EXECUTION ERROR / ROUTE EFFECT / MACHINE-LAW EFFECT / PLATFORM ARTIFACT / INTERPRETATION ERROR`

The player does not need the hidden manufacturer table. They need enough stable, sourced/observable invariants and enough partial-stop history to keep unknown outcomes inside a trusted law rather than between competing causal sources.

Research-only attribution ladder:

`ACTION ACKNOWLEDGED?`
`→ ROUTE AS INTENDED?`
`→ AIM PLAUSIBLE?`
`→ PARTIAL-STOP HISTORY COHERENT?`
`→ KNOWN MACHINE LAW SATISFIED / CONTRADICTED?`
`→ REPEATABILITY / PLATFORM HEALTH?`

## Main principles

- `A SURPRISING STOP NEEDS A CAUSAL HISTORY, NOT ONLY A FINAL PICTURE.`
- `FAILURE ATTRIBUTION SHOULD SEPARATE EXECUTION ERROR / ROUTE EFFECT / MACHINE-LAW EFFECT / PLATFORM ARTIFACT / INTERPRETATION ERROR.`
- `PARTIAL STOPS ARE CAUSAL BREADCRUMBS.`
- `THE PLAYER DOES NOT NEED THE HIDDEN TABLE; THEY NEED ENOUGH STABLE INVARIANTS TO TRUST THE UNKNOWN PART.`
- `LEGITIMATE UNCERTAINTY EXISTS INSIDE A LEARNED LAW; ARBITRARY UNCERTAINTY EXISTS BETWEEN COMPETING CAUSAL SOURCES.`
- `SKILL VALUE REQUIRES ATTRIBUTION PRECISION AS WELL AS TIMING PRECISION.`
- `ACTION ACKNOWLEDGEMENT IS PART OF REEL SEMANTICS WHEN PLAYER INPUT CLAIMS TO MATTER.`
- `SURPRISE WITHOUT CAUSAL TRUST BECOMES SUSPICION; SURPRISE INSIDE A TRUSTED LAW BECOMES DISCOVERY.`
- `DO NOT INVENT MISSING STOP-CONTROL TABLES TO MAKE ATTRIBUTION LOOK COMPLETE.`
