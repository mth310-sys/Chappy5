## Central integration

Run 6 established that less checking is not enough; healthy offloading requires preserved discrimination and low false alarms.

Run 7 adds a second temporal requirement:

`GOOD INTERRUPTION = CORRECT RE-ENGAGEMENT + CORRECT ACTION + CLEAN RELEASE`

A responsibility-bearing cue can be detected correctly and still fail QA if the Human remains partially vigilant after the temporary duty has ended.

The complete future acceptance target is:

`MINIMUM NECESSARY MONITORING + PRESERVED DISCRIMINATION + TIMELY RE-ENGAGEMENT + CORRECT RESPONSIBILITY ACTION + CLEAN POST-CUE RELEASE`

## Closed 新ハナビ reality anchor

Completed 新ハナビ research is used only as a non-proprietary anchor for this temporal structure:

`LOW-DUTY ROUTINE -> LEGITIMATE DEVIATION -> TEMPORARY RESPONSIBILITY -> RESOLUTION -> LOW-DUTY ROUTINE`

The same lever/STOP hardware can remain stable while responsibility temporarily changes, then returns to normal reel-centered play. No protected cue, sound, waveform, melody, timing table, visual design or stop-control table is copied or inferred.

## Main principles

- `DETECTION CAN BE CORRECT WHILE THE MONITORING POLICY IS STILL TOO EXPENSIVE.`
- `MEASURE THE COST OF HOLDING THE POSSIBILITY OF INTERRUPTION, NOT ONLY THE INTERRUPT RESPONSE.`
- `EVERY INTERRUPTION TRAINS THE NEXT MONITORING POLICY.`
- `A RESPONSIBILITY CUE SHOULD NOT LEAVE AN UNBOUNDED ATTENTIONAL AFTERTASTE.`
- `POST-CUE VIGILANCE IS A SEPARATE QA VARIABLE FROM CUE DETECTION.`
- `A TEMPORARY TASK IS NOT COMPLETE UNTIL ITS ATTENTION SET ALSO CLOSES.`
- `SPONTANEOUS RE-ENGAGEMENT IS STRONGER EVIDENCE THAN SUCCESS UNDER INSTRUCTED VIGILANCE.`
- `FALSE INTERRUPTION DAMAGES BOTH SIDES OF THE CONTRACT: IT CAN CREATE VIGILANCE FIRST AND IGNORING LATER.`
- `RELEASE IS PASSED BY RECOVERY TOWARD BASELINE, NOT BY THE DISAPPEARANCE OF THE CUE ALONE.`
- `CORRECT RESPONSE + FAILED RELEASE IS STILL A QA PROBLEM.`
- `APPARENT RELEASE + LOST DISCRIMINATION = DESENSITIZATION.`
- `A RELEASE PROBE CAN PREVENT RELEASE.`

## Research-only future sequence

Later Human trials, if authorized, should treat each responsibility event as:

`BASELINE -> OPEN -> ACTION -> RESOLVE -> RELEASE`

and distinguish:
- baseline false alarms / defensive checking;
- spontaneous opening before the required action;
- correct behavioral use of the cue;
- legible end of temporary duty;
- return of monitoring/checking toward baseline over subsequent ordinary games.

Do not immediately ask the Human whether they are still monitoring the just-resolved cue; that probe can reactivate the task-set and contaminate release measurement.
