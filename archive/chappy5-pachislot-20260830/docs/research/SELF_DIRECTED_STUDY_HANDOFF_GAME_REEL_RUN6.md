## Central integration

`SAFE AUTOMATICITY = CHUNKED ROUTINE + RELIABLE RESPONSIBILITY-REOPENING CUES + PRESERVED OUTCOME DISCRIMINATION`.

The key distinction is:

`MASTERY`
= routine checks disappear only where observable evidence makes them redundant, while role duty, inference duty, state duty and causal duty still reopen attention promptly.

versus

`CARELESS OMISSION`
= the action chunk continues after its preconditions have ended, causing missed role coverage, missed technical intervention, lost inference or state-procedure errors.

## Responsibility triggers

Four reusable trigger classes were extracted from the closed 新ハナビ anchor:

1. `ROLE DUTY OPENS` — a surviving role candidate requires precision.
2. `INFERENCE DUTY OPENS` — a partial stop / role denial creates a new reach-eye or bonus question.
3. `STATE DUTY OPENS` — BIG / REG / RT changes the active procedure.
4. `CAUSAL DUTY OPENS` — a result contradicts the learned route strongly enough to require source attribution.

## Main principles

- `AUTOMATE THE STABLE ACTION CLASS, NOT THE WHOLE GAME.`
- `RESPONSIBILITY SHOULD REOPEN ATTENTION; NOVELTY ALONE SHOULD NOT.`
- `A PARTIAL STOP CAN FUNCTION AS A BRANCH CONDITION, NOT JUST AN OUTCOME.`
- `EXPERTISE INCLUDES SELECTIVE DE-AUTOMATION.`
- `FAST ROUTINE PLAY IS NOT EVIDENCE OF MASTERY UNTIL RESPONSIBILITY CHANGES ARE HANDLED CORRECTLY.`
- `MONITORING COMPRESSION IS SAFE ONLY WHILE PREVENTABLE LOSS AND MISCLASSIFICATION DO NOT RISE.`
- `RE-ENGAGEMENT BOUNDARIES ARE PART OF THE REEL GAME'S LEARNABLE LAW.`
