# 2. まず確認した事実 — 1Gの価値は均一ではない

## SOURCED FACT

- 設定1のBB初当たりは約1/383.4、設定6は約1/235.1。
- 設定1のベースは約34.7G/50枚とされる。
- 通常天井は1268G+α、設定変更後は800G+α。
- 通常時には地獄・通常・天国・本前兆のモードがあり、レア役の本前兆期待がモードで変化する。
- 中段チェリーは地獄/通常では本前兆移行約25%、天国では本前兆濃厚。
- 本前兆移行後は最大32G以内でBBへ到達。
- BBは小役パート30G+αとバトルパート8Gを繰り返す継続型。
- 基本継続率は66% / 79% / 84% / 89%。
- 上位の無想転生バトルは基本ゲーム性を保ちながら継続率94%。

## INTERPRETATION

設定1で1/383.4という数字だけを見れば、100Gでは当たりが来ない方が普通である。しかし実遊技では「383Gまで空白」ではない。

プレイヤーが待つ対象は同時に複数ある。

`次のレア役 / 今のモードが天国か / 役を引いた後に上がったか / 前兆へ入ったか / 本前兆か / 天井短縮点 / 最終天井`

したがって北斗の通常時は、毎Gに新しいイベントを置くのではなく、**同じ反復入力の上へ異なる時間スケールの期待を重ねている**。

## REUSABLE QA PRINCIPLE

Chappy5通常時を評価する時、単に「○Gに1回イベントが起きる」ではなく、次の3層を別々に確認する。

1. `1G scale`: 今のレバーON/停止で何を見ているか。
2. `10–50G scale`: 役・状態・前兆によって何が変わったか。
3. `100G+ scale`: ハマリが進んだ時に現実の価値や判断が何か変わるか。

# 3. 最初の5分 — 全仕様を理解しなくても「何を見る台か」は分かる

## VIDEO OBSERVATION / SOURCED FACT

攻略・試打資料では中押し赤7狙いが代表的な遊技法として説明される。中リール第1停止位置から役候補を絞り、右/左でチェリー・スイカ等を判別する。

通常画面では大液晶のキャラクター行動・ステージ、物理リール、左サブ液晶が同時に存在するが、毎Gすべてを精読する必要はない。

## INTERPRETATION

初見プレイヤーが最初に学ぶのは全モード移行率ではない。

最小学習はおおむね以下。

`中を狙う → 中段チェリー/スイカ等が止まれば注意 → 液晶/ステージが変わる → 少し追って当否を見る`

さらに知識が増えると「今は天国示唆か」「この弱役で状態が変わったか」へ視点が深くなる。

ここでは初心者の `強い出目を認識する` と熟練者の `状態を読む` が同じ通常遊技上に共存している。

## REUSABLE QA PRINCIPLE

最初5分PASS条件は「全部分かる」ではない。

**5分で、この台がどの注意行動を報いるかが分かること。**

- リールを見る台なのか。
- 状態を推測する台なのか。
- ポイントを貯める台なのか。
- 目押しを成功させる台なのか。

これすら分からない場合は情報量ではなくAttention Designの失敗。

# 4. 通常100G — 北斗は「約3回のレア役だけ」で持たせているわけではない

## SOURCED FACT

Game & Reel研究で設定1のレア役合算約1/32.1が確認されている。単純期待値として100Gあたり約3.1回だが、実際の成立間隔はランダム。

## INTERPRETATION

100G中にプレイヤーが繰り返すのは、概念上こうなる。

`BET → レバー → 中押し/停止 → 通常役なら高速処理 → 液晶の小さな状態示唆を必要な分だけ見る → 次BET`

レア役成立時だけ注意密度が上がる。

`レア役認識 → 今のモードとの組み合わせで価値判断 → 数G〜最大32Gの挙動観測 → 当否/状態再推測`

ここで重要なのは、通常役の大多数を「強い演出で埋めない」こと。普通のゲームを早く捨てられるから、レア役後だけ自然に観察時間を伸ばせる。

## FATAL RISK FOUND

将来Chappy5が通常100Gを成立させようとして、毎Gに意味深なCue・色変化・煽りを置くと、北斗から学ぶべき構造の逆になる。

北斗の深さは「毎G情報が多い」ではなく、**情報密度を上げるべきゲームと捨ててよいゲームが分かれていること**にある。

## REUSABLE QA PRINCIPLE — `ATTENTION COMPRESSION`

100G検証では「何を見るか」だけでなく **何を見なくてよいか** を確認する。

プレイヤーが100Gすべてで液晶・リール・ランプ・サブ液晶・音を同じ強度で監視しなければならない台は、深いのではなく疲れる。

# 5. 500G級ハマリ — 退屈より先に「期待の再解釈」が起こる

## SOURCED FACT / FIELD REPORT

- 通常天井1268G+α、リセット時800G+α。
- 300G / 777G / 800G到達時には天井短縮抽選が存在する。
- 推定高設定8000G超実戦の記事でも、その日の最大800Gハマリが記録されている。

## INTERPRETATION

500Gまで当たらなかった時、同じ中段チェリーでも心理は序盤と違う。

序盤:
`当てたい / 天国に上げたい`

500G:
`そろそろ当てたい / この役で決めたい / 天井までどれだけか / ここからやめる合理性はあるか`

つまり、ハマリは単に退屈が長くなるのではなく **残投資・天井距離・期待値・中断判断までゲーム外経済を侵入させる**。

Chappy5は金銭賭博そのものを再現する必要はないが、長時間で「今やめる/次を押す」の意味が変わる現実感は無視できない。

## 500G DISLIKE TEST — 北斗から見えるチェック項目

500Gでも耐えられるために必要なのは強演出追加ではない。

- 基本BET/START/STOP音が怒りを増幅しない。
- 通常役は高速に処理できる。
- ハズレ演出が長くない。
- レア役不発のたびに最大感情ピークを要求しない。
- ステージ/モード示唆が「いつでも何かある」に堕ちない。
- 具体的な天井/状態/役の価値がある。

## REUSABLE QA PRINCIPLE

500Gテストでは「退屈だったか」だけでは弱い。

記録項目を分ける。

1. `Irritation`: 基本音・長演出・偽チャンスへの苛立ち。
2. `Emptiness`: 次Gに何も意味がない時間。
3. `Compulsion by sunk cost`: 面白さではなくここまで使ったから続けるだけになっていないか。
4. `Real changing value`: 本当に状態/天井/情報が変わっているか。

# 6. レア役HIT/MISS — 中段チェリー不発でも完全なゼロではない

## SOURCED FACT

地獄/通常の中段チェリーは約25%で本前兆。一方、本前兆へ直結しなかった場合でもモード昇格の可能性を持つ。

## INTERPRETATION

これは失敗の扱いとして重要。

中段チェリーを引いた瞬間に期待が発生する。しかし75%側へ落ちた時でも、プレイヤーは「通常→天国へ上がったかもしれない」という次の観測理由を持てる。

ただしこれは毎回救済されるという意味ではない。最終的には何も起きないこともある。

北斗の構造は `FAILURE RESIDUE` と `TRUE LOSS` が混在する。

- 直撃しない。
- 状態が上がった可能性はある。
- それも否定されれば本当に終わる。

## REUSABLE QA PRINCIPLE

失敗後に残すものは「惜しかった映像」ではなく、内部的に本物でなければならない。

同時に毎回何かを残す必要もない。**完全な失敗があるから、残留価値が価値になる。**

# 7. 前兆 — 最大32Gは「当たるまでの映像尺」ではなく再評価区間

## SOURCED FACT

本前兆は最大32G以内でBBへ到達する。前兆中にはステージや演出法則、矛盾等で当否を読む余地がある。

## INTERPRETATION

前兆が面白くなり得る条件は、32Gのストーリーを全部見ることではない。

プレイヤーは1Gごとに `本物らしさ` を更新している。

`レア役 → ステージ/挙動変化 → 対応役/矛盾 → 連続演出 → 確定`

したがって前兆は、内部当否を隠すための時間ではなく **仮説更新ゲーム** として機能している。

## FATAL RISK

毎回レア役後に長い前兆を強制し、途中情報が単に赤くなるだけなら、500Gハマリ時に最も強い疲労源になる。

## REUSABLE QA PRINCIPLE — `PRECURSOR INFORMATION GAIN`

前兆1Gごとに、少なくともどこかで以下が増えるか確認する。

- 当否情報
- 状態情報
- 対応役情報
- 終了/継続判断

何も増えず尺だけ増えるGは削除候補。

# 8. BB ENTRY — 「ハマリ終了の安堵」と「当たり自体の快感」を分離

## SOURCED FACT

BB当選後は告知/準備を経て赤7または北斗揃いを狙い、ATへ入る。純増は約4.1枚/G。通常時とは明確にゲーム状態が変わる。

## INTERPRETATION

500G以上のハマリ後のBB当選は感情が大きい。しかし、その強さの全部を「BBが気持ちいい」と評価するとQAを誤る。

感情を分ける。

- `RELIEF`: これ以上通常時を回さなくてよい。
- `ENTRY IMPACT`: 揃える行為、告知、状態転換が気持ちいい。
- `REWARD EXPECTATION`: ここから継続させられる期待。

北斗の入口が強いのは、この3つが重なるが同一ではない。

## REUSABLE QA PRINCIPLE

将来の試打で必ず別質問にする。

- 「当選した瞬間そのものは気持ちよかったか」
- 「当たるまでの通常時も遊ぶ価値があったか」
- 「単にハマリが終わってホッとしただけではないか」

# 9. 単発/低連BB — 普通の当たりは普通に失敗できる

## FIELD REPORT

なな徹の天井実戦記事では、長連・昇天・1G連という大きな成功の直後に、1G連から入ったBBが単発165枚で終了した記録がある。

別記事でも無想転生へ入って2〜3セットで終わった経験が複数回あるとのField reportがある。

## INTERPRETATION

重要なのは「上位に入れば必ず長く楽しい」でも「BBなら一定枚数保証」でもない。

BBは当たりであると同時に **次の継続判定へ賭ける新しいゲーム**。66%継続でも初回で終わり得る。

そのため、当たりの価値は結果枚数だけではなく

`突入 → 30G小役パート → 次のバトルへ向けた積み上げ → 継続ジャッジ`

という1セット自体にも必要になる。

## QA WARNING — `RESULT RETROACTIVE DEVALUATION`

終了が早かったから「全部無価値だった」と感じる台は危険。

普通のBB1セットに、結果とは独立した遊技価値が必要。

ただし単発を過剰に慰める演出も不要。負けは負けとして短く終わらせることもリアリティ。

# 10. BB SUSTAIN — 入口の派手さを38G以上繰り返さない

## SOURCED FACT

1セットは小役パート30G+αとバトルパート8G。小役パートでは宿命バトル/Vストック等、バトルでは継続判定という責務がある。

## INTERPRETATION

BBの中でも時間の質が違う。

### 小役パート
- 基本反復を高速消化。
- レア役が来た時だけ注意を上げる。
- 次の継続判定へ備える。

### バトルパート
- 情報密度と緊張を上げる。
- 攻防の展開から継続期待を読む。
- 最終的に継続/終了を確定する。

つまりAT中ずっと最大テンションではない。

## REUSABLE QA PRINCIPLE — `ENTRY IMPACT != SUSTAIN QUALITY`

AT評価を最低2軸に分ける。

1. `ENTRY IMPACT`: 入った瞬間。
2. `SUSTAIN QUALITY`: 10分以上続いた時。

入口だけ良い台は短尺動画では強く見えるが、長時間商品としては未完成。

# 11. 継続バトル反復 — 同じ8Gでも「今までの履歴」が意味を変える

## SOURCED FACT

通常BBは継続率管理。Vストック、共闘、特定演出、BGM変化等によって継続確定/期待度を読む場面がある。

## INTERPRETATION

同じ継続バトルを5回・10回繰り返しても心理が同一ではない。

- 1戦目: まず単発を避けたい。
- 数連後: 収支/獲得が積み上がり安心が出る。
- 長連: 終了への恐怖より昇天/上位等の新目標が生まれる。

BGM変化などの「継続確定情報」は、同じバトルを見続ける疲労を一時的に別体験へ変える。

## REUSABLE QA PRINCIPLE

反復ループを評価する時は、同一セットを1回だけ見て判断しない。

`1回目 / 3回目 / 10回目 / 20回目` で意味がどう変わるかを見る。

同じVisualを繰り返しても「累積履歴」「次目標」「確定法則」が変われば体験は変わり得る。

# 12. 上位非到達 — 無想転生がなくても通常BBが主商品として成立しているか

## SOURCED FACT / FIELD REPORT

Field reportでは約25,000G打って北斗揃い未経験だが無想転生は2回という個別例がある。これは確率の一般値ではなく、上位/プレミア経路の体験がプレイヤーごとに大きく偏る実例として扱う。

## INTERPRETATION

長時間打っても上位へ入らないことは十分あり得る。したがって、上位の94%継続だけが商品の本体なら、多くの遊技時間が「本番前」になってしまう。

北斗では通常BBにも
- 継続率差
- 継続バトル
- 共闘/Vストック
- BGM変化
- 昇天
- 1G連

など複数の目標がある。

上位は通常BBの文法を破壊して別ゲームにするのではなく、既存ループを高継続へ増幅する。

## REUSABLE QA PRINCIPLE — `UPPER ABSENCE TEST`

将来のChappy5候補では必ず

**「3時間上位へ一度も行かなくても、普通の当たりをまた引きたいか」**

を判定する。

NOなら上位依存。

# 13. 無想転生ENTRY — 大きいのは演出差より確率構造の変化

## SOURCED FACT

無想転生バトルは継続率94%、純増約4.1枚/G、基本の小役パート30G+α＋バトル8G構造を継承する。突入期待枚数2500枚以上と解析されている。

無想転生チャンスは15Gで、レア役等で成功抽選を行う。強スイカ50%、中段チェリー75%など公開値がある。

## INTERPRETATION

上位化の本質は「背景やBGMが豪華になる」ことではない。

通常BBで既に学習した
`30G消化 → バトル → 継続`

を保ったまま、継続に対する未来期待を大きく変える。

このためプレイヤーは新ルールを学び直すより、**知っているゲームが急に価値を増した**と感じられる。

## REUSABLE QA PRINCIPLE

上位状態は別ゲーム化しなくてもよい。むしろ

`INPUT GRAMMAR KEEP / VALUE GRAMMAR UPGRADE`

という設計は、学習負荷を抑えながら大きな状態差を出せる。

---

# 14. 上位SUSTAIN — 94%でも「ずっと安心」ではない

## FIELD REPORT

実戦記事では無想転生へ突入後2〜3セットで終了した経験が複数回あると記されている。

## INTERPRETATION

94%は高いが100%ではない。上位に入った瞬間からプレイヤーは「終わらない安心」ではなく、各バトルで薄い終了可能性を持ち続ける。

長く続けば続くほど、1戦ごとの報酬より累積枚数・昇天・エンディング・1G連等へ目標が移る。

## FATIGUE QUESTION

20セット以上同じ小役30G＋バトル8Gを繰り返す時、演出差・法則・BGM変化がどの程度疲労を抑えるかは、今回の公開テキスト/編集動画だけでは定量化できない。

`UNRESOLVED`: 実機/アプリ/ノーカット長尺を人間が連続視聴または試打して確認する必要がある。

---

# 15. 終了 — 「終わった」で即ゼロへ戻らない

## SOURCED FACT

- AT終了画面の第3停止を離すタイミングで1G連抽選が行われる。
- 1G連当選時は次GでAT再当選し、50%で北斗揃いスタート。
- 1G連に漏れても本前兆から通常へ戻る可能性がある。
- ラオウ昇天中も成立役に応じ1G連抽選があり、終了後1G目の演出が強い示唆になる。

## INTERPRETATION

終了時は「ATが終わる」だけではなく、直後に

`終了画面 → 第3停止 → 1G連抽選 → 通常復帰のステージチェンジ → 1G目 → 天国/本前兆/示唆確認`

という短いAftercare Gameが存在する。

このため終了演出を見た瞬間に心理が完全に通常時0Gへ切れない。

## REUSABLE QA PRINCIPLE — `POST-END CONTRACT`

終了後に追わせるなら、追う理由を本当に用意する。

- 1G連
- 引戻し
- 保持状態
- モード
- 示唆

何もないのに「何かあるかも」の演出だけでBETさせるのはFalse Residue。

逆に完全リセット設計なら、終了を明快にして即ヤメ可能にする方が誠実。

---

# 16. 次BETの瞬間 — 一番小さいのに重要な商品継続点

## INTERPRETATION

大当たり終了後にプレイヤーが次BETを押す理由は単一ではない。

1. 1G連/本前兆確認。
2. 天国の可能性確認。
3. 終了後ボイス等の情報取得。
4. まだ出玉/時間があり続行したい。
5. 「もう一度中段チェリーから当てたい」という通常ループへの再参加。

QA上もっとも重要なのは5。

後処理が終わった後でも、**通常遊技へ戻ること自体を受け入れられるか**。

上位/長連後に通常が罰ゲーム化していれば、台は長時間循環していない。

## REUSABLE QA PRINCIPLE — `RETURN ACCEPTANCE`

AT終了後の試打で

`また通常100Gを回してもよいと思えるか`

を独立評価する。

「出たから満足してやめたい」と「通常へ戻りたくない」は別。

# 17. 30分品質と3時間品質

## 30-MINUTE QUALITY

北斗は30分でも核を見せやすい。

- 中押しで役判別。
- 中段チェリーの即時期待。
- 前兆。
- BB突入。
- 38G単位の継続ループ。

この短時間では「中チェを引きたい」「BBを継続させたい」が明快。

## 3-HOUR QUALITY

3時間になると評価軸が変わる。

- レア役不発を何回許容できるか。
- 500G級ハマリで基本演出が嫌いにならないか。
- BB単発/2連を繰り返しても普通の当たりを価値と感じるか。
- 高設定推測という長期課題が支えになるか。
- 上位非到達でも継続できるか。
- 終了後の天国/示唆確認が作業化しないか。

## FIELD REPORT SUPPORT

推定高設定8000G超実戦でも800G級ハマリが存在する。高設定だから「常に快適」ではない。

設定1/5/6のP-WORLD実戦サンプルでも数千G単位で小役・初当たり・終了後ボイス等を数えるプレイが行われており、長時間では出玉だけでなく設定推測が別の注意タスクになる。

## REUSABLE QA PRINCIPLE

30分の「また見たい演出」と3時間の「まだレバーを叩ける」は別物。

Human Gate前の企画でも両方を文章で説明できなければならない。

# 18. プレイヤーが実際に見る/待つ/狙う/予測する/無視するもの

## LOOKS AT

- 中リール第1停止位置。
- チェリー/スイカ等の停止形。
- レア役後の液晶/ステージ変化。
- バトル継続時の攻防/チャンスアップ。
- 終了後のステージチェンジ/サブ液晶示唆。

## WAITS FOR

- 中段チェリー等の強契機。
- モード上昇。
- 本前兆。
- BB継続。
- 無想転生チャンス/上位。
- 長連時の昇天/1G連等。

## AIMS AT

- 通常時の代表打ち方では中リール赤7等を目印に役判別。
- BB入賞時の図柄狙い。

## PREDICTS

- 今のモード。
- レア役が刺さったか。
- 前兆が本物か。
- 次セットが継続するか。
- 高設定か。
- 終了後に追う価値があるか。

## IGNORES / SHOULD BE ABLE TO IGNORE

- 大多数の普通の通常役ゲーム。
- 意味のない通常モーション。
- 毎回すべてのサブ表示。

## INTERPRETATION

パチスロ熟練者は「全部を見る」のではない。むしろ **捨てる情報を学習して高速化する**。

Chappy5も、情報を増やすより `重要な時だけ注意を奪える通常の静けさ` を作る必要がある。

# 19. Proposal DocumentとActual Machineを分けるQA

北斗を企画書だけで説明すれば、

`中段チェリー → 25% → BB → 継続率 → 94%上位`

という非常に分かりやすい強い企画に見える。

しかし実遊技の大半は

`通常役 → 通常役 → 通常役 → 弱役 → 状態推測 → 何もなし → また通常役…`

である。

機械の品質は、この多数派の時間を含めて初めて評価できる。

## REUSABLE QA PRINCIPLE — `HIGHLIGHT RATIO TRAP`

企画比較で
- Signature effect
- 上位性能
- プレミア演出
- 最大出玉

だけを説明して高得点にしない。

必ず **90%以上を占め得る通常/非当選/失敗時間の説明** を同じ文字量で要求する。

# 20. 北斗から得たPlaytest & QAの新規原則

### 20-1. `ATTENTION COMPRESSION`
深さとは監視対象を増やすことではない。普通のGを捨て、意味が発生したGだけ注意を上げられること。

### 20-2. `MULTI-SCALE EXPECTATION`
1G、数十G、数百Gの期待が重なっていると、通常時は一枚の空白になりにくい。

### 20-3. `FAILURE RESIDUE + TRUE LOSS`
不発後に本物の状態価値が残る場合と、本当に何も残らない場合を混在させる。毎回救済しない。

### 20-4. `PRECURSOR INFORMATION GAIN`
前兆尺は情報更新量で評価する。赤くなるだけのGを増やさない。

### 20-5. `RELIEF ≠ REWARD`
深いハマリ後の当たりでは、解放感と当たりそのものの質を分ける。

### 20-6. `ENTRY IMPACT ≠ SUSTAIN QUALITY`
AT突入1回を見てAT品質を評価しない。

### 20-7. `RESULT RETROACTIVE DEVALUATION`
単発だった結果だけで、その1セット全部が無意味に感じられないかを見る。

### 20-8. `UPPER ABSENCE TEST`
上位0回の3時間でも商品として成立するか。

### 20-9. `INPUT GRAMMAR KEEP / VALUE GRAMMAR UPGRADE`
上位は既習操作を保ち、同じ操作の価値を増幅する方法も強い。

### 20-10. `POST-END CONTRACT`
終了後に追わせるなら本当の理由を置く。False Residue禁止。

### 20-11. `RETURN ACCEPTANCE`
終了後、通常100Gへ戻ること自体を受け入れられるか。

### 20-12. `HIGHLIGHT RATIO TRAP`
見せ場の強さを、台全体の強さと誤認しない。

# 21. Fatal-risk conditions — 将来Chappy5で即警戒する条件

1. 通常100Gの説明が「強演出を待つ」しかない。
2. 毎G何かを見せないと退屈になる。
3. レア役不発後が常に完全ゼロ、または常に偽の救済。
4. 前兆が当否情報を増やさず長い。
5. 初当たりの快感がハマリ終了の安堵に依存。
6. BONUS/ATが入口だけ気持ちよく、中身が同じ強刺激の反復。
7. 普通の当たりが上位への失敗扱い。
8. 上位0回だと3時間の記憶が何も残らない。
9. 終了後に理由なく「まだあるかも」で追わせる。
10. 長連後、通常へ戻るのが罰ゲーム。
11. 熟練しても見るべき情報を減らせず、常時全画面監視が必要。
12. 動画で映える瞬間を足した数を商品性だと評価する。

# 22. UNRESOLVED — 次の研究/人間実機確認で必要

1. ノーカット3時間以上の実戦映像で、通常時の実時間割合と演出密度を計測。
2. 設定1実戦を複数本比較し、500G級ハマリ中のレア役間隔・前兆反復・ヤメ判断を観察。
3. 無想転生20セット以上をノーカットで見た時のVisual/Audio疲労。
4. 初代カスタムON/OFFで同じ通常100Gを比較し、presentation density差を人間評価。
5. 実機の中押し反復を30分行った際の目・手の疲労。
6. 3STOP押下、PUSH、サブ液晶タッチを含む身体移動負荷。
7. BB単発を3回以上短時間に経験した場合の「また当てたい」残存率。
8. 高設定推測がないプレイヤーでも通常時ループが成立するか。
9. 上位経験後の通常復帰で期待基準が壊れないか。
10. 実ホール騒音下で通常CueとレアCueをどこまで識別できるか。

これらは現段階で `UNRESOLVED`。動画編集済み素材から定量値を捏造しない。

# 23. Machine Directorへの引き継ぎ

Playtest & QA第1深掘りの核心は以下。

**北斗の通常時は、毎Gを面白くしているのではない。普通のGを高速に捨てられるようにし、レア役・モード・前兆・天井という複数時間スケールで「注意を上げる理由」を作っている。**

さらに、BBは入口だけではなく30G+α→8Gの反復、上位は別ゲームではなく既習ループの価値増幅、終了後は1G連/本前兆/示唆という真のAftercareを持つ。

Machine Directorは次巡で5 Directorのケーススタディを統合する際、特に次を確認すること。

1. `NORMAL-PLAY ECONOMY` を「レア役待ち」という一言へ縮約しない。
2. `REWARD LADDER` を上位の強さだけで評価しない。単発/低連/通常BBの価値を見る。
3. `PHYSICAL/SENSORY BASELINE` を強演出時ではなく、普通の90%以上の時間で統合する。
4. 北斗固有の中段チェリー・32G・継続率・演出をコピーしない。
5. Case Study 01が終わってもReality Baseline completeとは自動判定しない。次に真逆の機種系統（ノーマル/リーチ目/技術介入等）を比較ケースとして検討する。

既存 `SIGNAL//3 / FORGE//HEART / VAULT://3` は引き続き `PROVISIONAL_FROZEN`。企画へ戻らない。
