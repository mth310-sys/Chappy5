## 0. Scope / evidence discipline

This run studies the machine as a repeated reel game, not as a list of famous reach eyes.

Evidence labels used below:
- `MANUFACTURER FACT`: official Universal material.
- `PUBLISHED ANALYSIS`: major strategy/analysis source.
- `FIELD / VIDEO EVIDENCE`: published long-form or specialist play evidence; existence/content description only unless directly observable from accessible material.
- `INTERPRETATION`: Game & Reel Director inference from sourced structure.
- `UNRESOLVED`: not promoted to fact.

Never treat community-inferred stop-control tables as manufacturer disclosure. Detailed control, exact slip behavior for every flag/position, priority tables and every reach-eye cause remain unresolved unless a reliable source explicitly documents them.

## 1. The machine's declared grammar

### MANUFACTURER FACT

Universal describes 新ハナビ as the 6th-generation A PROJECT third title, `ボーナス＋RT`, released July 2021. The official product page states that the game flow fully inherits 5号機「ハナビ」, that medals are increased primarily through bonuses, that `花火チャレンジ` retains JAC-IN avoidance, and that 6号機-specific additions include level-based RB technical intervention, the mini-LCD `たまやチャレンジ`, and changes to reel arrangement / blackout rules.

Official source:
- https://www.universal-777.com/product/slot/shin_hanabi/

### PUBLISHED ANALYSIS

Major references converge on:
- BIG max 202 medals.
- REG max 112 medals.
- BIG always leads into RT `花火チャレンジ`; successful JAC-IN management can extend the first RT phase, then JAC-IN moves to `花火GAME`.
- Approximately 3,500 reach-eye patterns are advertised/reported for this machine.
- Settings are 1 / 2 / 5 / 6.

Reference values from 一撃 / なな徹:

| Setting | BIG | REG | Combined | Base payout | Full strategy (upper REG method) |
|---|---:|---:|---:|---:|---:|
| 1 | 1/277.7 | 1/356.2 | 1/156.0 | 98.1% | 102.0% |
| 2 | 1/268.6 | 1/331.0 | 1/148.3 | 99.9% | 104.0% |
| 5 | 1/256.0 | 1/306.2 | 1/139.4 | 102.3% | 106.5% |
| 6 | 1/248.2 | 1/280.1 | 1/131.6 | 104.6% | 109.0% |

Sources:
- https://1geki.jp/slot/s_shinhanabi/
- https://nana-press.com/kaiseki/machine/134/3862/

### INTERPRETATION

This makes the baseline fundamentally different from Case Study 01 北斗. The ordinary objective is not to climb a state ladder. The ordinary objective is to execute a stop routine while continuously asking:

`What role can still be alive? → Did the reel slip? → Does the second reel preserve or deny that role? → Is the final shape ordinary, a role, a contradiction, or a bonus discovery?`

The next three STOPs can therefore be content before any explicit chance state exists.

## 2. Reel array and valid-line reality

### PUBLISHED ANALYSIS

A published reel-table reference lists the machine as:
- 3BET: 5 valid lines.
- 1BET: 2 valid lines.

Source:
- https://p.hisshobon.jp/machine/list.php?c=1&d=82177&mid=3661&p=2

The public reel table shows a 21-symbol arrangement on each reel, with multiple visually distinct landmarks including BAR / 暖簾, red 7, Don, ice, cherry, wind bell and replay-related symbols. Strategy pages explicitly support multiple left-reel entry routes rather than a single mandatory first-stop point:
- BAR / 暖簾 route.
- single Don route.
- red-7 route.

Sources:
- https://1geki.jp/slot/s_shinhanabi/
- https://nana-press.com/kaiseki/machine/134/3865/
- https://nana-press.com/kaiseki/machine/134/3866/
- https://nana-press.com/kaiseki/machine/134/3867/

### INTERPRETATION — `ARRAY AS PLAYFIELD`

The reel array is not merely a symbol asset. It is a physical information field whose landmarks support different questions. The player's chosen first-stop target changes which candidate roles and bonus possibilities are easy to discriminate.

This immediately rejects a weak design habit:

`one optimal visual marker → same stop every game → only result animation matters`

A reel-centered machine can use the same three reels as several overlapping reading instruments.

## 3. Three practical normal-play entry routes

### 3.1 BAR / 暖簾 route

### PUBLISHED ANALYSIS

A common procedure is to aim the left reel around the upper BAR / 暖簾 region, then use right-reel free stopping and only aim the middle reel when ice remains possible. Published examples separate first-reel stop forms into different candidate sets. Examples include:
- a BAR-area stop that leaves wind bell / ice / special replay / bonus possibilities;
- a cherry stop that resolves as cherry;
- another stop that narrows to wind bell / replay.

Source:
- https://nana-press.com/kaiseki/machine/134/3865/

### INTERPRETATION

The first STOP does not need to be an authored dramatic beat. It is a **candidate-set classifier**. The value of the second and third STOP emerges because the first stop leaves some roles alive and excludes others.

### 3.2 Single-Don route

### PUBLISHED ANALYSIS

The single-Don route likewise creates different first-stop candidate sets. Published examples include:
- wind bell / ice / replay / special replay / bonus;
- miss / bonus / ice;
- cherry.

Source:
- https://nana-press.com/kaiseki/machine/134/3866/

### INTERPRETATION — `AIMING ROUTE = INFORMATION LENS`

A different first-stop target does not merely create cosmetic variety. It changes which uncertainty is easy to read. This can keep the same internal lottery fresh because the player can choose a different information lens.

### 3.3 Red-7 route

### PUBLISHED ANALYSIS

A published red-7 procedure allows cherry coverage while producing another set of stop-form classifications, including:
- wind bell / replay;
- wind bell / ice / bonus;
- replay / miss;
- cherry substitute form.

Source:
- https://nana-press.com/kaiseki/machine/134/3867/

### REUSABLE PRINCIPLE — `ROUTE CHOICE SHOULD ALTER OBSERVATION, NOT ONLY STYLE`

If multiple aiming routes exist in a future original reel game, they should ideally change what the player can infer or how they reach a solution, not just move the same animation to another symbol.

## 4. Small-role economy: ordinary games are not empty

### PUBLISHED ANALYSIS

Setting 1 reference frequencies from なな徹 include approximately:
- normal replay: 1/7.3;
- wind bell A: 1/15.3;
- wind bell B: 1/15.3;
- cherry A1: 1/99.4;
- cherry A2: 1/21.0;
- cherry B: 1/282.5;
- ice A: 1/52.9;
- ice B: 1/1638.4.

The same source gives about 44G per 50 medals.

Source:
- https://nana-press.com/kaiseki/machine/134/4508/

### INTERPRETATION

The normal loop is not `155 empty games → bonus`. Frequent replay / wind-bell / cherry / ice events continually change how the player should stop or classify the reels.

This matters for a 500G dry spell. Even when the bonus lottery has not paid, the hands and eyes still receive repeated micro-tasks:
- cover cherry;
- notice when ice remains possible;
- decide whether the middle reel needs an aim;
- read slip / stop position;
- check role completion or denial;
- recognize a reach eye before a lamp explicitly tells the answer.

`DRY SPELL` in this lineage therefore means `no bonus`, not necessarily `no game events`.

## 5. INTERNAL ROLE != OBSERVED STOP FORM

### PUBLISHED ANALYSIS

The machine exposes multiple observable forms for role families. Strategy sources separate wind-bell A/B, cherry A1/A2/B and ice A/B internally for probability analysis, while normal play pages teach the player through visible stops and candidate sets rather than by displaying the internal role name every game.

Sources:
- https://nana-press.com/kaiseki/machine/134/4508/
- https://nana-press.com/kaiseki/machine/134/3865/
- https://nana-press.com/kaiseki/machine/134/3866/
- https://nana-press.com/kaiseki/machine/134/3867/

### INTERPRETATION

A good reel game does not have to reveal the internal lottery directly. It can reveal a physical consequence that becomes legible with knowledge.

The important architecture is:

`INTERNAL FLAG / BONUS STATE × STOP POSITION × STOP ORDER × CONTROL → OBSERVED FORM → PLAYER INFERENCE`

The exact control table for 新ハナビ is not claimed here. The equation is a design model, not a reverse-engineered manufacturer table.

### INTERPRETATION — `SLIP IS TEMPORAL INFORMATION`

A stopped symbol is spatial information. The amount or character of slip adds temporal information: the player compares `where I aimed` with `where it stopped` before the final three-reel picture is complete.

That creates a powerful property:

**the answer can begin before the reels are all stopped.**

A future reel design should therefore avoid treating slip as a purely cosmetic easing animation if the goal is authentic reel play.

## 7. Reach eyes are a grammar, not 3,500 collectibles

### PUBLISHED ANALYSIS / MANUFACTURER CONTEXT

Major strategy sources report roughly 3,500 reach-eye patterns, increased after the reel-array change.

Sources:
- https://1geki.jp/slot/s_shinhanabi/
- https://www.p-world.co.jp/machine/database/9401

### INTERPRETATION

The useful lesson is not `make thousands of patterns`.

A reach eye is valuable because it is the endpoint of a rule relationship. Reusable families include concepts such as:
- a role appears to be possible, then the final stop denies it;
- a familiar role shape stops in a position that should not coexist with an ordinary miss;
- a two-reel relation makes the third reel meaningful before explicit notification;
- an unusual slip converts an ordinary-looking final picture into a discovered bonus;
- a flash / blackout / delay creates a corresponding-role contract, so a contradiction changes the meaning of the reels.

The content is the **rule network**, not the count.

### REUSABLE PRINCIPLE — `REACH-EYE SCALE SHOULD EMERGE FROM RULE COMBINATORICS`

Do not hand-author thousands of disconnected pictures. Build a coherent reel / role / control grammar from which many valid discoveries emerge.

## 8. Role denial and presentation contradiction

### MANUFACTURER FACT

Universal explicitly says the new machine changes blackout rules and adds `たまやチャレンジ` while preserving the inherited game flow.

Source:
- https://www.universal-777.com/product/slot/shin_hanabi/

### PUBLISHED ANALYSIS

`たまやチャレンジ` can occur after three-blackout replay/cherry-related sequences. A major source reports normal-play total occurrence about 1/290.5 and total bonus expectation 36.4%, with occurrence / expectation depending on triggering role and flash pattern.

Source:
- https://nana-press.com/kaiseki/machine/134/3871/

### INTERPRETATION

The mini-LCD does not replace reel discovery. It adds another conditional layer to an existing role/flash/reel language.

For Game & Reel, the important distinction is:

`PRESENTATION SAYS WHAT MAY BE TRUE` versus `REELS RESOLVE WHAT IS TRUE`.

If a future game lets the LCD announce the final answer before the reels can matter, it destroys this layer.

## 9. Bonus discovery: reward can begin before explicit announcement

### PUBLISHED ANALYSIS

The machine has BIG and REG rather than an AT entry ladder. A reach eye can establish that a bonus is already present before a final explicit bonus notification. Public first-play guidance emphasizes checking for a reach eye and then identifying/lining up the bonus.

Source:
- https://www.p-world.co.jp/machine/database/9401

### INTERPRETATION — `DISCOVERY REWARD PRECEDES PAYOUT REWARD`

There are at least three reward moments:
1. **Recognition** — the player realizes the reels have already answered `bonus`.
2. **Confirmation / identification** — the player determines which bonus to line up.
3. **Economic reward** — the bonus pays medals and transitions play.

This is crucial. In a reel-centered game, the first reward can occur before the machine celebrates.

## 10. BIG: short reward, then player-operated RT transition

### PUBLISHED ANALYSIS

BIG max payout is 202 medals. After BIG, `花火チャレンジ` starts automatically.

`花火チャレンジ`:
- maximum 20G;
- approx. 0.3 medal/G in major 新ハナビ references;
- JAC-IN / transition-replay management allows the player to extend the first phase;
- while enough games remain, reverse-order guidance can prompt a left-reel BAR / 暖簾 aim to avoid JAC-IN;
- later the player intentionally accepts JAC-IN to move to `花火GAME`.

`花火GAME`:
- fixed 20G once entered (unless bonus interrupts);
- approx. 0.6 medal/G in major 新ハナビ references;
- reel/role reading continues, with presentation cues changing what needs to be covered.

Sources:
- https://1geki.jp/slot/s_shinhanabi/64/
- https://1geki.jp/slot/s_shinhanabi/65/
- https://nana-press.com/kaiseki/machine/134/3869/
- https://nana-press.com/kaiseki/machine/134/3872/
- https://nana-press.com/kaiseki/machine/134/3873/

### INTERPRETATION — `REWARD CHANGES RESPONSIBILITY`

BIG does not suspend the player's learned control language and replace it with a passive cinematic. After the payout, the player acquires a new responsibility:

`preserve RT now → accept transition later → continue small-role/bonus reading`

Reward therefore changes the **meaning of stop order and timing**, not just the background or payout rate.

## 11. REG: skill is explicitly tiered

### PUBLISHED ANALYSIS

REG ends after 12 games or 8 small-role entries and has three published difficulty routes:
- Beginner: normal order / easy play.
- Intermediate: reverse-order method involving 3-Don aiming.
- Advanced: middle-first method, aiming ice on all reels with a 2-frame window, for max 112 medals when executed successfully.

The payout-rate table changes materially by which REG method is assumed. For setting 1, the widely published figures are approximately:
- base: 98.1%;
- intermediate complete strategy: 100.1%;
- advanced complete strategy: 102.0%.

Sources:
- https://1geki.jp/slot/s_shinhanabi/63/
- https://nana-press.com/kaiseki/machine/134/3989/

### INTERPRETATION — `SKILL HAS A LADDER, NOT A BINARY GATE`

This is an important contrast with a technical intervention that simply says `success or lose`.

The machine offers an explicit progression:

`I can complete REG safely → I can use a moderate aiming routine → I can chase maximum efficiency.`

This may reduce intimidation because the beginner can participate before mastering the hardest route.

But it also creates a real economic gap. Therefore:

`SKILL REWARD` and `SKILL TAX` coexist.

The Playtest Director must later test whether the visible choice feels empowering or whether the published 102% discourse makes a weaker player feel they are playing incorrectly.

The settings differ in bonus frequency, and some small-role / RT-hazard frequencies also carry setting differences. Examples from なな徹:

- some cherry frequencies differ;
- `花火チャレンジ` miss frequency is reported to become more common at higher settings;
- `花火GAME` miss frequency differs more strongly, around 1/13.4 (setting 1) to 1/9.5 (setting 6).

Sources:

- https://nana-press.com/kaiseki/machine/134/3872/

### INTERPRETATION — `SETTING READ IS EMBEDDED IN PLAY`

Setting inference is not a separate menu screen. The same events the player already watches for play value also accumulate statistical meaning over hundreds/thousands of games.

This creates a third time scale:
- immediate: `what role / reach eye is this stop?`
- medium: `when is the next bonus?`
- long: `what does the accumulated role / bonus / RT behavior imply about this machine?`

Deep play can therefore exist without adding modes.

## 13. 100G / 500G / 3-hour reconstruction

These are `INTERPRETATION` grounded in the sourced mechanics, not claims of direct human play.

### 13.1 First 100G

A beginner can survive with one basic left-reel aiming route and conditional middle-reel ice aim. The primary learning burden is not 3,500 reach eyes; it is:
1. protect cherry;
2. notice ice candidates;
3. understand when middle-reel aim is required;
4. learn that some unusual final shapes mean bonus;
5. discover that presentation changes can create role expectations.

The design therefore supports **progressive legibility**: basic economic correctness first, deeper pattern reading later.

### 13.2 500G bonus dry spell

At setting 1 combined bonus 1/156.0, 500G without a bonus is entirely plausible even though it is well above one mean interval. There is no CZ checkpoint or game-number rescue goal. The game must therefore survive by local reel events.

What remains during the dry spell:
- frequent wind bell / replay;
- cherry and ice handling;
- different first-stop routes;
- slip observation;
- blackout / flash / timing deviations;
- candidate-set narrowing;
- occasional near-discovery that is still grounded in real role rules rather than a fake progress meter.

The danger is equally clear: if the player does not yet understand these relationships, the same 500G can collapse into repetitive aiming with little visible reward.

### 13.3 Three hours

Three-hour depth can come from **perceptual expansion** rather than state expansion:
- more first-stop positions become usable;
- more slips become meaningful;
- more two-reel relations are recognized before third stop;
- bonus presence is discovered sooner;
- technical intervention becomes more reliable;
- setting inference accumulates.

The same physical three STOP buttons therefore can become a richer instrument over time.

This is qualitatively different from unlocking a stronger game state.

## 15. What the player is actually doing — Game & Reel model

Across the full loop, the player's work is not simply `press STOP three times`.

### Normal
`choose an aiming lens → protect small roles → compare aim to stop → maintain candidate set → resolve/deny role → discover bonus or continue`

### Bonus recognition
`notice reach eye / contradiction → identify bonus → line up bonus`

### BIG
`collect short payout → enter RT → use stop order/aiming to manage transition timing`

### REG
`choose skill level → execute repeatable aiming task → convert execution quality into payout`

### RT
`use presentation cue to decide whether to protect roles / avoid transition / accept transition → continue bonus/reel reading`

### Return to normal
`same reels, but player knowledge is richer`

This yields the Case Study 02 Game & Reel loop:

`AIM → CLASSIFY → RESOLVE → DISCOVER → EXECUTE → EXTEND / TRANSITION → RETURN WITH MORE KNOWLEDGE`

## 16. Reusable principles extracted

### 16.1 `FIRST STOP CAN BE A CLASSIFIER`
Do not script every STOP as escalating drama. A first stop can simply reduce the set of possible truths.

### 16.2 `AIMING ROUTE = INFORMATION LENS`
Alternative aim points are valuable when they reveal different relationships, not when they are only cosmetic.

### 16.3 `SLIP IS TEMPORAL INFORMATION`
The difference between aimed position and stopped position can communicate before the final result exists.

### 16.4 `REACH EYE = RULE RELATIONSHIP, NOT ART ASSET`
A reach eye is meaningful because it resolves role/control rules. Large counts should emerge combinatorially.

### 16.5 `DISCOVERY REWARD CAN PRECEDE PAYOUT`
Recognizing a bonus from reels can be rewarding before explicit announcement or medal payout.

### 16.6 `REWARD CAN CHANGE STOP RESPONSIBILITY`
BIG→RT changes what stop order and aim are for; it does not need to discard the learned reel grammar.

### 16.7 `SKILL SHOULD HAVE AN ENTRY RAMP`
Beginner/intermediate/advanced methods can let mastery increase agency without making the hardest execution a hard access gate.

### 16.8 `SETTING DEPTH CAN ACCUMULATE THROUGH ORDINARY EVENTS`
Long-term inference can be built into the same roles/reels used for moment-to-moment play.

### 16.9 `MASTERY EXPANDS PERCEPTION`
A deep reel game can make game 3000 perceptually richer than game 30 without adding a new mode.

### 16.10 `DRY SPELL QUALITY DEPENDS ON LOCAL TRUTH`
Without CZ/game-number milestones, a 500G drought must still contain truthful small-role, stop, slip and contradiction information. Fake progress would violate this lineage's strength.

## 17. Contradictions / cautions

1. **3,500 reach eyes do not prove accessibility.** Large combinatorial depth can intimidate a beginner if no safe basic route is legible.
2. **Full-strategy payout is not player-neutral.** 102% at setting 1 depends on execution assumptions and cannot be described as the beginner experience.
3. **Sparse state architecture does not mean simple implementation.** Deep reel control can be more structurally demanding than a state-machine-heavy game.
4. **Community control knowledge is not official disclosure.** Specialist findings must stay labeled FIELD / INFERRED unless independently documented.
5. **Nostalgia can amplify value.** We must extract the underlying stop/role grammar, not copy HANABI-specific symbols, flashes, sounds, reach eyes or branded traditions.
6. **RT pure-increase figures vary slightly by source/rounding.** This file uses the values reported by the named sources and preserves source-specific differences rather than forcing a false single exact value.
