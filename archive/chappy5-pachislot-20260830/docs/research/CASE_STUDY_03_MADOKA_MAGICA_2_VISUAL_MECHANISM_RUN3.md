## 1. Run 3 question — can the eyes return to HOME while the consequence remains open?

### SOURCED FACT

P-WORLD documents the normal left-BAR-first reel routine and the special watermelon branch requiring additional targeting. It also documents a 12G+3G `魔女の結界` CZ, a real BIG of about 150 coins, and a 50G+α ART. NANA PRESS further documents that CZ itself has a persistent frame-effect hierarchy (white → blue → yellow → red → rainbow) while the player continues playing.

Game & Reel Run 3 establishes that a physical role can be classified now while its consequence may remain unresolved for later games. Therefore the Visual question is not only `can the reel be seen?`; it is `can the player visually return to the reel/operation anchor while a previous consequence question remains alive?`

### DIRECT REAL-MACHINE PHOTO OBSERVATION

The cabinet maintains the same fixed vertical body map across states:

`upper LCD → recessed reel aperture → three STOP buttons → illuminated lower panel`.

The reel aperture is physically bounded by a dedicated bezel and does not disappear when the LCD owns the narrative foreground. The STOP row remains directly mapped left/middle/right beneath the three cylinders. The large contextual PUSH/touch interaction is visually and spatially separate from the three STOPs.

### INTERPRETATION

This fixed geometry gives the player a low-cost HOME anchor even while the LCD carries a delayed question. The consequence can remain visually alive above the reels without requiring the player to reconstruct where the next physical action occurs.

The design therefore separates two kinds of persistence:

- `QUESTION PERSISTENCE`: the screen may continue carrying uncertainty;
- `MOTOR-MAP PERSISTENCE`: reel and STOP locations remain stable.

### REUSABLE PRINCIPLE

`A DELAYED CONSEQUENCE IS CHEAPER WHEN THE MOTOR MAP DOES NOT MOVE WITH IT.`

`QUESTION PERSISTENCE SHOULD NOT REQUIRE MOTOR-MAP RECONSTRUCTION.`

## 2. Consequence-window occupancy is not the same as continuous attention claim

### SOURCED FACT

The CZ is documented as 12G exploration + 3G battle, and its frame color carries expectation information. ART is a persistent 50G+α state with stage changes that communicate internal opportunity. These are multi-game visual contexts rather than single-frame result flashes.

### DIRECT REAL-MACHINE PHOTO/FOOTAGE OBSERVATION

Available cabinet imagery and published test-play footage show that even when the LCD is in an active context, the lower reel/STOP zone remains visually exposed. The screen can carry animated foreground information without physically covering the reels.

### INTERPRETATION

A multi-game state need not claim maximum visual attention every frame. It can retain a persistent context marker while permitting lower-demand intervals in which the player can primarily operate/read reels.

For Run 3, distinguish:

- `CONTEXT PRESENT`: the state remains visually identifiable;
- `ATTENTION CLAIM ACTIVE`: animation/color/motion asks for immediate visual processing;
- `ATTENTION RELEASE`: state context remains but the player can safely return primary gaze to reels/operation.

This distinction matters because a documented 12G+3G CZ should not be counted as 15 games of uninterrupted maximum visual demand merely because the CZ graphics remain on screen.

### REUSABLE PRINCIPLE

`STATE PERSISTENCE ≠ ATTENTION PERSISTENCE.`

`A GOOD MULTI-GAME VISUAL STATE CAN REMAIN LEGIBLE WHILE RELEASING PRIMARY GAZE BETWEEN DECISION MOMENTS.`

## 3. What happens when a new reel event arrives before the old question closes?

### SOURCED FACT

P-WORLD documents that rare roles can lead to BIG, CZ or ART-related outcomes while the normal reel routine continues. NANA PRESS documents CZ expectation changing by established role and by visible frame-effect level.

### INTERPRETATION

This produces possible `QUESTION OVERLAP`: a previous role's consequence is still being evaluated while a new role appears on the physical reels.

The cabinet has an architectural advantage here: the old question can remain represented on the LCD while the new physical evidence appears in a separate recessed plane. This is not proof that every actual presentation branch handles overlap optimally; it is a structural capacity visible in the cabinet.

A failure pattern would be:

`old consequence animation occupies all foreground attention → new role stops → player must read reels while old screen motion still claims priority → new consequence is added before old question closes`.

A lower-cost pattern is:

`old question remains contextually marked → reel event becomes locally legible → player classifies it → screen reprioritizes only when the new consequence needs interpretation`.

### REUSABLE PRINCIPLE

`WHEN QUESTIONS OVERLAP, SEPARATE WHERE OLD CONTEXT LIVES FROM WHERE NEW EVIDENCE ARRIVES.`

`VISUAL OVERLAP SHOULD PRESERVE EVIDENCE ORDER, NOT MERELY ADD MORE FOREGROUND MOTION.`

## 4. Reel re-acquisition after STOP3

### DIRECT REAL-MACHINE PHOTO OBSERVATION

The LCD is large and bright, but the reel aperture is immediately below it with strong border contrast; the STOP row directly continues the three-column reel mapping. The eye therefore needs a short vertical movement rather than a lateral search to return from screen interpretation to physical evidence.

### INTERPRETATION

The relevant metric is not LCD area but `HOME RE-ACQUISITION PATH`:

`LCD consequence region → reel aperture → exact symbol landmark → matching STOP column`.

The stable border, recess and three-column alignment make this path repeatable. Run 2 already established this qualitatively; Run 3 connects it to delayed consequence windows: the path remains available even while the previous question is not fully resolved.

### REUSABLE PRINCIPLE

`RE-ACQUISITION QUALITY = SHORT GAZE PATH + STABLE BORDER + STABLE COLUMN MAPPING + LOW SEARCH AMBIGUITY.`

`A SCREEN-FIRST MACHINE SHOULD PROTECT THE PATH BACK TO PHYSICAL EVIDENCE, NOT ONLY THE EVIDENCE ITSELF.`

## 5. REST visual under a live question

### DIRECT REAL-MACHINE PHOTO OBSERVATION

The cabinet's static identity remains visible without large moving mechanisms: top landmark, dark upper side fields, luminous side forms, landscape LCD, recessed reels, STOP row and broad illuminated lower panel. In ordinary photographs the machine remains identifiable even when no dramatic motion is captured.

### INTERPRETATION

REST should not be defined only as `normal state with no pending event`. In a machine with delayed consequence resolution, there is also a useful intermediate condition:

`QUESTION STILL OPEN + PLAYER PHYSICALLY BACK HOME`.

This is a **conditional REST** state. The machine can retain one expectation marker while releasing most motion/brightness claims and allowing the player to resume the physical loop.

### REUSABLE PRINCIPLE

`REST CAN EXIST INSIDE AN OPEN QUESTION.`

`A PERSISTENT EXPECTATION MARKER SHOULD COST LESS ATTENTION THAN THE EVENT THAT CREATED IT.`

This is a direct Visual complement to Game & Reel's distinction between role-classification latency and consequence-resolution latency.

## 6. CZ frame color as persistent context, not proof of constant motion

### SOURCED FACT

NANA PRESS documents CZ frame-effect color progression `white < blue < yellow < red < rainbow` as expectation information.

### INTERPRETATION

A frame-level state marker is efficient because it can persist spatially at the perimeter while the central task area continues to be used for play. The transferable lesson is the information architecture only; the specific color order, shape and artwork are protected machine-specific presentation and are not reusable.

### REUSABLE PRINCIPLE

`PERSISTENT STATE INFORMATION IS CHEAPEST WHEN IT HAS A STABLE ADDRESS.`

`PERIPHERAL CONTEXT CAN PRESERVE STATE WHILE CENTRAL VISION RETURNS TO ACTION.`

## 7. BONUS / ART return and visual HOME

### SOURCED FACT

P-WORLD documents BIG as a real approximately-150-coin reward and ART as a persistent 50G+α state. NANA PRESS documents ART stage variation. BONUS-end touch/PUSH interaction is also documented, meaning the large screen can temporarily become an input/information surface.

### INTERPRETATION

The return requirement after temporary foreground states is stronger than `show ART graphics again`. The player must rapidly recover:

1. reel location;
2. STOP ownership/order responsibility;
3. persistent-state display location;
4. remaining-value context.

Because the physical reel/STOP anchors do not move, the visual system can change the screen's meaning without changing the player's body map.

### REUSABLE PRINCIPLE

`A VISUAL RETURN IS COMPLETE ONLY WHEN THE PLAYER KNOWS WHERE TO LOOK, WHAT TO TOUCH, AND WHICH PERSISTENT VALUE IS STILL ALIVE.`

## 8. Material/depth claims — interpretation only

### DIRECT REAL-MACHINE PHOTO OBSERVATION

The reel surface visibly sits behind a front aperture. Top-center and side components transmit colored light. Some trim appears specular/metallic; dark upper fields appear grille-like.

### INTERPRETATION

The reel cavity likely gains readability from real front-to-back separation and internal shadow. Light-transmitting perimeter parts likely use translucent/light-guiding molded components. Metallic-looking trim may be plated or otherwise reflective. Dark upper fields may have acoustic/ventilation roles.
