## Central integration

`SAFE VISUAL AUTOMATICITY = STABLE OWNERSHIP + PERSISTENT EVIDENCE + LOW FALSE INTERRUPTION + TIMELY RULE-BEARING REOPENING + CLEAN RELEASE`.

The key distinction is:

`RESPONSIBILITY REOPENING`
= a visible/mechanical change matters because it changes the next required action, current inference, active state procedure or causal attribution.

versus

`DECORATIVE NOVELTY`
= a salient change attracts attention but does not change responsibility.

Run 6 concludes that novelty alone must not earn interruption authority.

## Main principles

- `RESPONSIBILITY, NOT NOVELTY, EARNS INTERRUPTION AUTHORITY.`
- `CHANGE THE STATUS OF THE EVIDENCE SURFACE BEFORE ADDING A SECOND EVIDENCE SURFACE.`
- `A BRANCH CUE IS STRONGEST WHEN IT CHANGES THE MEANING OF WHAT THE PLAYER IS ALREADY LOOKING AT.`
- `A RESPONSIBILITY CUE THAT ARRIVES AFTER THE REQUIRED ACTION IS FEEDBACK, NOT GUIDANCE.`
- `RE-ENGAGEMENT LATENCY IS PART OF VISUAL/MECHANICAL LEGIBILITY.`
- `A STOPPED REEL CAN ALSO BE AN ATTENTION-REOPENING SURFACE.`
- `STABLE HARDWARE SUPPORTS FAST RE-ENGAGEMENT BECAUSE MOTOR OWNERSHIP DOES NOT MOVE.`
- `TEMPORARY TASK PRIORITY SHOULD EXPIRE CLEANLY.`
- `STATE CHANGE SHOULD CHANGE RESPONSIBILITY BEFORE IT CHANGES THE PLAYER'S PHYSICAL MAP.`
- `STATIC IDENTITY CONTRAST != PER-GAME ATTENTION CLAIM.`
- `HALL PRESENCE CAN BE CONTINUOUS; GAMEPLAY INTERRUPTION AUTHORITY SHOULD BE SCARCE.`
- `THE PLAYER SHOULD NOT HAVE TO INSPECT THE WHOLE CABINET TO KNOW WHETHER RESPONSIBILITY CHANGED.`
- `REOPEN ATTENTION LOCALLY BEFORE REROUTING ATTENTION GLOBALLY.`
- `FALSE INTERRUPTION SPENDS FUTURE INTERRUPTION AUTHORITY.`
