- `THE MACHINE SHOULD BECOME QUIET THROUGH PREDICTABILITY, NOT THROUGH PLAYER RESIGNATION.`

- `LOW-MONITORING REST IS A MACHINE PROPERTY ONLY WHEN THE PLAYER CAN STILL DETECT AND ATTRIBUTE LEGITIMATE CHANGE.`
