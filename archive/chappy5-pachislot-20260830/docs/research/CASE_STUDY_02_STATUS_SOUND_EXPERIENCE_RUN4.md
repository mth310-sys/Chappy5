## Run 4 delta

Run 4 does not create an original audio concept. It studies audio return-path geometry, reward music as session memory, RT BGM as an anomaly reference, technical-intervention feedback without punitive overload, and false listening duty across long repeated play.

New reusable research principles:

- `AUDIO ATTENTION CLAIMS SHOULD HAVE A SHORT SEMANTIC RETURN PATH.`
- `THE PLAYER SHOULD NOT HAVE TO KEEP LISTENING AFTER THE LISTENING TASK IS RESOLVED.`
- `AUDIO RETURN COST IS SEMANTIC, NOT ONLY TEMPORAL.`
- `AUDIO CAN ENCODE SESSION MEMORY WITHOUT CREATING A NEW UPPER STATE.`
- `REWARD MUSIC MAY REPORT HISTORY, NOT ONLY PRESENT INTENSITY.`
- `STATE LADDER AND MUSIC LADDER ARE NOT THE SAME THING.`
- `SUSTAIN AUDIO CAN DOUBLE AS AN ANOMALY REFERENCE.`
- `WHEN FAILURE ALREADY COSTS VALUE, AUDIO SHOULD PRIORITIZE CLARITY OVER PUNISHMENT.`
- `AUDIO PHASE CHANGE DOES NOT REQUIRE CONTROL-SURFACE CHANGE.`
- `AUDIO SPARSITY REQUIRES NON-AUDIO INFORMATION WEALTH.`
- `GOOD AUDIO DOES NOT ONLY ESCALATE AND RELEASE; IT RE-ANCHORS.`
- `THE NORMAL MACHINE MUST BECOME AUDIBLE AGAIN AFTER A SPECIAL DUTY ENDS.`
- `AMBIGUITY IS ENGAGING ONLY WHEN THE PLAYER CAN RESOLVE IT; OTHERWISE IT BECOMES VIGILANCE DEBT.`
- `LONG-SESSION AUDIO QA SHOULD COUNT FALSE REORIENTATIONS, NOT ONLY LOUD EVENTS.`
- `DO NOT DERIVE PHYSICAL AUDIO MIX VALUES FROM ONLINE VIDEO.`

## Key sourced delta

Published BIG documentation shows BGM changes tied not only to the current BIG but to recent session history: RT-linked second/third BIGs, cumulative payout thresholds within a 100G continuity rule, and a first-game-after-RT BIG. This supports treating reward music as session-memory feedback rather than assuming every musical change represents a new upper gameplay state.

Published RT documentation continues to confirm `BGM停止でボーナス` in both 花火チャレンジ and 花火GAME, so continuity itself remains a gameplay-relevant reference surface.

Published REG documentation confirms meaningful payout consequences for success/failure by difficulty route. Exact proprietary failure-audio behavior remains unresolved; the study does not infer it.
