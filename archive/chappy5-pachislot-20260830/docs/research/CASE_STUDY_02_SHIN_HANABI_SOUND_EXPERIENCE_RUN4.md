## 0. Run purpose

Run 4 follows Machine Run 3, Game & Reel Run 3 and Visual & Mechanism Run 4. It does not create original Chappy5 sound concepts, assets, code or prototypes.

The new focus is **audio return-path geometry and session memory**:

- how sound claims attention and then returns the player to reel reading;
- how reward music can encode recent play history without an AT upper-state ladder;
- how technical-intervention feedback can remain informative without turning misses into punitive spectacle;
- how repeated-play sound density differs by phase while preserving one stable physical/reel interaction.

Evidence labels remain:
- `SOURCED FACT`
- `DIRECT OBSERVATION`
- `INTERPRETATION`
- `REUSABLE PRINCIPLE`
- `UNRESOLVED`

No melody, sample, signature SE, arrangement or protected audio is reproduced.

## 2. Visual Run 4's short gaze-return path has an audio equivalent

Visual Run 4 established:

`ATTENTION CLAIMS SHOULD HAVE A SHORT RETURN PATH TO THE PRIMARY PRECISION SURFACE.`

and:

`THE PLAYER SHOULD NOT HAVE TO SEARCH FOR THE NORMAL VIEW AFTER THE TASK ENDS.`

### INTERPRETATION

The audio equivalent is not simply “make cues short.” It is that the player should be able to return to ordinary reel listening immediately after the cue has served its function.

A sound can create a long return path even when its duration is short if it leaves unresolved semantic duty: “Do I still need to listen for another cue?” Conversely, a state BGM can be long but low-duty if its continuation is predictable and the player does not have to consciously parse it each game.

### REUSABLE PRINCIPLES

- `AUDIO ATTENTION CLAIMS SHOULD HAVE A SHORT SEMANTIC RETURN PATH.`
- `THE PLAYER SHOULD NOT HAVE TO KEEP LISTENING AFTER THE LISTENING TASK IS RESOLVED.`
- `AUDIO RETURN COST IS SEMANTIC, NOT ONLY TEMPORAL.`

This extends Run 3's `AUDIO PRIORITY SHOULD EXPIRE WHEN THE PLAYER'S RESPONSIBILITY EXPIRES.`

## 3. BIG music can encode session history, not only current state intensity

### SOURCED FACT

Published BIG documentation lists distinct BGM conditions for:
- ordinary first BIG;
- a second BIG while still inside the RT-linked sequence;
- a third BIG while still inside that sequence;
- a special one-bet/right-downward bonus alignment condition;
- BIG after cumulative payout reaches 400+ while the sequence remains within a 100G boundary;
- BIG after cumulative payout reaches 800+ under the same 100G continuity rule;
- a BIG on the first game after RT, with different legacy references depending on BIG type.

Sources:
- https://1geki.jp/slot/s_shinhanabi/62/
- https://nana-press.com/kaiseki/machine/134/4241/

Official/distribution soundtrack metadata separately confirms dedicated tracks for the two BB types, 花火チャレンジ, 花火GAME, RB and RB all-high-skill completion.

Sources:
- https://music.apple.com/jp/song/1573550197
- https://open.spotify.com/track/4INsbOT2W7pXATSEhHaXu6

### INTERPRETATION

This is a different escalation model from “higher state = louder/newer soundtrack.” The music can act as **memory of what has just happened across multiple rewards**.

The player may hear a changed reward context because:

`current BIG + recent RT/bonus history + accumulated outcome + elapsed games`

crossed a rule boundary.

Therefore music can increase significance without inventing a new gameplay state.

### REUSABLE PRINCIPLES

- `AUDIO CAN ENCODE SESSION MEMORY WITHOUT CREATING A NEW UPPER STATE.`
- `REWARD MUSIC MAY REPORT HISTORY, NOT ONLY PRESENT INTENSITY.`
- `TEMPORAL CONTEXT CAN CREATE AUDIO NOVELTY WITHOUT PER-GAME ESCALATION.`
- `STATE LADDER AND MUSIC LADDER ARE NOT THE SAME THING.`

No protected legacy melody or condition should be copied into an original machine; only the abstract information-role is reusable.

## 4. RT BGM has two simultaneous duties: sustain and anomaly detection

### SOURCED FACT

花火チャレンジ is maximum 20G after BB and uses JAC-IN avoidance to extend RT. 花火GAME is 20G after JAC IN. Published material explicitly says BGM stopping signals a bonus in both phases.

Sources:
- https://1geki.jp/slot/s_shinhanabi/64/
- https://1geki.jp/slot/s_shinhanabi/65/

### INTERPRETATION

Run 3 already identified BGM as an interruptible state surface. Run 4 adds that this creates **dual duty**:

1. while present, BGM supplies state continuity and phase atmosphere;
2. because its presence becomes expected, disappearance becomes a low-addition/high-information event.

This resembles a measuring reference: stability creates the sensitivity of interruption.

### REUSABLE PRINCIPLES

- `SUSTAIN AUDIO CAN DOUBLE AS AN ANOMALY REFERENCE.`
- `THE MORE TRUSTED THE CONTINUITY, THE LESS EXTRA AUDIO IS NEEDED TO SIGNAL ITS BREAK.`
- `AUDIO HEADROOM CAN BE CREATED BY RELIABLE CONTINUITY, NOT ONLY LOW VOLUME.`

## 5. Technical-intervention audio must distinguish information from punishment

### SOURCED FACT

REG offers beginner, intermediate and advanced procedures. Published tables show meaningful payout differences between success and failure depending on procedure; advanced play can return 15枚 on success, while certain misses return lower amounts. Published documentation also identifies local successful stop forms, and existing Case Study 02 evidence records a success sound plus a separate all-high-skill mastery jingle.

Sources:
- https://1geki.jp/slot/s_shinhanabi/63/
- https://nana-press.com/kaiseki/machine/134/3989/
- official soundtrack metadata / `RB ALL神技` track listing

### INTERPRETATION

A miss already has game/economic consequence. A strong dedicated negative sound could add a second punishment channel that is not necessary for learning.

The minimum useful feedback chain is:

`input accepted → execution outcome becomes legible → payout consequence becomes legible`

The machine does not need to humiliate the miss for the player to understand it.

### REUSABLE PRINCIPLES

- `WHEN FAILURE ALREADY COSTS VALUE, AUDIO SHOULD PRIORITIZE CLARITY OVER PUNISHMENT.`
- `NEGATIVE FEEDBACK INTENSITY SHOULD NOT EXCEED THE INFORMATION NEEDED TO CORRECT THE NEXT ACTION.`
- `SUCCESS FEEDBACK MAY CONFIRM AGENCY; FAILURE FEEDBACK MUST NOT TURN SKILL PRACTICE INTO AVERSION.`
- `MISSING A SUCCESS CUE CAN SOMETIMES BE LESS FATIGUING THAN ADDING A FAILURE STINGER.`

The last point remains an interpretation because exact proprietary miss-audio behavior is not safely established.

## 6. Repeated play contains multiple audio-density regimes without changing the control surface

### SOURCED FACT

A published 24-minute trial/video index explicitly moves through:
- normal play;
- presentation/reach-eye examples;
- REG advanced procedure;
- REG intermediate procedure;
- BIG;
- 花火チャレンジ / 花火GAME;
- delayed-start examples.

Source:
- https://1geki.jp/slot/s_shinhanabi/7/

### DIRECT OBSERVATION — EVIDENCE-LIMITED

The indexed structure is useful as a phase map because it demonstrates that the same machine is discussed/played across ordinary reel work, technical-intervention reward phases and RT without introducing an AT/CZ upper-state ladder.

This run does **not** infer exact dB, EQ, speaker response, loop seam or fatigue from compressed online video.

### INTERPRETATION

The important experience change is therefore not necessarily “more layers each time.” It can be:

`routine operation → temporary anomaly → reward music → technical task feedback → RT sustain → anomaly interruption → return`

Different phases can allocate listening effort differently while the lever and three STOPs remain stable.

### REUSABLE PRINCIPLES

- `AUDIO PHASE CHANGE DOES NOT REQUIRE CONTROL-SURFACE CHANGE.`
- `DIFFERENT PHASES MAY CHANGE LISTENING DUTY MORE THAN SOUND COUNT.`
- `A REWARD PHASE SHOULD NOT ERASE THE AUDIBILITY OF THE PLAYER'S REEL/STOP RESPONSIBILITY.`

## 7. Sparse sound works only when ordinary physical/reel information remains rich

### SOURCED FACT

Normal presentation has a comparatively small documented family, while the machine's reel system contains extensive reach-eye/stop-control information and technical procedures. Game & Reel Run 3 also documents that ordinary small roles and different stop orders continue to carry payout, inference and session-information value.

Repository sources:
- `docs/research/CASE_STUDY_02_SHIN_HANABI_GAME_REEL_RUN3.md`
- `docs/research/CASE_STUDY_02_STATUS_GAME_REEL_RUN3.md`

### INTERPRETATION

A sparse soundtrack is sustainable because the player has something else meaningful to perceive. If ordinary STOPs were semantically empty, reducing sound would simply expose emptiness.

This matches Playtest Run 3:

`SPARSITY IS AN AMPLIFIER OF UNDERLYING GAME QUALITY, NOT A SUBSTITUTE FOR IT.`

### REUSABLE PRINCIPLES

- `AUDIO SPARSITY REQUIRES NON-AUDIO INFORMATION WEALTH.`
- `SILENCE IS VALUABLE WHEN IT RETURNS PERCEPTUAL BANDWIDTH TO A MEANINGFUL TASK.`
- `DO NOT REMOVE AUDIO MERELY TO APPEAR RESTRAINED; REMOVE IT WHEN ANOTHER PLAYER-READABLE SIGNAL DESERVES THE BANDWIDTH.`

## 8. Run 4 attention model: CLAIM → RESOLVE → RELEASE → RE-ANCHOR

### INTERPRETATION

Run 3 described opening/closing responsibility. Visual Run 4 adds explicit return-path design. Sound Run 4 combines them:

`ROUTINE → AUDIO CLAIM → PLAYER RECLASSIFIES → INFORMATION RESOLVES → AUDIO RELEASE → RE-ANCHOR TO REEL/STOP ROUTINE`

The missing step in many overloaded presentations is `RE-ANCHOR`. A cue ends, but the soundscape remains so dense that the player never clearly regains the ordinary machine.

### REUSABLE PRINCIPLES

- `GOOD AUDIO DOES NOT ONLY ESCALATE AND RELEASE; IT RE-ANCHORS.`
- `RE-ANCHORING IS PART OF STATE TRANSITION QUALITY.`
- `THE NORMAL MACHINE MUST BECOME AUDIBLE AGAIN AFTER A SPECIAL DUTY ENDS.`

Cross-modal equivalent with Visual Run 4:

- Visual: normal view should be easy to find again.
- Sound: normal listening baseline should be easy to recognize again.

## 9. Long-session fatigue update: false listening duty

### INTERPRETATION

Playtest Run 3 identified `FALSE VIGILANCE`: players can appear engaged while actually monitoring constantly because they fear missing a required action.

Sound has the same risk. If many routine sounds are designed as near-alerts, players may remain in a state of “was that meaningful?” even when no action is required.

Run 4 adds:

`FALSE LISTENING DUTY = FREQUENT AMBIGUOUS CUES × COST OF MISSING THEM`

### REUSABLE PRINCIPLES

- `DO NOT MAKE ROUTINE AUDIO SOUND LIKE AN ALERT UNLESS MISSING IT HAS A REAL GAMEPLAY COST.`
- `AMBIGUITY IS ENGAGING ONLY WHEN THE PLAYER CAN RESOLVE IT; OTHERWISE IT BECOMES VIGILANCE DEBT.`
- `LONG-SESSION AUDIO QA SHOULD COUNT FALSE REORIENTATIONS, NOT ONLY LOUD EVENTS.`

This is a reusable QA model, not a measured claim about 新ハナビ's exact human fatigue.

## 10. Speaker / low-frequency boundary

### SOURCED FACT

Current online sources establish authored BGM/SE/state roles but do not safely establish the exact driver count, crossover, enclosure path, SPL, cabinet transfer or seated low-frequency response of the real machine.

### INTERPRETATION

Because this case study is specifically about reel-reading preservation, it would be unsafe to infer that low-frequency energy is absent or dominant from web video. Camera AGC, phone microphones, hall noise and upload compression distort this evidence.

### REUSABLE PRINCIPLE

`DO NOT DERIVE PHYSICAL AUDIO MIX VALUES FROM ONLINE VIDEO.`

Physical speaker/low-frequency questions remain `UNRESOLVED` until real-machine measurement or sufficiently authoritative hardware documentation exists.
