## Central finding

This run answers Machine Run 7's question about how visible Game/Reel evidence can close a temporary responsibility without requiring a redundant "all clear" presentation.

Central rule:

`GOOD REEL CLOSURE = SUFFICIENT EVIDENCE THAT THE OLD DUTY NO LONGER APPLIES + LEGIBLE EVIDENCE OF WHAT ACTION LAW APPLIES NEXT`

Short form:

`CLOSE THE QUESTION, THEN MAKE THE NEXT GRAMMAR OBVIOUS.`

Game/Reel closure is not an event tag. It is a reduction of which action laws can still legitimately govern the next STOP.

## Main principles

- `CANDIDATE EXHAUSTION CAN CLOSE A DUTY WITHOUT AN ALL-CLEAR SIGNAL.`
- `CLOSE DUTIES AS EARLY AS EVIDENCE ALLOWS.`
- `ROLE FULFILLMENT AND ROLE DENIAL ARE DIFFERENT CLOSURE OPERATORS.`
- `ONE DUTY CLOSING CAN OPEN ANOTHER.`
- `CLOSURE IS RESPONSIBILITY-SPECIFIC, NOT A GLOBAL CALM FLAG.`
- `ANSWER FOUND != ROUTINE RESTORED.`
- `A STATE-SPECIFIC DUTY SHOULD CLOSE WHEN A LEGIBLE STATE TRANSITION INVALIDATES THE OLD ACTION LAW.`
- `RETURN COST FALLS WHEN SPECIAL PLAY MODIFIES ONLY A SUBSET OF THE BASE GRAMMAR.`
- `SKILL ATTEMPTS NEED EPISODIC CLOSURE.`
- `THE END CONDITION SHOULD BE PART OF THE ACTION'S EVIDENCE CHAIN, NOT HIDDEN IN INTERNAL STATE.`
- `MASTERY SHOULD COMPRESS BOTH OPENING AND CLOSING: EXPERTS SHOULD CARRY FEWER DEAD RESPONSIBILITIES.`

## Why this changes the previous model

Machine Run 7 separated objective responsibility resolution from Human attention-set release. Game/Reel Run 7 now provides the reel-side proof operators that can support closure:

1. candidate exhaustion;
2. role fulfillment;
3. role denial / contradiction;
4. state-transition proof;
5. bounded skill-attempt result;
6. next-action grammar recognition.

A local role can close before the whole game returns to low-monitoring rest. Therefore closure must be tracked per responsibility, not as one global "special state ended" bit.
