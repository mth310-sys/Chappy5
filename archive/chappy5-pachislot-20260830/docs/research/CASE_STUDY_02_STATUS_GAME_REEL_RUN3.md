## New research

Run 3 adds these evidence-backed Game/Reel deltas:

1. `3BET = 5 valid lines`, `1BET = 2 valid lines` in published 2021 新ハナビ material, making BET/line geometry part of reel grammar rather than only cost.
2. Visible payout categories are separated from internal role / bonus-trigger families and from player inference.
3. Setting-1 published frequencies show that a 500G no-bonus span can still contain roughly 65 wind bells, 30 cherries, 10 ice and 68 normal replays in expectation; reward drought and reel-event drought are therefore distinct QA hypotheses.
4. Common small-role procedure opens additional aiming duty only when the partial stop form requires it.
5. Run 2's `STOP ORDER = QUERY ORDER` is extended to `STOP ORDER = INFORMATION ORDER + RESPONSIBILITY ORDER`.
6. Bonus discovery and bonus-type discrimination are treated as two consecutive reel problems rather than announcement = immediate entry.
7. BIG / REG / 花火チャレンジ / 花火GAME redistribute the same three STOPs into different control contracts without requiring new physical input devices.
8. Setting inference and execution skill are preserved as separate information/economic axes.
9. Long-session mastery is modeled as attention redistribution across the same three STOPs, not permanent maximum attention.
10. Post-reward return can reset machine state while preserving accumulated player knowledge.

## Current reusable principles added

- `IF BET CHANGES VALID LINES, BET IS PART OF REEL GRAMMAR, NOT ONLY COST.`
- `PAYOUT, INTERNAL CAUSE, AND PLAYER INFERENCE ARE THREE DIFFERENT LAYERS.`
- `DROUGHT QUALITY MUST BE TESTED AFTER REMOVING PAYOFF, NOT AFTER REMOVING ALL REEL EVENTS.`
- `FREQUENT LOW-PRESTIGE EVENTS CAN KEEP THE RULE MODEL ACTIVE DURING REWARD ABSENCE.`
- `EVENT COUNT != QUESTION QUALITY.`
- `GOOD TECHNICAL DEPTH CAN BE CONDITIONAL: ROUTINE SAFE PLAY SHOULD OPEN EXTRA DUTY ONLY WHEN THE REEL STATE REQUIRES IT.`
- `STOP ORDER = INFORMATION ORDER + RESPONSIBILITY ORDER.`
- `ALTERNATE STOP ORDERS ARE MEANINGFUL WHEN THEY CHANGE BOTH WHAT IS LEARNED AND WHAT THE PLAYER MUST DO NEXT.`
- `REWARD DISCOVERY CAN CREATE A NEW REEL QUESTION BEFORE REWARD ENTRY.`
- `PHASE CHANGE CAN BE REAL WHEN THE CONTROL CONTRACT CHANGES, EVEN IF THE HARDWARE DOES NOT.`
- `SETTING EVIDENCE AND EXECUTION QUALITY MUST BE LOGGED SEPARATELY.`
- `PLAYER SKILL SHOULD NOT BE MISTAKEN FOR CONTROL OVER RANDOM OUTCOME.`
- `MASTERY SHOULD CHANGE THE DISTRIBUTION OF ATTENTION ACROSS THE SAME THREE STOPS.`
- `POST-REWARD RETURN CAN RESET MACHINE STATE WITHOUT RESETTING PLAYER KNOWLEDGE.`
