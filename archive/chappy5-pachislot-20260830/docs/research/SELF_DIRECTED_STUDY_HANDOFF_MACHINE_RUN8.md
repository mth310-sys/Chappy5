## Central integration

Playtest & QA Run 8 showed that quiet behavior is not proof of closure. Machine Run 8 therefore replaces a global CALM/ALERT reading of the Attention Contract with local responsibility lifecycles over a compressible baseline.

Research abstraction:

`RESPONSIBILITY_BINDING = {QUESTION, EVIDENCE_SOURCE, ACTION_LAW, END_CONDITION, REOPEN_CONDITION}`

This is not an implementation schema.

Central rules:

`CLOSURE = SELECTIVE RETIREMENT OF A BINDING, NOT GLOBAL CALM.`

`HEALTHY CLOSURE RETIRES THE OLD DUTY WITHOUT RETIRING THE CHANNEL.`

`TRUSTWORTHY INVISIBILITY = LOW BASELINE MONITORING + PRESERVED LEGITIMATE REOPENABILITY.`

A duty can close while another remains open. A later legitimate deviation must still be able to earn attention authority.

## Revised research-only Attention Contract

Stable layer:

`STABLE BASELINE -> MONITORING COMPRESSION`

Local lifecycle, zero or more at once:

`LEGITIMATE DEVIATION -> BINDING OPEN -> SOURCE AUTHORITY -> ACTION / EVIDENCE -> LOGICAL RESOLUTION -> CLOSURE EVIDENCE -> BINDING RETIRED`

Then:

`ROUTINE RE-CHUNKING + TRUST UPDATE`

Other bindings may remain open; later deviations may open new ones.
