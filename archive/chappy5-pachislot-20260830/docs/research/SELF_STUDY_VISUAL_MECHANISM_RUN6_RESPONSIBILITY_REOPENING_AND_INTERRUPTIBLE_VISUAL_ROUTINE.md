This run answers Game & Reel Run 6's handoff:

> Which real-machine visual/mechanical conditions let a player stay in a low-monitoring routine but promptly recognize when role duty, inference duty, state duty or causal duty genuinely reopens?

---

# 1. Topic reason

Game & Reel Run 6 established that expert reel play is not continuous attention and not continuous automation. It is a conditional routine that must be interruptible when the current evidence changes what the player must do or infer.

Visual & Mechanism therefore has a narrower responsibility than “make important things stand out.” The stronger question is:

**Can the physical-looking machine preserve a stable low-duty scene while making a responsibility boundary legible before the next consequential action, without training the player to inspect every lamp, panel or animation every game?**

This is a visual/mechanical interruption problem, not an effect-intensity problem.

---

# 2. Prior unknown

Previous Visual runs established:

- the reel aperture is a precision/evidence surface;
- stopped reels can serve as external working memory;
- hand plane and evidence plane should remain spatially separable;
- partial-stop evidence must persist through STOP1 → STOP2 → STOP3;
- cabinet geometry is a stable causal reference frame;
- visual simplification must not erase hypothesis-eliminating evidence.

Still unresolved was how attention should **reopen** after successful monitoring compression.

Specific questions:

1. Can responsibility reopen through a change to an existing surface rather than a new overlay?
2. Which kinds of physical visual change are early enough to interrupt an automatic STOP chunk?
3. How do we distinguish a branch cue from decorative novelty?
4. Can a strong hall identity remain visually active without becoming a per-game monitoring obligation?
5. What must remain stable so a player can compare “ordinary” and “deviant” states without consciously checking the whole cabinet?

# 3. Investigation

## 3.1 Real-machine anchor: cabinet hierarchy stays stable while state meaning changes

### SOURCED FACT
Universal Entertainment's official 新ハナビ product page identifies the machine as the Archer cabinet and explicitly positions it as a bonus + RT machine. The manufacturer says the 5号機ハナビ game flow is inherited while adding a mini-LCD `たまやチャレンジ`, changed reel arrangement / blackout rules and level-based REG technical intervention.

Source:
- https://www.universal-777.com/product/slot/shin_hanabi/
- https://www.universal-777.co.jp/news/20210510001505/

### DIRECT OBSERVATION
Official product imagery and completed Case Study 02 front/oblique references show a stable vertical body grammar:

- upper identity / illumination mass;
- central recessed three-reel work surface;
- compact secondary information/display region;
- projecting operation deck;
- fixed horizontal three-STOP row;
- broad lower identity panel.

The cabinet does not physically transform into a new anatomy for ordinary role questions, bonus discovery, technical intervention or RT. The **same physical surfaces change responsibility**.

### INTERPRETATION
This supports:

`STABLE BODY + TEMPORARY SURFACE REASSIGNMENT > CONSTANT ANATOMICAL ESCALATION`

A low-monitoring player can retain a learned scene map because the cabinet's ownership structure does not reset whenever game responsibility changes.

### UNRESOLVED
Exact 新ハナビ cabinet dimensions, reel-window depth, material chemistry, internal lamp construction, glare, STOP travel/force and speaker topology remain unverified without physical measurement.

## 3.2 Blackout is a change in the condition of an existing evidence field

### SOURCED FACT
Published analysis documents the normal blackout/消灯 system as changing with each reel stop and carrying role-denial information. Typical documented relations include:

- no blackout: replay denied;
- one blackout: miss/ice denied;
- two blackouts: wind-bell/ice denied;
- three blackouts: wind-bell denied.

The exact role table must remain source-bounded; the reusable point here is that blackout count is tied to STOP progression and inference.

Sources:
- https://pachiseven.jp/articles/detail/14698
- https://p.hisshobon.jp/machine/3661/1/83312

### INTERPRETATION
Blackout is mechanically/visually important because it does not require the player to relocate gaze to a new modal panel. It modifies the condition of a surface already adjacent to the reel evidence.

That yields:

`RESPONSIBILITY CAN REOPEN BY ALTERING THE STATUS OF THE CURRENT WORK SURFACE.`

This is stronger than “use a flash.” The change is useful because it participates in the same STOP-indexed rule system the player is already reading.

### REUSABLE PRINCIPLE
- `CHANGE THE STATUS OF THE EVIDENCE SURFACE BEFORE ADDING A SECOND EVIDENCE SURFACE.`
- `A BRANCH CUE IS STRONGEST WHEN IT CHANGES THE MEANING OF WHAT THE PLAYER IS ALREADY LOOKING AT.`

### MISUSE WARNING
Do not copy 新ハナビ's blackout patterns, lamp choreography, art or correspondence table into an original machine. The reusable principle is about surface ownership and conditional meaning only.

## 3.3 Responsibility cue versus decorative novelty

### SOURCED FACT
新ハナビ combines normal-play deviations such as blackout, reel flash and delayed reel-start sound with reel-based role/reach-eye inference. Strategy documentation treats these deviations as rule-bearing because their combination with stopped results changes what roles or bonus possibilities remain.

Sources:
- https://pachiseven.jp/articles/detail/14698
- https://1geki.jp/slot/s_shinhanabi/

### INTERPRETATION
A visually salient event is not automatically a responsibility cue.

A useful boundary test is:

`WOULD IGNORING THIS CHANGE ALTER THE NEXT REQUIRED ACTION OR THE CURRENT INFERENCE?`

If no, it may be identity, atmosphere or decoration. If yes, it can legitimately reopen monitoring.

This leads to four Visual/Mechanism mappings for Game & Reel's duty classes:

1. `ROLE DUTY OPENS`
   - stopped-reel geometry leaves a coverable role alive;
   - the relevant evidence must remain legible before the next precision STOP.

2. `INFERENCE DUTY OPENS`
   - partial stop + lamp/blackout/flash relationship creates a new contradiction or reach-eye question;
   - the cue must preserve the stopped evidence rather than cover it.

3. `STATE DUTY OPENS`
   - bonus/RT/technical-intervention procedure changes;
   - an existing display/panel/operation cue may temporarily gain priority, but the temporary priority must expire when the duty ends.

4. `CAUSAL DUTY OPENS`
   - a visible result conflicts with the learned action → consequence relation;
   - the stable physical map must remain intact enough for the player to attribute whether the contradiction belongs to reel result, input, state or platform failure.

### REUSABLE PRINCIPLE
`RESPONSIBILITY, NOT NOVELTY, EARNS INTERRUPTION AUTHORITY.`

---

## 3.4 A cue must arrive before the next consequential action

### INTERPRETATION grounded in the real-machine procedure
If a partial stop opens a small-role aiming duty, a signal presented only after STOP3 can explain what happened but cannot support the action that was required at STOP2 or STOP3.

Therefore visual responsibility has a timing boundary:

`TRIGGER EVIDENCE -> RE-ENGAGE -> CONSEQUENTIAL ACTION`

not

`CONSEQUENTIAL ACTION -> EXPLANATORY EFFECT`.

This yields:

- `A RESPONSIBILITY CUE THAT ARRIVES AFTER THE REQUIRED ACTION IS FEEDBACK, NOT GUIDANCE.`
- `RE-ENGAGEMENT LATENCY IS PART OF VISUAL/MECHANICAL LEGIBILITY.`

No millisecond threshold is claimed. Exact acceptable timing remains a future Human-test question after production authorization.

## 3.5 Stopped reels are the primary reopening surface for role/inference duty

### SOURCED FACT
The official product page explicitly makes changed reel arrangement and new aiming points part of the product. Major strategy sources describe conditional normal procedures in which the need to aim ice depends on the first-stop result.

Sources:
- https://www.universal-777.com/product/slot/shin_hanabi/
- https://1geki.jp/slot/s_shinhanabi/

### INTERPRETATION
For role/inference duty, the machine does not need to “tell” the player with a second UI if the partial reel result itself is the branch condition.

This protects the prior Run 5 finding:

`A STOPPED REEL IS AN EXTERNAL MEMORY SURFACE.`

Run 6 extends it:

`A STOPPED REEL CAN ALSO BE AN ATTENTION-REOPENING SURFACE.`

The physical result can simultaneously:

- preserve history;
- eliminate candidates;
- reopen precision duty;
- create a contradiction worth investigating.

### REUSABLE PRINCIPLE
`WHEN THE PHYSICAL RESULT ALREADY CONTAINS THE BRANCH, DO NOT REQUIRE A SEPARATE VISUAL ALARM TO AUTHORIZE READING IT.`

## 3.6 Temporary state priority should use stable hardware and expire cleanly

### SOURCED FACT
Published RT procedure for 新ハナビ changes the player's task during 花火チャレンジ / 花火GAME while using the same lever and three STOP buttons. Strategy material documents reverse-order navigation / JAC-IN handling and ordinary small-role handling depending on the current cue.

Sources:
- https://nana-press.com/kaiseki/machine/134/3869/
- https://1geki.jp/slot/s_shinhanabi/

### INTERPRETATION
The important physical lesson is not the proprietary visual instruction itself. It is that **stable controls can carry different temporary responsibilities without the cabinet teaching a new motor map**.

A temporary panel/lamp/display cue may claim priority because the procedure has changed, but that claim should end when the procedure ends.

Reusable principles:

- `STABLE HARDWARE SUPPORTS FAST RE-ENGAGEMENT BECAUSE MOTOR OWNERSHIP DOES NOT MOVE.`
- `TEMPORARY TASK PRIORITY SHOULD EXPIRE CLEANLY.`
- `STATE CHANGE SHOULD CHANGE RESPONSIBILITY BEFORE IT CHANGES THE PLAYER'S PHYSICAL MAP.`

## 3.7 Hall identity can remain strong while decision-space monitoring stays low

### DIRECT OBSERVATION
Front/oblique imagery shows that large identity masses exist above and below the precision reel zone. Reflective/metallic-looking framing, translucent/illuminated areas and large panel graphics contribute to room-distance recognition while the central reel aperture remains geometrically bounded.

### INTERPRETATION
The restrained quality of this machine is not “everything is dim and minimal.” It is **temporal and topological restraint**.

The cabinet can have a loud static face while ordinary per-game signals remain sparse enough to preserve deviation value.

`STATIC IDENTITY CONTRAST != PER-GAME ATTENTION CLAIM.`

`HALL PRESENCE CAN BE CONTINUOUS; GAMEPLAY INTERRUPTION AUTHORITY SHOULD BE SCARCE.`

This explains how a machine can remain identifiable in a noisy hall without giant moving mechanisms: identity can be carried by fixed silhouette, panel mass, material contrast, bounded luminous regions and repeated body geometry, while meaningful per-game change is reserved for state/inference changes.

### INTERPRETATION — materials/depth
The exact materials are not verified. From photographs, some frame regions appear reflective/metallic or plated, some illuminated regions appear translucent, and the reel window appears physically recessed behind a bezel/glazing layer. These are **visual interpretations only**, not manufacturer-verified material specifications.

---

## 3.8 Visual quiet is not absence; it is predictable ownership

### INTERPRETATION
A machine that is visually quiet but ambiguous can still demand constant checking. Conversely, a visually rich machine can become low-monitoring if ownership is stable and irrelevant regions do not repeatedly change meaning.

Therefore:

`LOW-MONITORING REST = STABLE OWNERSHIP + PREDICTABLE BASELINE + LOW FALSE INTERRUPTION`

not simply low luminance or low animation count.

A player should be able to learn:

- this region is the reel evidence surface;
- this region is the hand/control surface;
- this region is secondary state/instruction;
- these ordinary lights are identity/availability, not a new question;
- when a rule-bearing condition changes, the affected surface changes in a learnable way.

### REUSABLE PRINCIPLE
`THE PLAYER SHOULD NOT HAVE TO INSPECT THE WHOLE CABINET TO KNOW WHETHER RESPONSIBILITY CHANGED.`

# 4. New learning

## 4.1 Responsibility reopening is a scene-graph change, not necessarily an effect escalation

A useful cue can be small if the baseline scene is stable and its ownership is trusted.

Run 6 model:

`STABLE SCENE GRAPH -> LOW-MONITORING ROUTINE -> RULE-BEARING SURFACE CHANGE -> RESPONSIBILITY REOPENS -> EVIDENCE RESOLVES -> SURFACE RETURNS -> MONITORING RECOMPRESSES`

This links directly to Machine Run 6's monitoring-compression model and Game & Reel Run 6's selective de-automation model.

## 4.2 The best interruption often preserves the player's current gaze

For reel-centered play, a branch that can be read in the stopped reel/adjacent condition is cheaper than a branch that forces gaze to a distant status panel and then back to the reel before the next STOP.

New principle:

`REOPEN ATTENTION LOCALLY BEFORE REROUTING ATTENTION GLOBALLY.`

This does not forbid secondary displays. It requires their claim to be proportional to the responsibility they add.

## 4.3 False interruptions create defensive visual monitoring

If lamps/panels repeatedly change with no consequence for action, belief, value or state, the player has two bad adaptation paths:

- keep checking them defensively;
- learn to ignore them, risking missed meaningful changes that use the same channel later.

Therefore:

`FALSE INTERRUPTION SPENDS FUTURE INTERRUPTION AUTHORITY.`

This is a visual/mechanical counterpart to prior Audio attention-authority findings.

# 5. Changed understanding

Before this run, Visual hierarchy could be framed as “keep the reels readable and make meaningful things salient.”

The stronger model is:

**Visual/Mechanism must support an interruptible routine.**

The player should be able to compress ordinary visual monitoring because the cabinet remains predictable, then re-expand attention from a **rule-bearing boundary** that appears on the correct physical surface before the next consequential action.

Thus readability alone is insufficient. The system needs:

- stable ownership;
- persistent stopped evidence;
- branch-local state change;
- low false interruption;
- temporary priority with clean release;
- preserved causal map after touch/occlusion.

# 7. Limits / misuse warnings

Do not misuse this research to conclude:

- every important event needs a flash or lamp;
- every unusual visual should change player responsibility;
- 新ハナビ's blackout/flash patterns should be copied;
- secondary displays are undesirable;
- a quiet machine must be dark/minimal;
- hall identity requires giant moving mechanisms;
- exact 新ハナビ depth/material/lamp/button dimensions are known;
- visual change alone can prove state truth when Game/Reel law does not support it;
- millisecond timing limits have been established for Chappy5;
- a browser overlay is an acceptable substitute for physical reel evidence.

No original cabinet concept, protected artwork, proprietary lamp pattern or unreleased stop-control logic is derived here.
