## Research question

Visual & Mechanism Run 8 handed off the following question:

> When one visual action-law owner retires but another inference remains live on the same stopped result, what auditory behavior can release the obsolete duty without sounding like a global ALL CLEAR, and how can the next valid grammar regain authority without creating a new confirmation-listening burden?

This run studies **selective auditory release**: how sound can stop asking the player to do one thing while avoiding the false implication that there is nothing left to inspect, infer or learn.

It does not create an original Chappy5 sound concept, audio asset, implementation, prototype, event table, timing table, mix target or signal ranking.

# 2. Topic reason

Visual Run 8 introduced an important distinction:

`DORMANT != RETIRED`

and:

`one stopped object may be closed for action while remaining open for inference.`

Sound has a specific failure mode here. A clear “completion” sound can efficiently end a motor duty, yet the same sound may semantically overreach and tell the player that the whole situation is finished.

That creates a false global closure:

`local action complete -> global certainty implied`

The opposite failure also exists. If sound refuses to mark local completion at all, the player may continue listening defensively for an obsolete instruction.

So the Sound problem is not simply “play a cue when done.” The problem is to **retire exactly the auditory responsibility that has ended, no more and no less**.

---

# 3. Prior unknown

Before this run, Sound research had established:

- routine audio should confirm prediction more often than demand orienting;
- attention authority is finite;
- learnable absence can be an information state;
- audio should be able to close responsibility, not only open it;
- a trusted baseline makes timing deviations meaningful;
- execution confirmation should arrive close to the action it validates;
- continuity can be an information channel;
- interruption can outperform addition;
- the player should not have to keep listening after the listening task is resolved;
- the normal machine must become audible again after a special duty ends.

But one boundary remained under-specified:

**How do we close one duty without closing the entire interpretation space?**

A binary model — cue present / cue absent, active / finished — is too coarse when motor responsibility, perceptual inspection and inference have different lifetimes.

# 5. New learning — auditory ownership has more than two states

### INTERPRETATION

A useful research model is to stop describing audio as merely “on” or “off.” For player responsibility, at least four semantic states are needed:

1. `ROUTINE` — no special auditory duty; baseline confirms machine operation.
2. `CLAIMED` — sound/timing has opened a temporary question or required action.
3. `LOCALLY_RELEASED` — the required action is complete; no further listening is required for that duty.
4. `INFERENCE_REMAINS` — the local motor duty is closed, but the visible/result evidence may still carry unresolved meaning.

The key point is that 3 and 4 can coexist.

This gives a more precise statement:

`AUDITORY DUTY CLOSED != SEMANTIC SCENE CLOSED`

### REUSABLE PRINCIPLE

`A COMPLETION CUE SHOULD CLOSE THE SMALLEST TRUE RESPONSIBILITY DOMAIN.`

If STOP2 finishes a technical duty but the stopped reels still contain information relevant to STOP3 or post-result inference, a cue that sounds like total victory is semantically too large.

---

# 6. Local release should usually be subtractive before it is additive

### INTERPRETATION

When an attention-demanding sound layer has been active, the cheapest way to say “you no longer need to monitor this layer” may be to **stop renewing the claim** rather than emit a second strong sound announcing release.

This is consistent with closed 新ハナビ evidence where learned absence can distinguish branches, and where a stable BGM can become informative through interruption.

Research distinction:

- `ADDITIVE RELEASE` — play a dedicated success / completion / all-clear cue.
- `SUBTRACTIVE RELEASE` — remove or cease the temporary instruction layer and let the baseline regain audibility.

Additive release is useful when immediate motor confirmation is necessary. But it also creates a new thing the player must hear and decode.

### REUSABLE PRINCIPLES

- `DO NOT CREATE A SECOND LISTENING TASK JUST TO ANNOUNCE THAT THE FIRST LISTENING TASK ENDED.`
- `WHEN BASELINE RECOVERY IS UNAMBIGUOUS, SUBTRACTION CAN BE A STRONGER RELEASE SIGNAL THAN ADDITION.`
- `A TEMPORARY AUDIO CLAIM SHOULD HAVE A NATURAL DECAY PATH BACK INTO THE MACHINE BASELINE.`

---

# 7. Release should preserve inferential residue

### INTERPRETATION

Visual Run 8 says terminal old evidence can remain visible because it explains why the old action law retired.

The Sound equivalent is not necessarily to leave a residual tone. Rather, Sound should avoid erasing the semantic importance of the still-visible result.

A useful abstraction is:

`SELECTIVE AUDITORY RELEASE = END OBSOLETE DUTY + RESTORE BASELINE + DO NOT OVERRIDE LIVE EVIDENCE`

This means an audio release can be successful precisely by becoming less prominent and allowing the reel/result surface to own attention again.

### REUSABLE PRINCIPLES

- `AUDIO SHOULD YIELD OWNERSHIP WHEN THE NEXT IMPORTANT EVIDENCE IS VISUAL OR REEL-BASED.`
- `SILENCE AFTER CONFIRMATION CAN PRESERVE THE PLAYER'S RIGHT TO INSPECT.`
- `DO NOT SONICALLY SUMMARIZE A RESULT THAT THE PLAYER IS STILL MEANT TO READ.`
- `THE SOUND SYSTEM SHOULD KNOW WHEN NOT TO INTERPRET.`

This is not “make sound sparse” as an aesthetic goal. It is ownership discipline.

---

# 8. Next-grammar authority should come from resumed predictability, not repeated confirmation

### INTERPRETATION

After a temporary law retires, there is a temptation to announce the return of the base grammar with another explicit cue.

But if every return requires a “normal mode restored” sound, the player must maintain a new confirmation-listening duty:

`did I hear the return cue?`

That defeats the original goal.

A more robust model is:

`NEXT GRAMMAR AUTHORITY = RESUMED TRUSTED BASELINE + CONSISTENT CAUSAL TIMING + NO CONFLICTING SPECIAL CLAIM`

The baseline regains authority because familiar BET / lever / reel / STOP / settlement relationships resume predictably, not because a narrator announces normality.

### REUSABLE PRINCIPLES

- `NORMALITY SHOULD USUALLY REASSERT ITSELF BY BEHAVING NORMALLY.`
- `BASE GRAMMAR SHOULD NOT REQUIRE A PER-GAME AUDIO ACKNOWLEDGEMENT.`
- `THE RETURN OF PREDICTABILITY IS ITSELF A RELEASE SIGNAL.`
- `NEXT-GRAMMAR BINDING SHOULD REDUCE LISTENING OBLIGATION, NOT MOVE IT TO A DIFFERENT CUE.`

---

# 9. Separate execution confirmation from state interpretation

### SOURCED FACT — closed 新ハナビ anchor

Published REG documentation captured in Case Study 02 shows that technical-intervention success can receive immediate confirmation while payout consequence exists separately.

### INTERPRETATION

This supports a useful separation:

`ACTION VALIDATION` versus `STATE INTERPRETATION`

An immediate local success cue can validate the player's just-executed action without explaining the entire machine state.

If a success cue also carries large reward semantics, transition semantics and “all done” semantics, it becomes overloaded.

### REUSABLE PRINCIPLES

- `CONFIRM THE ACTION AT THE SCALE OF THE ACTION.`
- `DO NOT FORCE ONE SOUND TO MEAN SUCCESS, REWARD, STATE CHANGE AND GLOBAL CLOSURE AT ONCE.`
- `LOCAL FEEDBACK SHOULD BE SEMANTICALLY NARROW ENOUGH TO LEAVE FUTURE QUESTIONS OPEN.`

---

# 10. Dormant and retired auditory duties must not sound identical

### INTERPRETATION

Visual Run 8 distinguishes `DORMANT` from `RETIRED`.

Sound needs the same distinction.

- `DORMANT`: the special duty may return because its question is still open. Audio may temporarily fall quiet, but the player should not infer terminal completion from that quiet alone.
- `RETIRED`: the local duty has been causally resolved. The machine can safely return to baseline without expecting the player to preserve that listening task.

This exposes a risk:

If both states are represented by exactly the same sudden silence, the player may not know whether to keep the special cue template in working memory.

The answer is not automatically “add different sounds.” Context may already distinguish them through reel/result state, timing and known grammar.

### REUSABLE PRINCIPLES

- `AUDITORY SILENCE HAS MEANING ONLY THROUGH CONTEXT.`
- `DO NOT ASK AUDIO ALONE TO DISTINGUISH STATES THAT THE WHOLE MACHINE CAN DISTINGUISH CHEAPER.`
- `A RETIRED DUTY SHOULD RELEASE WORKING MEMORY; A DORMANT DUTY MAY PRESERVE A CONDITIONAL EXPECTATION.`

---

# 11. Repeated duties should have episode boundaries, not continuous alarm identity

### INTERPRETATION

Visual Run 8 says repeated technical duties should retire per attempt and reopen as new episodes.

Sound should mirror that structure.

A poor pattern is:

`special duty begins -> special audio identity persists across many attempts -> player never fully returns to baseline`

Even if each attempt is mechanically separate, persistent high-salience audio can merge them into one continuous vigilance episode.

A better research abstraction is:

`OPEN -> EXECUTE -> LOCAL CONFIRM/RESOLVE -> RELEASE -> BASELINE GAP -> NEXT EPISODE OPENS IF NEEDED`

The `BASELINE GAP` need not be long in time. It is semantic: enough to let the previous obligation be truly over before another claim begins.

### REUSABLE PRINCIPLES

- `REPEATED DUTIES NEED SEMANTIC BREATHING ROOM, NOT NECESSARILY LONG SILENCE.`
- `EPISODE BOUNDARIES PREVENT TECHNICAL PLAY FROM BECOMING CONTINUOUS ALARM LISTENING.`
- `A NEW DUTY SHOULD REOPEN ATTENTION; THE OLD DUTY SHOULD NOT SIMPLY FAIL TO END.`

---

# 12. Cross-modal ownership rule

### INTERPRETATION

The strongest synthesis with Visual Run 8 is:

`KEEP ACOUSTIC BODY STABLE; MOVE AUDITORY RULE OWNERSHIP THROUGH CAUSE.`

The machine's ordinary sound family should remain recognizable while temporary rule ownership moves among:
- routine confirmation,
- mandatory action cue,
- local execution confirmation,
- reward/phase audio,
- baseline recovery.

This parallels Visual's:

`KEEP MOTOR OWNERSHIP STABLE; MOVE RULE OWNERSHIP THROUGH EVIDENCE.`

Combined:

`STABLE MACHINE IDENTITY + SELECTIVE RULE OWNERSHIP + LOCAL CLOSURE = LOW-VIGILANCE DEPTH`

This is a research abstraction, not an implementation formula.

# 13. New Stage-1 research checks

These are future research/QA concepts only, not authorized browser tests in Stage 1.

### Selective Release Test
After one special action duty resolves, does audio stop asking for that duty without implying that all interpretation is finished?

### Baseline Re-entry Test
Can the player infer that the ordinary grammar has regained authority from normal causal behavior, without needing a dedicated “normal restored” cue?

### Residual Evidence Respect Test
When stopped reels / result evidence remain meaningful, does post-action audio leave enough semantic space to inspect them?

### Dormant-vs-Retired Context Test
Can the whole machine distinguish “may reopen” from “causally finished” without requiring two extra high-salience sounds?

### Episode Boundary Test — Audio
For repeated technical duties, does each attempt close cleanly enough that the player is not held in continuous alarm listening?

### Confirmation Overreach Test
Does any local success sound accidentally imply reward, transition or global closure that has not actually occurred?

# 16. Limits / misuse risks

### UNRESOLVED

This run does not establish:
- exact SPL, spectral, transient or decay values for any future cue;
- exact acceptable latency for local confirmation;
- exact gap needed to create an auditory episode boundary;
- whether a specific future state should use additive or subtractive release;
- real-device masking behavior on iPhone speakers;
- hall-noise behavior;
- novice/expert differences in interpreting silence;
- whether visual evidence alone can distinguish dormant/retired states in every future machine;
- minimum perceptible changes needed for baseline re-entry;
- accessibility behavior for hearing-impaired users.

Misuse risks:
- treating “subtractive release” as a blanket rule to remove feedback;
- using silence where the player actually requires action confirmation;
- assuming sparse audio is automatically low-fatigue;
- letting Visual carry every state distinction and making audio ambiguous;
- creating a special “return to normal” cue on every episode, producing the exact listening burden this study warns against;
- copying 新ハナビ proprietary sounds, melodies, flash/sound tables or timing.

`AUDIO_UNVERIFIED` and `REALITY_UNVERIFIED` remain appropriate for physical / unmeasured claims.

2. How much semantic separation can timing alone provide without timbral differentiation?
3. How should auditory release behave when the next live inference is also auditory rather than visual?
4. What happens when two legitimate listening duties overlap?
5. How should touch occlusion / Safari interruption affect audio ownership and re-entry?
6. Can haptic output eventually share local completion responsibility without producing duplicate confirmation burden?
7. What practical iPhone-only Human test can distinguish “I knew the duty ended” from “I merely stopped paying attention”?
8. How does selective release interact with long-session habituation when the special cue is rare?

# 18. Next worthwhile study

For Playtest & QA, the highest-value next question is:

**How can a future Human test tell the difference between true selective closure and false calm — i.e. the player correctly knows one duty ended while preserving the remaining inference, versus the player simply disengaging and missing still-live information?**

Useful future measurements would need to pair:
- action correctness,
- inference correctness,
- confidence,
- unnecessary re-checking,
- false “all clear” reports,
- missed reopened duties,
- repeated-session vigilance cost.

No browser test is authorized by this Stage-1 document.

# 19. Possible future Chappy5 value

If later validated and admitted through Human Gate, the principle set could help Chappy5 build machines where:
- technical duties feel bounded rather than exhausting;
- reel evidence retains authority after local success;
- routine play becomes learnably quiet without becoming informationally empty;
- strong sounds are reserved for moments that truly deserve semantic expansion;
- returning to ordinary play feels like returning to a trusted physical machine rather than closing a modal dialog;
- mastery reduces listening burden while preserving information.
