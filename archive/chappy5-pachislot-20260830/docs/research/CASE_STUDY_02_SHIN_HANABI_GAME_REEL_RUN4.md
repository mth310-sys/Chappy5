## 1. Ordinary play is a confidence ladder, not one final judgement

### SOURCED FACT

P-WORLD documents a common normal procedure: aim a cherry-covering landmark on the left reel, stop the right reel freely, then only aim ice on the middle reel when the partial stop form leaves ice relevant. It separately lists left-red-7 play and notes that reach-eye examples shown for that route are valid under specified 3-BET / stop-order conditions rather than universally.

Source:
- https://www.p-world.co.jp/machine/database/9401

### INTERPRETATION

A normal game does not need to remain equally uncertain through STOP3. The player can move through confidence stages:

`SAFE OPENING → PARTIAL CLASSIFICATION → DUTY OPENS / DUTY CLOSES → FINAL RESOLUTION`

The important design property is not only what STOP3 shows, but how much uncertainty is removed at STOP1 and STOP2 and whether that removal legitimately lets the player lower precision burden.

### REUSABLE PRINCIPLES

- `REEL PLAY CAN HAVE A CONFIDENCE LADDER BEFORE THE FINAL RESULT.`
- `A PARTIAL STOP SHOULD BE ALLOWED TO CLOSE RESPONSIBILITY, NOT ONLY OPEN NEW RESPONSIBILITY.`
- `GOOD REEL DEPTH IS NOT PERMANENT UNCERTAINTY; IT IS LEARNABLE UNCERTAINTY RESOLUTION.`

## 2. First-stop control evidence proves state-sensitive response without revealing the full algorithm

### SOURCED FACT

一撃 publishes separate first-stop control material for LEFT / MIDDLE / RIGHT first stops and separates at least bonus-not-established, Don BIG-established, red-7 BIG-established and REG-established states. Published examples show fixed press positions producing documented slip counts under specific role/state conditions.

Sources:
- https://1geki.jp/slot/s_shinhanabi/47/
- https://1geki.jp/slot/s_shinhanabi/48/
- https://1geki.jp/slot/s_shinhanabi/49/

### INTERPRETATION

The reel response can carry evidence before a famous reach eye is completed:

`player remembers approximate press point`
`+ observed slip / stop position`
`+ current stop order`
`+ surviving role possibilities`
`→ revised belief about internal truth`

This is not permission to reconstruct the missing second-/third-stop control tables.

### REUSABLE PRINCIPLES

- `SLIP IS USEFUL WHEN IT UPDATES BELIEF, NOT MERELY WHEN IT LOOKS DRAMATIC.`
- `REEL INFORMATION CAN ARRIVE AS A PROBABILITY UPDATE BEFORE IT ARRIVES AS A CERTAINTY.`
- `CONTROL-BASED DISCOVERY REQUIRES TRUST IN BOTH AIM MEMORY AND RULE CONSISTENCY.`

## 3. Reach eyes are one endpoint of a larger contradiction system

### SOURCED FACT

P-WORLD describes approximately 3,500 reach-eye forms and explicitly documents flash/role relationships where denial can indicate bonus. It also describes delayed reel-start timing as cherry-or-bonus information and gives red-7-area reach-eye laws that depend on slip/stop form and role denial.

Source:
- https://www.p-world.co.jp/machine/database/9401

### INTERPRETATION

The interesting unit is not the catalogued final pattern alone. A complete reel question can be:

`expected small-role family`
`→ STOP1/STOP2 preserves a plausible route`
`→ STOP3 denies that role`
`→ contradiction resolves as bonus evidence`

or:

`timing deviation`
`→ role set narrows`
`→ alternate stop order chosen`
`→ early two-reel certainty / strong inference`
`→ final confirmation / bonus discrimination`

### REUSABLE PRINCIPLES

- `A REACH EYE IS STRONGEST WHEN IT IS THE RESOLUTION OF A PRIOR QUESTION.`
- `ROLE DENIAL CAN BE GAMEPLAY ONLY WHEN THE PLAYER HAD A REASONABLE ROLE EXPECTATION TO DENY.`
- `CATALOG SIZE DOES NOT EQUAL DEPTH; THE VALUE IS IN HOW MANY PATTERNS ARE LEARNABLY GENERATED BY RULE RELATIONSHIPS.`

## 4. Small-role sampling serves three simultaneous economies

### SOURCED FACT

Published setting-1 normal frequencies are approximately replay `1/7.3`, wind bell combined `1/7.7`, cherry combined `1/16.4`, ice combined `1/51.2`; setting differences exist in wind-bell/cherry/ice families. Bonus combined ranges from about `1/156.0` at setting 1 to `1/131.6` at setting 6.

Sources:
- https://nana-press.com/kaiseki/machine/134/4508/
- https://nana-press.com/kaiseki/machine/134/4233/
- https://www.p-world.co.jp/machine/database/9401

### INTERPRETATION

A wind bell or cherry can simultaneously be:
1. immediate payout/value protection;
2. reel-information material through stop form/flash/control relationship;
3. a statistical sample for long-session setting inference.

These layers should not be collapsed. A player can execute the role correctly while misunderstanding its information meaning, or understand the setting implication while failing execution elsewhere.

### REUSABLE PRINCIPLE

`ONE REEL EVENT MAY HAVE PAYOUT VALUE + LOCAL INFORMATION VALUE + SESSION-SAMPLING VALUE, AND THESE SHOULD BE EVALUATED SEPARATELY.`

## 5. 100G / 500G / 3-hour loop — Game & Reel Run 4

### 100G

Using published setting-1 frequencies only as expectation values, 100G contains roughly 14 replays, 13 wind bells, 6 cherries and 2 ice events even when no bonus arrives. The repeated loop is therefore not simply waiting for a 1/156 event; it repeatedly asks whether responsibility opens, whether the stopped form matches expectation, and whether a suspicious relation deserves further attention.

`100G QUALITY = ROUTINE COMPRESSION + MEANINGFUL PARTIAL QUESTIONS + LOW FALSE DUTY`

### 500G bonus drought

A conditional 500G no-bonus block still contains many role samples, but Run 4 strengthens the evidence boundary: event density cannot prove intrinsic enjoyment. The critical QA question is whether the player still receives satisfying *resolutions* rather than merely obligations to protect value.

`DROUGHT DEPTH REQUIRES RESOLUTION DENSITY, NOT JUST EVENT DENSITY.`

### 3 hours

Long-form/field material shows both beginner practice and expert/high-volume play exist. A 35-minute beginner-focused actual-play program explicitly frames delayed-start reverse stopping and RT avoidance as skills to learn, while a 44-minute expert-oriented report centers repeated REG high-skill execution; a separate edited 7,800G report demonstrates the machine can support very high game volume but is not evidence that uninterrupted 3-hour fatigue is low.

Sources:
- https://www.niconana.net/movie/%E3%80%90%E6%96%B0%E3%83%8F%E3%83%8A%E3%83%93%E3%80%91%E6%94%BB%E7%95%A5%E3%81%B8%E3%81%AE%E9%81%93-%E9%81%85%E3%82%8C%E9%80%86%E6%8A%BC%E3%81%97%E3%81%A8%E3%83%8F%E3%82%BA%E3%82%B7%E3%81%AE%E4%B8%8A/
- https://yutura.net/channel/3934/video/UHi1cInu2tM/
- https://yutura.net/channel/98894/video/-uhM0NgM1pY/

### INTERPRETATION

Mastery changes the same three STOPs in at least four ways:
- fewer routine decisions need conscious thought;
- the player recognizes earlier when precision is unnecessary;
- the player can choose alternate stop orders to ask different questions;
- setting samples and execution performance can be tracked without treating every event as equally important.

### REUSABLE PRINCIPLES

- `MASTERY SHOULD REDUCE REQUIRED DECISIONS FASTER THAN IT REDUCES AVAILABLE QUESTIONS.`
- `EXPERT DEPTH CAN COME FROM SELECTIVE ATTENTION, NOT HIGHER CONSTANT INPUT LOAD.`
- `DROUGHT DEPTH REQUIRES RESOLUTION DENSITY, NOT JUST EVENT DENSITY.`

## 6. Bonus → skill → RT → return is one changing control contract

### SOURCED FACT

P-WORLD documents BIG maximum 202 medals with one technical adjustment, REG maximum 112 medals with difficulty-dependent procedures, and BIG → max-20G 花火チャレンジ → JAC IN → 20G 花火GAME. なな徹 documents 花火GAME as 20G fixed RT, approximately +0.6 medals/G, ending early if a bonus establishes; it also documents setting-dependent miss rates.

Sources:
- https://www.p-world.co.jp/machine/database/9401
- https://nana-press.com/kaiseki/machine/134/3873/

### INTERPRETATION

The same physical controls move through different contracts:

`normal safe aim/read`
`→ bonus evidence and discrimination`
`→ bonus-entry alignment`
`→ BIG/REG technical execution`
`→ RT JAC-IN avoidance/acceptance`
`→ lower-duty RT observation`
`→ ordinary safe aim/read`

Run 4 links this directly to Machine Run 4's `RE-ANCHOR` model: the return to normal should not require the player to relearn where precision is mandatory.

### REUSABLE PRINCIPLES

- `CONTROL CONTRACTS MAY CHANGE BY STATE, BUT THE RETURN CONTRACT MUST BE EXPLICITLY RECOVERABLE.`
- `A STATE TRANSITION IS STRONGER WHEN IT CHANGES WHAT THE SAME STOP MEANS, NOT ONLY WHAT THE SCREEN SAYS.`

## 7. Skill and setting must remain analytically separate

### SOURCED FACT

Published nominal and complete-strategy return figures differ materially. P-WORLD lists setting-1 nominal return around 98.1% and complete-strategy reference around 102.0%; setting differences separately exist in bonus and small-role/RT statistics.

Source:
- https://www.p-world.co.jp/machine/database/9401

### INTERPRETATION

A session can produce at least two independent uncertainty channels:
- `What setting / statistical environment am I observing?`
- `How well am I executing the available strategy?`

Mixing them can make a player blame the machine for execution misses or blame execution for statistical variance.

### REUSABLE PRINCIPLES

- `SETTING UNCERTAINTY != EXECUTION UNCERTAINTY.`
- `A SKILL MACHINE SHOULD MAKE IT POSSIBLE TO ATTRIBUTE OUTCOME SOURCES WITHOUT REQUIRING PERFECT INTERNAL KNOWLEDGE.`

## 8. Cross-specialty integration from Machine Run 4

Game & Reel now aligns with the shared model:

`HOME → CLAIM → TEMPORARY RESPONSIBILITY → RESOLUTION → RELEASE → RE-ANCHOR → HOME`

Game/Reel mapping:
- `HOME`: safe ordinary aiming routine;
- `CLAIM`: timing/flash/slip/partial-form anomaly;
- `TEMPORARY RESPONSIBILITY`: additional aim, stop-order choice, bonus discrimination, RT intervention;
- `RESOLUTION`: payout/role denial/reach-eye/technical outcome;
- `RELEASE`: extra precision no longer required;
- `RE-ANCHOR`: ordinary safe routine resumes without persistent false vigilance.

New Game/Reel statement:

`THE REELS SHOULD TELL THE PLAYER NOT ONLY WHEN TO PAY MORE ATTENTION, BUT WHEN THEY MAY SAFELY PAY LESS.`
