## 3. Integrated real-machine model

Run 2 converges on one machine-level structure:

`TRUSTED HOME ROUTINE → ROLE/STATE QUESTION → PHYSICAL REEL EVIDENCE → CONSEQUENCE WINDOW → LOCAL REWARD OR PERSISTENT-STATE EDIT → RE-ANCHOR → TRUSTED HOME ROUTINE`

The important property is not simply that A+ART offers several parallel features. It is that temporary questions must close cleanly enough that the player can repeatedly return to a low-cost HOME without losing orientation.

### 3.1 Same body map, changing responsibility

The physical lever / MAX BET / three-STOP map remains stable while responsibility changes by state. Normal play emphasizes role following and classification; ART can add stop-order compliance; bonus and special branches alter what a recognized role is worth. This supports the reusable distinction:

`BODY GRAMMAR CAN STAY STABLE WHILE RESPONSIBILITY GRAMMAR CHANGES.`

This is sourced from the specialist research; undisclosed stop-control tables remain unresolved and are not inferred.

### 3.2 Role recognition and consequence closure are different clocks

A visible stop form can classify a role before the machine has finished resolving what that role means for BONUS/CZ/ART/state. Run 2 therefore confirms:

`ROLE CLASSIFICATION LATENCY ≠ CONSEQUENCE-RESOLUTION LATENCY.`

Machine-level consequence: suspense is sustainable only if those open questions close at a manageable rate. If too many remain live, parallel depth becomes attention debt rather than richness.

### 3.3 Physical hierarchy protects the reel task

Visual research shows a large LCD does not automatically demote the physical reels. The seated loop can remain short:

`LCD meaning → reel evidence → STOP action → LCD consequence`.

Apparent recess, border/occlusion and stable physical anchors help separate the reel work surface from the dynamic display. Exact cabinet depth/material construction remains unresolved where not documented.

Reusable principle:

`ATTENTION HIERARCHY IS BETTER JUDGED BY RE-ACQUISITION COST THAN BY SCREEN AREA.`

### 3.4 Audio can move certainty to different motor boundaries

BIG notification customization demonstrates that certainty can be attached to lever ON, reel start, payout-end or other documented interaction boundaries. The important abstraction is not the protected sound itself but the timing relationship:

`CERTAINTY TIMING IS AN EXPERIENCE PARAMETER.`

Persistent ART audio can carry HOME/state context while intermittent navigation/action cues temporarily own required-input moments. Exact machine-specific samples, SPL, frequency response and speaker construction remain unresolved.

### 3.5 A+ART succeeds only if local rewards remain locally complete

Playtest Run 2 separates a real BIG's local satisfaction from its usefulness as an ART gateway. This is critical. If a BIG without ART is experienced only as failure, the nominally parallel A+ART structure collapses psychologically into one long ART-waiting ladder.

Machine QA principle:

`LOCAL REWARD COMPLETION MUST BE TESTED BEFORE DOWNSTREAM STATE VALUE IS COUNTED.`

Likewise, base ART must retain value before exceptional extension states are counted (`BASE-STATE INDEPENDENCE`).

### 3.6 Re-anchor is a cross-discipline contract

The strongest cross-Director convergence is the return problem. For example:

`ART HOME → BIG FOREGROUND → BIG RESOLUTION → ART HOME RESTORED`

is complete only when all of the following are restored:

1. internal state location;
2. visual attention location;
3. action/STOP responsibility;
4. audible context;
5. the player's understanding of remaining value.

This yields the integrated principle:

`A STATE RETURN IS NOT COMPLETE UNTIL THE PLAYER'S ACTION MODEL HAS RETURNED.`

### 3.7 Long-session fatigue is attention economics

Run 2 does not support treating three-hour fatigue as mere motor repetition. The combined model is:

- routine motor duty;
- concurrent information claims;
- unresolved consequence duration;
- orientation switching;
- re-anchor cost;
- statistical maintenance;
- relief dependence during dry stretches.

Motor mastery can reduce hand/eye cost while increasing the amount of statistical and state evidence a skilled player chooses to track.

## 4. Machine verdict on the Run 2 integration question

Question:

`DOES THE MACHINE SUCCESSFULLY RETURN THE PLAYER TO A LOW-COST, TRUSTED HOME ROUTINE AFTER EACH TEMPORARY ROLE/STATE/REWARD QUESTION, OR DOES PARALLEL DEPTH ACCUMULATE AS UNRESOLVED ATTENTION DEBT?`

Verdict: **the available evidence supports the existence of a coherent HOME-and-return architecture, but is insufficient to quantify its failure boundary over long low-setting play.**

The specialist evidence shows mechanisms that should reduce attention debt: a stable physical body map, branch-based role-follow routine, a visually re-acquirable reel surface, state-context audio, real local BONUS reward, and explicit returns from temporary states. However, the same evidence also identifies unresolved risk: multiple state/statistical questions can remain live, and no controlled long-form measurement yet establishes how quickly they close or how much cognitive cost they accumulate over repeated dry segments.

Therefore Run 2 is **complete as a research pass**, but the real-machine study is not saturated.

## 5. Decision: open targeted Real-Machine Run 3, not another lineage yet

Do not open Phase C and do not return to original concepts. Do not declare the Reality Baseline complete.

A third Case Study 03 real-machine pass is justified, but it must be narrower than Run 2. It exists to attack unresolved evidence rather than repeat general description.

### Run 3 shared target

`MEASURE / TRIANGULATE THE HOME-RETURN FAILURE BOUNDARY.`

All Directors must prioritize evidence that can distinguish a coherent repeated loop from accumulated attention debt.

### Game & Reel Run 3 target

- quantify, where reliable sources allow, how often normal play actually branches away from the low-cost routine;
- map which role/state questions close immediately, after a short observation window, or remain statistical only;
- distinguish mandatory player duty from optional expert inference;
- retain all undisclosed stop-control details as `UNRESOLVED`.

### Visual & Mechanism Run 3 target

- timestamp long-form real-machine footage for gaze-demand/state-density samples where feasible;
- test how quickly reels/operation anchors can be visually re-acquired after LCD-heavy events;
- separate documented hardware from inferred depth/material observations.

### Sound & Experience Run 3 target

- sample repeated long-form footage for cue density and silence/rest intervals rather than memorable cues only;
- identify which audio events close questions, which merely prolong them, and which restore HOME;
- do not infer clean audio assets, SPL or speaker hardware from compressed video.

### Playtest & QA Run 3 target

- reconstruct at least one low-reward/dry long-form sequence and one reward-rich sequence using the same evaluation frame;
- separate `REWARD SATISFACTION` from `RELIEF`;
- track `OPEN-QUESTION COUNT`, `RE-ANCHOR LATENCY`, and optional statistical-maintenance burden;
- compare beginner-required duties with expert-chosen observation load.
