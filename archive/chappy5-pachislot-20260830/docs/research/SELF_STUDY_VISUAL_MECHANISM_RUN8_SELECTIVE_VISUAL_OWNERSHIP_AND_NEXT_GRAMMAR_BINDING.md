This run answers Game & Reel Run 8's question:

> What persistent visual/physical ownership cues make `DORMANT` versus `RETIRED` distinguishable when the same STOP hardware remains on screen, and how can the player see that the base motor grammar has regained authority without adding a global reset/all-clear layer?

---

## 1. Central distinction: control ownership can stay fixed while rule ownership changes

Game & Reel Run 8 established:

`CONTROL IDENTITY != ACTION-LAW IDENTITY.`

Visual & Mechanism implication:

The same physical-looking STOP control must not be forced to visually impersonate every temporary action law. Its stable geometry should continue to mean `this is the place where stopping happens`, while nearby/reel-state evidence temporarily determines **which question currently owns that stop**.

This creates three layers:

1. `CONTROL OWNERSHIP` — where the hand acts;
2. `EVIDENCE OWNERSHIP` — which surface contains the information that governs the next stop;
3. `ACTION-LAW OWNERSHIP` — which temporary or baseline rule is currently valid.

Reusable principle:

`KEEP MOTOR OWNERSHIP STABLE; MOVE RULE OWNERSHIP THROUGH EVIDENCE.`

This is an abstraction only. No protected cabinet layout, reel table, lamp choreography or artwork is copied.

---

## 2. DORMANT and RETIRED need different visual consequences

### Definitions carried from Game & Reel

- `DORMANT`: a law is not required at this exact instant but can govern a later stop in the same unresolved episode.
- `RETIRED`: its target question is resolved and no remaining valid stop can improve that question by following the old law.

### Interpretation

If the machine visually collapses both states into the same generic calm, the player cannot know whether responsibility is merely waiting or actually finished.

A useful distinction is therefore not `bright vs dark`, but:

- **DORMANT** — the evidence chain that owns the law is still visibly incomplete;
- **RETIRED** — the evidence chain contains a visible/stable terminal fact that makes the old law non-actionable.

Examples at abstraction level:

- one stopped reel remains an unresolved branch input → old handling rule may be dormant;
- a stopped arrangement eliminates the target candidate → old handling rule may be retired while another inference remains active;
- a bounded technical attempt reaches its terminal result → that attempt's visual ownership can retire even if the surrounding state continues.

Reusable principles:

`DORMANCY PRESERVES AN OPEN QUESTION; RETIREMENT PRESERVES THE FACT THAT CLOSED IT.`

`DO NOT REPRESENT RETIREMENT BY MERE EFFECT DISAPPEARANCE.`

## 3. Stopped-result persistence is the cheapest proof of local retirement

### Closed 新ハナビ anchor — source-bounded

Official Universal material identifies 新ハナビ as a bonus+RT machine with changed reel arrangement/blackout rules, mini-LCD `たまやチャレンジ`, and technical-intervention contexts while retaining a stable three-reel / three-STOP play grammar.

Source:
- https://www.universal-777.com/product/slot/shin_hanabi/

Completed Case Study 02 already established that role denial, blackout/flash relation and temporary RT duties can change meaning without relocating the physical reel workspace.

### Interpretation

When a stopped result is what makes an old law impossible to improve, that result should remain visually authoritative long enough for the next action to be selected.

The player should not need a separate `DONE` indicator if the stopped evidence itself already proves `done`.

`LOCAL RETIREMENT PROOF = TERMINAL EVIDENCE STILL VISIBLE + OLD TARGET NO LONGER ACTIONABLE.`

No time threshold is asserted.

Reusable principle:

`PRESERVE THE PROOF THAT RETIRED THE RULE UNTIL THE NEXT RULE HAS A LEGIBLE OWNER.`

## 4. Next-grammar binding should restore hierarchy, not reset the whole screen

### Interpretation

A global reset/all-clear layer creates a new question: `has the reset finished?` It can also falsely imply that every inference channel is closed.

A cleaner next-grammar handoff is selective:

1. the old duty's evidence becomes terminal rather than erased;
2. temporary state-specific emphasis loses authority;
3. the stable reel/control hierarchy becomes dominant again;
4. any still-live inference remains visible on the same physical result;
5. the next consequential input is governed by a surface whose ownership is already legible.

Research abstraction:

`NEXT-GRAMMAR BINDING = TERMINAL OLD EVIDENCE + RESTORED BASE HIERARCHY + LEGIBLE NEXT OWNER.`

Reusable principle:

`RETURN AUTHORITY BY RESTORING PRIORITY, NOT BY ANNOUNCING RESET.`

## 5. Visual ownership should survive brief touch occlusion

### General perception evidence

Research on object persistence and object-based attention shows that spatiotemporal continuity supports maintaining correspondence across brief disruption, and that continuity can support attention/memory across dynamic visual conditions. These are general perception findings, not pachislot thresholds.

Sources:
- Liverence & Scholl (2015), *Object Persistence Enhances Spatial Navigation*: https://doi.org/10.1177/0956797614547705
- Watanabe (2011), *Maintaining Visual Attention over Time: Effects of Object Continuity*: https://doi.org/10.1068/ic207
- Chen (2012), *Object-based attention: A tutorial review*: https://doi.org/10.3758/s13414-012-0322-z

### Interpretation

A finger can briefly hide part of the operation plane without forcing the machine to restate its whole mode if:

- the evidence surface remains fixed in position;
- the stopped result is unchanged behind/after the gesture;
- no unrelated overlay replaces the evidence during the touch;
- the same STOP row remains spatially owned by the same action function;
- the next grammar is recoverable from the same spatial map after release.

Reusable principle:

`TOUCH MAY OCCLUDE PIXELS; IT SHOULD NOT REASSIGN OWNERSHIP.`

This extends Run 7 from closure persistence to selective action-law retirement.

## 6. Stable layout is necessary but insufficient for mode clarity

### General HCI caution

Mode-error literature and practical HCI guidance repeatedly warn that a state can remain visually present yet still be missed if the transition is too weak or if the user continues acting under the previous rule. The useful lesson here is not to add a modal overlay, but to ensure the transition that changes action-law ownership is perceptible at the relevant evidence surface.

Reference used as secondary HCI guidance:
- https://interface-design.co.uk/docs/mode-changes-are-unclear/

### Interpretation

`same layout` is valuable because it preserves motor memory, but it cannot be the only cue when the valid action law truly changes.

Therefore:

- preserve control geometry;
- make the **evidence relation** that changed rule ownership legible;
- avoid relying on a single global color wash or tiny mode label;
- do not require the player to monitor a secondary display every game to know which STOP law applies.

Reusable principle:

`PRESERVE THE MAP; MAKE OWNERSHIP CHANGE LEGIBLE AT THE SOURCE OF THE DECISION.`

## 7. One visual object may retire one rule while keeping another inference alive

Game & Reel Run 8 emphasizes `ACTION-LAW CLOSURE != INFERENCE CLOSURE`.

### Interpretation

The stopped reel surface can simultaneously carry:

- a terminal fact for one handling duty;
- an open contradiction / bonus / state inference for another question;
- the positional anchor needed for the next stop.

Therefore visual cleanup must be **selective**.

A global desaturation, wipe, reset or return-to-neutral animation could destroy still-live information even though one action law is genuinely retired.

Reusable principles:

`RETIRE THE RULE, NOT THE EVIDENCE OBJECT.`

`VISUAL CALM MUST BE LOCAL ENOUGH TO PRESERVE LIVE INFERENCE.`

`THE SAME STOPPED OBJECT CAN BE CLOSED FOR ACTION AND OPEN FOR INTERPRETATION.`

---

## 8. Repeated skill attempts need episode-local ownership

### Closed 新ハナビ anchor

Completed Case Study 02 established bounded REG technical-intervention attempts and bounded RT duties as useful reality anchors. The exact proprietary procedure is not reproduced here.

### Interpretation

A repeated skill task should not keep one continuous visual responsibility active across the whole reward state if each attempt has a discrete start and terminal result.

Each attempt should be understood as:

`OPEN LOCAL RESPONSIBILITY → ACT → TERMINAL EVIDENCE → RETIRE LOCAL LAW → RETURN TO PARENT GRAMMAR / OPEN NEXT ATTEMPT WHEN WARRANTED`

Reusable principle:

`REPEATED DUTY SHOULD REOPEN AS A NEW EPISODE, NOT LINGER AS PERMANENT VIGILANCE.`

Visual benefit: the player is allowed to stop checking the task between valid responsibility windows.

## 9. Visual/Mechanism test questions derived from Run 8

These are Stage-1 research tests, not implementation specs.

### A. Dormant-vs-Retired Evidence Test

Ask whether an observer can explain why the old rule may still return (`DORMANT`) versus why it cannot matter again in the current episode (`RETIRED`) using visible evidence rather than a mode label.

### B. Selective Cleanup Test

After one duty retires, verify that still-live inference evidence remains visually readable. Fail if the machine visually resets more of the state than logic actually closed.

### C. Next-Owner Test

Before the next consequential STOP, identify which surface owns the action decision. Fail if the player must scan multiple unrelated regions to discover who owns the next action.

### D. Occlusion Ownership Test

Briefly obscure the control plane. After release, verify that the same stopped evidence, same control identity and same action-law owner are recoverable without a global reminder.

### E. Episode Boundary Test

For repeated technical/temporary duties, verify that the visual responsibility clearly retires per attempt and reopens only when a new valid attempt/question exists.
