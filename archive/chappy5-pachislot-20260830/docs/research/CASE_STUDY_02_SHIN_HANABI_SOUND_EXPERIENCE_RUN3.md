## 0. Run purpose

Run 3 extends Sound Run 1–2 after Visual & Mechanism Run 3. It does not create Chappy5 audio concepts, assets, code or prototypes. The focus is **attention routing in a stable reel-centered machine**: when sound should remain routine, when a deviation may claim attention, when sound should stop, and how technical-intervention/state feedback avoids covering the primary reel-reading task.

Evidence labels:
- `SOURCED FACT`
- `DIRECT OBSERVATION`

## 1. Current evidence boundary

### SOURCED FACT

Official manufacturer material defines 新ハナビ as a 2021 bonus+RT machine preserving the 5th-generation HANABI game flow while adding RB technical intervention, mini-LCD `たまやチャレンジ`, reel-array changes and blackout-rule changes.

Source:
- https://www.universal-777.com/product/slot/shin_hanabi/

Major strategy documentation groups ordinary presentation around four principal families:
1. reel-start-sound delay;
2. blackout;
3. flash;
4. `たまやチャレンジ`.

The same material states that normal flash occurs with small-role payout and can be cancelled.

Source:
- https://1geki.jp/slot/s_shinhanabi/

### INTERPRETATION

The machine does not require continuous narrative audio to make ordinary play legible. Its audio grammar can remain comparatively stable because the physical reels themselves carry unresolved information.

### REUSABLE PRINCIPLE

`PRIMARY GAMEPLAY INFORMATION SHOULD NOT HAVE TO FIGHT ITS OWN SOUNDTRACK.`

If the player's main task is precise visual/reel interpretation, audio should clarify timing/state/agency rather than continuously compete for conscious attention.

## 2. Normal rhythm is an attentional contract

### SOURCED FACT

`リール始動音遅れ` is a documented normal-game presentation indicating cherry or bonus possibility.

Source:
- https://1geki.jp/slot/s_shinhanabi/

### INTERPRETATION

Run 2 established `DEVIATION SPENDS BASELINE TRUST`. Visual Run 3 adds that a stable body can redirect attention without changing hardware. Sound has the same property: the ordinary START/reel rhythm can remain habitual and low-duty until a timing displacement asks the player to reclassify the game.

A delayed start does not need to be globally louder than the baseline. Its value can come from **temporal mismatch against a learned expectation**.

### REUSABLE PRINCIPLES

- `TIMING DIFFERENCE CAN CLAIM ATTENTION WITHOUT LEVEL ESCALATION.`
- `ROUTINE AUDIO SHOULD BECOME MOTOR MEMORY; RULE-BEARING AUDIO SHOULD INTERRUPT THAT MEMORY PRECISELY.`

This is not permission to imitate the protected delayed-start sound itself.

---

## 3. Flash cancellation shows that presentation tail is optional after knowledge resolves

### SOURCED FACT

Published analysis states that the payout-linked reel flash can be cancelled.

Source:
- https://1geki.jp/slot/s_shinhanabi/

### INTERPRETATION

The player's informational task can finish before the machine's full audiovisual flourish would naturally finish. Allowing the presentation to end protects self-selected play rhythm and avoids forcing repeated attention claims after the result is already known.

This is especially relevant to a machine consumed over thousands of ordinary games.

### REUSABLE PRINCIPLES

- `PLAYER KNOWLEDGE CAN BE A VALID END CONDITION FOR PRESENTATION.`
- `TAIL LENGTH IS PART OF INPUT LATENCY EXPERIENCE, EVEN WHEN THE INPUT HAS ALREADY BEEN ACCEPTED.`

The point is not that every effect must be cancellable; it is that repeated presentation should justify continuing after informational resolution.

## 4. REG separates action acknowledgement, skill judgement and mastery acknowledgement

### SOURCED FACT

Nana-Press documents that REG offers beginner/intermediate/advanced technical-intervention procedures. During technical intervention, successful aiming produces a sound, while the mini display shows success feedback. Faster/high-level completion can earn the `神技!!` designation. Official soundtrack material separately lists an `RB ALL神技` jingle.

Sources:
- https://nana-press.com/kaiseki/machine/134/3989/
- https://www.universal-777.com/fun/music/shin_hanabi/

### INTERPRETATION

This provides a concrete example of feedback hierarchy:

`STOP accepted → aimed execution judged → per-game success acknowledged → accumulated mastery acknowledged`

These are not the same semantic event. A machine can preserve agency by keeping their feedback responsibilities distinct.

### REUSABLE PRINCIPLES

- `DO NOT USE REWARD AUDIO TO HIDE EXECUTION INFORMATION.`
- `LOCAL SKILL FEEDBACK AND SESSION MASTERY FEEDBACK SHOULD OCCUPY DIFFERENT SEMANTIC LEVELS.`
- `AGENCY FEEDBACK SHOULD BE IMMEDIATE; MASTERY FEEDBACK MAY BE SPARSE.`

A failure remains sensitive: because a miss can have economic consequence, exaggerated negative feedback risks converting useful error information into punishment.

## 5. RT music is a state surface, not only entertainment

### SOURCED FACT

花火チャレンジ is a maximum-20G RT after BB with JAC-IN avoidance; 花火GAME is a 20G RT after JAC IN. Major strategy documentation explicitly states `BGM停止でボーナス` in both phases.

Sources:
- https://1geki.jp/slot/s_shinhanabi/64/
- https://1geki.jp/slot/s_shinhanabi/65/

Official soundtrack material separately identifies music for red-7 BB, Don BB, 花火チャレンジ, 花火GAME, RB and RB mastery completion.

Source:
- https://www.universal-777.com/fun/music/shin_hanabi/

### INTERPRETATION

RT BGM therefore participates in the machine's rule surface. Continuation says "state persists"; disappearance can say "reclassify the current game". The useful event is not necessarily an added cue but the removal of an expected layer.

This aligns with Visual Run 3's principle that existing surfaces can be reallocated before new surfaces are added.

### REUSABLE PRINCIPLES

- `STATE AUDIO CAN BE A TEMPORARY ATTENTION SURFACE.`
- `WHEN CONTINUITY CARRIES MEANING, INTERRUPTION IS AN EVENT.`
- `STATE CHANGE CAN REALLOCATE EXISTING AUDIO BEFORE ADDING NEW AUDIO.`

This does not authorize copying any melody, sample, arrangement or signature interruption behavior.

## 6. Audio attention should open and close with player responsibility

### SOURCED FACT

Published 花火チャレンジ procedure changes player responsibility according to remaining games/panel instructions while retaining the same lever and three STOP buttons.

Source:
- https://1geki.jp/slot/s_shinhanabi/64/

Game & Reel Run 2 already established `REEL RESPONSIBILITY SHOULD OPEN AND CLOSE WITH INFORMATION NEED`; Visual Run 3 established `TEMPORARY TASK PRIORITY SHOULD EXPIRE CLEANLY`.

### INTERPRETATION

Sound should obey the same contract. A task cue is valuable when responsibility changes. Once that task is resolved, continuing to demand attention acoustically competes with the return to reel reading.

### REUSABLE PRINCIPLES

- `AUDIO PRIORITY SHOULD EXPIRE WHEN THE PLAYER'S RESPONSIBILITY EXPIRES.`
- `ATTENTION ROUTING IS CROSS-MODAL; VISUAL AND AUDIO SHOULD RELEASE THE PLAYER TOGETHER.`

A sparse machine can therefore feel responsive without becoming sonically empty: routine confirmation remains, but conscious-attention claims are temporary.

---

## 7. Sparse presentation does not mean weak identity

### SOURCED FACT

The official soundtrack contains distinct identities for both BB types, RB, 花火チャレンジ, 花火GAME and mastery completion, while normal play retains a comparatively limited presentation family.

Source:
- https://www.universal-777.com/fun/music/shin_hanabi/

### INTERPRETATION

The contrast is **temporal allocation**, not absence of authored sound. Strong identity can be concentrated at phase boundaries/reward states while ordinary reel work remains acoustically spacious.

This matches Visual Run 3:

`STATIC IDENTITY CONTRAST != PER-GAME ATTENTION CLAIM`

Sound equivalent:

`AUDIO IDENTITY DENSITY != PER-GAME ATTENTION DENSITY`

### REUSABLE PRINCIPLE

`A MACHINE CAN HAVE A STRONG AUDIO IDENTITY WITHOUT MAKING EVERY GAME AN AUDIO EVENT.`

## 8. Long-session fatigue model refined

### INTERPRETATION

Run 2 used:

`FATIGUING = HIGH FREQUENCY × SHARP ATTENTION CLAIM × LOW NEW INFORMATION`

Run 3 adds attention duration and release:

`ATTENTION DEBT ≈ REPETITION × CLAIM STRENGTH × CLAIM DURATION × SEMANTIC REDUNDANCY`

A high-frequency sound can remain sustainable if it is brief, expected and does not demand conscious interpretation. A rare cue can still be exhausting if it is very long or masks the reel task.

### REUSABLE PRINCIPLES

- `AUDIT ATTENTION DURATION, NOT ONLY EVENT COUNT.`
- `ROUTINE CONFIRMATION MAY BE FREQUENT IF CONSCIOUS CLAIM IS LOW.`
- `RECOVERY REQUIRES RELEASE, NOT JUST LOWER VOLUME.`

This is an analytical model, not a measured claim about 新ハナビ's proprietary mix.

- `PROTECT THE PRIMARY PRECISION TASK FROM AUDIO MASKING.`

- `STABLE BASELINE AUDIO CAN SUPPORT VARIABLE LISTENING CONTRACTS.`

## 10. Unresolved

Online evidence still cannot safely establish:
- exact BET / lever / reel / STOP / payout / replay timbre;
- exact relative SPL, EQ, transient shape or tails;
- exact start-delay duration in milliseconds;
- speaker count/routing, low-frequency driver behavior or cabinet vibration;
- whether reel mechanics are acoustically prominent to the seated player in an actual hall;
- exact flash-cancel audio behavior frame-by-frame;
- exact success/failure sound hierarchy for every REG procedure;
- whether a miss has a dedicated negative sound versus only absence/change of success feedback;
- BGM loop length, loop seam, transition/crossfade and stop latency;
- controlled three-hour auditory fatigue/habituation;
- novice recognition rates for subtle timing deviations;
- effect of neighboring machines and hall PA on cue audibility.

Compressed online video must not be used to manufacture these values.
