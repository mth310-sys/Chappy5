### 1. 有効ラインとリールは「見た目」ではなく判別器

**SOURCED FACT**
- 本機は公開されている1ライン機で、通常時は中押し赤7狙い、順押し白BAR狙い、順押し赤7狙いなど複数の打ち方で小役をフォローできる。
- 中押し赤7狙いでは、最初に中リールの停止位置から成立役候補を絞り、その後の右・左停止で小役/リーチ目等を判別していく。
- 中押しではスイカの強弱を判別可能だが、中段チェリーA/Bの判別はできなくなる。
- 順押しでは中段チェリーA/Bの判別に使える停止形が存在する一方、媒体上ではスイカA/B判別に制約があると説明されている。

**INTERPRETATION**
押し順の違いは単なる「好きな打ち方」ではない。同じ内部抽選を、どの情報から読むかという観測方法の選択になっている。中押しは第1停止で候補集合を大きく絞り、第3停止まで答えが残る形を作りやすい。一方、順押しは別の役分類情報を保持する。

**REUSABLE PRINCIPLE**
パチスロの押し方選択には、`情報を増やす代わりに別情報を捨てる` というトレードオフを持たせられる。3STOP全部へ毎回テーマ上の別役割を人工的に与えなくても、配列と判別構造があれば停止順自体がゲームになる。

### 2. 「中段チェリー」は単独機能ではなく通常時ループの中心ノード

**SOURCED FACT**
- 中段チェリー合算は設定1で約1/210.1、設定6で約1/190.5。レア役全体は設定1で約1/32.1。
- 地獄/通常滞在時の中段チェリーは設定によらず約25%で本前兆へ移行する。
- 天国滞在時の中段チェリーは本前兆移行濃厚（公開解析では100%）。
- 本前兆へ移行すると32G以内にバトルボーナスへ当選する。
- 中段チェリーが本前兆に直結しなかった場合でも、地獄→通常以上、通常→天国など状態を押し上げ得る。

**INTERPRETATION**
中段チェリーが強い理由は「1/約200の赤い出目だから」だけではない。

`通常Gを回す → 現在モードを演出から推測 → レバーONでレア役成立 → リールで中段チェリーを認識 → 今いるモードによって同じ役の価値が変わる → 直撃しなくても状態上昇の可能性 → 以後最大32Gの演出/挙動を読む → BB` 

という複数分の時間軸を一本につないでいる。

このためプレイヤーは中段チェリー停止時だけでなく、**その前に「今は天国かもしれない」と考える時間と、その後に「入ったか」を読む時間まで含めて役を遊んでいる**。

**REUSABLE PRINCIPLE**
強レア役を作るなら確率・派手さだけでは不足。`出る前の期待状態 / 停止した瞬間 / 外れた場合の残留価値 / その後の判定時間` が一続きであることが重要。

**DO NOT COPY**
「中段チェリー」「25%」「32G」をそのまま企画へ移植することは禁止。学ぶ対象は、1つの役が前後の時間を接続している構造。

### 3. 同じ成立役でも内部モードによって心理価値が変わる

**SOURCED FACT**
通常時には地獄・通常・天国・本前兆の4モードが存在する。

例：設定1
- 弱スイカ：地獄では通常以上への移行が中心、通常では約31.19%で天国へ、天国では約10.66%で本前兆。
- 強スイカ：通常では約89.84%で天国、約10.16%で本前兆。天国では約50%で本前兆。
- チャンス目：通常では約23.53%で天国、約1.47%で本前兆。天国では25%で本前兆。
- 中段チェリー：地獄/通常では本前兆25%、天国では本前兆100%。

またモード移行は昇格・転落とも第3停止ボタンを離した瞬間に行われると公開解析されている。演出はレバーON時点のモードを参照する場合があるため、「示唆を見たゲームで成立したリプレイ等により第3停止後には転落している可能性」が生じる。

**INTERPRETATION**
ここではレバーONと第3停止が内部状態上も別タイミングの責務を持つ。
- レバーON：現在状態を参照した演出/成立役の入口。
- リール停止：成立役をプレイヤーが認識する過程。
- 第3停止離し：次ゲームへ向けた状態更新ポイント。

したがって3STOPは毎回劇的でなくても、「今見ている情報がどの時点の状態を指すのか」という時間的整合性を持つ。

**REUSABLE PRINCIPLE**
内部状態を使う場合、抽選タイミングと表示タイミングを設計者自身が明確に区別しなければならない。示唆演出は単なる期待度パーセントではなく、`どの時点の内部状態を観測している情報か` を持つ。

### 4. 通常100Gは「イベント待ち」ではなく小役による状態編集の反復

**SOURCED FACT**
設定1のレア役合算は約1/32.1。単純平均では100Gに約3回程度のレア役機会がある。ただし役種と成立間隔はランダムで、毎100Gに3回保証されるわけではない。

AT初当たりは設定1で約1/383.4、設定6で約1/235.1。高設定では小役確率の一部・弱役からの本前兆・モード移行など複数箇所に設定差が配置されている。

**INTERPRETATION — 100G**
100Gの実体は、単純な「1/383を100回抽選する」ではない。
- 普通のハズレ/ベル/リプレイを高速に処理する。
- 演出から現在モードを推測する。
- 約数十G単位で現れるレア役をリールで分類する。
- 弱役なら状態が上がった可能性を読む。
- 強役/中段チェリーなら直撃と状態上昇を同時に疑う。
- 以後の演出変化を「当否」と「モード」の両方として読む。

このため「何も起きていない通常G」と「状態推測に必要な静かなG」が同一ではない。

**INTERPRETATION — 500G**
500G級ハマリでは中段チェリーやスイカを複数回引いても本前兆へ届かない局面が生じ得る。ここで中段チェリー25%という単発期待だけを商品化すると外れの累積が苦痛になる。一方、外れた役がモードを動かし、その後の演出で天国期待を追えるため、完全なゼロリセットにはしない設計になっている。

**INTERPRETATION — 3時間**
3時間では「当たり回数」だけでなく、弱役からの当選・モード上昇頻度・初当たり軽さ等を設定推測材料として蓄積できる。つまり長時間になるほど、1回の出目価値に加えて統計的な読みが増える。

**REUSABLE PRINCIPLE**
長時間台では、単発の期待だけでなく `1Gの結果が短期状態推測と長期設定推測の両方へデータを残す` と、通常時の情報寿命を延ばせる。

### 5. 設定差は「最上位報酬」より通常時の循環速度に多く置かれている

**SOURCED FACT**
- AT初当たりは設定1 1/383.4 → 設定6 1/235.1。
- 弱スイカ、強スイカA、中段チェリーA、リーチ目等に設定差がある。
- 弱スイカや角チェリーなど弱い契機からのモード移行/本前兆移行に設定差が存在する。
- AT終了後の天国選択率も高設定ほど優遇される。
- 一方、基本的な赤7/北斗揃いからのBB継続率選択には設定差を置かないと解析されている。

**INTERPRETATION**
高設定は「同じ当たりが突然ものすごく強くなる」というより、通常時に状態が上がる・弱い役が仕事をする・次の初当たりへ戻る速度が改善される側へ差が分散している。

これは3時間体験で重要。設定差を上位状態の爆発力だけへ置くと通常Gから読み取れず、長時間の観測ゲームになりにくい。

**REUSABLE PRINCIPLE**
設定差を考える場合、`当たりの量` だけでなく `通常時の因果関係がどれほど頻繁に成立するか` に配置する選択肢がある。

### 6. BBは通常時と同じ「成立役を見る」を別目的へ再利用する

**SOURCED FACT**
バトルボーナスは主に以下で構成される。
- 小役パート：30G+α、純増約4.1枚/G。
- バトルパート：8G。
- BB継続率は66% / 79% / 84% / 89%が基本。
- 小役パート中のレア役では「宿命バトル」抽選を行い、勝利でVストック獲得。
- バトルパートでは継続率による継続抽選があり、非継続時のレア役で書き換え、継続時のレア役で継続率昇格/演出書き換え等がある。

**INTERPRETATION**
通常時：レア役 = `モードを動かす / BBへ近づく`
BB中：レア役 = `Vストック / 敗北書き換え / 継続側を強化する`

同じレバーONとリール停止を使いながら、状態が変わると役の目的が変わる。これによりAT中だけ別ゲームを載せるのではなく、通常時に学んだ「レア役を見る」という認知をそのまま報酬区間へ持ち込める。

**REUSABLE PRINCIPLE**
状態遷移のたびに入力ルールを総入替えする必要はない。`同じ成立役を、状態によって違う価値へ翻訳する` 方が学習資産を再利用できる。

### 7. 上位「無想転生」は通常BBのルールを否定せず、継続率上限を拡張する

**SOURCED FACT**
無想転生チャンスは主にバトル継続後の一部から突入する15GのCZで、成功すると継続率94%の無想転生バトルへつながる。公開解析では中段チェリー等のレア役が成功抽選に強く関与する。

**INTERPRETATION**
上位状態へ入っても「セットを継続させる」というBBの基本文法そのものは残る。通常BBを無価値な前座へ置換するのではなく、既知の継続ゲームの天井を上げる構造になっている。

ただし94%という巨大差があるため、プレイヤー体験上「普通BBが上位非到達の失敗」に見える瞬間はあり得る。これはPlaytest & QA側で長尺実戦から確認が必要。

**REUSABLE PRINCIPLE**
上位状態は別ゲームを足すだけでなく、`既存の報酬ループで最も気持ちいい軸を拡張する` 方式がある。ただし通常報酬を相対的に殺すリスクを必ず別評価する。

### 8. 「第3停止まで期待が持てる」は演出文句ではなく配列と判別候補数から生じる

**SOURCED FACT**
攻略媒体自身が中押し赤7狙いを「第3停止まで期待が持てる王道の打ち方」と説明している。中リール第1停止の位置ごとに複数の成立役候補が残り、右/左停止でリプレイ・チェリー・スイカ・チャンス目・リーチ目等を判別する。

**INTERPRETATION**
重要なのは「1st=情報、2nd=期待、3rd=結果」という脚本を先に作ったことではない。配列上、最初の停止だけでは役候補が確定しないケースが存在するため、自然に第2・第3停止へ情報が残る。

**REUSABLE PRINCIPLE**
3STOPの意味は台詞や液晶で付与するのではなく、先に `停止位置ごとの候補集合` を設計して作るべき。候補集合が第1→第2→第3でどう縮むかがリールゲームの骨格になる。

### 9. 内部フラグと見た目の停止形を同一視してはいけない

**SOURCED FACT**
- 中段チェリーAは基本的に中段チェリー停止だが、左リール下段にチェリーをビタ押しすると角に停止する場合があると解析されている。
- 中押しと順押しではA/B判別や強弱判別のできる範囲が異なる。
- チャンス目とベルこぼしが同系統の停止形として扱われる箇所がある。

**INTERPRETATION**
画面上の「中段チェリー」という見た目だけを内部役名として実装すると実機構造を壊す。成立フラグと停止型の間に押し位置・停止順・制御がある。

**UNRESOLVED**
全フラグの停止制御テーブル、全押し位置に対する引込み/蹴り分け、BB中を含む制御優先順位は公開資料だけでは完全復元できていない。ここは推定しない。

### 10. Game & Reelとして今回得た最大の修正

以前のChappy5企画研究では「3つのSTOPそれぞれにテーマ上の意味を与える」方向へ寄り過ぎていた。

スマスロ北斗を実機1台として深掘ると、リールのリアリティはむしろ次の積層で生まれている。

`内部状態`
→ `レバーON時の成立役/演出`
→ `押し方を選ぶ`
→ `配列と停止位置で候補を見る`
→ `第2/第3停止で役を分類する`
→ `成立役が現在モードに応じて違う価値を持つ`
→ `第3停止後に内部状態が更新される`
→ `以後の数G〜32Gで当否/モードを読む`
→ `BBでは同じレア役が継続資源へ役割変更する`

つまり、**3STOPの面白さは3STOPの瞬間だけでは完結していない。前のゲームから内部状態を引き継ぎ、停止後の未来まで価値が残る。**

これはChappy5が最初に欠いていたRealityの一つと判断する。
