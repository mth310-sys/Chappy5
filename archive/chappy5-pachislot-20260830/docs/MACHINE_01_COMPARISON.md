## Director評価差分
Machine Director総合暫定順位: `VAULT → SIGNAL → FORGE`。
Game & Reel専門評価: `SIGNAL → VAULT → FORGE`。
Visual & Mechanism専門評価: `VAULT ≈ SIGNAL → FORGE`。
Sound & Experience専門評価: `SIGNAL → VAULT → FORGE`。
Playtest & QA机上試打評価: `SIGNAL → VAULT → FORGE`。

順位を一本化しない。Playtest & QAでは「企画書の一撃」より、最初の5分→100G→ハマり→失敗→初当たり→上位非到達→上位→終了→次BETという時間軸を優先した。その結果、SIGNALは学習コストがある代わりに通常時の微差を遊技へ変換できる可能性が最も高い。VAULTは初見理解が圧倒的だが長時間で二値化しやすい。FORGEは報酬瞬間は強いが通常時が独立して面白い証明がまだ不足。

## Playtest & QA 第1巡 — 机上試打

### SIGNAL//3
**最初の5分:** 初Gから完全には分からない。STOP1の基準、STOP2のズレ、STOP3の確定を3〜10G程度で身体的に理解できる設計が必要。ここを液晶説明で救うと企画が死ぬ。一方、一度「同じ図柄揃いではなく関係を見る」と気づくと自発的にリール窓を見る理由が生まれる。

**通常100G:** 3案中もっとも100Gをゲームにできる可能性が高い。条件は `SYNCだけが正解` にしないこと。ECHO、DRIFT、SILENT、片側共鳴、保持などが「ハズレの装飾」ではなく、次G期待・状態・報酬ルートへ異なる実利を持つ必要がある。実利がなければ20Gで模様認識作業になる。

**深いハマり:** 強演出が来ない時間でも、ズレの種類を読むこと自体が情報なら耐えられる。逆に全ての微差が結局「当たっていない」の一語へ収束すると、最も難解で疲れる台になる。

**初当たり:** `THREE-LOCK RESOLVE` は机上でも明確な再体験動機がある。重要なのは大音量ではなく、通常時に学習したズレが完全同期へ反転すること。学習した法則が報酬になる。

**CZ失敗／上位へ行けない時間:** LOCK/ECHO保持が本当のゲーム上の意味を持てば失敗後BETが自然。見せかけの持越しなら期待を煽るだけで不信につながる。上位に行けなくても通常の読みが成立することが必須。

**上位／終了:** CONTACTで「ズレを探す台」から「同期を維持する台」へ体験法則が変わるのは長時間変化として強い。終了時は一気に通常へ落とすより同期成分が崩れ、最後に一つだけ残ると次BETが自然。ただし示唆と実利を混同しない。

**30分:** 最も知的な中毒性が出る候補。**3時間:** 情報密度・高域・常時ノイズを抑えれば最も持続可能。ただし「理解する努力」を毎G要求すると逆に最も疲れる。

**致命傷条件:** ①液晶を見ないと位相が分からない、②SYNC以外の出目に実利がない、③STOP順が結果演出を進めるだけ、④音を切るとゲームが成立しない、のいずれか。

### VAULT://3
**最初の5分:** 3案中最良。リール＝タンブラー、STOP＝固定、SHEAR LINEを通すという因果が説明なしでも最も見える。1ゲーム目から「もう一本止めたい」が成立しやすい。

**通常100G:** 危険域は早い。「開いた／開かなかった」だけなら50G前後で反復作業になる。`DOUBLE CLICK / OFFSET / CROSS / ONE PIN LEFT / AUTH` が単なる期待度違いではなく、次の押し方・次G・中間状態に違う意味を持つ必要がある。

**深いハマり:** ONE PIN LEFTを頻発させると“惜しい詐欺”になる。FALSE GATEを増やすと初見の信用を消費する。長ハマり中ほど誠実な機械反応が重要で、「惜しい」を演出量で作らないこと。

**初当たり:** `FULL WITHDRAWAL` は何が起きたか最も理解しやすく、報酬感が即時。筐体全体の解錠がゲーム結果の物理化になっている。

**CZ失敗／上位へ行けない時間:** AUTHの半固定が実際に次ゲームの条件を変えるなら再BET理由は強い。単に高期待演出の見た目だけなら失敗後の落差が大きい。INNERへ行けない時間は通常解錠パターンに十分な横幅がないと苦しい。

**上位／終了:** INNERで解錠法則が反転する案は長時間変化として有効だが、初見の強みだった直感性を壊す危険もある。終了時RELOCKは次BETまでの物理的余韻として非常に自然。

**30分:** 最も触りやすく気持ちいい。**3時間:** CLICK音よりも「毎ゲームまた鍵を開ける」という心理的反復が主疲労源。解錠の途中結果にゲーム上の幅が必要。

**致命傷条件:** ①OPEN/NO OPENの二値ゲーム、②ONE PIN LEFTが頻繁な煽り、③AUTHが見せかけ保持、④INNERの複雑化で直感性を失う、のいずれか。

### FORGE//HEART
**最初の5分:** 押す＝加工する身体感覚は理解しやすい。しかしORE/HEAT/EDGE/SEAL等の関係を見て「何を作っているか」「なぜ次STOPが楽しみか」がVAULTほど一目で出ない。

**通常100G:** 最大課題。材質差・加工結果が実際の選択／期待形成へつながらなければ、静かな通常は“余白”ではなく“何も起きない工場”になる。REFORGEが単なるもう一回表示では足りない。

**深いハマり:** 熱・残響・炉光を徐々に増やして耐えさせる設計は危険。ハマりを演出蓄積で誤魔化すと、当たらないのに台だけ熱い不快感になる。通常出目単体の面白さが必要。

**初当たり:** `DEAD-AIR PRESS` は3案中もっとも一撃の身体感覚が強い。希少なら記憶点になる。だがこの瞬間の強さが通常時の弱さを隠してはいけない。

**CZ失敗／上位へ行けない時間:** REFORGEが次ゲームの加工条件へ実際に残るなら成立。上位へ行けない時間に「いつか大プレスを見る」だけが動機になると、パチスロではなく役物待ちになる。

**上位／終了:** CORE MELTの空間解放は視聴覚上強い。COOL DOWNから次BETへの余韻も作れる。ただし熱量を常に上げるだけの長時間設計は疲れる。

**30分:** 物質感と初当たりで印象を残す。**3時間:** 現状では最も不安。通常加工の結果語彙にプレイヤーが読む／待つ／次へ繋ぐ意味が増えない限り、作業化が早い。

**致命傷条件:** ①通常リールよりRAMを待つ台になる、②REFORGEに実利がない、③熱量上昇が期待度演出だけ、④Sound/Visualを外すと加工ゲームが残らない、のいずれか。

## 横断QA結論
1. **企画書として最も即効性があるのはVAULT。実遊技として最も長く伸びる可能性があるのはSIGNAL。**
2. `SIGNAL//3` は初見理解を改善しすぎて単純な線合わせへ落とさず、ECHO/DRIFT等へ実利を与えることが次巡の核心。
3. `VAULT://3` はOPEN以外の結果に実利を与え、「惜しい」を煽りではなく状態差へ変えることが必要。
4. `FORGE//HEART` は次巡で通常100Gの独立した面白さを証明できなければ、淘汰候補へ下げるべき。
5. 3案すべて、Signature Sound／大型機構／上位状態がなくても通常時のリールと3STOPだけで再BET理由が残ることをHuman Gate前に説明できなければならない。

## 次巡Machine Directorへの要求
点数合算で採択しない。次巡では3候補を維持したまま、**「外部報酬がなくても通常100Gで成立する最小反復単位」**を候補別に一文で定義する。その一文を作れない候補は、看板性やSignatureの強さに関係なく淘汰検討へ進める。
