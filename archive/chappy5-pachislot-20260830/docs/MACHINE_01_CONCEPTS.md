# Candidate A — `SIGNAL//3`
**一文フック:** 3回のSTOPで、雑音の中から「当たりの信号」を捕まえる。

世界観は未知の信号を探す巨大受信施設。NORMAL SCAN → SIGNAL TRACE → LOCK WINDOW → TRANSMISSION → CONTACT → LOST SIGNAL / RE-SCAN。Signature体験は雑音が3STOPで純音／音楽へ解像すること。

### Game & Reel骨格
レバーONでそのGの帯域が開く。リール語彙は `PULSE / WAVE / NODE / LOCK / VOID`。1stで基準波、2ndで同位相・1コマ遅れ・鏡像・断線等の位相差、3rdで `SYNC / ECHO / DRIFT / NOISE` を確定する。通常は短いSCANを基準とし、ECHO、片側共鳴、SILENT等を混在。LOCK WINDOWではECHOを次Gへ保持。TRANSMISSIONでは3STOPで音楽レイヤーを確定し、CONTACTでは通常時の“ズレ”が完全同期へ意味反転する。設定差で出目法則を壊さない。

### Visual & Mechanism骨格
上部中央の半埋込み `TUNING RING`＋左右フィン＋横長走査光を遠景シルエットとする。暗い梨地金属、スモーク樹脂、乳白導光材を分離し、液晶は奥窓、リールは厚い透明層と遮光壁の内側に独立した回転体として置く。固定 `PHASE MARK` と図柄側の太い波形端部で「つながる／一段ずれる／反転する」を読む。液晶は答えを先出ししない。1st局所光→2nd二本間導光→3rd成立関係がTUNING RINGへ到達する光路とし、リングはSYNC級以上だけ短く作動する。CONTACTでは筐体が初めて完全左右対称へ同期する。

### Sound & Experience Director深化 — 「音程が上がる台」ではなく、雑音が意味へ変わる台
**通常音場:** 常時SFノイズを鳴らさない。通常BGMは極薄、または環境的な低い機械床音だけにし、リール回転音とSTOPの物理感を前へ出す。レバーONで毎回派手なスキャン音を鳴らさず、意味ある帯域だけ短い空気の切替／狭いノイズ片を置く。

**BET / LEVER:** BETは乾いた短い接点音。レバーONは“探索開始”を示す一発の広帯域ノイズではなく、短い帯域開放音＋リール始動へ自然接続。期待Gでは同じ音量のまま残響尾だけが不自然に長い等、音量以外で違和感を作る。

**STOP1 / 2 / 3:** STOP1は基準となる短い純音成分をリール停止の機械音の奥に残す。STOP2は単純に高音化せず、同位相なら二音が一つへ寄る、ECHOなら時間差で薄く返る、DRIFTなら左右定位／残響がずれる。STOP3で初めて関係を閉じる。NOISEは派手な失敗音を鳴らさず自然に消える。これにより耳だけでも「合った／残った／ずれた」を感じるが、答えの説明はしない。

**Signature Sound — `THREE-LOCK RESOLVE`:** 強いSYNC時、STOP3直後に通常存在する床ノイズが約一瞬だけ完全に抜け、3STOPで残った三成分が一つの透明な和音へ収束。その収束点にTUNING RINGの短い機械ロック音が“第四音”ではなく物理終止として入る。その後にだけ受信音楽が開く。核は大音量ではなく **雑音→無音→完全同期** の落差。「あの無音の後の一音をもう一度聞きたい」を狙う。

**前兆 / LOCK WINDOW:** 前兆は音を足すより、通常存在した床音の一部が欠ける、左右どちらかだけ残響が返る等の“欠損”で作る。LOCK保持中は前Gで残った一成分が次BETまでごく薄く残り、BETで再捕捉する。保持を音声ナビで説明しない。

**TRANSMISSION / CONTACT:** 報酬中BGMは完成曲を一方的に流すのでなく、3STOPの結果がパーカッション／低域／旋律片などの音楽レイヤーへ反映される。ただし毎G編曲が激変して疲れないよう、変化はフレーズ境界へ量子化する思想。CONTACTでは通常の探索ノイズ語彙をほぼ捨て、完全同期した広いステレオ像と長い呼吸を持つ音楽へ移る。

**終了 / LOST SIGNAL:** 大きな終了SEで断ち切らず、同期成分が一つずつ失われ、最後に通常の機械床音へ戻る。RE-SCAN余地がある場合だけ微かな一成分を次BETまで残す。

**30分 / 3時間疲労:** 30分ではECHO・SILENT・SYNCの耳の違いを学ぶ楽しさが強い。3時間では高域電子音と常時ノイズが最大疲労源になるため、通常は低密度、Signatureは希少、無音も演出資源として使用する。毎GのスキャンSE、毎STOPの音階上昇、常時ビープは禁止方向。

**Sound判定:** 3案中もっとも“音そのものがゲーム結果”になれる。Visualの線接続とAudioの位相／残響が同じ因果を別感覚で返せるため統合力が高い。最大リスクは電子音の気持ちよさを追うほどSF UI音の寄せ集めになること。

# Candidate B — `FORGE//HEART`
**一文フック:** 3回のSTOPを3回の鍛打に変え、台そのものを鍛えて当たりを打ち出す。

世界観は巨大自動鍛造炉。IDLE FORGE → HEAT RISE → ANVIL CHANCE → FORGE RUSH → CORE MELT → COOL DOWN。核は熱・質量・反動。

### Game & Reel骨格
全リール共通語彙 `ORE / HEAT / EDGE / SEAL / CRACK / CORE`。1stで加工起点、2ndで `TEMPER / OVERHEAT / COLD / FOLD`、3rdで `MASTER / USABLE / CRACK / REFORGE`。通常は静かなGを基準とし、REFORGEを次BET理由にする。ANVIL CHANCEは加工連鎖、報酬中も出目で品質を変える。

### Visual & Mechanism骨格
低重心鋳造台＋太い支柱＋上部 `PRESS RAM`。黒皮鉄、焼け縁、耐熱ガラス、炉内だけの間接光で物質感を作る。通常はRAMを動かさず、金属図柄の輪郭関係と局所残熱で加工状態を読む。MASTER級のみRAMが短距離作動し、CORE MELTでは左右炉扉が開いて深層発光部を露出する。

### Sound & Experience Director深化 — 「毎STOPドカン」を捨て、材質と圧力で重さを作る
**通常音場:** 炉の轟音を常時鳴らさない。遠い送風／金属筐体の低い共振を極薄く置き、通常遊技はむしろ乾いている。熱量は音量ではなく低域の厚み、残響時間、金属の鳴り方で変化させる。

**BET / LEVER:** BETは厚い金属板の内側でラッチが入る短い音。レバーは工具を噛ませるような硬い接点＋リール始動。HEAT RISEでも毎G炎SEを追加せず、始動時の低域共振が少し長くなる程度から始める。

**STOP1 / 2 / 3:** 通常STOPは大打撃ではなく、回転体が治具へ収まる `tok / ting / thud` 系の材質差。加工関係が良い時だけ停止後にごく短い金属の“鳴き”が残る。2ndでFOLDなら二枚が密着する鈍い擦過、CRACK方向なら高域の細い亀裂音。3rdでUSABLEは短く締まり、REFORGEは結果音を完結させず低い残熱共振を次BETまで残す。

**Signature Sound — `DEAD-AIR PRESS`:** MASTER級でSTOP3後、通常の炉床音が急に落ち、PRESS RAMが動き出す低い油圧／機械摺動を短く聞かせる。衝突直前に音を膨らませず **一瞬止める**。その直後、単発の深い圧着音と筐体内部から返る短い金属倍音、炉光の解放と同時に報酬BGMへ入る。連打ではなく「静けさ→質量の一撃」が記憶点。

**前兆 / ANVIL CHANCE:** 前兆は炎や警報音の連発ではなく、STOP後の残響が次Gへ残る、通常は聞こえない内部ラッチが一段沈む等、圧力蓄積を耳で感じる。ANVIL CHANCEではリズムを速くするより、3STOPの金属音が同じ材質へ揃っていくことで加工精度上昇を表す。

**FORGE RUSH / CORE MELT:** FORGE RUSHは重いロック／インダストリアル方向だが、打撃音をキック代わりに毎G鳴らさない。リール結果が曲のアクセントへ入る余白を残す。CORE MELTは音量をさらに上げず、炉扉が開くことで閉鎖的な金属残響から広い内部空間の低い唸りへ“空間そのもの”を変える。

**終了 / COOL DOWN:** 高域倍音→低域共振の順に冷え、最後に乾いた機械音へ戻る。REFORGE余地がある時だけ完全に冷え切らない。

**30分 / 3時間疲労:** 30分の物質感は非常に強い。3時間では低音・打撃・炎・警報の反復が最も危険なので、大型衝突は希少、通常STOPは小さく乾いた音、無音区間を確保する。Signatureを希少化できれば疲労は大幅に改善するが、通常出目そのものが弱い問題をSoundで隠してはならない。

**Sound判定:** REALITY/PRESENCEの補強力は最強。ただし音が良いほど“工場アトラクション”として成立してしまい、リールゲームの弱さを覆い隠す危険がある。Soundは救済ではなく、通常出目が成立した後にのみ強みとなる。

# Candidate C — `VAULT://3`
**一文フック:** 3つのリールを3つのタンブラーとして止め、毎ゲーム金庫を開ける。

世界観は巨大自律金庫。LOCKED FLOOR → CLICK TRACE → AUTH WINDOW → OPEN VAULT → INNER VAULT → RELOCK。台そのものが金庫に見えることがREALITYの核。

### Game & Reel骨格
主図柄 `PIN / KEY / BOLT / SEAL / BAR` に大きな `GATE CUT` を持たせる。1stで基準角、2ndで `DOUBLE CLICK / OFFSET / CROSS / DEAD`、3rdで `OPEN LINE / FALSE GATE / ONE PIN LEFT / RELOCK`。AUTH WINDOWでは一部タンブラー半固定。報酬中も切欠き法則を残し、INNERで解錠法則を反転候補とする。

### Visual & Mechanism骨格
厚い円形 `LOCK RING`＋左右水平 `BOLT` が遠景シルエット。一本の横長深窓に三つの回転体と固定 `SHEAR LINE` を置き、太いGATE CUTが横の解錠路を作るかを一瞥する。通常CLICKではリングが数度だけ回り、OPEN級でのみBOLTが後退。AUTHは小型ラッチで保持、INNERでは内輪逆回転／せり出しで法則差を物理化する。

### Sound & Experience Director深化 — 「クリックが三段階で大きくなる台」ではなく、内部機構の位置を耳で感じる台
**通常音場:** 金庫内の低い閉鎖空間を感じるが、常時ゴウンという低音を敷かない。リール回転音は比較的乾き、筐体内部の機械音だけ短い奥行き残響を持つ。音源の“手前／内部／左右側面”を分け、機械がどこで動いたかを感じさせる。

**BET / LEVER:** BETは小さな認証ラッチ音。レバーONは解錠レバーが内部カムへ噛む硬い一音からリール始動へ。期待Gでも音量を上げず、内部で一つ余計なラッチが返る等の差に留める。

**STOP1 / 2 / 3:** STOP1は停止したタンブラー位置で小さな金属ピンが落ちる。STOP2でGATEが接続する場合は、二つ目のピン音に続き中央内部から短い“受け”が返る。接続しない場合は乾いて終わる。STOP3のOPEN LINEでは三つ目のピン音の後、SHEAR LINEを横切るように左右へ小さなラッチ解放が連鎖する。単純な音程上昇は禁止。

**FALSE GATE / ONE PIN LEFT:** FALSE GATEは一度だけ本物に近い内部ラッチが入るが、100〜300ms程度の間の後に奥で鈍く戻る。ONE PIN LEFTは最後のBOLT直前で片側だけ機械音が止まり、視覚の“あと数cm”と一致させる。失敗SEを被せず、機械がどこで止まったかを音で示す。

**Signature Sound — `FULL WITHDRAWAL`:** OPEN級で3STOP後に三連ピン→左右へ走るラッチ解放→短い静止。そこからLOCK RINGの重い歯送りが一度だけ入り、最後に左右BOLTが **別々の位置からほぼ同時に後退する二重の金属音**。その直後、閉鎖的だった音場が一気に開き、内部空間の空気と報酬BGMが前へ出る。Signatureは“派手な解錠ジングル”ではなく、密閉されていた機械が本当に開いた聴覚的解放。

**AUTH WINDOW:** 半固定されたリールに対応するラッチは次BETまで極小の保持共振を残すのではなく、BET時に“まだ掛かっている”短い再確認音を返す。常時鳴らして疲労させない。

**OPEN VAULT / INNER VAULT:** OPEN VAULTのBGMは閉鎖的な短い残響から、広く乾いた高解像度の音場へ変える。INNERでは単純にBGMを豪華にせず、通常は左→右へ解錠した機械音の方向が内輪逆回転に合わせて逆転／内向きへ収束するなど、物理法則変更をAudioにも反映する。

**終了 / RELOCK:** 終了は警報で追い出さず、BOLTが左右から戻り、リングが一段ずつ噛み、最後のラッチで音場が再び閉じる。引き戻し余地がある場合は最後の一枚だけ完全に噛み切らない音を残せる。

**30分 / 3時間疲労:** 30分では材質差と左右位置で機構を覚える入口が非常に速い。3時間ではCLICKの反復が最大リスク。通常ピン音は短く小さく、意味ある接続時だけ内部応答を足し、BOLT音はOPEN級へ限定する。失敗ごとにブザーを鳴らさない。音の種類を増やしすぎると金庫ASMRになりゲーム情報が薄まるため、機構因果に必要な音だけ残す。

**Sound判定:** 初見理解と物理的解放感は最強。SIGNALほど音がゲーム法則そのものではないが、視覚のGATE/SHEAR LINEと左右ラッチ音を一致させれば3STOPの因果が極めて身体的になる。最大リスクはCLICKの気持ちよさだけで通常時を埋め、単調化を隠すこと。

# Sound & Experience Director 第1巡 統合所見
3案ともSoundを後付けせず、Game Event → Reel → Visual/Mechanism → Audioの同一因果へ接続できる。ただしSoundで企画の弱点を覆い隠さないことを共通条件とする。

- `SIGNAL//3`: **Sound統合力は首位。** 位相・残響・無音がゲーム結果と同義になり、`THREE-LOCK RESOLVE` の「雑音→無音→完全同期」は1号機固有のSignature候補になり得る。
- `VAULT://3`: **物理解放の聴覚理解は最速。** `FULL WITHDRAWAL` は三連ピン→ラッチ→リング→左右BOLT→音場開放まで機械の因果をそのまま報酬へできる。通常CLICK反復の単調化が課題。
- `FORGE//HEART`: **質量感は最強。** `DEAD-AIR PRESS` は希少なら強烈。ただしSoundが通常リールの弱さを救ってしまう構造なら不採択方向。

Sound & Experience専門評価は `SIGNAL → VAULT → FORGE`。採択はしない。3時間疲労の観点では、3案とも「強い音を増やす」より、通常時の静けさと希少な解放の落差を価値にする方向を確定する。
