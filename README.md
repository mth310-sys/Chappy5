# Chappy5 — パチスロホール経営ゲーム

## このリポジトリについて

Chappy5は、地元の小さなパチスロホールを立て直していく経営シミュレーションゲームの開発リポジトリです。

現在の重点作業は、ゲーム内の架空パチスロ機を現実的な性能値で設計できるようにするための **実機性能「物差し」データベース** の構築です。

## 現在の実機DBミッション

対象は **5号機初期から2026年現行機まで**。

代表機だけではなく、確認可能な範囲で **可能な限り全機種** を対象とします。

目的は実機を完全再現することではありません。

実機群から必要な性能値を集め、最終的に

> 「この世代・この系統の台なら、このくらいの性能が現実的」

と判断できる数値の物差しを作ることが目的です。

### 基本的に集める性能値

- 機種名
- メーカー
- 導入時期
- 世代 / 規格
- ゲーム性分類
- 設定別機械割 / 出玉率
- 主要初当たり確率
- 50枚あたりゲーム数 / ベース
- 純増（該当機）
- 基本獲得枚数 / 基本獲得性能
- 方式別に物差し作成へ必要な最低限の追加値

ノーマル、ART/AT、CZ主体、スマスロ上位AT、技術介入機などの詳細な取得ルールは必ずミッション文書を参照してください。

## 今は集めないもの

現在の実機性能DBでは、アウト、台売上、台粗利、コイン単価、中古価格、稼働貢献、客層、客AI評価、ホール経営評価などを必須収集しません。

また、小役確率全部、モード移行率全部、演出期待度、細かな上乗せ振り分けなど、実機完全再現のためだけの詳細解析も原則対象外です。

## データ品質

- 不明値を推測で埋めない
- 出典URLと取得日を残す
- メーカー公式・公的/業界一次資料を優先する
- 信頼できる攻略/解析資料を利用する
- 情報源間で違う数値は平均せず `CONFLICT` とする
- 単位と数値の定義を必ず確認する
- 異なる定義の数値を同じ物差しに混ぜない
- 同名シリーズや別スペックを混同しない

## 物差しの完成形

十分な実機サンプルが集まった系統について、サンプル数、最小値、最大値、中央値、必要に応じ平均値、代表レンジを算出します。

将来、架空機を設計するときに

> 「○号機の○○系統で、少し当たりが軽め」

のような指定から、現実の実機群を根拠とした性能レンジを提示できる状態を目指します。
