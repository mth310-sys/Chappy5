# Chappy5 — パチスロホール経営ゲーム

## このリポジトリについて

Chappy5は、地元の小さなパチスロホールを立て直していく経営シミュレーションゲームの開発リポジトリです。

現在の重点作業は、ゲーム内の架空パチスロ機を現実的な性能値で設計できるようにするための **実機性能「物差し」データベース** の構築です。

## 作業者への最重要ルール

**作業を開始する前に、必ず最新mainのREADMEを全文読み、正本文書と最新INDEX/進捗を確認してください。**

過去のチャット、古いローカル情報、以前の担当範囲を正本にしません。GitHubの最新mainを正とします。

実機DB作業の正本:
- `docs/CHAPPY5_REAL_MACHINE_DATABASE_MISSION_V01.md`

ゲーム設計の正本:
- `docs/HALL_MANAGEMENT_GAME_DESIGN.md`

基準データ:
- `docs/HALL_MANAGEMENT_BASELINE_DATA.md`

## 現在の実機DBミッション

対象は **5号機初期から2026年現行機まで**。

代表機だけではなく、確認可能な範囲で **可能な限り全機種** を対象とします。

目的は実機を完全再現することではありません。実機群から必要な性能値を集め、最終的に **「この世代・この系統の台なら、このくらいの性能が現実的」** と判断できる数値の物差しを作ります。

### 基本的に集める性能値
- 機種名
- メーカー
- 導入時期
- 世代 / 規格
- ゲーム性分類
- 設定別機械割 / 出玉率
- 主要初当たり確率
- 50枚あたりゲーム数 / ベース
- 純増（該当機）
- 基本獲得枚数 / 基本獲得性能
- 方式別に物差し作成へ必要な最低限の追加値

方式別の詳細な取得ルールは必ずミッション文書を参照してください。

## 今は集めないもの

アウト、台売上、台粗利、コイン単価、中古価格、稼働貢献、客層、客AI評価、ホール経営評価などは現在の必須収集対象外です。

小役確率全部、モード移行率全部、演出期待度、細かな上乗せ振り分けなど、実機完全再現のためだけの詳細解析も原則対象外です。

## データ品質

- 不明値を推測で埋めない
- 出典URLと取得日を残す
- メーカー公式・公的/業界一次資料を優先する
- 信頼できる攻略/解析資料を利用する
- 情報源間で違う数値は平均せず `CONFLICT` とする
- 単位と数値の定義を必ず確認する
- 異なる定義の数値を同じ物差しに混ぜない
- 同名シリーズや別スペックを混同しない

## 作業方式 — リレー方式

作業者ごとに年代を固定分担しません。**全作業者が同じ一本の収集作業を順番に引き継ぎます。**

毎回必ず次の順で進めます。

1. 最新mainを取得する
2. READMEを全文読む
3. 最新ミッション文書を読む
4. `docs/real_machine_db/INDEX.md` と既存機種データを確認する
5. 直前の作業者が完了した地点を特定する
6. **その次の未処理機種から**収集を再開する
7. 調査結果・出典・進捗をGitHubへ保存する
8. 次の作業者が迷わず再開できる状態で終了する

### 重要

- 前の作業者が保存した最新mainを必ず引き継ぐ
- 自分の固定担当年代を持たない
- 既収集機種を最初からやり直さない
- 未処理機種を飛ばさない
- 並列で別年代へ勝手に分岐しない
- 進捗地点をINDEX等に明示する
- 境界が不明な場合は最新データを確認して重複より漏れ防止を優先する
- 定期的に重複・出典・CONFLICT・欠損を確認する

収集順は原則として **5号機初期 → 時系列に前進 → 2026年現行** とし、全体を一本のキューとして扱います。

## 物差しの集計

十分な実機サンプルが集まった系統について、サンプル数、最小値、最大値、中央値、必要に応じ平均値、代表レンジを算出します。

集計のために収集作業そのものを止める必要はありません。QA/集計は最新データに対して適宜行い、異なる定義の値を同じ物差しに混ぜません。
